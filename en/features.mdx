## Overview

Talkturo provides enterprise-grade tools to deploy AI voice agents for real phone calls. You manage CRM integrations, launch outbound campaigns, configure intelligent assistants, and analyze interactions through transcripts and recordings. Key features include customizable AI assistants with prompt templates and functions, campaign scheduling, contact management, and comprehensive analytics.

## AI Assistants

Configure AI assistants to handle inbound and outbound calls. Customize voices, prompts, and integrate functions for dynamic interactions.

<Tabs>
  <Tab title="Voice Configuration" icon="mic">
    Select from natural-sounding voices and adjust parameters like speed and tone.
  </Tab>
  <Tab title="Prompt Templates" icon="file-text">
    Use templates to define conversation flows. Example template:
    
````json
{
  "system_prompt": "You are a helpful sales assistant for Talkturo. Greet callers warmly and qualify leads.",
  "user_prompt": "{caller_name}, how can I assist you today?"
}
````
  </Tab>
</Tabs>

<Steps>
  <Step title="Create Assistant" icon="plus">
    Navigate to the Assistants dashboard and click "New Assistant".
  </Step>
  <Step title="Configure Prompts" icon="edit-3">
    Enter your system and user prompts. Test with sample inputs.
  </Step>
  <Step title="Add Functions" icon="code">
    Define custom functions for CRM lookups or scheduling.
    
````javascript
const functions = [
  {
    name: "lookup_contact",
    description: "Look up contact by phone number",
    parameters: { phone: "string" }
  }
];
````
  </Step>
  <Step title="Deploy" icon="rocket">
    Assign a phone number and publish your assistant.
  </Step>
</Steps>

## CRM Integration

Handle contacts and companies effortlessly.

<ParamField path="phone" param-type="string" required="true">
  Contact phone number in E.164 format, e.g., `+15551234567`.
</ParamField>

<ParamField body="company_id" param-type="string" required="false">
  Associate contact with a company for better tracking.
</ParamField>

Example API call to add a contact:

<CodeGroup tabs="cURL,JavaScript">
```bash
curl -X POST https://api.talkturo.ai/v1/contacts \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "phone": "+15551234567",
    "name": "Jane Doe",
    "company_id": "comp_123"
  }'
```

```javascript
const response = await fetch('https://api.talkturo.ai/v1/contacts', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    phone: '+15551234567',
    name: 'Jane Doe',
    company_id: 'comp_123'
  })
});
```
</CodeGroup>
