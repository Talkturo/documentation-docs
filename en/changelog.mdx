## Recent Updates

Stay informed about the latest enhancements to Talkturo's enterprise voice AI platform. Review release notes below, ordered newest first.

<Update label="2026-08-15" description="v2.6.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - **Switzerland available for phone number purchase** — Switzerland is now available for buying phone numbers. Regulatory verification is required, and number search automatically shows only countries the selected carrier serves. See [Telephony](/en/telephony).
  - **Canton and state dropdowns in verification address** — Swiss cantons (26) and German federal states are now selectable from a dropdown instead of free-text entry, preventing rejections caused by misspelling. See [Telephony](/en/telephony).
  - **Email-domain enforcement for verification** — The authorized representative's email must match your business website's domain. Submissions with mismatched domains are blocked before they reach the carrier, preventing a common cause of regulatory rejection. See [Telephony](/en/telephony).
  - **Admin impersonation return banner** — Admins impersonating a user now see a banner with a one-click "Switch back" button to return to their admin account without signing in again.

  ## Improvements

  - **Verification limited to supported carriers** — Only carriers that can complete the verification process end-to-end are offered for regulatory verification, preventing you from selecting a carrier that can't process your filing. See [Telephony](/en/telephony).
  - **Gmail integration: send-only OAuth scope** — Reduced Google OAuth permissions from full mailbox access to send-only, minimizing data access for compliance. See [Integrations](/en/integrations).

  ## Bug Fixes

  - **SIP trunk connectivity** — Fixed a critical issue where calls failed because the SIP endpoint pointed to the wrong server. Stale trunk URIs that were routing calls to a dead endpoint have been removed. See [Telephony](/en/telephony).
  - **Post-approval number purchase** — Fixed a bug where the first phone number purchase after a compliance approval failed because the address reference wasn't saved during submission. See [Telephony](/en/telephony).
</Update>

<Update label="2026-08-14" description="v2.5.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - **Per-document carrier rejection detail** — When a carrier rejects a verification document, you now see exactly which document was refused and the carrier's reason, and can replace just that document instead of resubmitting the entire filing. See [Telephony](/en/telephony).
  - **Carrier requirements comparison** — Before choosing a carrier for regulatory verification, see a side-by-side summary of what each carrier requires — number of items and documents — so you can pick the simpler option upfront. See [Telephony](/en/telephony).
  - **Address-based city for verification** — The verification city is now derived from the address you enter instead of a dropdown, preventing silent mismatches and supporting businesses registered in any city. An "Add another location" button lets businesses with multiple offices file separate verifications. See [Telephony](/en/telephony).
  - **"Check with carrier" button** — Manually trigger a live carrier status check for pending verifications instead of waiting for the next automatic sync. See [Telephony](/en/telephony).

  ## Improvements

  - **Full filing details in admin review** — Admin reviewers now see all submitted form fields — business name, registration number, representative details, address, and comments — alongside uploaded documents. A warning highlights when the representative's email domain doesn't match the business domain, a common cause of regulatory rejections. See [Telephony](/en/telephony).
  - **TTS voice catalogue sync** — Fixed a silent sync failure that left the voice library stale. Voice providers now sync one at a time with live progress indicators, and existing voices are protected from accidental deletion during sync. See [Voice Library](/en/voice-library).
  - **Billing webhook reliability** — Billing webhooks now have an extended runtime budget and bounded external API calls, reducing the chance of missed billing events during high-traffic periods. See [Billing](/en/billing).

  ## Bug Fixes

  - **Call pricing for LLM and TTS** — Fixed a bug where LLM and TTS call costs were silently billed as zero due to missing cost catalogue entries. Calls now correctly include LLM, TTS, and STT costs. See [Billing](/en/billing).
  - **Recheck button while blocked** — The "Check with carrier" button is now available even when a filing is blocked waiting for a carrier response, exactly when it's most useful.
  - **Admin impersonation logout** — Fixed an intermittent issue where admin account switching would log you out instead of switching accounts.
  - **Review dialog scroll** — The admin verification review dialog now scrolls when content exceeds the viewport, keeping action buttons reachable.
</Update>

<Update label="2026-08-13" description="v2.4.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - **Compliance verification page** — Upload business documents for regulatory verification directly in your workspace. Required for purchasing phone numbers in regulated markets like Germany, with per-city approval for specific dialing areas. See [Telephony](/en/telephony).
  - **Phone number release** — Release phone numbers you no longer need without waiting for a suspension period to expire. See [Telephony](/en/telephony).
  - **Credit dunning reminders** — Receive email reminders before suspended phone numbers are released to the carrier, with a 7-day grace period to top up and restore service. See [Billing](/en/billing).

  ## Improvements

  - **Per-carrier phone number pricing** — Phone number costs now reflect real carrier rates instead of a flat monthly fee, so pricing matches actual provider costs per number type and country. See [Telephony](/en/telephony).

  ## Bug Fixes

  - **Call routing restored after credit top-up** — When you top up credits after a suspension, call routing is now restored automatically — previously numbers reactivated but continued refusing incoming calls. See [Billing](/en/billing).
  - **Call cost estimate crash** — Fixed a crash when calculating call cost estimates for certain rate configurations.
</Update>

<Update label="2026-08-12" description="v2.3.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - **Credits and profile menu on mobile** — Your credit balance and profile menu are now accessible from the mobile top bar, so you can check credits and manage your account without switching to desktop. See [Billing](/en/billing).
  - **Telnyx city-level verification enforcement** — Telnyx phone number purchases now enforce city-level regulatory verification, matching the protection Twilio already provides. This prevents buying numbers in cities you aren't verified for. See [Telephony](/en/telephony).

  ## Improvements

  - **Compliance city selector redesigned** — When requesting regulatory verification, you must now explicitly select or enter your city. A new note explains that approval covers only that city — not the entire country. See [Telephony](/en/telephony).
  - **Admin account search improved** — Admin account search now matches name, email, and workspace slug, case-insensitively, making it faster to locate the right account.
  - **Expired Telnyx verifications detected** — Expired carrier approvals for Telnyx are now automatically detected and re-evaluated, keeping the purchase gate accurate over time. See [Telephony](/en/telephony).

  ## Bug Fixes

  - **Mobile menu scrolling** — The mobile hamburger menu now scrolls on small screens, so all navigation items — including sign-out — are always reachable.
  - **Twilio compliance approval webhook** — Real-time approval notifications from Twilio are now processed correctly instead of being silently skipped, so approvals reflect immediately.
  - **Verification review dialog layout** — Fixed a layout issue where long field names caused the admin verification review dialog to clip labels and buttons.
  - **Regulatory bundle renewal logging** — Fixed a logging error in the nightly regulatory bundle renewal job that made it impossible to distinguish successful renewals from carrier outages.
</Update>

<Update label="2026-08-11" description="v2.2.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - **Transcription Settings panel** — Configure how your AI assistant processes caller speech directly in the assistant editor. Add up to 100 custom keyterms (names, product names, spellings), enable smart formatting, profanity filtering, sensitive-data redaction, GDPR training opt-out, speaker diarization, and provider-specific options for Deepgram and AssemblyAI. See [Features](/en/features).
  - **German localization for transcription settings** — All transcription setting labels, help texts, and descriptions are now fully translated into German.
  - **Dual-carrier phone number purchasing** — Workspaces can now buy and use phone numbers from two Talkturo carriers at the same time, plus their own connected Twilio account. See [Quickstart](/en/quickstart).

  ## Improvements

  - **Workflow publish validation** — Publishing a workflow now checks for missing required fields before saving, with clear error messages instead of silent failures during live calls. See [Integrations](/en/integrations).
  - **Admin verification list shows city** — The admin Verifications page now displays the city alongside the country, making it easier to match submitted documents to the correct dialing area.

  ## Bug Fixes

  - **Outbound answering-machine detection** — Fixed an issue where detection ran on ringback audio instead of the actual answered call, causing incorrect voicemail vs. live-answer classification on all outbound calls. See [Call Quality Troubleshooting](/en/help-center/troubleshooting/call-quality).
  - **Workflow tool definitions now match the editor** — The tool name and parameters the voice agent registers now exactly match what you see in the editor, so prompt-authored tool calls work reliably. See [Integrations](/en/integrations).
  - **Failed workflow triggers now visible** — Rejected workflow triggers now create a failed run record with the reason, so they appear in the Runs view instead of silently disappearing.
  - **Transcription settings preserved across actions** — Settings are no longer lost when switching models within the same provider, when using the default provider, or when cloning an assistant.
  - **City-level verification enforcement** — Phone number purchases in compliance-gated countries now enforce city-level verification with a clear error message, preventing silent purchase failures.
  - **Expired carrier verifications detected** — Expired carrier approvals are now detected and re-evaluated automatically, preventing silent purchase rejections.
  - **Workflow function cards show current name** — Function cards in the assistant editor now display the current workflow name instead of a stale snapshot from when it was first attached.
</Update>

## Migration Guide

For upgrades involving breaking changes, follow these steps to update your Talkturo integration seamlessly.

<Steps>
  <Step title="Update SDK Version" icon="package" title-type="p">
    Install the latest SDK across platforms.

    <CodeGroup show-lines="true">
      ```bash
      npm install @talkturo/sdk@2.1.0
      ```

      ```bash
      yarn add @talkturo/sdk@2.1.0
      ```

      ```bash
      pip install talkturo-sdk==2.1.0
      ```
    </CodeGroup>
  </Step>

  <Step title="Replace API Keys with JWT" icon="key" title-type="p">
    Generate JWT tokens via the new auth endpoint.

    ```bash
    curl -X POST https://api.example.com/v2/auth/token \
      -H "Content-Type: application/json" \
      -d '{"client_id": "YOUR_CLIENT_ID", "client_secret": "YOUR_CLIENT_SECRET"}'
    ```

    Update your requests:

    <ParamField header="Authorization" param-type="string" required="true" deprecated="false" show-location="true">
      Bearer `{YOUR_JWT_TOKEN}`
    </ParamField>
  </Step>

  <Step title="Test Updated Endpoints" icon="play" title-type="p">
    Verify voice configurations with the new paths.

    <Callout kind="tip" collapsed="false">
      Run end-to-end tests on staging before production deployment.
    </Callout>
  </Step>
</Steps>
