## Recent Updates

Stay informed about the latest enhancements to Talkturo's enterprise voice AI platform. Review release notes below, ordered newest first.

<Update label="2026-09-04" description="v3.3.0" tags={["feature","improvement"]}>
  ## New Features

  - **Payment Methods tab** — Manage saved cards directly from the billing page. Add cards through Stripe, view all saved cards, set a default card, and remove cards when no longer needed. The last card can't be removed while auto-reload or an active Desktop App subscription depends on it. See [Billing](/en/billing).

  ## Improvements

  - **Automatic card on file for Desktop App subscriptions** — When a subscription is created through the Desktop App, the card used is automatically saved to your workspace. See [Billing](/en/billing).
  - **Stripe card sync** — If a card is removed directly in Stripe, it's automatically removed from your saved cards list in Talkturo, keeping both sides consistent. See [Billing](/en/billing).
</Update>

<Update label="2026-09-03" description="v3.2.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - **AI Employee — self-service voice agent creation** — Visitors can generate a draft voice agent from a website URL or business description, test it with a free browser-based demo call, upload supporting documents, choose a use case, and purchase through a shared payment link. After purchase, the draft agent and its documents are claimed into the buyer's workspace, with documents imported into the Knowledge Base. See [AI Voice Agents](/en/assistants/overview).

  ## Improvements

  - **Admin-managed use cases** — Admins can create and manage AI Employee use cases with localized labels, editable core prompts, activation toggles, and custom ordering.
  - **Dedicated AI Employee payment links** — Admins can now create payment links specifically for AI Employee purchases, distinct from standard agent payment links. See [Billing](/en/billing).
  - **Richer draft prompts** — AI Employee draft agents now generate richer, website-grounded prompts with use-case-specific guidance.
  - **Inlined document content in demo calls** — Uploaded TXT and Markdown files are added directly to the draft agent's prompt so demo calls can reference that business information immediately. PDFs and Word documents are processed into the Knowledge Base after purchase. See [Knowledge Base](/en/knowledge-base).
  - **Uncached payment link pages** — Payment link pages now always load live data, ensuring current pricing and draft state without stale cached content.

  ## Bug Fixes

  - **Irrelevant setup-fee note on zero-fee links** — The payment success page no longer shows a setup-fee explanation when the link charges no setup fee.
</Update>

<Update label="2026-09-02" description="v3.1.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - **Call success scoring** — Define what makes a successful call for each assistant using AI-generated criteria. Every call is scored 1–10 against your definition, with success rates displayed on the dashboard. EU scoring rules are opt-in and off by default. See [Intelligence](/en/intelligence).
  - **Close.com CRM integration** — Connect your Close.com account using an API key, with tools available for assistants and workflows. Connections are labeled with your account name for easy identification. See [Integrations](/en/integrations).
  - **Phone numbers for Finland, Netherlands, Estonia, and the UK** — Purchase local mobile numbers in four new countries with full compliance support, including Finland's simplified address-only verification. See [Telephony](/en/telephony).
  - **Per-day campaign scheduling** — Choose which days of the week your campaign runs, set per-day time slots, add an end date, and track voicemail statistics — all from the campaign editor. See [Campaign Configuration](/en/campaigns/configuration).
  - **Telephony usage in billing charts** — The billing usage chart now includes telephony and realtime credits alongside existing metrics. See [Billing](/en/billing).
  - **Copyable group IDs** — Each contact group now displays a copyable ID in the groups list, making it easier to reference groups in API calls. See [Campaigns](/en/campaigns/overview).

  ## Improvements

  - **More callable countries** — Finland, Netherlands, Estonia, Poland, and the UK are now available in test-call, transfer, and callback dropdowns. See [Telephony](/en/telephony).
  - **Country-specific compliance requirements** — Verification requirements now match what each country's carrier actually asks for: name-only for the Netherlands, proof-of-address document for the UK. See [Telephony](/en/telephony).

  ## Bug Fixes

  - **Dashboard trend charts missing today's calls** — Day buckets were seeded in the wrong timezone, causing today's calls to not appear in trend charts until the next day. See [Intelligence](/en/intelligence).
  - **OAuth connections blocked by browser isolation** — Integration connections now complete reliably even when browser cross-origin isolation blocks the popup handshake. See [Integrations](/en/integrations).
  - **Verification blocked when no documents required** — Submissions were incorrectly rejected when a country's regulation requires no uploaded documents. See [Telephony](/en/telephony).
  - **German phone number purchase address errors** — The bundle's own address is now kept and revalidated in place instead of being swapped during purchase, preventing failed purchases. See [Telephony](/en/telephony).
</Update>

<Update label="2026-08-30" description="v3.0.0" tags={["feature","improvement","bugfix"]}>
  ## New Features

  - **Saved cards from agent payment links** — When someone buys through an agent payment link, their card can now be saved as the default payment method for the workspace. Auto-reload and future charges use this card automatically. See [Billing](/en/billing).
  - **Up to 20 concurrent campaign calls** — Campaigns now support up to 20 simultaneous calls (up from 10). Adjust the concurrency limit from the campaign detail modal while a campaign is paused. See [Campaigns](/en/campaigns/overview).
  - **Cal.com integration on Talkturo infrastructure** — The Cal.com scheduling integration now runs on Talkturo-hosted servers. Existing connections may need a one-time reauthorization. See [Integrations](/en/integrations).

  ## Improvements

  - **Origin-aware call pricing** — Call costs now factor in both the origin and destination country, with route-type classification (mobile, landline, special, other). Billing estimates and call logs reflect this more accurate breakdown. See [Billing](/en/billing).
  - **Server-side contact pagination** — Contact lists now paginate beyond the first 100 records, with page controls and a total count. See [Contacts](/en/crm/contacts).
  - **Campaign outcomes sync to CRM** — Completed campaign calls automatically update CRM contact state — contacts move from "new" to "contacted" and last-contacted timestamps are refreshed. See [Contacts](/en/crm/contacts).
  - **More accurate cost estimates** — Assistant billing estimates now use the assistant's own phone number as the pricing origin for more precise cost projections. See [Billing](/en/billing).
  - **Automatic SIP trunk reconciliation** — When phone numbers move between assistants, SIP trunks are automatically cleaned up and recreated to match the new assignment. See [Telephony](/en/telephony).

  ## Bug Fixes

  - **Payment methods table restored in production** — Fixed a production issue where the saved-card system was missing, causing auto-reload to report "No saved card on file." See [Billing](/en/billing).
  - **Phantom credit prevention** — Unknown Stripe products no longer create credits through a fallback conversion, preventing phantom credit grants. See [Billing](/en/billing).
  - **Telephony settings save across carriers** — Workspaces can now save telephony settings without being rejected for lacking a carrier connection. See [Telephony](/en/telephony).
  - **Voicemail changes enable Save** — Edits to voicemail detection, action, and message are now recognized as unsaved changes, so the Save button activates correctly. See [Telephony](/en/telephony).
</Update>

## Migration Guide

For upgrades involving breaking changes, follow these steps to update your Talkturo integration seamlessly.

<Steps>
  <Step title="Update SDK Version" icon="package" title-type="p">
    Install the latest SDK across platforms.

    <CodeGroup show-lines="true">
      ```bash
      npm install @talkturo/sdk@2.1.0
      ```

      ```bash
      yarn add @talkturo/sdk@2.1.0
      ```

      ```bash
      pip install talkturo-sdk==2.1.0
      ```
    </CodeGroup>
  </Step>

  <Step title="Replace API Keys with JWT" icon="key" title-type="p">
    Generate JWT tokens via the new auth endpoint.

    ```bash
    curl -X POST https://api.example.com/v2/auth/token \
      -H "Content-Type: application/json" \
      -d '{"client_id": "YOUR_CLIENT_ID", "client_secret": "YOUR_CLIENT_SECRET"}'
    ```

    Update your requests:

    <ParamField header="Authorization" param-type="string" required="true" deprecated="false" show-location="true">
      Bearer `{YOUR_JWT_TOKEN}`
    </ParamField>
  </Step>

  <Step title="Test Updated Endpoints" icon="play" title-type="p">
    Verify voice configurations with the new paths.

    <Callout kind="tip" collapsed="false">
      Run end-to-end tests on staging before production deployment.
    </Callout>
  </Step>
</Steps>
