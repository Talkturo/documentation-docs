---
title: Launching a Voice Agent Campaign
description: Deploy a new AI voice agent for outbound calls.
---

## Overview

Enterprise AI voice agents can be deployed in minutes.

## Steps

<Steps>
  <Step title="Access Dashboard">
    Log in at https://dashboard.talkturo.com
  </Step>
  <Step title="Create Agent">
    Click "Add Agent", select a template or start custom.
  </Step>
  <Step title="Configure Settings">
    - Enter campaign name
    - Set default script
    - Upload contact list (CSV)
  </Step>
  <Step title="Deploy">
    Click "Start Campaign" and monitor results in real time.
  </Step>
</Steps>
