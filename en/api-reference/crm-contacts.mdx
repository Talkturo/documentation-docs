## CRM contacts endpoints

Use CRM contact endpoints to manage contact records, filter contact lists, and import contacts in bulk.

<Callout kind="info">

CRM contact endpoints accept dual authentication through `withApiAuth`. Send either an API key in the `Authorization` header or a signed-in session cookie. API keys need `contacts:read` scope for `GET` endpoints and `contacts:write` scope for `POST`, `PUT`, and `DELETE` endpoints.

</Callout>

### Endpoint summary

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | List contacts with pagination and filters |
| `POST` | `/api/crm/contacts` | Create a contact |
| `GET` | `/api/crm/contacts/{id}` | Get a single contact by ID |
| `PUT` | `/api/crm/contacts/{id}` | Update a contact |
| `DELETE` | `/api/crm/contacts/{id}` | Delete a contact |
| `POST` | `/api/crm/contacts/import` | Bulk import contacts from JSON or CSV |

## Create contact

Create a single CRM contact by sending contact fields in the request body. Include custom fields and campaign enrollment details when your workflow needs them.

<Callout kind="info">

Send `phone` in E.164 format such as `+14155550231`. The endpoint deduplicates contacts by phone number and merges fields when a matching contact already exists.

</Callout>

<Request tabs="cURL,JavaScript" default-tab="1">

  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -H "Content-Type: application/json" \
  -d '{
    "teamId": "tm_4c8d12",
    "groupId": "grp_29fa10",
    "firstName": "Priya",
    "lastName": "Natarajan",

## Delete a contact

Delete a contact by ID.

<Callout kind="alert">

Delete is blocked when the contact is enrolled in active campaigns. Remove the contact from all active campaigns before sending the delete request.

</Callout>

## Bulk import contacts

Import many contacts in a single request from CSV-derived JSON data. Include the team ID once at the top level, then send contact records in the `contacts` array.

<Request tabs="JSON import,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -H "Content-Type: application/json" \
  -d '{
    "teamId": "tm_12ab45",
    "contacts": [
      {
        "firstName": "Alicia",
        "lastName": "Moreno",
        "phone": "+14155550311",
        "email": "alicia.moreno@brightpath.io",
        "groupId": "grp_18cd77",
        "companyName": "Brightpath",
        "leadStatus": "new",
        "source": "api",
        "customFields": {
          "region": "West"
        },
        "tags": ["conference"]
      },
      {
        "firstName": "Marcus",
        "lastName": "Reed",
        "phone": "+14155550329",
        "email": "marcus.reed@brightpath.io",
        "groupId": "grp_18cd77",
        "companyName": "Brightpath",
        "leadStatus": "new",
        "source": "api",
        "customFields": {
          "region": "Central"
        },
        "tags": ["conference"]
      }
    ]
  }'
```

### JSON request body

<ParamField body="teamId" param-type="string" required="true">
Team UUID that owns imported contacts.
</ParamField>

<ParamField body="contacts" param-type="array" required="true">
Array of contacts to import.
</ParamField>

<ParamField body="contacts[].firstName" param-type="string" required="true">
Contact first name for each imported record.
</ParamField>

<ParamField body="contacts[].lastName" param-type="string" required="true">
Contact last name for each imported record.
</ParamField>

<ParamField body="contacts[].phone" param-type="string" required="true">
Primary contact phone number in E.164 format.
</ParamField>

<ParamField body="contacts[].email" param-type="string" required="false">
Contact email address.
</ParamField>

<ParamField body="contacts[].groupId" param-type="string" required="false">
CRM group UUID to associate with each imported contact.
</ParamField>

<ParamField body="contacts[].companyName" param-type="string" required="false">
Company name for each imported contact.
</ParamField>

<ParamField body="contacts[].jobTitle" param-type="string" required="false">
Job title for each imported contact.
</ParamField>

<ParamField body="contacts[].phoneSecondary" param-type="string" required="false">
Secondary phone number for each imported contact.
</ParamField>

<ParamField body="contacts[].leadStatus" param-type="string" required="false">
Lead status for each imported contact.
</ParamField>

<ParamField body="contacts[].source" param-type="string" required="false">
Source label for each imported contact.
</ParamField>

<ParamField body="contacts[].timezone" param-type="string" required="false">
Timezone for each imported contact.
</ParamField>

<ParamField body="contacts[].preferredContactMethod" param-type="string" required="false">
Preferred contact method for each imported contact.
</ParamField>

<ParamField body="contacts[].doNotCall" param-type="boolean" required="false">
Do-not-call flag for each imported contact.
</ParamField>

<ParamField body="contacts[].notes" param-type="string" required="false">
Notes for each imported contact.
</ParamField>

<ParamField body="contacts[].customFields" param-type="object" required="false">
Custom field values for each imported contact.
</ParamField>

<ParamField body="contacts[].tags" param-type="array" required="false">
Tags for each imported contact.
</ParamField>

<ParamField body="contacts[].campaignId" param-type="string" required="false">
Campaign UUID used to enroll each imported contact.
</ParamField>

<ParamField body="contacts[].campaignPriority" param-type="integer" required="false">
Priority assigned within the campaign for each imported contact.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Returns `true` when the import request is processed.
</ResponseField>

<ResponseField name="imported" field-type="integer" required="true">
Number of contacts imported successfully.
</ResponseField>

<ResponseField name="failed" field-type="integer" required="true">
Number of contacts that failed to import.
</ResponseField>

<ResponseField name="errors" field-type="array" required="true">
List of import errors for records that could not be processed.
</ResponseField>

## Notes on custom fields

Contact create, update, and import endpoints accept custom fields in addition to the standard contact properties.

<Callout kind="info">

Send custom fields in the `customFields` object. Keep field names consistent with your CRM configuration so imported and updated data maps to the expected contact fields.

</Callout>
