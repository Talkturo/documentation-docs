## CRM contacts endpoints

Use CRM contact endpoints to manage contact records, filter contact lists, and import contacts in bulk.

<Callout kind="info">

List, create, and import endpoints accept API key authentication or an authenticated session cookie. Contact detail, update, and delete endpoints require a Talkturo session cookie from an authenticated browser session.

</Callout>

### Endpoint summary

| Method | Path | Authentication | Description |
| --- | --- | --- | --- |
| `GET` | `/api/crm/contacts` | API key or session cookie | List contacts with pagination and filters |
| `POST` | `/api/crm/contacts` | API key or session cookie | Create a contact |
| `GET` | `/api/crm/contacts/{id}` | Session cookie | Get a single contact by ID |
| `PUT` | `/api/crm/contacts/{id}` | Session cookie | Update a contact |
| `DELETE` | `/api/crm/contacts/{id}` | Session cookie | Delete a contact |
| `POST` | `/api/crm/contacts/import` | API key or session cookie | Bulk import contacts from CSV |

## List contacts

Retrieve a paginated list of contacts for a team. Use filters to narrow results by company, lead status, contactability, or free-text search.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://app.talkturo.com/api/crm/contacts?teamId=9f2a4d44-7f0b-4fd4-a7b9-1f1d98fd9d2a&limit=25&offset=0&search=chen&companyId=cmp_9f3e21&leadStatus=qualified&doNotCall=false&hasPhone=true" \
  -H "Authorization: Bearer tk_example_9xmk7q2r"
```

  -d '{

    "companyId": "cmp_4c8d12",
    "firstName": "Priya",
    "lastName": "Natarajan",
    "phone": "+14155550231",
    "phoneSecondary": "+14155550232",
    "email": "priya.natarajan@lakesidepartners.com",

## Bulk import contacts

Import contacts from a CSV file by sending `multipart/form-data`. Talkturo deduplicates records by normalized phone number and can create missing companies during the import.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Authorization: Bearer tk_example_9xmk7q2r" \
  -F "file=@contacts-import.csv;type=text/csv" \
  -F "teamId=9f2a4d44-7f0b-4fd4-a7b9-1f1d98fd9d2a" \
  -F 'columnMapping={"first_name":"First Name","last_name":"Last Name","phone":"Mobile","email":"Work Email","company_name":"Company"}' \
  -F "autoCreateCompanies=true" \
  -F "importCompanyFields=false" \
  -F "duplicateMode=update"
```

### Form fields

<ParamField body="file" param-type="file" required="true">
CSV file to import.
</ParamField>

<ParamField body="teamId" param-type="string" required="true">
Team ID as a UUID. The import runs within this team.
</ParamField>

<ParamField body="columnMapping" param-type="string" required="true">
JSON string that maps CSV column names to Talkturo fields. You must map `first_name`.
</ParamField>

<ParamField body="autoCreateCompanies" param-type="string" required="false" enum="true,false">
Creates company records for rows that reference companies not already in the CRM.
</ParamField>

<ParamField body="importCompanyFields" param-type="string" required="false" enum="true,false">
Imports supported company fields from the CSV when company data is present.
</ParamField>

<ParamField body="defaultCompanyId" param-type="string" required="false">
Fallback company ID for rows that do not resolve to a company from the CSV.
</ParamField>

<ParamField body="duplicateMode" param-type="string" required="false" enum="skip,update,replace">
Duplicate handling mode. Defaults to `skip`.
</ParamField>

<Callout kind="info">

Talkturo identifies duplicates by normalized phone number. If `autoCreateCompanies` is `true`, the import creates missing companies before creating or updating matching contacts.

</Callout>

## Notes on custom fields

Contact create and update endpoints accept `customFields` in addition to the standard contact properties.

<Callout kind="info">

Send `customFields` as a JSON object in the request body. Keep field names consistent with your CRM configuration so imported and updated data maps to the expected contact fields.
