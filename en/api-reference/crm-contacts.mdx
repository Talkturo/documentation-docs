## CRM contacts endpoints

Use CRM contact endpoints to manage contact records, filter contacts, import CSV files, and review import batches.

<Callout kind="info">

CRM contact endpoints support API key authentication and session cookie authentication. API key requests use the account associated with the key, so `teamId` is optional. Session requests must include `teamId` in the query string or request body.

</Callout>

### Endpoint summary

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | List contacts with pagination and filters |
| `POST` | `/api/crm/contacts` | Create or deduplicate a contact |
| `GET` | `/api/crm/contacts/{id}` | Get an enriched contact by ID |
| `PUT` | `/api/crm/contacts/{id}` | Update a contact |
| `DELETE` | `/api/crm/contacts/{id}` | Delete a contact |
| `POST` | `/api/crm/contacts/import` | Import contacts from a CSV file |
| `GET` | `/api/crm/import-batches` | List contact import batches |

### Query parameters

<ParamField query="teamId" param-type="string" required="false">
Team to search. Required for session requests when the team cannot be resolved from authentication. API key requests use the key's associated account.
</ParamField>

<ParamField query="groupId" param-type="string" required="false">
Restrict results to contacts in the specified group.
</ParamField>

<ParamField query="search" param-type="string" required="false">
Case-insensitive partial search across `first_name`, `last_name`, `email`, and `phone`.
</ParamField>

<ParamField query="leadStatus" param-type="string" required="false">
Filter contacts by an exact lead status.
</ParamField>

<ParamField query="doNotCall" param-type="boolean" enum="true,false" required="false">

</ParamField>

</ParamField>

Maximum number of contacts to return. Defaults to `50`.
</ParamField>

<ParamField query="offset" param-type="integer" required="false">
Number of matching contacts to skip before returning results. Defaults to `0`.
</ParamField>

### Deduplication and campaign enrollment

The endpoint checks for an existing contact with the same phone number. When a match exists, the endpoint merges supplied non-empty fields into the existing record and returns `existing: true` instead of creating a duplicate.

When `campaignId` is supplied, the response also includes `campaign_enrollment` with the campaign contact ID, enrollment status, and exclusion reason when applicable.

<ResponseField name="success" field-type="boolean" required="true">
Returns `true` when the request succeeds.
</ResponseField>

<ResponseField name="contact" field-type="object" required="true">
Created or updated contact record.
</ResponseField>

<ResponseField name="existing" field-type="boolean" required="true">
Returns `true` when the phone number matched an existing contact.
</ResponseField>

<ResponseField name="campaign_enrollment" field-type="object" required="false">
Campaign enrollment result when `campaignId` is supplied.
</ResponseField>

<ResponseField name="campaign_enrollment.campaign_contact_id" field-type="string" required="false">
Identifier for the campaign contact record.
</ResponseField>

<ResponseField name="campaign_enrollment.status" field-type="string" required="false">
Enrollment status: `enrolled`, `already_enrolled`, or `excluded`.
</ResponseField>

<ResponseField name="campaign_enrollment.excludedReason" field-type="string or null" required="false">
Exclusion reason. Possible values include `no_phone` and `do_not_call`.
</ResponseField>

## Bulk import contacts

Import contacts from a CSV file with `multipart/form-data`. The `file`, `teamId`, and `columnMapping` form fields are required.

<Request tabs="API key,Session cookie" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/crm/contacts/import" \
  -H "Authorization: Bearer tk_test_example_9xmk7q2r" \
  -F "file=@contacts.csv" \
  -F "teamId=team_4c8d12" \
  -F "groupId=grp_7d2a44" \
  -F "duplicateMode=skip" \
  -F 'columnMapping={"firstName":"first_name","lastName":"last_name","phone":"phone","email":"email"}'
```

```bash
curl -X POST "https://api.talkturo.com/api/crm/contacts/import" \
  -H "Cookie: sb-access-token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example" \
  -F "file=@contacts.csv" \
  -F "teamId=team_4c8d12" \
  -F "newGroupName=Healthcare prospects" \
  -F "duplicateMode=update" \
  -F 'columnMapping={"firstName":"first_name","lastName":"last_name","phone":"phone","email":"email"}'
```
</Request>

<Response tabs="200">

## Notes on custom fields

Contact create, update, and import endpoints accept custom fields in addition to the standard contact properties.

<Callout kind="info">

Send custom fields through the camelCase `customFields` object. Keep field names consistent with your CRM configuration so created, updated, and imported data maps to the expected contact fields.

</Callout>
