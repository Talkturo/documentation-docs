## CRM contacts endpoints

Use CRM contact endpoints to manage contact records, filter contact lists, and import contacts in bulk.

<Callout kind="info">

`GET /api/crm/contacts` and `POST /api/crm/contacts` accept either API key authentication or an authenticated session cookie.

`GET /api/crm/contacts/{id}`, `PUT /api/crm/contacts/{id}`, and `DELETE /api/crm/contacts/{id}` require an authenticated session cookie.

</Callout>

### Endpoint summary

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | List contacts with pagination and filters |
| `POST` | `/api/crm/contacts` | Create a contact |
| `GET` | `/api/crm/contacts/{id}` | Get a single contact by ID |
| `PUT` | `/api/crm/contacts/{id}` | Update a contact |
| `DELETE` | `/api/crm/contacts/{id}` | Delete a contact |
| `POST` | `/api/crm/contacts/import` | Bulk import contacts from JSON or CSV |

## List contacts

Retrieve a paginated list of contacts. Use query parameters to search across contact fields or narrow results by company and lead state.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://app.talkturo.com/api/crm/contacts?companyId=cmp_9f3e21&search=chen&leadStatus=qualified&hasPhone=true&limit=25&offset=0" \
  -H "x-api-key: tturo_example_9xmk7q2r"
```

```javascript
const response = await fetch(

  {
    method: "GET",
    credentials: "include",
```

## Create contact

Create a single CRM contact by sending contact fields in the request body. You can also enroll the new contact in a campaign during creation.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts" \
  -H "Content-Type: application/json" \
  -H "x-api-key: tturo_example_9xmk7q2r" \
  -d '{
    "companyId": "cmp_4c8d12",
    "firstName": "Priya",
    "lastName": "Natarajan",
    "phone": "+14155550231",
    "phoneSecondary": "+14155550232",
    "email": "priya.natarajan@lakesidepartners.com",
    "jobTitle": "Operations Director",
    "leadStatus": "new",
    "source": "webinar",
```

## Bulk import contacts

Import many contacts in a single request. Send either structured JSON with a `contacts` array or CSV data, depending on your import flow.

<Request tabs="JSON import,CSV import" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example" \
  -d '{
    "contacts": [
      {
        "firstName": "Alicia",
        "lastName": "Moreno",
        "email": "alicia.moreno@brightpath.io",
        "phone": "+14155550311",
        "companyId": "cmp_12ab45",
        "customFields": {
          "region": "West"
        }
      },
      {
        "firstName": "Marcus",
        "lastName": "Reed",
        "email": "marcus.reed@brightpath.io",
        "phone": "+14155550329",
        "companyId": "cmp_12ab45",
        "customFields": {
          "region": "Central"
        }
      }
    ]
  }'
```

```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Content-Type: text/csv" \
  -H "Cookie: sb-access-token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example" \
  --data-binary $'firstName,lastName,email,phone,companyId,region\nAlicia,Moreno,alicia.moreno@brightpath.io,+14155550311,cmp_12ab45,West\nMarcus,Reed,marcus.reed@brightpath.io,+14155550329,cmp_12ab45,Central'
```
</Request>

## Notes on custom fields

Contact create, update, and import endpoints accept a `customFields` object in addition to the standard contact properties.

<Callout kind="info">

Send custom field values inside the `customFields` object. Talkturo stores this object as JSONB, so keep keys consistent with your CRM configuration to preserve reliable field mapping across create, update, and import flows.

</Callout>
