## CRM contacts endpoints

Use CRM contact endpoints to search, create, update, delete, and import contact records in Talkturo CRM.

<Callout kind="info">

`GET /api/crm/contacts`, `POST /api/crm/contacts`, and `POST /api/crm/contacts/import` accept API key authentication, bearer session authentication, or session cookie authentication. `GET /api/crm/contacts/[id]`, `PUT /api/crm/contacts/[id]`, and `DELETE /api/crm/contacts/[id]` require a session cookie from an authenticated Talkturo browser session.

</Callout>

### Endpoint summary

| Method | Path | Auth | Description |
| --- | --- | --- | --- |
| `GET` | `/api/crm/contacts` | API key or session | List contacts with filtering and offset pagination |
| `POST` | `/api/crm/contacts` | API key or session | Create a contact |
| `GET` | `/api/crm/contacts/{id}` | Session cookie | Get a single contact by ID |
| `PUT` | `/api/crm/contacts/{id}` | Session cookie | Update a contact |
| `DELETE` | `/api/crm/contacts/{id}` | Session cookie | Delete a contact |
| `POST` | `/api/crm/contacts/import` | API key or session | Import contacts from CSV using multipart form data |

  -H "Content-Type: application/json" \

  -d '{

    "companyId": "cmp_4c8d12",
    "firstName": "Priya",
    "lastName": "Natarajan",

### Form fields

<ParamField body="file" param-type="file" required="true">
CSV file to import. The file must be UTF-8 encoded, comma-separated, and start with a header row.
</ParamField>

<ParamField body="teamId" param-type="string" required="true">
Team that will own the imported contacts.
</ParamField>

<ParamField body="columnMapping" param-type="string" required="true">
JSON string that maps CSV column names to Talkturo field names.
</ParamField>

<ParamField body="autoCreateCompanies" param-type="string" required="false" enum="true,false">
When set to `true`, the importer creates company records for mapped company data that does not already exist.
</ParamField>

<ParamField body="importCompanyFields" param-type="string" required="false" enum="true,false">
When set to `true`, the importer reads mapped company fields from the CSV and applies them during import.
</ParamField>

<ParamField body="defaultCompanyId" param-type="string" required="false">
Company to apply when a row does not include company data or when you want all imported contacts attached to the same company.
</ParamField>

<ParamField body="duplicateMode" param-type="string" required="false" enum="skip,update,replace">
Duplicate handling mode. Defaults to `skip`.
</ParamField>

## Notes on custom fields

Create and update requests accept `customFields` as a JSON object. List and detail responses return those values in `custom_fields`.

<Callout kind="info">

Keep your custom field keys consistent across create, update, and import workflows. When you import CSV data, map custom values into standard supported fields first, then keep any application-specific metadata in `customFields` during API-based create or update operations.

</Callout>
