## CRM contacts endpoints

Manage contact records in Talkturo CRM, including list, create, retrieve, update, delete, and bulk import operations.

<Callout kind="info">

Authentication depends on the endpoint:

- **List contacts** and **create contact** accept either a session cookie or an API key in the `Authorization` header.
- **Get a contact**, **update a contact**, and **delete a contact** require a session-authenticated request.
- **Bulk import contacts** accepts either a session cookie or an API key.

</Callout>

### Endpoint summary

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | List contacts with filters and pagination |
| `POST` | `/api/crm/contacts` | Create a contact |
| `GET` | `/api/crm/contacts/{id}` | Get a single contact by ID |
| `PUT` | `/api/crm/contacts/{id}` | Update a contact |
| `DELETE` | `/api/crm/contacts/{id}` | Delete a contact |
| `POST` | `/api/crm/contacts/import` | Import contacts from a CSV file using multipart form data |

### Form fields
