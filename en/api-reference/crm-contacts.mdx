## CRM contacts endpoints

Use CRM contact endpoints to manage contact records, filter contact lists, and import contacts in bulk.

<Callout kind="info">

All CRM contact endpoints support dual authentication. Use either an API key (`Authorization: Bearer tk_live_...`) or an authenticated session cookie. The code examples on this page use API key authentication.

</Callout>

### Endpoint summary

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | List contacts with pagination and filters |
| `POST` | `/api/crm/contacts` | Create a contact |
| `GET` | `/api/crm/contacts/{id}` | Get a single contact by ID |
| `PATCH` | `/api/crm/contacts/{id}` | Update a contact |
| `DELETE` | `/api/crm/contacts/{id}` | Delete a contact |
| `POST` | `/api/crm/contacts/import` | Bulk import contacts from JSON or CSV |

## List contacts

Retrieve a paginated list of contacts. Use query parameters to search by text or narrow results to a company or lead status.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://app.talkturo.com/api/crm/contacts?search=chen&companyId=cmp_9f3e21&leadStatus=new&limit=25&offset=0" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z"
```

```javascript
const response = await fetch(
```

## Create contact

Create a single CRM contact by sending the contact fields in the request body. Include custom fields alongside the standard fields when your workspace uses them.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -d '{
    "firstName": "Priya",
    "lastName": "Natarajan",
    "email": "priya.natarajan@lakesidepartners.com",
    "phone": "+14155550231",
    "companyId": "cmp_4c8d12",
    "jobTitle": "Operations Director",
    "source": "webinar",
    "campaignId": "camp_7d2a44",
    "campaignPriority": 2
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/contacts", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    Authorization: "Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z",
  },
  body: JSON.stringify({
    firstName: "Priya",
    lastName: "Natarajan",
    email: "priya.natarajan@lakesidepartners.com",
    phone: "+14155550231",
```

## Update a contact

Update one or more contact fields by sending a partial request body. Omit fields you do not want to change.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X PATCH "https://app.talkturo.com/api/crm/contacts/2c7f1c6c-4d67-45f0-bf0e-5c9d3d2f2e41" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -d '{
    "leadStatus": "qualified",
    "notes": "Requested a follow-up call next week."
  }'
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/crm/contacts/2c7f1c6c-4d67-45f0-bf0e-5c9d3d2f2e41",
  {
    method: "PATCH",
    headers: {
      "Content-Type": "application/json",
      Authorization: "Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z",
    },
    body: JSON.stringify({
      leadStatus: "qualified",
      notes: "Requested a follow-up call next week.",
    }),
  }
);

const data = await response.json();
console.log(data);
```

## Bulk import contacts

Import many contacts in a single request. Send either structured JSON with a `contacts` array or CSV data, depending on your import flow.

<Request tabs="JSON import,CSV import" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -d '{
    "contacts": [
      {
        "firstName": "Alicia",
        "lastName": "Moreno",
        "email": "alicia.moreno@brightpath.io",
        "phone": "+14155550311",
        "companyId": "cmp_12ab45",
        "region": "West"
      },
      {
        "firstName": "Marcus",
        "lastName": "Reed",
        "email": "marcus.reed@brightpath.io",
        "phone": "+14155550329",
        "companyId": "cmp_12ab45",
        "region": "Central"
      }
    ]
  }'
```

```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Content-Type: text/csv" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  --data-binary $'firstName,lastName,email,phone,companyId,region\nAlicia,Moreno,alicia.moreno@brightpath.io,+14155550311,cmp_12ab45,West\nMarcus,Reed,marcus.reed@brightpath.io,+14155550329,cmp_12ab45,Central'
```
</Request>

<Response tabs="200">
```json

  "success": true,
  "imported": 2,
  "failed": 0,
  "errors": []
}
```
</Response>

## Notes on custom fields

Contact create, update, and import endpoints accept custom fields in addition to the standard contact properties.

<Callout kind="info">

Send custom fields as top-level properties in the JSON body. Keep field names consistent with your CRM configuration so imported and updated data maps to the expected contact fields.

</Callout>
