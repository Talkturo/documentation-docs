## Manage tool configs

Attach external tools to assistants so the AI agent can call them during conversations. Configure Zapier webhook integrations, custom HTTP webhook endpoints with AI-generated parameters, and TurboFlow workflow triggers through dedicated endpoints.

<Callout kind="info">

All tool config endpoints require an authenticated session cookie. The signed-in user must belong to the workspace that owns the assistant.

</Callout>

### Endpoint summary

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `https://api.talkturo.com/api/assistants/{assistantId}/tool-configs/zapier` | Fetch the first enabled Zapier config, one config by ID, or all enabled Zapier configs |
| `POST` | `https://api.talkturo.com/api/assistants/{assistantId}/tool-configs/zapier` | Create or update a Zapier tool config |
| `DELETE` | `https://api.talkturo.com/api/assistants/{assistantId}/tool-configs/zapier` | Delete one Zapier config or all Zapier configs for the assistant |
| `GET` | `https://api.talkturo.com/api/assistants/{assistantId}/tool-configs/custom_webhook` | Fetch the first enabled custom webhook config, one config by ID, or all enabled custom webhook configs |
| `POST` | `https://api.talkturo.com/api/assistants/{assistantId}/tool-configs/custom_webhook` | Create a custom webhook tool config |
| `DELETE` | `https://api.talkturo.com/api/assistants/{assistantId}/tool-configs/custom_webhook` | Delete one custom webhook config by ID |
| `POST` | `https://api.talkturo.com/api/assistants/{assistantId}/tools/workflow` | Attach a TurboFlow workflow to an assistant |

<Callout kind="info">

The `config` field stores a free-form JSON object. Its required keys and nested structure depend on the tool type you create.

</Callout>

## Integration tool configs

Use the `zapier` tool type to attach a Zapier integration to an assistant. The `toolType` route currently supports the `zapier` value in the database.

### Create or update a Zapier config

Create a Zapier config by posting a free-form `config` object. If a matching config already exists, the API updates that row and returns the saved record.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl --request POST \
  --url "https://api.talkturo.com/api/assistants/asst_9f3c2d11-0e7d-4d36-8f3c-0e14a8b2f701/tool-configs/zapier" \
  --header "Content-Type: application/json" \
  --header "Cookie: tt_session=tt_session_example_f82b9c1a7d" \
  --data '{
    "config": {
      "integration_id": "5eeaeb73-1f36-4f7f-a20f-6c0d3fd0c5d2"
    },
    "is_enabled": true
  }'
```

<ExpandableGroup>
  <Expandable title="Zapier route behavior" default-open="false">

The `zapier` route uses the generic `tool-configs/[toolType]` handler. `GET` returns enabled configs, `POST` accepts a free-form `config` object and optional `is_enabled`, and `DELETE` can remove one row or all rows for that tool type.

  <Expandable title="Supported tool types in the database" default-open="false">

Current database constraints allow `zapier`, `custom_webhook`, and `workflow`. Use the dedicated routes for `custom_webhook` and `workflow` instead of the generic `toolType` route.

  </Expandable>
</ExpandableGroup>

## Workflow tool configs

Use the workflow route to attach a TurboFlow workflow to an assistant. The stored config contains the workflow identifier.

### Create a workflow config

Attach a workflow by posting a `flow_id`. The API accepts `name` and `description` in the request body, but stores only `flow_id` in the config object.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl --request POST \
  --url "https://api.talkturo.com/api/assistants/asst_9f3c2d11-0e7d-4d36-8f3c-0e14a8b2f701/tools/workflow" \
  --header "Content-Type: application/json" \
  --header "Cookie: tt_session=tt_session_example_f82b9c1a7d" \
  --data '{
    "flow_id": "3f2a6dcb-8868-4df4-8911-b7a73a6e4e2f"
  }'
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/assistants/asst_9f3c2d11-0e7d-4d36-8f3c-0e14a8b2f701/tools/workflow",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Cookie: "tt_session=tt_session_example_f82b9c1a7d"
    },
    body: JSON.stringify({
      flow_id: "3f2a6dcb-8868-4df4-8911-b7a73a6e4e2f"
    })
  }
);

const data = await response.json();
console.log(data);
```

#### Path parameters

<ParamField path="assistantId" param-type="string" required="true">
Assistant identifier.
</ParamField>

#### Body parameters

<ParamField body="flow_id" param-type="string" required="true">
TurboFlow workflow UUID to attach.
</ParamField>

<ParamField body="name" param-type="string" required="false">
Accepted by the endpoint but ignored when the config is stored.
</ParamField>

<ParamField body="description" param-type="string" required="false">
Accepted by the endpoint but ignored when the config is stored.
</ParamField>

#### Response fields

<ResponseField name="id" field-type="string" required="true">
Unique tool config identifier.
</ResponseField>

<ResponseField name="assistant_id" field-type="string" required="true">
Assistant that owns the config.
</ResponseField>

<ResponseField name="account_id" field-type="string" required="true">
Workspace account that owns the assistant.
</ResponseField>

<ResponseField name="tool_type" field-type="string" required="true">
Stored tool type. The value is `workflow`.
</ResponseField>

<ResponseField name="config" field-type="object" required="true">
Workflow config object containing `flow_id`.
</ResponseField>

<ResponseField name="is_enabled" field-type="boolean" required="true">
Whether the workflow config is enabled.
</ResponseField>

<ResponseField name="created_at" field-type="string" required="true">
Creation timestamp in ISO 8601 format.
</ResponseField>

<ResponseField name="updated_at" field-type="string" required="true">
Last update timestamp in ISO 8601 format.
</ResponseField>

<ExpandableGroup>
  <Expandable title="Workflow route behavior" default-open="false">

The workflow endpoint validates `flow_id` as a UUID. The saved config object contains only `flow_id`, even if you send `name` or `description` in the request body.
