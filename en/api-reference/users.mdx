## Endpoint summary

| Method | Path | Purpose | Auth |
| --- | --- | --- | --- |
| `GET` | `/api/users/me` | Get the current desktop user profile | Desktop JWT |
| `PUT` | `/api/users/me` | Update the current desktop user profile | Desktop JWT |
| `GET` | `/api/users/me/subscription` | Get subscription status, limits, and usage | Desktop JWT |
| `GET` | `/api/users/me/workspaces` | List workspaces available to the current user | Desktop JWT |
| `GET` | `/api/account/business` | Get a workspace business profile | Session cookie |
| `PUT` | `/api/account/business` | Update a workspace business profile | Session cookie |
| `PUT` | `/api/account/language` | Update a workspace language | Session cookie, owner only |

<Callout kind="info">

Desktop user endpoints use desktop JWT authentication. Send the desktop token in the `Authorization` header as `Bearer dt_example_9xmk7q2r`.

Workspace business endpoints use a session cookie from an authenticated web app session instead of a desktop JWT.

</Callout>

## Get current user

Returns the authenticated desktop user's profile and desktop-specific settings.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request GET \
  --url https://app.talkturo.com/api/users/me \
  --header "Authorization: Bearer dt_example_9xmk7q2r"
```

```javascript
const response = await fetch("https://app.talkturo.com/api/users/me", {
  method: "GET",
  headers: {
    Authorization: "Bearer dt_example_9xmk7q2r"
  }
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,401,500" default-tab="1">
```json

  "email": "jane.chen@acme.com",

  "has_migrated_to_firebase": true
}
```


</Response>

## Update current user

Updates the authenticated desktop user's profile.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request PUT \
  --url https://app.talkturo.com/api/users/me \
  --header "Authorization: Bearer dt_example_9xmk7q2r" \
  --header "Content-Type: application/json" \
  --data '{
    "display_name": "Jane Chen"
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/users/me", {
  method: "PUT",
  headers: {
    Authorization: "Bearer dt_example_9xmk7q2r",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    display_name: "Jane Chen"
  })
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,400,401,500" default-tab="1">
```json
{
  "uid": "usr_7f3d2a91"
}
```

```json
{
  "error": "display_name is required"
}
```

```json
{
  "error": "Unauthorized"
}
```

```json
{
  "error": "Internal server error"
}
```
</Response>

## Get subscription

Returns subscription state, account context, plan limits, and current usage for the authenticated desktop user.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request GET \
  --url https://app.talkturo.com/api/users/me/subscription \
  --header "Authorization: Bearer dt_example_9xmk7q2r" \
  --header "X-Talkturo-Account: acme-sales"
```

```javascript
const response = await fetch("https://app.talkturo.com/api/users/me/subscription", {
  method: "GET",
  headers: {
    Authorization: "Bearer dt_example_9xmk7q2r",
    "X-Talkturo-Account": "acme-sales"
  }
});

const data = await response.json();
console.log(data);
```
</Request>

## Update language

Updates the language for a workspace. Only workspace owners can change this setting.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request PUT \
  --url https://app.talkturo.com/api/account/language \
  --header "Content-Type: application/json" \
  --header "Cookie: sb-access-token=sb_example_71k2xm; sb-refresh-token=sb_refresh_example_48znq1" \
  --data '{
    "account": "acme-sales",
    "language": "en"
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/account/language", {
  method: "PUT",
  credentials: "include",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    account: "acme-sales",
    language: "en"
  })
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,400,401,403,404,500" default-tab="1">

```json
{
  "success": true,
  "language": "en"
```




### Endpoint

`PUT https://app.talkturo.com/api/account/language`

### Body parameters

<ParamField body="account" param-type="string" required="true">
Workspace slug whose language you want to update.
</ParamField>

<ParamField body="language" param-type="string" required="true" enum="en,de">
Workspace language. Supported values are `en` and `de`.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Whether the language update succeeded.
</ResponseField>

<ResponseField name="language" field-type="string" required="true">
Updated workspace language.
</ResponseField>

<Callout kind="alert">

This endpoint rejects non-owner requests with `403`. Check the current user's workspace role before showing language controls in your application.

</Callout>

## Error codes

| Status | Meaning |
| --- | --- |
| `400` | Missing required input or invalid request body |
| `401` | Authentication failed or no valid authenticated session exists |
| `403` | Access is denied for the current user or workspace context |
| `404` | The requested workspace was not found |
| `500` | The server failed to complete the request |
