## Users endpoints

Use the users API to read the authenticated desktop user's profile, update the display name, list desktop-enabled workspaces, and check subscription access.

<Callout kind="info">

**Authentication**
- `GET /api/users/me`
- `PUT /api/users/me`
- `DELETE /api/users/me`
- `GET /api/users/me/workspaces`
- `GET /api/users/me/subscription`
- `GET /api/users/me/auto-update`
- `PUT /api/users/me/auto-update`

These endpoints require a desktop session JWT in the `Authorization` header using the format `Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt`. They do not use API keys.

</Callout>

## Endpoint summary

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| GET | `/api/users/me` | Desktop Bearer JWT | Return the authenticated user's profile |
| PUT | `/api/users/me` | Desktop Bearer JWT | Update the user's `display_name` |
| DELETE | `/api/users/me` | Desktop Bearer JWT | Return a stub deletion response |
| GET | `/api/users/me/workspaces` | Desktop Bearer JWT | List workspaces with desktop access |
| GET | `/api/users/me/subscription` | Desktop Bearer JWT | Return subscription status for the user or a workspace |
| GET | `/api/users/me/auto-update` | Desktop Bearer JWT | Return the current auto-update setting stub |
| PUT | `/api/users/me/auto-update` | Desktop Bearer JWT | Accept and ignore auto-update updates |

## Get the authenticated user

`GET /api/users/me` returns the current desktop user's profile.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://api.talkturo.com/api/users/me" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt"
```

```javascript
const response = await fetch("https://api.talkturo.com/api/users/me", {
  method: "GET",
  headers: {
    Authorization: "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt"
  }
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,401" default-tab="1">

## Update the display name

`PUT /api/users/me` updates the authenticated user's `display_name`.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X PUT "https://api.talkturo.com/api/users/me" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt" \
  -H "Content-Type: application/json" \
  -d '{
    "display_name": "Jane Q. Chen"
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/users/me", {
  method: "PUT",
  headers: {
    Authorization: "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    display_name: "Jane Q. Chen"
  })
});

const data = await response.json();
console.log(data);
```
</Request>

```json
  }
}
```


## Get desktop subscription status

`GET /api/users/me/subscription` returns subscription access for the current user or for a specific workspace.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash

  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt" \
  -H "X-Talkturo-Account: acme-sales"
```

```javascript
const response = await fetch("https://api.talkturo.com/api/users/me/subscription", {
```

## Update the auto-update setting

`PUT /api/users/me/auto-update` accepts a request body but ignores it and returns a stubbed enabled state.

<Callout kind="alert">

This endpoint ignores the request body and always returns `enabled: true`.

</Callout>

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt" \
```
