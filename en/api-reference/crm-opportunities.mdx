## Manage CRM opportunities

Use the CRM Opportunities endpoints to track deals, pipeline stage, ownership, forecasted revenue, and related contacts or companies from your Talkturo account.

<Callout kind="info">

`GET /api/crm/opportunities` and `POST /api/crm/opportunities` accept either an authenticated API key or a session cookie. `GET`, `PUT`, and `DELETE` requests to `/api/crm/opportunities/{id}` require an authenticated session cookie and do not accept API key authentication.

</Callout>

### Endpoints at a glance

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/opportunities` | List opportunities with pagination and filters |
| `POST` | `/api/crm/opportunities` | Create a new opportunity |
| `GET` | `/api/crm/opportunities/{id}` | Retrieve one opportunity by ID |
| `PUT` | `/api/crm/opportunities/{id}` | Update an existing opportunity |
| `DELETE` | `/api/crm/opportunities/{id}` | Delete an opportunity |

### Query parameters

<ParamField query="teamId" param-type="string" required="false">
Return only opportunities that belong to the specified team.
</ParamField>

Return only opportunities associated with the specified company.
</ParamField>

<ParamField query="stage" param-type="string" required="false" enum="lead,qualified,proposal,negotiation,won,lost">

</ParamField>

</ParamField>

<ParamField query="limit" param-type="integer" required="false">

## Create opportunity

Create a new sales opportunity with a required name and optional deal metadata.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/opportunities" \
  -H "Authorization: Bearer ttro_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Enterprise Expansion - Northwind Health",
    "stage": "qualified",
    "companyId": "cmp_7f3d21a9",
    "primaryContactId": "cnt_91b4a2e7",
    "amount": 48000,
    "currency": "USD",
    "probability": 70,
    "expectedCloseDate": "2026-10-15",
    "ownerUserId": "usr_28ab41d7",
    "notes": "Expansion opportunity for the analytics rollout.",
    "customFields": {
      "region": "North America",
      "segment": "Enterprise"
    }
  }'
```
