## Manage CRM opportunities

Use the CRM Opportunities API to manage deals for a team. You can filter opportunities by pipeline stage and owner, track amounts and close dates, and retrieve related contact activity.

<Callout kind="info">

All CRM Opportunities endpoints require an authenticated session cookie. These endpoints do not accept API key authentication.

</Callout>

The item route derives the opportunity's `team_id` and verifies that the authenticated session can access the team before it reads, updates, or deletes the opportunity.

### Endpoints at a glance

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/opportunities` | List opportunities for a team |
| `POST` | `/api/crm/opportunities` | Create an opportunity |
| `GET` | `/api/crm/opportunities/{id}` | Retrieve an opportunity and related activities |
| `PUT` | `/api/crm/opportunities/{id}` | Update an opportunity |
| `DELETE` | `/api/crm/opportunities/{id}` | Delete an opportunity |

### Pipeline stages

The `stage` field accepts these values:

- `lead`
- `qualified`
- `proposal`
- `negotiation`
- `won`
- `lost`

## List opportunities

Retrieve opportunities for a team with optional stage and owner filters. Use `limit` and `offset` to paginate the results.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl -X GET "https://app.talkturo.com/api/crm/opportunities?teamId=team_4f8a2c91&stage=proposal&ownerUserId=usr_82c1d7a4&limit=25&offset=0" \
  -H "Cookie: sb-access-token=example_session_cookie"
```

## Create an opportunity

Create an opportunity for a team. The `teamId` and `name` fields are required; all other fields are optional.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl -X POST "https://app.talkturo.com/api/crm/opportunities" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=example_session_cookie" \
  -d '{
    "teamId": "team_4f8a2c91",
    "name": "Northwind Health Platform Expansion",
    "primaryContactId": "cnt_91b4a2e7",
    "stage": "qualified",
    "amount": 48000,
    "currency": "USD",
    "probability": 60,
    "expectedCloseDate": "2026-10-15",
    "ownerUserId": "usr_82c1d7a4",
    "notes": "Expansion opportunity identified during the quarterly review.",
    "customFields": {
      "region": "North America",
      "contractTermMonths": 24
    }
  }'
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/crm/opportunities",
  {
    method: "POST",
    credentials: "include",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      teamId: "team_4f8a2c91",
      name: "Northwind Health Platform Expansion",
      primaryContactId: "cnt_91b4a2e7",
      stage: "qualified",
      amount: 48000,
      currency: "USD",
      probability: 60,
      expectedCloseDate: "2026-10-15",
      ownerUserId: "usr_82c1d7a4",
      notes: "Expansion opportunity identified during the quarterly review.",
      customFields: {
        region: "North America",
        contractTermMonths: 24
      }
    })
  }
);

const data = await response.json();

```
