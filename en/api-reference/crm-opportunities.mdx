## Manage CRM opportunities

Use the CRM Opportunities endpoints to track deals, pipeline stages, owners, forecasted close dates, and related companies or contacts in Talkturo CRM.

<Callout kind="info">

Authentication depends on the endpoint:

- **List opportunities** and **create opportunity** accept either a session cookie or an API key.
- **Get opportunity**, **update opportunity**, and **delete opportunity** require an authenticated session cookie.

</Callout>

### Endpoints at a glance

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/opportunities` | List opportunities with filters, pagination, and stage totals |
| `POST` | `/api/crm/opportunities` | Create a new opportunity |
| `GET` | `/api/crm/opportunities/{id}` | Retrieve one opportunity by ID |
| `PUT` | `/api/crm/opportunities/{id}` | Update an existing opportunity |
| `DELETE` | `/api/crm/opportunities/{id}` | Delete an opportunity |

### Valid stages

Every endpoint that accepts `stage` uses the same set of values.

| Stage | Meaning |
| --- | --- |
| `lead` | Early-stage opportunity that has not been qualified yet |
| `qualified` | Opportunity has been validated and is worth pursuing |
| `proposal` | A formal offer or proposal is in progress |
| `negotiation` | Terms, scope, or pricing are being negotiated |
| `won` | Opportunity closed successfully |
| `lost` | Opportunity closed without a sale |

## List opportunities

Retrieve opportunities for a team and filter the results by company, stage, or owner. If you omit `teamId`, the API uses the authenticated account ID.

<Request tabs="cURL session,cURL API key,JavaScript" default-tab="1">

```bash
  -H "Cookie: sb-access-token=example_session_cookie"
```

## Create opportunity

Create a sales opportunity with a required name and optional forecast, ownership, relationship, and custom field data. If you omit `teamId`, the API uses the authenticated account ID.

<Request tabs="cURL session,cURL API key,JavaScript" default-tab="1">
```bash

  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=example_session_cookie" \
  -d '{
    "name": "Enterprise Expansion - Northwind Health",
    "companyId": "6d9f4f52-9e8a-4ea9-b9da-7b5e2a0c4312",
    "primaryContactId": "c4e2c51c-b1e5-4f04-9e7d-6e4f9fcb7d19",
    "stage": "qualified",
    "amount": 48000,
    "currency": "USD",
    "probability": 65,
    "expectedCloseDate": "2026-10-15",
    "ownerUserId": "0e8ef9a6-85d1-4d18-95cf-1f3d87281d34",
    "notes": "Expansion opportunity tied to the annual renewal review.",
    "customFields": {
      "region": "North America",
      "productLine": "Enterprise"
    }
  }'
```

## Update opportunity

Update one or more fields on an existing opportunity. This endpoint uses `PUT` and requires a session cookie.

### Path parameter

<ParamField path="id" param-type="string" required="true">
Unique opportunity identifier.
</ParamField>

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X PUT "https://app.talkturo.com/api/crm/opportunities/opp_6c52a1ef" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=example_session_cookie" \
  -d '{
    "stage": "won",
    "amount": 52000,
    "probability": 100,
    "actualCloseDate": "2026-10-31",
    "wonDetails": "Expanded to three business units."
  }'
```

```javascript
const response = await fetch("/api/crm/opportunities/opp_6c52a1ef", {
  method: "PUT",
  credentials: "include",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    stage: "won",
    amount: 52000,
    probability: 100,
    actualCloseDate: "2026-10-31",
    wonDetails: "Expanded to three business units."
  })
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200">
