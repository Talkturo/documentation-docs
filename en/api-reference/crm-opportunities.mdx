## Manage CRM opportunities

Use the CRM Opportunities endpoints to track deals, pipeline stage, owners, associated contacts, and expected close dates from your Talkturo account.

<Callout kind="info">

All CRM Opportunities endpoints use dual authentication. Send an API key in the `Authorization` header as a Bearer token, or make the request from a signed-in session with a valid session cookie.

</Callout>

<Callout kind="info">

Valid pipeline stages are `lead`, `qualified`, `proposal`, `negotiation`, `won`, and `lost`.

</Callout>

### Endpoints at a glance

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/opportunities` | List opportunities with pagination and filters |
| `POST` | `/api/crm/opportunities` | Create a new opportunity |
| `GET` | `/api/crm/opportunities/{id}` | Retrieve one opportunity by ID |
| `PUT` | `/api/crm/opportunities/{id}` | Update an existing opportunity |
| `DELETE` | `/api/crm/opportunities/{id}` | Delete an opportunity |

## List opportunities

Retrieve a list of opportunities and narrow the results by team, stage, or owner.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://app.talkturo.com/api/crm/opportunities?teamId=0f4c2d10-6a8d-4dc6-b7c1-9c8b7d94c221&stage=proposal&ownerUserId=9b1f4b6d-8e6d-4f1c-b8a4-2d64c2fbe731&limit=25&offset=0" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r"
```


### Query parameters

<ParamField query="teamId" param-type="string" required="false">
Return only opportunities that belong to the specified team.
</ParamField>

<ParamField query="stage" param-type="string" required="false" enum="lead,qualified,proposal,negotiation,won,lost">
Return only opportunities in the specified pipeline stage.
</ParamField>

<ParamField query="ownerUserId" param-type="string" required="false">

</ParamField>

<ParamField query="offset" param-type="integer" required="false">

## Create opportunity

Create a new sales opportunity with a required team ID and name, plus optional pipeline and ownership details.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/opportunities" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -d '{
    "teamId": "0f4c2d10-6a8d-4dc6-b7c1-9c8b7d94c221",
    "primaryContactId": "7c64f4df-3f20-4b48-9b62-3d5f8f3951d8",
    "name": "Enterprise Expansion - Northwind Health",
    "stage": "qualified",
    "amount": 48000,
    "currency": "USD",
    "probability": 60,
    "expectedCloseDate": "2026-10-15",
    "ownerUserId": "9b1f4b6d-8e6d-4f1c-b8a4-2d64c2fbe731",
    "notes": "Expansion opportunity for the analytics team.",
    "customFields": {
      "segment": "Enterprise",
      "renewalType": "Expansion"
    }
  }'
```
