## Manage CRM groups

Use the CRM Groups endpoints to organize contacts into reusable segments for campaigns, outreach workflows, and reporting in your Talkturo account.

<Callout kind="info">

All CRM Groups endpoints use dual authentication. Send an API key in the `Authorization` header as a Bearer token, or make the request from a signed-in session with a valid session cookie.

API key scope guards apply by method:

- `contacts:read` for `GET` endpoints
- `contacts:write` for `POST`, `PUT`, and `DELETE` endpoints

</Callout>

### Endpoints at a glance

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/groups` | List groups with contact counts |
| `POST` | `/api/crm/groups` | Create a new group |
| `GET` | `/api/crm/groups/{id}` | Get a group |
| `PUT` | `/api/crm/groups/{id}` | Update a group |
| `DELETE` | `/api/crm/groups/{id}` | Delete a group |
| `GET` | `/api/crm/groups/{id}/contacts` | List contacts in a group |
| `POST` | `/api/crm/groups/{id}/contacts` | Add or remove contacts from a group |

### Authentication formats

## List groups

List CRM groups for the authenticated account. Each group includes its current contact count so you can show segment size without making a second request.

<Request tabs="cURL,JavaScript,Python" default-tab="1">

## Create a group

Create a CRM group before assigning contacts to it. New groups start with a contact count of `0`.

<Request tabs="cURL,JavaScript,Python" default-tab="1">

```bash
curl -X POST "https://api.talkturo.com/api/crm/groups" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r8n4v6p1d5s7u0w3y" \
  -H "Content-Type: application/json" \
  -d '{
    "teamId": "team_7f3d2b91",
    "name": "Enterprise leads",
    "description": "High-value accounts for Q4 outbound campaigns"
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/crm/groups", {
  method: "POST",
  headers: {
    "Authorization": "Bearer tk_live_example_9xmk7q2r8n4v6p1d5s7u0w3y",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    teamId: "team_7f3d2b91",
    name: "Enterprise leads",
    description: "High-value accounts for Q4 outbound campaigns"
  })
});

const data = await response.json();
console.log(data);
```

```python
import requests

response = requests.post(
    "https://api.talkturo.com/api/crm/groups",
    headers={
        "Authorization": "Bearer tk_live_example_9xmk7q2r8n4v6p1d5s7u0w3y",
        "Content-Type": "application/json"
    },
    json={
        "teamId": "team_7f3d2b91",
        "name": "Enterprise leads",
        "description": "High-value accounts for Q4 outbound campaigns"

)
```

## Delete a group

Delete a group when you no longer need the segment. Deleting a group removes the grouping, not the underlying contacts.

<Callout kind="alert">

Deleting a group does not delete the contacts within it. Contacts remain in the CRM but are ungrouped.

</Callout>

<Request tabs="cURL,JavaScript,Python" default-tab="1">

```bash
curl -X DELETE "https://api.talkturo.com/api/crm/groups/grp_8c4d1f29" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r8n4v6p1d5s7u0w3y"
```

## Manage group contacts

Add contacts to a group or remove contacts from it in a single request. Set `action` to `add` or `remove` and pass the contact IDs you want to update.

<Request tabs="cURL,JavaScript,Python" default-tab="1">

```bash
curl -X POST "https://api.talkturo.com/api/crm/groups/grp_8c4d1f29/contacts" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r8n4v6p1d5s7u0w3y" \
  -H "Content-Type: application/json" \
  -d '{
    "contactIds": ["cnt_4e82b731", "cnt_2c97a880"],
    "action": "add"
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/crm/groups/grp_8c4d1f29/contacts", {
```
