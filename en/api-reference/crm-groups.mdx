## Endpoint summary

| Method | Path | Purpose | Auth |
| --- | --- | --- | --- |
| `GET` | `/api/crm/groups` | List groups for a workspace | Session cookie or API key |
| `POST` | `/api/crm/groups` | Create a group | Session cookie or API key |
| `GET` | `/api/crm/groups/{id}` | Get one group with contacts | Session cookie or API key |
| `PUT` | `/api/crm/groups/{id}` | Rename a group | Session cookie or API key |
| `DELETE` | `/api/crm/groups/{id}` | Not supported | Session cookie or API key |
| `GET` | `/api/crm/groups/{id}/contacts` | List contacts in a group | Session cookie or API key |
| `POST` | `/api/crm/groups/{id}/contacts` | Add a contact to a group | Session cookie or API key |
| `DELETE` | `/api/crm/groups/{id}/contacts` | Remove a contact from a group | Session cookie or API key |

<Callout kind="info">

Use the base URL `https://app.talkturo.com`. These endpoints accept either a Talkturo session cookie or an `Authorization` header with a Bearer API key. For API key requests, the team is derived from the key and any `teamId` value in the request is ignored.

</Callout>

<Callout kind="alert">

`DELETE /api/crm/groups/{id}` always returns `405 Method Not Allowed`. Groups cannot be deleted. Rename the group instead, or leave it unused.

</Callout>

## List groups

List all CRM groups in a workspace. Use `search` to filter groups by name.

### Endpoint

`GET https://app.talkturo.com/api/crm/groups`

### Query parameters

<ParamField query="teamId" param-type="string" required="true">

Workspace ID. Required when you authenticate with a session cookie. Ignored for API key requests because the API key already scopes the request to a team.

</ParamField>

<ParamField query="search" param-type="string" required="false">

Case-insensitive filter applied to the group name.

</ParamField>

### Request example

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl --request GET \
  --url "https://app.talkturo.com/api/crm/groups?teamId=team_9f2c1a7d&search=vip" \
  --header "Authorization: Bearer tk_example_9xmk7q2r"
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/crm/groups?teamId=team_9f2c1a7d&search=vip",
  {
    method: "GET",
    headers: {
      Authorization: "Bearer tk_example_9xmk7q2r"
    }
  }
);

const data = await response.json();
console.log(data);
```

</Request>

## Create group

Create a new contact group in a workspace. Group names must be unique within the team.

### Endpoint

`POST https://app.talkturo.com/api/crm/groups`

### Body parameters

<ParamField body="teamId" param-type="string" required="true">

Workspace ID. Required when you authenticate with a session cookie. Ignored for API key requests.

</ParamField>

<ParamField body="name" param-type="string" required="true">

Group name. The name must be unique within the team.

</ParamField>

### Request example

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl --request POST \
  --url "https://app.talkturo.com/api/crm/groups" \
  --header "Authorization: Bearer tk_example_9xmk7q2r" \
  --header "Content-Type: application/json" \
  --data '{
    "teamId": "team_9f2c1a7d",
    "name": "Assistant Overflow"
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/groups", {
  method: "POST",
  headers: {
    Authorization: "Bearer tk_example_9xmk7q2r",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    teamId: "team_9f2c1a7d",
    name: "Assistant Overflow"
  })
});

const data = await response.json();
console.log(data);
```

</Request>

### Response example

<Callout kind="info">

This endpoint requires `auth.accountId` in addition to authentication. If the request identity does not include an account context, the API returns `401`.

</Callout>

<ParamField path="id" param-type="string" required="true">

</ParamField>

## Update group

Rename an existing group. This endpoint does not let you change whether a group is the default.

### Endpoint

`PUT https://app.talkturo.com/api/crm/groups/{id}`

<Callout kind="alert">

Do not send `is_default` in the request body. This endpoint does not support changing it.

</Callout>

### Path parameters

<ParamField path="id" param-type="string" required="true">

Group UUID.

</ParamField>

### Body parameters

<ParamField body="name" param-type="string" required="false">

New group name. If you send `name`, it must not be an empty string.

</ParamField>

### Request example

<Request tabs="cURL,JavaScript" default-tab="1">

```bash

  --url "https://app.talkturo.com/api/crm/groups/grp_2c7f4f91" \

  --header "Content-Type: application/json" \
  --data '{
    "name": "Strategic Accounts"
  }'
```

```javascript
const response = await fetch(
```

```javascript
const response = await fetch(
```

## Group contact membership

Manage which contacts belong to a CRM group. Add, remove, and list contacts within a group using these membership endpoints.

### List contacts in a group

Retrieve paginated contacts for a specific group. Results are ordered by membership creation time, newest first.

#### Endpoint

`GET https://app.talkturo.com/api/crm/groups/{id}/contacts`

#### Path parameters

<ParamField path="id" param-type="string" required="true">

Group UUID.

</ParamField>

#### Query parameters

<ParamField query="limit" param-type="integer" required="false">

Maximum number of contacts to return. Defaults to 100.

</ParamField>

<ParamField query="offset" param-type="integer" required="false">

Number of contacts to skip for pagination. Defaults to 0.

</ParamField>

#### Response fields

<ResponseField name="success" field-type="boolean" required="true">

Indicates whether the request succeeded.

</ResponseField>

<ResponseField name="contacts" field-type="array" required="true">

Array of contact records in the group.

</ResponseField>

<ResponseField name="count" field-type="integer" required="true">

Total number of contacts in the group.

</ResponseField>

<ResponseField name="limit" field-type="integer" required="true">

Pagination limit used for this request.

</ResponseField>

<ResponseField name="offset" field-type="integer" required="true">

Pagination offset used for this request.

</ResponseField>

#### Error responses

| Status | Meaning |
| --- | --- |
| `401` | Missing authentication or account context |
| `404` | Group not found or does not belong to the account |

### Add a contact to a group

Add a contact to a CRM group. The contact and group must both belong to the same account. This operation is idempotent, so adding a contact that is already in the group returns success without creating a duplicate.

#### Endpoint

`POST https://app.talkturo.com/api/crm/groups/{id}/contacts`

#### Path parameters

<ParamField path="id" param-type="string" required="true">

Group UUID.

</ParamField>

#### Body parameters

<ParamField body="contactId" param-type="string" required="true">

UUID of the contact to add. The contact must belong to the same account as the group.

</ParamField>

<Callout kind="info">

API keys require the `contacts:write` scope for this endpoint.

</Callout>

#### Response fields

<ResponseField name="success" field-type="boolean" required="true">

Returns `true` when the contact is added or was already a member.

</ResponseField>

#### Error responses

| Status | Meaning |
| --- | --- |
| `400` | Missing `contactId` |
| `401` | Missing authentication or account context |
| `404` | Group or contact not found |

### Remove a contact from a group

Remove a contact from a CRM group by contact ID. Removing a contact that is not in the group still returns success.

#### Endpoint

`DELETE https://app.talkturo.com/api/crm/groups/{id}/contacts?contactId={contactId}`

#### Path parameters

<ParamField path="id" param-type="string" required="true">

Group UUID.

</ParamField>

#### Query parameters

<ParamField query="contactId" param-type="string" required="true">

UUID of the contact to remove from the group.

</ParamField>

<Callout kind="info">

API keys require the `contacts:write` scope for this endpoint.

</Callout>

#### Response fields

<ResponseField name="success" field-type="boolean" required="true">

Returns `true` when the contact is removed or was not a member.

</ResponseField>

#### Error responses

| Status | Meaning |
| --- | --- |
| `400` | Missing `contactId` |
| `401` | Missing authentication or account context |
| `404` | Group not found or does not belong to the account |
