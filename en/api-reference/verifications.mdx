## Endpoint summary

| Method | Path | Purpose | Auth |
| --- | --- | --- | --- |
| `POST` | `/api/verifications/filings` | Create a new filing, resume an existing draft, or reopen a rejected filing for resubmission | Session cookie |
| `GET` | `/api/verifications/filings/{bundleSid}` | Retrieve filing details for a regulatory bundle | Session cookie |
| `PUT` | `/api/verifications/filings/{bundleSid}` | Update filing data before submission | Session cookie |
| `POST` | `/api/verifications/filings/{bundleSid}/submit` | Submit a filing for carrier review and approval | Session cookie |
| `GET` | `/api/verifications/filings/{bundleSid}/documents` | List documents attached to a filing | Session cookie |
| `POST` | `/api/verifications/filings/{bundleSid}/documents` | Upload a document to a filing | Session cookie |
| `GET` | `/api/verifications/live` | Check live verification status across current filings | Session cookie |

<Callout kind="info">

All Verifications endpoints require an authenticated Talkturo session cookie. These routes use server-side session auth rather than API keys, so requests from backend integrations must act on behalf of a signed-in workspace user.

</Callout>

## Create or resume a filing

Create a regulatory filing for a phone number compliance workflow, or resume the active draft that already matches the same country and number type.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/verifications/filings" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=sb_session_example_8df31f; sb-refresh-token=sb_refresh_example_6ad92k" \
  -d '{
    "account": "acme-voice",
    "country": "US",
    "numberType": "local",
    "carrier": "twilio"
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/verifications/filings", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Cookie": "sb-access-token=sb_session_example_8df31f; sb-refresh-token=sb_refresh_example_6ad92k"
  },
  body: JSON.stringify({
    account: "acme-voice",
    country: "US",
    numberType: "local",
    carrier: "twilio"
  })
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,400" default-tab="1">
```json
{
  "success": true,
  "bundleSid": "BU7c9d2d9d6e5a4b1f8b7c3a2d4e9f1a2",
  "resumed": false
}
```

```json
{
  "error": "country is required"
}
```
</Response>

### Body parameters

<ParamField body="account" param-type="string" required="true">
Workspace slug that owns the filing.
</ParamField>

<ParamField body="carrier" param-type="string" required="false">
Carrier identifier for the filing workflow. If omitted, Talkturo uses the default carrier flow for the workspace.
</ParamField>

<ParamField body="country" param-type="string" required="true">
Two-character ISO country code for the filing, such as `US` or `CA`.
</ParamField>

<ParamField body="numberType" param-type="string" required="false" enum="local,toll-free,mobile,national">
Phone number category for the filing. Defaults to `local`.
</ParamField>

<ParamField body="resubmitOf" param-type="string" required="false">
Existing Twilio bundle SID to reopen as the basis for a new draft after rejection.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Indicates whether the filing was created or resumed successfully.
</ResponseField>

<ResponseField name="bundleSid" field-type="string" required="true">
Twilio regulatory bundle SID for the filing.
</ResponseField>

<ResponseField name="resumed" field-type="boolean" required="true">
Returns `true` when Talkturo found and reused an existing matching draft instead of creating a new bundle.
</ResponseField>

### Behavior

Without `resubmitOf`, Talkturo checks for an existing draft bundle with the same `country` and `numberType`. If a matching draft exists, the endpoint returns that bundle and sets `resumed` to `true`.

If you pass `resubmitOf`, Talkturo reopens the rejected bundle workflow and creates a fresh draft for fix-and-resubmit. Use this path when carrier review failed and you need to correct documents or filing details before sending a new submission.

<Callout kind="alert">

A filing is tied to a workspace and regulatory context. Reusing the wrong `account`, `country`, or `numberType` can resume a draft you did not intend to modify.

</Callout>

### Error responses

| Status | Meaning |
| --- | --- |
| `400` | Missing or invalid request body values |
| `401` | No authenticated session |
| `403` | Authenticated user does not have access to the workspace |
| `404` | Workspace or filing context was not found |
| `502` | Upstream carrier or regulatory bundle provider error |

## Update a filing

Update filing data before submission. Use this endpoint to save applicant information, business details, addresses, and any other regulatory fields required by the active bundle workflow.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash

  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=sb_session_example_8df31f; sb-refresh-token=sb_refresh_example_6ad92k" \
  -d '{
    "businessName": "Acme Voice LLC",
    "contactEmail": "ops@acmevoice.com",
    "contactPhone": "+14155550123",
    "addressLine1": "548 Market Street",
    "city": "San Francisco",
    "state": "CA",
    "postalCode": "94104"
  }'
```

## Upload a document

Upload a supporting document to a filing before submission. The document type and file contents must match the regulatory requirements for the selected country and number type.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/verifications/filings/BU7c9d2d9d6e5a4b1f8b7c3a2d4e9f1a2/documents" \
  -H "Cookie: sb-access-token=sb_session_example_8df31f; sb-refresh-token=sb_refresh_example_6ad92k" \
  -F "documentType=business_registration" \
  -F "file=@certificate-of-incorporation.pdf"
```

```javascript
const formData = new FormData();
formData.append("documentType", "business_registration");
formData.append(
  "file",
  new File(
    ["PDF-1.4 regulatory document bytes"],
    "certificate-of-incorporation.pdf",
    { type: "application/pdf" }
  )
);

const response = await fetch(
  "https://app.talkturo.com/api/verifications/filings/BU7c9d2d9d6e5a4b1f8b7c3a2d4e9f1a2/documents",
  {
    method: "POST",
    headers: {
      "Cookie": "sb-access-token=sb_session_example_8df31f; sb-refresh-token=sb_refresh_example_6ad92k"
    },
    body: formData
  }
);

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,400" default-tab="1">
```json
{
  "success": true,
  "document": {
    "id": "RD0f74e517ef5c4bb7b6d0f83ab438b8d1",
    "name": "certificate-of-incorporation.pdf",
    "type": "business_registration",
    "status": "uploaded"
  }
}
```

```json
{
  "error": "file is required"
}
```
</Response>

</Callout>
