## Endpoint summary

| Method | Path | Purpose | Auth |
| --- | --- | --- | --- |
| `GET` | `/api/sessions` | List desktop sessions | Desktop JWT |
| `POST` | `/api/sessions` | Create a session | Desktop JWT |
| `GET` | `/api/sessions/{id}` | Get a session by ID | Desktop JWT |
| `PATCH` | `/api/sessions/{id}` | Update or end a session | Desktop JWT |
| `DELETE` | `/api/sessions/{id}` | Delete a session | Desktop JWT |
| `POST` | `/api/sessions/end-all` | End all active sessions | Desktop JWT |

<Callout kind="info">

Authenticate every request with a desktop JWT in the `Authorization` header. To scope requests to a specific workspace, add the optional `X-Talkturo-Account` header.

</Callout>

## List sessions

Return the desktop sessions available to the authenticated user.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash

  --url "https://app.talkturo.com/api/sessions" \
  --header "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example.desktopjwt" \
  --header "X-Talkturo-Account: acc_northstar_sales"
```

## Create session

Create a new desktop session, or return the existing active session when you use `getOrCreateActive`.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request POST \
  --url "https://app.talkturo.com/api/sessions" \
  --header "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example.desktopjwt" \
  --header "X-Talkturo-Account: acc_northstar_sales" \
  --header "Content-Type: application/json" \
  --data '{
    "mode": "create",
    "session_type": "listen"
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/sessions", {
  method: "POST",
  headers: {
    Authorization: "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example.desktopjwt",
    "X-Talkturo-Account": "acc_northstar_sales",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    mode: "create",
    session_type: "listen",
  }),
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,400">
```json
{
  "id": "3be8aaea-a2c8-466f-9984-b8780b3d6a50"
}
```

```json
{
  "error": "Invalid session_type"
}
```
</Response>

### Headers

<ParamField header="Authorization" param-type="string" required="true">
Bearer token containing a desktop JWT.
</ParamField>

<ParamField header="X-Talkturo-Account" param-type="string" required="false">
Workspace scope for the new session.
</ParamField>

### Body parameters

<ParamField body="mode" param-type="string" required="false" enum="create,getOrCreateActive">
Session creation mode. Defaults to `create`. Use `getOrCreateActive` to reuse an existing active session instead of creating a new one.
</ParamField>

<ParamField body="session_type" param-type="string" required="false" enum="ask,listen">
Session type for the desktop app. Defaults to `ask`.
</ParamField>

### Response fields

<ResponseField name="id" field-type="string" required="true">
UUID of the created session, or the active session returned by `getOrCreateActive`.
</ResponseField>

### Errors

| Status | Meaning |
| --- | --- |
| `400` | Invalid request body |
| `401` | Missing or invalid desktop JWT |
| `500` | Server error |

## Update session

Update mutable fields on a session. Set `end` to `true` to complete the session, stamp `ended_at`, compute `duration_seconds`, and trigger background AI analysis.

<Callout kind="alert">

Ending a session is a state change, not a soft preview. When you send `end: true`, the API marks the session as `completed` and starts post-session analysis in the background.

</Callout>

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request PATCH \
  --url "https://app.talkturo.com/api/sessions/f9c5808d-e1da-4f1f-b1f0-d0b2f9923fc6" \
  --header "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example.desktopjwt" \
  --header "Content-Type: application/json" \
  --data '{
    "title": "Discovery call with Greenline Solar",
    "status": "completed",
    "notes": "Strong discovery questions. Missed budget confirmation.",
    "voice_metrics": {
      "talk_share_pct": 46,
      "wpm": 132,
      "patience_pct": 82,
      "longest_monologue_seconds": 38
    },
    "end": true
  }'
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/sessions/f9c5808d-e1da-4f1f-b1f0-d0b2f9923fc6",
  {
    method: "PATCH",
    headers: {
      Authorization: "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example.desktopjwt",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      title: "Discovery call with Greenline Solar",
      status: "completed",
      notes: "Strong discovery questions. Missed budget confirmation.",
      voice_metrics: {
        talk_share_pct: 46,
        wpm: 132,
        patience_pct: 82,
        longest_monologue_seconds: 38,
      },
      end: true,
    }),
  }
);

const data = await response.json();
console.log(data);
```
</Request>

```json

```

```json

```
