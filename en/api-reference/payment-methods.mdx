## Payment methods endpoints

Use the payment methods endpoints to list saved cards, attach new Stripe payment methods, set a default payment method, and remove saved methods for a Talkturo account.

<Callout kind="info">

**Authentication**

All payment method endpoints use API authentication and accept either:

- An API key in the `Authorization` header
- A signed-in session cookie

If you omit `accountId` where it is optional, the API falls back to the authenticated account when that context is available.

</Callout>

<Callout kind="alert">

Create `paymentMethodId` values with Stripe Elements before calling `POST /api/payment-methods`. The API expects a Stripe payment method ID in the `pm_` format and does not collect raw card details directly.

</Callout>

## Endpoint summary

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| GET | `/api/payment-methods` | API key or session | List saved payment methods for an account |
| POST | `/api/payment-methods` | API key or session | Add a new saved payment method |
| GET | `/api/payment-methods/[id]` | API key or session | Get one saved payment method |
| PATCH | `/api/payment-methods/[id]` | API key or session | Set a saved payment method as default |
| DELETE | `/api/payment-methods/[id]` | API key or session | Remove a saved payment method |

## List payment methods

`GET /api/payment-methods` returns the saved payment methods for an account. Use this endpoint to show available cards in billing settings or to confirm the current default payment method.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash

  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -H "Accept: application/json"
```

```javascript
const response = await fetch("https://api.talkturo.com/api/payment-methods?accountId=acc_7f3k2m9q", {
```

## Add a payment method

`POST /api/payment-methods` attaches a Stripe payment method to the account. Pass the Stripe `pm_` identifier created on the client side, and optionally make it the default immediately.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/payment-methods" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "accountId": "acc_7f3k2m9q",
    "paymentMethodId": "pm_1QyS7kD8wL9mN2pR4t6v8x0z",
    "setAsDefault": true
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/payment-methods", {
  method: "POST",
  headers: {
    "Authorization": "Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z",
    "Content-Type": "application/json",
    "Accept": "application/json"
  },
  body: JSON.stringify({
    accountId: "acc_7f3k2m9q",
    paymentMethodId: "pm_1QyS7kD8wL9mN2pR4t6v8x0z",
    setAsDefault: true
  })
});

const data = await response.json();
console.log(data);
```
</Request>

## Set a default payment method

`PATCH /api/payment-methods/[id]` marks an existing saved payment method as the account default. The API updates the default through the billing RPC used by Talkturo internally.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash

  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -H "Accept: application/json"
```

```javascript
const response = await fetch("https://api.talkturo.com/api/payment-methods/6c1e4f7a-92b7-4a6f-8f52-5b60e6f1a1c4?accountId=acc_7f3k2m9q", {
  method: "PATCH",
  headers: {
    "Authorization": "Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z",
    "Accept": "application/json"

```

## Remove a payment method

`DELETE /api/payment-methods/[id]` soft-deletes the saved payment method record and detaches the payment method from Stripe. If you remove the current default, the API promotes another saved payment method as the new default when one is available.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash

  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -H "Accept: application/json"
```

```javascript
const response = await fetch("https://api.talkturo.com/api/payment-methods/6c1e4f7a-92b7-4a6f-8f52-5b60e6f1a1c4?accountId=acc_7f3k2m9q", {
  method: "DELETE",
  headers: {
```

## Error behavior

Payment method endpoints return standard HTTP status codes for validation and billing state errors. The most common cases are:

| Status | When it happens |
| --- | --- |
| 400 | Required fields are missing, or the API cannot resolve `accountId` |
| 404 | The account has no billing customer, or the payment method does not exist |
| 409 | The payment method is already attached |
| 502 | Stripe detachment fails during removal |
