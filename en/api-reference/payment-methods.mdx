## Endpoints at a glance

Use the Payment Methods endpoints to list saved billing methods, attach a new Stripe payment method, mark a method as default, and remove a method from a Talkturo billing account.

<Callout kind="info">

Authenticate with either an API key or a signed-in session. These endpoints use Talkturo's shared API auth flow, so you can send `Authorization: Bearer tk_live_example_9xmk7q2r` or a valid session bearer token. If your API key does not resolve an account automatically, include `accountId` in the request.

</Callout>

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/api/payment-methods` | List payment methods |
| `POST` | `/api/payment-methods` | Add a payment method |
| `PATCH` | `/api/payment-methods/{id}` | Update a payment method |
| `DELETE` | `/api/payment-methods/{id}` | Remove a payment method |

## Add a payment method

Attach a Stripe PaymentMethod to the account's Stripe customer, then store a Talkturo billing record for it.

<Request>
```json
POST /api/payment-methods
Authorization: Bearer tk_live_example_9xmk7q2r
Content-Type: application/json

{
  "accountId": "3f2d7b4c-8a11-4c69-9a2c-21f6f1d29e41",
  "paymentMethodId": "pm_1Qz7R8K2exampleC62",
  "setAsDefault": true
}
```
</Request>

<Response>
```json
{
  "success": true,
  "paymentMethod": {
    "id": "9bc66f68-57ec-4f6c-b3a6-e9c64edda22e",
    "stripe_payment_method_id": "pm_1Qz7R8K2exampleC62",
    "card_brand": "visa",
    "card_last4": "4242",
    "card_exp_month": 10,
    "card_exp_year": 2029,
    "is_default": true
  }
}
```
</Response>

### Body parameters

<ParamField body="accountId" param-type="string" required="true">
Account UUID to attach the payment method to.
</ParamField>

<ParamField body="paymentMethodId" param-type="string" required="true">
Stripe PaymentMethod ID created on the client, typically from Stripe.js Elements.
</ParamField>

<ParamField body="setAsDefault" param-type="boolean" required="false">
Set to `true` to make the new payment method the account default after it is attached and stored.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Always `true` for a successful response.
</ResponseField>

<ResponseField name="paymentMethod" field-type="object" required="true">
Stored payment method summary.
</ResponseField>

<ResponseField name="paymentMethod.id" field-type="string" required="true">
Talkturo payment method record ID.
</ResponseField>

<ResponseField name="paymentMethod.stripe_payment_method_id" field-type="string" required="true">
Stripe PaymentMethod ID.
</ResponseField>

<ResponseField name="paymentMethod.card_brand" field-type="string" required="false">
Card network reported by Stripe.
</ResponseField>

<ResponseField name="paymentMethod.card_last4" field-type="string" required="false">
Last four digits of the card number.
</ResponseField>

<ResponseField name="paymentMethod.card_exp_month" field-type="number" required="false">
Card expiration month.
</ResponseField>

<ResponseField name="paymentMethod.card_exp_year" field-type="number" required="false">
Card expiration year.
</ResponseField>

<ResponseField name="paymentMethod.is_default" field-type="boolean" required="true">
Whether the new payment method is now the default.
</ResponseField>

<Callout kind="info">

Talkturo attaches the Stripe PaymentMethod to the Stripe customer before writing the database record. If the database insert fails after the Stripe attach succeeds, Talkturo automatically detaches the payment method to avoid leaving an orphaned Stripe record.

</Callout>

## Remove a payment method

Soft-delete a payment method record and detach the underlying Stripe PaymentMethod from the Stripe customer.

<Request>
```bash
curl -X DELETE "https://api.talkturo.com/api/payment-methods/9bc66f68-57ec-4f6c-b3a6-e9c64edda22e?accountId=3f2d7b4c-8a11-4c69-9a2c-21f6f1d29e41" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -H "Accept: application/json"
```
</Request>

<Response>
```json
{
  "success": true
}
```
</Response>

### Path parameters

<ParamField path="id" param-type="string" required="true">
Talkturo payment method record ID to remove.
</ParamField>

### Query parameters

<ParamField query="accountId" param-type="string" required="true">
Account UUID that owns the payment method.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Returned as `true` when the payment method was removed successfully.
</ResponseField>

### Error responses

| Status | Response body |
| --- | --- |
| `400` | Missing required account or payment method identifier |
| `401` | Authentication error |
| `404` | Billing customer or payment method not found |
| `500` | `{"success": false, "error": "..."}` |

<Callout kind="info">

Delete performs a soft delete by setting `deleted_at` on the Talkturo record. Subsequent list requests do not return soft-deleted payment methods.

</Callout>
