## Manage outbound CRM campaigns

Use the CRM Campaigns API to create outbound calling campaigns, enroll contacts, control dialing behavior, monitor execution, and retrieve campaign results. The endpoints support both authenticated session cookies and API key authentication.

<Callout kind="info">

For session authentication, provide `teamId` on campaign list and create requests. For API key authentication, send the key using the authentication scheme supported by your Talkturo account.

</Callout>

## Endpoint summary

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/crm/campaigns` | List campaigns |
| `POST` | `/api/crm/campaigns` | Create a campaign |
| `GET` | `/api/crm/campaigns/[id]` | Retrieve a campaign |
| `PUT` | `/api/crm/campaigns/[id]` | Update a campaign |
| `DELETE` | `/api/crm/campaigns/[id]` | Delete a campaign |
| `GET` | `/api/crm/campaigns/[id]/contacts` | List campaign contacts |
| `POST` | `/api/crm/campaigns/[id]/contacts` | Add contacts to a campaign |
| `GET` | `/api/crm/campaigns/[id]/dashboard` | Retrieve campaign execution data |
| `POST` | `/api/crm/campaigns/[id]/run` | Start a campaign run or perform a dry run |
| `POST` | `/api/crm/campaigns/preview-enrollment` | Preview audience enrollment |
| `GET` | `/api/crm/outbound-assistants` | List outbound assistants |
| `GET` | `/api/crm/calls` | List CRM call logs |
| `GET` | `/api/crm/intelligence` | Retrieve AI insights |

## Common workflow

Use the following sequence to create, validate, run, and monitor a campaign.

<Steps>

<Step title="Create the campaign" icon="plus">

Send `POST /api/crm/campaigns` with an assistant, at least one outbound number, and a campaign name. Use the `enrollment` object when the campaign should enroll an audience during creation.

</Step>

<Step title="Preview enrollment" icon="search">

Send `POST /api/crm/campaigns/preview-enrollment` with the campaign ID and audience filters. Confirm the `preview` counts before inserting contacts.

</Step>

<Step title="Enroll contacts" icon="upload">

Add existing contacts, create an inline contact, or submit an audience through `POST /api/crm/campaigns/[id]/contacts`. Confirm the `added` and `enrollment` values in the response.

</Step>

<Step title="Run the campaign" icon="play-circle">

Call `POST /api/crm/campaigns/[id]/run` with `accountSlug`. Use `dryRun` first when you need to inspect the selected contacts. A normal run returns `dialing: async`; the external dialer places calls on its next tick.

</Step>

<Step title="Monitor execution" icon="bar-chart">

Poll `GET /api/crm/campaigns/[id]/dashboard` to read status and outcome counts, queue contents, and recent calls.

</Step>

</Steps>
