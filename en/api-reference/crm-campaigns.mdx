## Manage outbound CRM campaigns

Use the CRM Campaigns endpoints to create outbound calling campaigns, preview enrollment, attach contacts, monitor live progress, and start or stop execution. All CRM campaign endpoints accept either an API key in the `Authorization` header or an authenticated Talkturo session cookie.

<Callout kind="info">

Authenticate these endpoints with either a Bearer API key or a valid Talkturo session cookie. Server-to-server integrations should use `Authorization: Bearer tk_live_example_9xmk7q2r`.

</Callout>

## Endpoint summary

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/crm/campaigns` | List campaigns |
| `POST` | `/api/crm/campaigns` | Create a campaign |
| `GET` | `/api/crm/campaigns/preview-enrollment` | Preview contact enrollment |
| `GET` | `/api/crm/campaigns/[id]` | Retrieve one campaign |
| `PUT` | `/api/crm/campaigns/[id]` | Update a campaign |
| `DELETE` | `/api/crm/campaigns/[id]` | Delete a campaign |
| `GET` | `/api/crm/campaigns/[id]/contacts` | List campaign contacts |
| `POST` | `/api/crm/campaigns/[id]/contacts` | Add contacts to a campaign |
| `GET` | `/api/crm/campaigns/[id]/dashboard` | Retrieve real-time campaign stats |
| `POST` | `/api/crm/campaigns/[id]/run` | Start or stop a campaign |
| `GET` | `/api/crm/outbound-assistants` | List assistants available for outbound calls |
| `GET` | `/api/crm/calls` | List CRM call logs |
| `GET` | `/api/crm/intelligence` | Retrieve AI insights |

## Create a campaign

Create a new outbound campaign with enrollment rules, call window settings, retry defaults, and webhook delivery options.

<Request>
```bash

  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -d '{
    "teamId": "8b9d7c42-0c95-4e96-8f3d-0bd3f7bf2c51",
    "assistantId": "c14cb1c2-6f2d-4f14-97df-caf4fd7776bb",
    "fromNumberIds": [
      "num_2ec5fa4a-7813-4f1b-bf89-f6a2d8f6f460"
    ],
    "name": "Q3 renewal outreach",
    "description": "Follow-up calls for accounts renewing this quarter",
    "scheduledStartAt": "2026-08-13T16:00:00Z",
    "callWindowStart": "09:00",
    "callWindowEnd": "18:00",
    "callWindowTimezone": "America/Los_Angeles",
    "maxConcurrentCalls": 5,
    "maxAttemptsPerContact": 3,
    "retryDelayMinutes": 60,
    "liveSync": true,
    "webhookEnabled": true,
    "webhookUrl": "https://ops.acme.io/talkturo/campaign-events",
    "webhookSecret": "whsec_example_2n4k8p1s",
    "webhookEvents": [
      "call.completed"
    ],
    "enrollment": {
      "mode": "delta",
      "notYetDialed": true,
      "addedAfter": "2026-08-01T00:00:00Z",
      "leadStatus": "open",
      "maxToAdd": 500
    }
  }'
```
</Request>

      "leadStatus": "open",

    }
  }
}

</Response>

<Callout kind="info">

Enrollment mode controls which contacts are added when the campaign is created. Use `all_eligible` to enroll all matching contacts, `delta` to enroll only new matching contacts since the last run, or `none` to create the campaign without enrollment.

</Callout>

<Callout kind="info">

Setting `liveSync` to `true` also sets `noAutoComplete` to `true`. Use this mode when the campaign should keep syncing newly eligible contacts in real time.

</Callout>

<Callout kind="alert">

Starting an outbound campaign requires at least 1 credit. Talkturo also enforces one active campaign per assistant.

</Callout>

## Common workflow

Most campaign integrations follow the same path:

<Steps>

<Step title="List outbound assistants" icon="users">

Call `GET /api/crm/outbound-assistants` and select the assistant you want to use for outbound calls.

</Step>

<Step title="Create the campaign" icon="plus">

Create a campaign with `POST /api/crm/campaigns`. A successful response returns `success: true` and a new `campaign.id`.

</Step>

<Step title="Add contacts" icon="upload">

Attach contacts with `POST /api/crm/campaigns/[id]/contacts`. After the request succeeds, the response includes a `contacts` array.

</Step>

<Step title="Start the run" icon="play-circle">

Send `POST /api/crm/campaigns/[id]/run` with `action` set to `start`. The response returns `status: running` when execution begins.

</Step>

<Step title="Monitor progress" icon="bar-chart">

Poll `GET /api/crm/campaigns/[id]/dashboard` to track `totalCalls`, `answered`, `failed`, and `inProgress` while the campaign runs.

</Step>

</Steps>
