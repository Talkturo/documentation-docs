## Manage outbound CRM campaigns

Use the CRM Campaigns endpoints to create outbound calling campaigns, enroll contacts, start campaign runs, and monitor live execution. Authentication and request shape vary by endpoint, so check each section before you integrate.

<Callout kind="info">

Authentication differs across campaign routes:

- `GET` and `POST` on `/api/crm/campaigns` accept API key or session authentication.
- `GET`, `PUT`, and `DELETE` on `/api/crm/campaigns/[id]` require a session cookie.
- `GET` and `POST` on `/api/crm/campaigns/[id]/contacts` accept API key or session authentication.
- `GET` on `/api/crm/campaigns/[id]/dashboard` requires a session cookie.
- `POST` on `/api/crm/campaigns/[id]/run` accepts API key or session authentication.

API key requests to contact enrollment and run routes require the appropriate campaign scopes.

</Callout>

## Endpoint summary

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/crm/campaigns` | List campaigns |
| `POST` | `/api/crm/campaigns` | Create a campaign |
| `GET` | `/api/crm/campaigns/[id]` | Retrieve one campaign |
| `PUT` | `/api/crm/campaigns/[id]` | Update a campaign |
| `DELETE` | `/api/crm/campaigns/[id]` | Soft delete a campaign |
| `GET` | `/api/crm/campaigns/[id]/contacts` | List campaign contacts |
| `POST` | `/api/crm/campaigns/[id]/contacts` | Add contacts to a campaign |
| `DELETE` | `/api/crm/campaigns/[id]/contacts` | Remove contacts from a campaign |
| `GET` | `/api/crm/campaigns/[id]/dashboard` | Retrieve dashboard metrics and queue state |
| `POST` | `/api/crm/campaigns/[id]/run` | Start a campaign run |

## Create a campaign

Create a campaign with a team, assistant, company, and one or more outbound numbers. The assistant, company, and numbers must belong to the same team.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/campaigns" \
  -H "Content-Type: application/json" \
  -H "x-api-key: ttr_example_api_9xmk7q2r" \
  -d '{
    "teamId": "team_7f3a2d91",
    "assistantId": "ast_9c41f8e2-7e93-4f8e-8d6c-2c9bdf8b9a33",
    "companyId": "co_29d4e1af",
    "fromNumberIds": [
      "num_3f1d9a22",
      "num_9b2a13d8"
    ],
    "name": "Q3 renewal outreach",
    "description": "Renewal follow-up for accounts expiring this quarter",
    "scheduledStartAt": "2026-08-13T16:00:00Z",
    "callWindowStart": "09:00",
    "callWindowEnd": "17:30",
    "callWindowTimezone": "America/Los_Angeles",
    "maxConcurrentCalls": 4,
    "maxAttemptsPerContact": 3,
    "retryDelayMinutes": 30,
    "settings": {
      "no_auto_complete": false
    },
    "noAutoComplete": false,
    "webhookEnabled": true,
    "webhookUrl": "https://ops.acme.io/talkturo/campaign-events",
    "webhookSecret": "whsec_example_4m8q2k1n",
    "webhookEvents": [
      "campaign.started",
      "campaign.completed",
      "call.completed"
    ]
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "campaign": {
    "id": "cmp_6df44cc0-5e10-4b0d-a3f5-ec6116f8c7d1",
    "team_id": "team_7f3a2d91",
```

<Callout kind="info">

Status changes have special rules:

- You cannot move a `completed` or `cancelled` campaign back to `draft`, `scheduled`, or `running`.
- When a campaign is already `running`, only status changes are allowed. Configuration changes return `409`.
- Changing status to `running` requires at least one available credit. The route returns `402` when credits are insufficient.
- Changing status to `running` sets `started_at` and `started_by`.
- Changing status to `completed` or `cancelled` sets `completed_at`.

</Callout>

## Common workflow

Most campaign integrations follow the same execution path.

<Steps>

<Step title="Create the campaign" icon="plus">

Send `POST /api/crm/campaigns` with `teamId`, `assistantId`, `companyId`, `fromNumberIds`, and `name`. A successful response returns `success: true` and a new `campaign.id`.

</Step>

<Step title="Add contacts" icon="upload">

Enroll contacts with `POST /api/crm/campaigns/[id]/contacts`. Success responses include `added`, `skipped`, and a summary `message`.

</Step>

<Step title="Start the run" icon="play-circle">

Call `POST /api/crm/campaigns/[id]/run` to move the campaign into `running` status and start outbound calls. Use `dryRun: true` first if you want to validate picks without placing calls.

</Step>

<Step title="Monitor the dashboard" icon="bar-chart">

Poll `GET /api/crm/campaigns/[id]/dashboard` to track queue counts, outcome counts, pending work, active calls, and recent call results.

</Step>

</Steps>
