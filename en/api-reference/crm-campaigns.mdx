## Manage outbound CRM campaigns

Use the CRM Campaigns endpoints to create outbound calling campaigns, attach contacts, list and retrieve campaigns, and control campaign status. Authentication depends on the route: collection routes support API key or session cookie authentication, while campaign-specific routes require a valid Talkturo session cookie.

<Callout kind="info">

Use either an API key or a valid Talkturo session cookie for `GET /api/crm/campaigns` and `POST /api/crm/campaigns`. Use a valid Talkturo session cookie for `GET`, `PUT`, and `DELETE` requests to `/api/crm/campaigns/[id]` and for campaign contact routes.

</Callout>

## Endpoint summary

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/crm/campaigns` | List campaigns |
| `POST` | `/api/crm/campaigns` | Create a campaign |
| `GET` | `/api/crm/campaigns/[id]` | Retrieve one campaign |
| `PUT` | `/api/crm/campaigns/[id]` | Update a campaign or change campaign status |
| `DELETE` | `/api/crm/campaigns/[id]` | Soft-delete a campaign |
| `GET` | `/api/crm/campaigns/[id]/contacts` | List campaign contacts |
| `POST` | `/api/crm/campaigns/[id]/contacts` | Add contacts to a campaign |

## Create a campaign

  -H "Content-Type: application/json" \
  -H "x-api-key: ttr_example_live_9xmk7q2r" \
  -d '{
    "teamId": "team_2a9f5e14-3d0d-4df5-bec7-b0c5a1f9ef40",
    "assistantId": "ast_9c41f8e2-7e93-4f8e-8d6c-2c9bdf8b9a33",
    "companyId": "co_6af7fdf4-8d84-46f7-8bd6-2f0a1c9f35c8",
    "fromNumberIds": [
      "pn_34a0f61a-52b4-4c9d-a6ef-0e8a3fd72f11"
    ],
    "name": "Q3 renewal outreach",
    "description": "Call active accounts before renewal dates",
    "scheduledStartAt": "2026-08-13T16:00:00Z",
    "callWindowStart": "09:00",
    "callWindowEnd": "17:30",
    "callWindowTimezone": "America/Los_Angeles",
    "maxConcurrentCalls": 8,
    "maxAttemptsPerContact": 3,

## Campaign status workflow

Campaign execution is controlled through the campaign `status` field on `PUT /api/crm/campaigns/[id]`.

- Create the campaign in `draft` or `scheduled`.
- Add contacts through `POST /api/crm/campaigns/[id]/contacts`.
- Start the campaign by updating `status` to `running`.
- Pause execution by updating `status` to `paused`.
- Cancel execution by updating `status` to `cancelled`.

If a campaign is already `running`, send a status-only update until the campaign leaves the running state.
