## Manage CRM custom fields

Custom fields let you extend Talkturo CRM records with data that does not fit the default schema. Use these endpoints to create, list, update, and delete field definitions for **contacts** and **companies**.

<Callout kind="info">

All CRM custom field endpoints require **session cookie authentication**. These endpoints do not accept API keys.

</Callout>

## Endpoints at a glance

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/api/crm/custom-fields` | List custom fields |
| `POST` | `/api/crm/custom-fields` | Create a custom field |
| `GET` | `/api/crm/custom-fields/{id}` | Get one custom field by ID |
| `PUT` | `/api/crm/custom-fields/{id}` | Update a custom field |
| `DELETE` | `/api/crm/custom-fields/{id}` | Delete a custom field |

## Supported field types and entity types

Create custom fields with one of these field types:

- **`text`** — short text values
- **`number`** — numeric values
- **`boolean`** — true or false values
- **`date`** — date values
- **`select`** — one value from a predefined list
- **`textarea`** — longer freeform text values

Attach each field to one supported CRM entity type:

- **`company`**
- **`contact`**

If you create a `select` field, send an `options` object with an `options` array inside it.

## List custom fields

Returns the custom fields available for a team. Filter the results by entity type, and include inactive fields when you need the full set.

<Request>
```bash
curl -X GET "https://app.talkturo.com/api/crm/custom-fields?teamId=team_9f2d3a1c&entityType=company&includeInactive=true" \
  -H "Cookie: sb-access-token=sb_session_example_f84k2m"
```
</Request>

## Create a custom field

Creates a new custom field definition for a contact or company. The API normalizes `key` to snake case before validation and storage.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/custom-fields" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=sb_session_example_f84k2m" \
  -d '{
    "teamId": "team_9f2d3a1c",
    "entityType": "company",
    "key": "Customer Tier",
    "label": "Customer tier",
    "fieldType": "select",
    "options": {
      "options": ["Starter", "Growth", "Enterprise"]
    },
    "isRequired": false,
    "sortOrder": 10,
    "isActive": true
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "field": {
    "id": "ec607f3e-77c8-45e7-a58d-62b8d09c4d5d",
    "entity_type": "company",
    "key": "customer_tier",
    "label": "Customer tier",
    "field_type": "select",
    "options": {
      "options": [
        "Starter",
        "Growth",
        "Enterprise"
      ]
    },
    "is_required": false,
    "sort_order": 10,
    "is_active": true
  }
}
```
</Response>

### Body parameters

<ParamField body="teamId" param-type="string" required="true">
Team ID that owns the new custom field.
</ParamField>

<ParamField body="entityType" param-type="string" required="true" enum="company,contact">
CRM entity type that this field applies to.
</ParamField>

<ParamField body="key" param-type="string" required="true">
Unique field key. The API normalizes the value to snake case, then validates it against `^[a-z][a-z0-9_]{1,63}$`.
</ParamField>

<ParamField body="label" param-type="string" required="true">
Human-readable display label shown in the CRM. This value cannot be blank.
</ParamField>

<ParamField body="fieldType" param-type="string" required="true" enum="text,number,boolean,date,select,textarea">
Type of field to create.
</ParamField>

<ParamField body="options" param-type="object" required="false">
Field-specific options object. For `select` fields, send an `options.options` array with one or more string values.
</ParamField>

<ParamField body="isRequired" param-type="boolean" required="false">
Marks the field as required. Defaults to `false`.
</ParamField>

<ParamField body="sortOrder" param-type="number" required="false">
Controls display order in the CRM. Defaults to `0`.
</ParamField>

<ParamField body="isActive" param-type="boolean" required="false">
Controls whether the field is active and visible. Defaults to `true`.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
`true` when the field is created successfully.
</ResponseField>

<ResponseField name="field" field-type="object" required="true">
The newly created custom field definition.
</ResponseField>

## Update a custom field

Updates an existing custom field definition. Use this endpoint to change the display label, field type, options, required status, sort order, or active status.

<Callout kind="info">

`key`, `entityType`, and `teamId` are immutable. Set those values when you create the field.

</Callout>

<Request>
```bash
curl -X PUT "https://app.talkturo.com/api/crm/custom-fields/ec607f3e-77c8-45e7-a58d-62b8d09c4d5d" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=sb_session_example_f84k2m" \
  -d '{
    "label": "Account tier",
    "fieldType": "select",
    "options": {
      "options": ["Starter", "Growth", "Enterprise", "Strategic"]
    },
    "isRequired": true,
    "sortOrder": 5,
    "isActive": true
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "field": {
    "id": "ec607f3e-77c8-45e7-a58d-62b8d09c4d5d",
    "entity_type": "company",
    "key": "customer_tier",
    "label": "Account tier",
    "field_type": "select",
    "options": {
      "options": [
        "Starter",
        "Growth",
        "Enterprise",
        "Strategic"
      ]
    },
    "is_required": true,
    "sort_order": 5,
    "is_active": true
  }
}
```
</Response>

### Path parameters

<ParamField path="id" param-type="string" required="true">
UUID of the custom field to update.
</ParamField>

### Body parameters

<ParamField body="label" param-type="string" required="false">
New display label for the field.
</ParamField>

<ParamField body="fieldType" param-type="string" required="false" enum="text,number,boolean,date,select,textarea">
New field type. The value must be one of the supported field types.
</ParamField>

<ParamField body="options" param-type="object" required="false">
Replacement options object for the field. For `select` fields, send an `options.options` array.
</ParamField>

<ParamField body="isRequired" param-type="boolean" required="false">
Updates whether the field is required.
</ParamField>

<ParamField body="sortOrder" param-type="number" required="false">
Updates the field display order.
</ParamField>

<ParamField body="isActive" param-type="boolean" required="false">
Toggles field visibility without deleting the definition.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
`true` when the update succeeds.
</ResponseField>

<ResponseField name="field" field-type="object" required="true">
The updated custom field definition.
</ResponseField>
