## Endpoint summary

| Method | Path | Purpose | Auth |
| --- | --- | --- | --- |
| `GET` | `/api/tts-voices` | List system voices and optionally merge cloned voices for an account | Public |
| `POST` | `/api/voice-cloning` | Create a cloned voice from an enrollment audio sample | Session cookie |
| `GET` | `/api/voice-providers/models` | List supported models for a voice provider | Public |
| `GET` | `/api/voice-providers/voices` | List provider voices from legacy providers | Public, deprecated |
| `GET` | `/api/voice-cloning` | List cloned voices for an account | Session cookie |
| `DELETE` | `/api/voice-cloning/{voiceId}` | Delete a cloned voice | Session cookie |
| `POST` | `/api/tts-voices/cartesia-preview` | Generate a Cartesia voice preview | Session cookie |
| `POST` | `/api/tts-voices/dashscope-preview` | Generate a DashScope voice preview | Session cookie |
| `POST` | `/api/tts-voices/inworld-preview` | Generate an Inworld voice preview | Session cookie |
| `POST` | `/api/tts-voices/kugel-preview` | Generate a Kugel voice preview | Session cookie |

<Callout kind="info">

`GET /api/tts-voices`, `GET /api/voice-providers/models`, and `GET /api/voice-providers/voices` do not require caller authentication. `POST /api/voice-cloning` requires a valid session cookie and verifies that your user belongs to the target account.

</Callout>

<Callout kind="alert">

`GET /api/voice-providers/voices` is deprecated. Use `GET /api/tts-voices` for new integrations.

</Callout>

## GET /api/tts-voices

List available TTS voices across Talkturo system voices and, when you provide an account ID, cloned voices owned by that account.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl "https://app.talkturo.com/api/tts-voices?provider=all&accountId=9b9c8c1d-7c35-4f8a-8d5d-2e7a5c9d1123"
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/tts-voices?provider=all&accountId=9b9c8c1d-7c35-4f8a-8d5d-2e7a5c9d1123"
);

const voices = await response.json();
console.log(voices);
```
</Request>

### Query parameters

<ParamField query="provider" param-type="string" required="false">
Filter voices by provider name. Pass `all` to return voices from every provider. If omitted, the endpoint returns the default unfiltered result set.
</ParamField>

<ParamField query="accountId" param-type="string" required="false">
Account UUID used to merge cloned voices with system voices. Without `accountId`, the response only includes public system voices.
</ParamField>

### Response fields

<ResponseField name="id" field-type="string">
Unique voice record ID in Talkturo.
</ResponseField>

<ResponseField name="provider" field-type="string">
Voice provider name such as `elevenlabs`, `cartesia`, or `dashscope`.
</ResponseField>

<ResponseField name="voice_id" field-type="string">
Provider-specific voice identifier used when generating speech.
</ResponseField>

<ResponseField name="name" field-type="string">
Display name of the voice.
</ResponseField>

<ResponseField name="description" field-type="string">
Short description of the voice. Some records may store an empty string or `null`.
</ResponseField>

<ResponseField name="language" field-type="string">
Language code or provider language label for the voice.
</ResponseField>

<ResponseField name="preview_url" field-type="string">
Preview audio URL when the provider or stored record includes one. This field may be `null`.
</ResponseField>

<ResponseField name="metadata" field-type="object">
Provider-specific metadata stored with the voice record.
</ResponseField>

<ResponseField name="voice_model" field-type="string">
Provider model associated with the voice.
</ResponseField>

<ResponseField name="account_id" field-type="string">
Owning account UUID for cloned voices. System voices return `null`.
</ResponseField>

<ResponseField name="voice_type" field-type="string">
Voice origin. Values are `system` or `cloned`.
</ResponseField>

### Error responses

| Status | Meaning |
| --- | --- |
| `500` | The server failed to fetch or assemble the voice list. |

## POST /api/voice-cloning

Create a cloned voice by submitting an enrollment audio sample for an account you can access.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/voice-cloning" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=sample_session_cookie" \
  -d '{
    "accountId": "9b9c8c1d-7c35-4f8a-8d5d-2e7a5c9d1123",
    "preferred_name": "Jane Sales Demo",
    "language": "en",
    "audio_base64": "UklGRiS3AABXQVZFZm10IBAAAAABAAEAQB8AAEAfAAABAAgAZGF0YcS2AAB/f39/fn5+fn19fXx8fHt7e3p6enl5eXd3d3Z2dnV1dXV0dHRzc3NycnJxcXFwcHBvb29ubm5tbW1sbGxra2tqamppaWlo",
    "audio_mime_type": "audio/wav"
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/voice-cloning", {
  method: "POST",
  credentials: "include",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    accountId: "9b9c8c1d-7c35-4f8a-8d5d-2e7a5c9d1123",
    preferred_name: "Jane Sales Demo",
    language: "en",
    audio_base64: "UklGRiS3AABXQVZFZm10IBAAAAABAAEAQB8AAEAfAAABAAgAZGF0YcS2AAB/f39/fn5+fn19fXx8fHt7e3p6enl5eXd3d3Z2dnV1dXV0dHRzc3NycnJxcXFwcHBvb29ubm5tbW1sbGxra2tqamppaWlo",
    audio_mime_type: "audio/wav"
```

### Request body

<ParamField body="accountId" param-type="string" required="true">
Account UUID that will own the cloned voice. The server checks that your authenticated user belongs to this account before creating the enrollment.
</ParamField>

<ParamField body="preferred_name" param-type="string" required="false">
Display name to store for the cloned voice. If omitted, Talkturo uses the provider enrollment result or a server-defined fallback.
</ParamField>

<ParamField body="language" param-type="string" required="false">
Language label to associate with the cloned voice.
</ParamField>

<ParamField body="audio_base64" param-type="string" required="true">
Base64-encoded audio sample used for voice enrollment.
</ParamField>

<ParamField body="audio_mime_type" param-type="string" required="false">
MIME type for the enrollment audio. Defaults to `audio/wav`.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Returns `true` when the voice was enrolled and stored successfully.
</ResponseField>

<ResponseField name="voice" field-type="object" required="true">
Stored cloned voice record from `tts_voices`.
</ResponseField>

<ResponseField name="voice.id" field-type="string">
Unique voice record ID in Talkturo.
</ResponseField>

<ResponseField name="voice.provider" field-type="string">
Provider used for enrollment. This flow submits voice cloning to DashScope.
</ResponseField>

<ResponseField name="voice.voice_id" field-type="string">
Provider-specific ID for the enrolled cloned voice.
</ResponseField>

<ResponseField name="voice.name" field-type="string">
Stored display name for the cloned voice.
</ResponseField>

<ResponseField name="voice.description" field-type="string">
Description saved with the cloned voice record.
</ResponseField>

<ResponseField name="voice.language" field-type="string">
Language associated with the cloned voice.
</ResponseField>

<ResponseField name="voice.preview_url" field-type="string">
Preview audio URL if available. This field may be `null`.
</ResponseField>

<ResponseField name="voice.metadata" field-type="object">
Provider enrollment details and Talkturo metadata stored with the voice.
</ResponseField>

<ResponseField name="voice.voice_model" field-type="string">
Model name associated with the cloned voice.
</ResponseField>

<ResponseField name="voice.account_id" field-type="string">
Owning account UUID for the cloned voice.
</ResponseField>

<ResponseField name="voice.voice_type" field-type="string">
Always `cloned` for this endpoint.
</ResponseField>

### Error responses

| Status | Meaning |
| --- | --- |
| `400` | Missing required `accountId` or `audio_base64`. |
| `403` | Your session does not have access to the target account. |
| `502` | DashScope returned an upstream enrollment error. |
| `503` | The DashScope API key is not configured on the server. |
| `500` | Talkturo failed to insert the cloned voice into `tts_voices`. |

<Callout kind="alert">

This endpoint expects a full base64-encoded audio payload in the request body. Large samples increase request size and can trigger upstream or gateway limits. Keep enrollment clips short and clean.

</Callout>

## List cloned voices

Retrieve cloned voices for a specific account. Requires an authenticated session and account membership.

### Endpoint

`GET /api/voice-cloning`

### Query parameters

<ParamField query="accountId" param-type="string" required="true">
Account UUID to list cloned voices for.
</ParamField>

### Response fields

<ResponseField name="voices" field-type="array">
Array of cloned voice records. Each record includes `id`, `provider`, `voice_id`, `name`, `description`, `language`, `preview_url`, `metadata`, `voice_model`, `account_id`, and `voice_type`, which is always `cloned`.
</ResponseField>

## Delete a cloned voice

Remove a cloned voice by its ID. The voice is removed from both Talkturo and the provider when applicable.

### Endpoint

`DELETE /api/voice-cloning/{voiceId}`

### Path parameters

<ParamField path="voiceId" param-type="string" required="true">
The ID of the cloned voice to delete.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Returns `true` when the cloned voice is deleted.
</ResponseField>

## Voice previews

Generate preview audio for specific TTS providers. All preview endpoints require session authentication and return an audio response or a URL to the generated preview audio.

| Method | Path | Provider |
| --- | --- | --- |
| `POST` | `/api/tts-voices/cartesia-preview` | Cartesia |
| `POST` | `/api/tts-voices/dashscope-preview` | DashScope |
| `POST` | `/api/tts-voices/inworld-preview` | Inworld |
| `POST` | `/api/tts-voices/kugel-preview` | Kugel/Fish |

Each preview endpoint accepts a voice ID and preview text in the request body, generates a short audio sample, and returns the preview audio. Use these endpoints to let users audition voices before assigning them to an assistant.

### Common body parameters

<ParamField body="voiceId" param-type="string" required="true">
Provider-specific voice ID to preview.
</ParamField>

<ParamField body="text" param-type="string" required="true">
Text to synthesize for the preview.
</ParamField>

### Common response

<ResponseField name="url" field-type="string">
URL to the generated preview audio file, or the audio data directly depending on the provider.
</ResponseField>
