## Overview

Manage inbox contacts, review call and email timelines, send emails, configure assistant mailboxes, organize threads, download attachments, and process Nylas events through the Inbox API.

<Callout kind="info">

All Inbox endpoints except the Nylas webhook require session authentication. Use an authenticated Supabase browser session or a bearer session token. API key authentication is rejected with HTTP `403` and the error `Not available with an API key`.

Include `accountSlug` with bearer-session requests. Cookie-based browser requests can use `accountSlug` or `teamId` to select the workspace.

</Callout>

| `GET` | `/api/inbox/assistants/{assistantId}/calls` | List calls for an assistant |
| `GET` | `/api/inbox/assistants/{assistantId}/calls/{callId}` | Retrieve call details and transcript |
| `GET` | `/api/inbox/assistants/{assistantId}/calls/summary` | Summarize assistant call activity |

## Inbox list

### `GET /api/inbox/list`

Retrieve a paginated list of inbox contacts. The default status filter is `open`, and each page contains up to 50 contacts.

<Request tabs="cURL">

```bash
curl --request GET \
  --url "https://app.talkturo.com/api/inbox/list?accountSlug=acme&status=open&page=0" \
  --header "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example"
```

</Request>

<ParamField query="accountSlug" param-type="string" required="true">
Workspace slug used to select the account.
</ParamField>

<ParamField query="assistants" param-type="string" required="false">
Comma-separated assistant UUIDs.
</ParamField>

<ParamField query="channel" param-type="string" enum="phone,web,email" required="false">
Limit results to a communication channel.
</ParamField>

<ParamField query="q" param-type="string" required="false">
Search text, trimmed and limited to 100 characters.
</ParamField>

<ParamField query="unread" param-type="string" enum="1" required="false">
Set to `1` to return only contacts with unread activity.
</ParamField>

<ParamField query="status" param-type="string" enum="open,done,all" required="false">
Contact status. Omitted or unrecognized values use `open`.
</ParamField>

<ParamField query="assigned" param-type="string" required="false">
Use `me`, `unassigned`, or a member UUID. Invalid values do not apply an assignment filter.
</ParamField>

<ParamField query="needs" param-type="string" enum="1" required="false">
Set to `1` to return contacts needing the current user.
</ParamField>

<ParamField query="page" param-type="integer" required="false">
Zero-based page number, clamped to the range `0` through `1000`.
</ParamField>

<Response tabs="200,500">

<ResponseField name="total" field-type="integer" required="true">
Total contacts matching the filters.
</ResponseField>

The returned zero-based page number.

Maximum number of contacts in a page. This value is `50`.
</ResponseField>

<ResponseField name="contacts" field-type="array" required="true">
Contacts with their latest interaction, channels, assistants, unread count, completion state, and assignee.
</ResponseField>

<Callout kind="alert">

A failed inbox query returns HTTP `500` with `Could not load the Inbox`.

</Callout>

## Contact search

### `GET /api/inbox/contacts`

Search contacts by name, email, or company. Results require a non-empty email address and are limited to eight contacts.

<Request tabs="cURL">

```bash
curl --request GET \
  --url "https://app.talkturo.com/api/inbox/contacts?q=maya%20patel&accountSlug=acme" \
  --header "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example"
```

</Request>

<ParamField query="q" param-type="string" required="true">
Search text. Special characters are removed, the value is trimmed, and the result is limited to 60 characters. Queries shorter than two characters return an empty result.
</ParamField>

<ParamField query="accountSlug" param-type="string" required="true">
Workspace slug used to select the account.
</ParamField>

<Response tabs="200,500">

```json
{
  "contacts": [
    {
      "id": "cnt_7f3c9a21",
      "name": "Maya Patel",
      "email": "maya.patel@northstar.example",
      "company": "Northstar Labs"
    }
  ]
}
```

</Response>

<ResponseField name="contacts" field-type="array" required="true">
Up to eight contacts with non-null email addresses.
</ResponseField>

<Callout kind="info">

A search query shorter than two characters returns `contacts: []` without querying the database.

</Callout>

## Contact state

### `POST /api/inbox/contact-state`

Assign, unassign, complete, or reopen up to 200 contacts in one request.

<Request tabs="cURL">

```bash
curl --request POST \
  --url "https://app.talkturo.com/api/inbox/contact-state?accountSlug=acme" \
  --header "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example" \
  --header "Content-Type: application/json" \
  --data '{
    "contactIds": ["cnt_7f3c9a21"],
    "action": "assign",
    "assigneeId": "usr_84a1c2d9"
  }'
```

</Request>

<ParamField query="accountSlug" param-type="string" required="true">
Workspace slug used to select the account.
</ParamField>

<ParamField body="contactIds" param-type="array" required="true">
One to 200 contact UUIDs.
</ParamField>

<ParamField body="action" param-type="string" enum="assign,unassign,done,reopen" required="true">
State operation to apply.
</ParamField>

<ParamField body="assigneeId" param-type="string" required="false">
Workspace member UUID. Required when `action` is `assign`.
</ParamField>

<Response tabs="200,400,404">

```json
{
  "updated": 1
}
```

</Response>

<ResponseField name="updated" field-type="integer" required="true">
Number of in-scope contacts changed.
</ResponseField>

<Callout kind="alert">

Contacts belonging to another workspace are silently excluded. If no valid, in-scope contacts remain, the API returns HTTP `404`.

</Callout>

```bash

  --url "https://app.talkturo.com/api/inbox/access?accountSlug=acme" \
  --header "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example" \
```

</Request>

<ResponseField name="assistantIds" field-type="array" required="false">
Valid assistant UUIDs retained by the workspace.
</ResponseField>

<Callout kind="alert">

Only authorized managers can update restrictions. You cannot assign restrictions to a manager, and assistant IDs outside the workspace are silently discarded.

</Callout>
