## Manage legacy CRM company records

Use the CRM Companies endpoints to list, retrieve, update, and delete existing organization records. Companies are deprecated and cannot be created.

<Callout kind="alert">

Companies are deprecated. Creating new companies is no longer supported. `POST /api/crm/companies` returns `410 Gone`. Use CRM Groups (`POST /api/crm/groups`) instead. Existing company records can still be listed, retrieved, updated, and deleted.

</Callout>

## Endpoints at a glance

| Method | Endpoint | Purpose | Status |
| --- | --- | --- | --- |
| `GET` | `/api/crm/companies` | List companies | Supported |
| `POST` | `/api/crm/companies` | Create a company | Deprecated, returns `410 Gone` |
| `GET` | `/api/crm/companies/{id}` | Retrieve a company | Supported |
| `PATCH` | `/api/crm/companies/{id}` | Update a company | Supported |
| `DELETE` | `/api/crm/companies/{id}` | Delete a company | Supported |
| `GET` | `/api/crm/companies/{id}/contacts` | List contacts for a company | Supported |

## List companies

Retrieve legacy companies with optional team, text, and industry filters. The `search` filter performs a case-insensitive substring match against the company name and website.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://app.talkturo.com/api/crm/companies?teamId=team_7f3a91&limit=50&offset=0&search=acme&industry=Manufacturing" \
  -H "Authorization: Bearer tk_live_example_7f3a91b2c4d5" \
  -H "Cookie: sb-session=example_session_cookie"
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/crm/companies?teamId=team_7f3a91&limit=50&offset=0&search=acme&industry=Manufacturing",
  {
    method: "GET",
    credentials: "include",
    headers: {
      "Authorization": "Bearer tk_live_example_7f3a91b2c4d5",
      "Content-Type": "application/json"
    }
  }
);

const data = await response.json();
console.log(data);
```
</Request>

</ParamField>

</ParamField>

</ParamField>

## Create a company

<Request tabs="cURL,JavaScript" default-tab="1">
```bash

  -H "Authorization: Bearer tk_live_example_7f3a91b2c4d5" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-session=example_session_cookie"
```

```javascript
    "Content-Type": "application/json"

```

## Common patterns

Use `GET /api/crm/companies` to search and paginate existing company records with `limit` and `offset`. Use `GET /api/crm/companies/{id}` when you already have the company ID and need the complete legacy record.

Use `PATCH /api/crm/companies/{id}` to update existing records and `DELETE /api/crm/companies/{id}` to remove them. New company creation is unavailable, so create new organization records with `POST /api/crm/groups` through the [CRM Groups API](/en/api-reference/crm-groups).
