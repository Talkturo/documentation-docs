## Manage CRM company records

Use the CRM Companies endpoints to store organization records, attach custom fields, and retrieve contacts associated with each company.

<Callout kind="info">

All CRM Companies endpoints accept either session cookie authentication or API key Bearer token authentication.

</Callout>

## Endpoints at a glance

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/api/crm/companies` | List companies |
| `POST` | `/api/crm/companies` | Create a company |
| `GET` | `/api/crm/companies/{id}` | Retrieve a company |
| `PATCH` | `/api/crm/companies/{id}` | Update a company |
| `DELETE` | `/api/crm/companies/{id}` | Delete a company |
| `GET` | `/api/crm/companies/{id}/contacts` | List contacts for a company |

## Company object

## List companies

Retrieve a paginated list of companies. Use `search` to filter results by company name or website.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://app.talkturo.com/api/crm/companies?limit=25&offset=0&search=Acme&industry=Manufacturing&teamId=2f6c1a91-0a41-4f91-b7e3-4d7d8d31d6a2" \
  -H "Authorization: Bearer tk_example_9xmk7q2r"
```

```javascript
const response = await fetch(

  {
    method: "GET",
    headers: {
      "Authorization": "Bearer tk_example_9xmk7q2r",
      "Content-Type": "application/json"
    }
  }
);

const data = await response.json();
```

### Query parameters

<ParamField query="teamId" param-type="string" required="false">

Workspace UUID. Defaults to the authenticated account ID.

</ParamField>

<ParamField query="search" param-type="string" required="false">

Search term used to filter company records by `name` or `website`.

</ParamField>

<ParamField query="industry" param-type="string" required="false">

Filter company records by industry.

</ParamField>

<ParamField query="limit" param-type="integer" required="false">

Maximum number of companies to return per page. Defaults to `50`.

</ParamField>

<ParamField query="offset" param-type="integer" required="false">

Number of company records to skip before returning results. Defaults to `0`.

</ParamField>

</ResponseField>

<ResponseField name="total" field-type="integer" required="true">

</ResponseField>

</ResponseField>

<ResponseField name="offset" field-type="integer" required="true">

</ResponseField>

## Create a company

Create a new company record by sending the company name and any additional fields you want to store.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/companies" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_example_9xmk7q2r" \
  -d '{
    "teamId": "2f6c1a91-0a41-4f91-b7e3-4d7d8d31d6a2",
    "name": "Acme Manufacturing",
    "website": "https://acmemanufacturing.com",
    "industry": "Manufacturing",
    "companySize": "201-500",
    "addressLine1": "1450 Market Street",
    "addressLine2": "Suite 300",
    "city": "San Francisco",
    "state": "CA",
    "postalCode": "94103",
    "country": "US",
    "phone": "+1-415-555-0142",
    "notes": "Priority expansion account",
    "customFields": {
      "accountOwner": "Maya Patel",
      "renewalMonth": "September"
    }
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/companies", {
```

## Common patterns

Use `GET /api/crm/companies` when you need pagination, search, or industry filtering across company records. Use `GET /api/crm/companies/{id}` when you already have the company ID and need the full record.

Create and update requests accept standard fields plus custom CRM fields. If your workspace defines additional fields on companies, include them in the JSON body under `customFields` using the field names configured in your CRM.
