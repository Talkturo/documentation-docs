## Manage CRM company records

Use the CRM Companies endpoints to store organization records, attach custom fields, retrieve related contacts and opportunities, and create contacts directly under a company.

<Callout kind="info">

Authentication depends on the endpoint:

- **`GET /api/crm/companies`** and **`POST /api/crm/companies`** accept either an API key or an authenticated session cookie.
- **`GET /api/crm/companies/{id}`**, **`PUT /api/crm/companies/{id}`**, **`DELETE /api/crm/companies/{id}`**, **`GET /api/crm/companies/{id}/contacts`**, and **`POST /api/crm/companies/{id}/contacts`** require an authenticated Talkturo session cookie.

</Callout>

## Endpoints at a glance

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/api/crm/companies` | List companies |
| `POST` | `/api/crm/companies` | Create a company |
| `GET` | `/api/crm/companies/{id}` | Retrieve a company |
| `PUT` | `/api/crm/companies/{id}` | Update a company |
| `DELETE` | `/api/crm/companies/{id}` | Delete a company |
| `GET` | `/api/crm/companies/{id}/contacts` | List contacts for a company |
| `POST` | `/api/crm/companies/{id}/contacts` | Create a contact for a company |

## List companies

Retrieve a filtered company list. Search matches company `name` and `website`, industry filtering uses an exact match, and pagination uses `limit` and `offset`.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://app.talkturo.com/api/crm/companies?teamId=team_7f2k9d&search=acme&industry=Manufacturing&limit=25&offset=0" \
  -H "x-api-key: talkturo_example_key_9xmk7q2r"
```

const response = await fetch(

## Common patterns

Use `GET /api/crm/companies` when you need filtered list results with `limit` and `offset`. Use `GET /api/crm/companies/{id}` when you need the full company record plus recent contacts and opportunities.

Create and update requests use camelCase field names in the request body, while responses return stored company fields in snake_case. If your workspace defines additional fields on companies or contacts, send them in `customFields` and read them back from `custom_fields`.
