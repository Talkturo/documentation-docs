## Manage CRM company records

Store company records in the Talkturo CRM, filter them by industry or search term, and retrieve related contacts and opportunities.

<Callout kind="info">

`GET /api/crm/companies` and `POST /api/crm/companies` accept either session cookie authentication or an API key. `GET /api/crm/companies/{id}`, `PUT /api/crm/companies/{id}`, `DELETE /api/crm/companies/{id}`, and `GET /api/crm/companies/{id}/contacts` require an authenticated Talkturo session.

</Callout>

## Endpoints at a glance

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/api/crm/companies` | List companies |
| `POST` | `/api/crm/companies` | Create a company |
| `GET` | `/api/crm/companies/{id}` | Retrieve a company |
| `PUT` | `/api/crm/companies/{id}` | Update a company |
| `DELETE` | `/api/crm/companies/{id}` | Delete a company |
| `GET` | `/api/crm/companies/{id}/contacts` | List contacts for a company |

## List companies

Retrieve companies with optional filters for search and industry. If you omit `teamId`, the API uses the authenticated account ID when auth context is available.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://api.talkturo.com/api/crm/companies?search=Acme&industry=Manufacturing&limit=50&offset=0" \
  -H "x-api-key: tturo_example_key_9xmk7q2r"
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/crm/companies?search=Acme&industry=Manufacturing&limit=50&offset=0",
  {
    method: "GET",
    credentials: "include",
    headers: {
      "Content-Type": "application/json"
    }
  }
);

const data = await response.json();
console.log(data);
```
</Request>

### Query parameters

<ParamField query="teamId" param-type="string" required="false">

Team ID in UUID format. If you omit `teamId`, the API falls back to the authenticated account ID.

</ParamField>

<ParamField query="search" param-type="string" required="false">

Case-insensitive search term applied to the `name` and `website` fields.

</ParamField>

<ParamField query="industry" param-type="string" required="false">

Exact-match filter on the company `industry` field.

</ParamField>

<ParamField query="limit" param-type="integer" required="false">

Maximum number of companies to return. Defaults to `50`.

</ParamField>

<ParamField query="offset" param-type="integer" required="false">

Number of matching records to skip before returning results. Defaults to `0`.

</ParamField>

</ResponseField>

</ResponseField>

<ResponseField name="count" field-type="integer" required="true">

Total number of matching company records before `limit` and `offset` are applied.

</ResponseField>

<ResponseField name="limit" field-type="integer" required="true">

Page size used for the response.

</ResponseField>

<ResponseField name="offset" field-type="integer" required="true">

Offset used for the response.

</ResponseField>

## Create a company

Create a company with standard CRM fields and an optional `customFields` object. If you do not send `teamId`, the API uses the authenticated account ID and returns `400` if neither value is available.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/crm/companies" \
  -H "Content-Type: application/json" \
  -H "x-api-key: tturo_example_key_9xmk7q2r" \
  -d '{
    "name": "Acme Manufacturing",
    "website": "https://acmemanufacturing.com",
    "industry": "Manufacturing",
    "companySize": "201-500",
    "addressLine1": "1450 Market Street",
    "addressLine2": "Suite 600",
    "city": "San Francisco",
    "state": "CA",
    "postalCode": "94103",
    "country": "US",
    "phone": "+1-415-555-0142",
    "notes": "Primary west coast manufacturing partner.",
    "customFields": {
      "accountTier": "enterprise",
      "partnerStatus": "reseller"
    }
  }'
```

const response = await fetch("https://app.talkturo.com/api/crm/companies", {

## Update a company

  -H "Content-Type: application/json" \

    "industry": "Industrial Manufacturing",

    "notes": "Updated after account review.",

      "accountTier": "strategic"

## Delete a company

Delete a company by ID. The API blocks deletion when contacts are still associated with the company.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X DELETE "https://app.talkturo.com/api/crm/companies/8b0c9f0d-9c9b-4d5b-9d4f-6d0c2c7f0132" \
  -H "Cookie: sb-session=example_session_cookie"
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/crm/companies/8b0c9f0d-9c9b-4d5b-9d4f-6d0c2c7f0132",
  {
    method: "DELETE",
    credentials: "include",
    headers: {
      "Content-Type": "application/json"
    }
  }
);

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,400" default-tab="1">
```json
{
  "success": true,
  "message": "Company deleted"
}
```

```json
{
  "error": "Cannot delete company: 3 contacts are associated with it. Remove or reassign them first."
}
```
</Response>

### Path parameters

<ParamField path="id" param-type="string" required="true">

Unique company identifier in UUID format.

</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean">

Returns `true` when the company is deleted.

</ResponseField>

<ResponseField name="message" field-type="string">

Deletion status message. Successful responses return `Company deleted`.

</ResponseField>

<ResponseField name="error" field-type="string">

Error message returned when associated contacts block deletion.

</ResponseField>

<Callout kind="alert">

Delete the company's associated contacts, or reassign those contacts to another company, before retrying the delete request.

</Callout>
