## Manage CRM company records

Use the CRM Companies endpoints to store organization records, attach custom fields, retrieve related contacts and opportunities, and create contacts directly from a company record.

<Callout kind="info">

Authentication depends on the endpoint:

- `GET /api/crm/companies` and `POST /api/crm/companies` accept an API key or an authenticated Talkturo session cookie.
- `GET /api/crm/companies/{id}`, `PUT /api/crm/companies/{id}`, and `DELETE /api/crm/companies/{id}` require an authenticated Talkturo session cookie.
- `POST /api/crm/companies/{id}/contacts` accepts an API key or an authenticated Talkturo session cookie. API key requests must include the `contacts:write` scope.

</Callout>

## Endpoints at a glance

| Method | Endpoint | Auth | Purpose |
| --- | --- | --- | --- |
| `GET` | `/api/crm/companies` | API key or session cookie | List companies |
| `POST` | `/api/crm/companies` | API key or session cookie | Create a company |
| `GET` | `/api/crm/companies/{id}` | Session cookie | Retrieve a company with recent contacts and opportunities |
| `PUT` | `/api/crm/companies/{id}` | Session cookie | Update a company |
| `DELETE` | `/api/crm/companies/{id}` | Session cookie | Delete a company |
| `POST` | `/api/crm/companies/{id}/contacts` | API key or session cookie | Create a contact for a company |
| `GET` | `/api/crm/companies/{id}/contacts` | Session cookie | List contacts for a company |

## Common patterns

Use `GET /api/crm/companies` when you need pagination, filtering, or search across company records within a team. Use `GET /api/crm/companies/{id}` when you already have the company ID and need the full record plus recent related contacts and opportunities.

Create and update requests accept standard fields plus `customFields`. If your workspace defines additional fields on companies, include them directly in the JSON body using the field names configured in your CRM.

Use `POST /api/crm/companies/{id}/contacts` when you want to create a contact and attach it to a company in one request. If you also pass `campaignId`, the API attempts campaign enrollment as part of the same workflow.
