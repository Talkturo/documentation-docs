## Legacy CRM company records

<Callout kind="alert">

Companies are deprecated and are being replaced by CRM Groups. Use the [CRM Groups API](/en/api-reference/crm-groups) for new integrations.

</Callout>

The legacy CRM Companies endpoints store organization records, attach custom fields, and retrieve contacts associated with each company.

## Endpoints at a glance

| Method | Endpoint | Purpose | Status |
| --- | --- | --- | --- |
| `GET` | `/api/crm/companies` | List companies | Deprecated |
| `POST` | `/api/crm/companies` | Create a company | Deprecated: Returns 410 Gone |
| `GET` | `/api/crm/companies/{id}` | Retrieve a company | Deprecated |
| `PATCH` | `/api/crm/companies/{id}` | Update a company | Deprecated |
| `DELETE` | `/api/crm/companies/{id}` | Delete a company | Deprecated |
| `GET` | `/api/crm/companies/{id}/contacts` | List contacts for a company | Deprecated |

## Company object

Company responses return a company record with core fields such as `id`, `name`, `website`, and `industry`. Records may also include additional standard or custom CRM fields stored on the company.

</ResponseField>

</ResponseField>

Company address.

</ResponseField>

## List companies

Retrieve a paginated list of companies. Use `search` to filter results by a search term.

<Callout kind="alert">

`GET /api/crm/companies` is deprecated but remains functional for backward compatibility. The request requires a `teamId` or `accountSlug`. Use the [CRM Groups API](/en/api-reference/crm-groups) for new integrations.

</Callout>

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://app.talkturo.com/api/crm/companies?page=1&limit=25&search=Acme" \
  -H "Cookie: sb-session=example_session_cookie"
```

```javascript
const response = await fetch(

  {

    credentials: "include",
    headers: {
```

## Create a company

`POST /api/crm/companies` is deprecated and no longer creates company records. The endpoint returns HTTP `410 Gone`; use `POST /api/crm/groups` instead.

<Callout kind="alert">

Requests to create a company through `POST /api/crm/companies` return `410 Gone`. Migrate clients to `POST /api/crm/groups` and follow the [CRM Groups API](/en/api-reference/crm-groups) reference.

</Callout>

## Common patterns

Use `GET /api/crm/companies` when you need pagination and search across company records. Use `GET /api/crm/companies/{id}` when you already have the company ID and need the full record.

Create and update requests accept standard fields plus custom CRM fields. If your workspace defines additional fields on companies, include them directly in the JSON body using the field names configured in your CRM.
