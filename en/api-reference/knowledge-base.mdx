## Knowledge base endpoints

Manage assistant-specific knowledge base files with endpoints under `/api/assistants/{assistantId}/knowledge-base`. Uploaded files are stored per assistant and processed for retrieval during calls.

<Callout kind="info">

These endpoints support dual authentication. Use either an authenticated browser session or an API key. When you use an API key, `GET` requests require the `kb:read` scope and `POST` requests require the `kb:write` scope.

</Callout>

<Callout kind="alert">

Upload requests use `multipart/form-data` and must include a file field. File processing happens after upload, so a newly uploaded file may appear with a non-ready `status` before it becomes available for retrieval.

</Callout>

## Endpoint summary

| Method | Path | Purpose | Auth |
| --- | --- | --- | --- |
| `GET` | `/api/assistants/{assistantId}/knowledge-base` | List knowledge base files for an assistant | API key or session |
| `POST` | `/api/assistants/{assistantId}/knowledge-base` | Upload a knowledge base file | API key or session |
| `POST` | `/api/assistants/{assistantId}/knowledge-base` | Attach an existing knowledge base file with a JSON body containing `file_id` | API key or session |
| `DELETE` | `/api/assistants/{assistantId}/knowledge-base/{fileId}` | Delete a knowledge base file | Session cookie |
| `GET` | `/api/assistants/{assistantId}/billing/estimate` | Get knowledge base processing cost estimate | Session cookie |

## List knowledge base files

Return all knowledge base files attached to an assistant.

```bash

  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base" \
  --header "Authorization: Bearer tk_example_kb_read_7f3m2q9x" \
  --header "Content-Type: application/json"
```

## Upload a knowledge base file

Upload a file to an assistant's knowledge base with `multipart/form-data`.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request POST \
  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base" \
  --header "Authorization: Bearer tk_example_kb_write_4m8p1z6n" \
  --form "file=@./docs/acme-support-playbook.pdf"
```

```javascript
const formData = new FormData();
formData.append("file", fileInput.files[0]);

const response = await fetch(
  "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base",
  {
    method: "POST",
    headers: {
      Authorization: "Bearer tk_example_kb_write_4m8p1z6n",
    },
    body: formData,
  }
);

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "file": {
    "id": "6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714",
    "filename": "acme-support-playbook.pdf",
    "size_bytes": 248193,
    "mime_type": "application/pdf",
    "status": "processing",
    "status_error": null,
    "char_count": 0,
    "chunk_count": 0,
    "created_at": "2026-02-11T14:22:09.000Z",
    "updated_at": "2026-02-11T14:22:09.000Z"
```

## Attach an existing file

Attach a previously uploaded knowledge base file to an assistant by sending a JSON body with `file_id`.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request POST \
  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base" \
  --header "Authorization: Bearer tk_example_kb_write_4m8p1z6n" \
  --header "Content-Type: application/json" \
  --data '{
    "file_id": "6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714"
  }'
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base",
  {
    method: "POST",
    headers: {
      Authorization: "Bearer tk_example_kb_write_4m8p1z6n",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      file_id: "6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714",
    }),
  }
);

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,idempotent 200">
```json
{
  "success": true,
  "file": {
    "id": "6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714",
    "filename": "acme-support-playbook.pdf",
    "size_bytes": 248193,
    "mime_type": "application/pdf",
    "status": "ready",
    "status_error": null,
    "char_count": 18422,
    "chunk_count": 37,
    "created_at": "2026-02-11T14:22:09.000Z",
    "updated_at": "2026-02-11T14:23:02.000Z"
  }
}
```

```json
{
  "success": true,
  "idempotent": true
}
```
</Response>

This operation is idempotent. If the file is already attached to the assistant, the API still returns success and sets `idempotent` to `true`.

The file must already exist in `assistant_knowledge_files` and belong to the same account as the assistant.

### Path parameters

<ParamField path="assistantId" param-type="uuid" required="true">
Assistant identifier that will receive the existing file attachment.
</ParamField>

### Body parameters

<ParamField body="file_id" param-type="uuid" required="true">
Identifier of the existing knowledge base file to attach.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Returns `true` when the attachment succeeds or the file was already attached.
</ResponseField>

<ResponseField name="idempotent" field-type="boolean" required="false">
Returns `true` when the file was already attached to the assistant.
</ResponseField>

<ResponseField name="file" field-type="object" required="false">
Metadata for the attached file when the API returns the file record.
</ResponseField>

## Delete a knowledge base file

Remove a file from an assistant's knowledge base.

<Request tabs="cURL" default-tab="1">
```bash
curl --request DELETE \
  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base/6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714" \
  --cookie "sb-access-token=sb_example_session_token"
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "message": "File deleted"
}
```
</Response>

### Path parameters

<ParamField path="assistantId" param-type="uuid" required="true">
Assistant identifier that owns the file.
</ParamField>

<ParamField path="fileId" param-type="uuid" required="true">
Knowledge base file identifier to delete.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Returns `true` when the file is removed.
</ResponseField>

<ResponseField name="message" field-type="string" required="true">
Human-readable deletion result.
</ResponseField>

## Get billing estimate

Retrieve the billing estimate for knowledge base processing for an assistant.

```bash
curl --request GET \
  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/billing/estimate" \
  --cookie "sb-access-token=sb_example_session_token"
```

The response returns a success flag and an `estimate` object.

### Path parameters

<ParamField path="assistantId" param-type="uuid" required="true">
Assistant identifier used to calculate the estimate.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Returns `true` when the estimate is available.
</ResponseField>

<ResponseField name="estimate" field-type="object" required="true">
Billing estimate details for knowledge base processing. The object shape depends on the current billing implementation.
</ResponseField>

## Typical workflow

Use the knowledge base endpoints in this order when automating document management:

<Steps>
<Step title="Upload the file" icon="upload">

Send a `POST` request with `multipart/form-data` to the assistant knowledge base endpoint.

Success looks like a response with `success: true` and a `file` object.

</Step>
<Step title="Poll for processing status" icon="check-circle">

Call `GET /api/assistants/{assistantId}/knowledge-base` and inspect each file's `status`.

Your workflow can continue once the uploaded file appears in the list and its status indicates processing is complete.

</Step>
<Step title="Estimate processing cost when needed" icon="bar-chart">

Call `GET /api/assistants/{assistantId}/billing/estimate` before or after upload if you need billing visibility for the assistant's knowledge base usage.

Success looks like a response with `success: true` and an `estimate` object.

</Step>
<Step title="Remove outdated files" icon="trash">

Delete files you no longer want the assistant to use by sending `DELETE /api/assistants/{assistantId}/knowledge-base/{fileId}`.

A successful deletion returns `success: true` and a confirmation message.

</Step>
</Steps>
