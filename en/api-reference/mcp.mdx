## Endpoint summary

| Method | Path | Purpose | Auth |
| --- | --- | --- | --- |
| `GET` | `/api/mcp/providers` | List available MCP providers | Session cookie |
| `GET` | `/api/mcp/plugins` | List plugins, connections, and assistant selections | Session cookie |
| `POST` | `/api/mcp/plugins/select` | Attach or detach a plugin for an assistant | Session cookie |
| `GET` | `/api/mcp/plugins/tools` | List tools available for a workspace connection | Session cookie |

<Callout kind="info">

All MCP plugin endpoints use the Talkturo web session for authentication. Send the authenticated Supabase session cookie with each request. These endpoints do not accept API keys.

</Callout>

## GET /api/mcp/providers

Returns the MCP providers that Talkturo can connect to.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request GET \
  --url "https://app.talkturo.com/api/mcp/providers" \
  --header "Cookie: sb-access-token=sb_example_access_token; sb-refresh-token=sb_example_refresh_token"
```

```javascript
const response = await fetch("https://app.talkturo.com/api/mcp/providers", {
  method: "GET",
  headers: {
    Cookie: "sb-access-token=sb_example_access_token; sb-refresh-token=sb_example_refresh_token"
  }
})

const data = await response.json()
console.log(data)
```
</Request>

## GET /api/mcp/plugins

Returns MCP plugins for the workspace, including available connections and the current selection for an assistant when `assistantId` is provided.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash

  --url "https://app.talkturo.com/api/mcp/plugins?accountSlug=acme&assistantId=1d9d4e3c-5296-4f9b-a6b7-4f0f2f5851d4" \
  --header "Cookie: sb-access-token=sb_example_access_token; sb-refresh-token=sb_example_refresh_token"
```

```javascript
const url = new URL("https://app.talkturo.com/api/mcp/plugins")
url.searchParams.set("accountSlug", "acme")
url.searchParams.set("assistantId", "1d9d4e3c-5296-4f9b-a6b7-4f0f2f5851d4")
```

## POST /api/mcp/plugins/select

Attaches a provider connection to an assistant and stores the selected tool list. If `tools` is an empty array, Talkturo detaches the plugin from the assistant and deletes the saved configuration.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request POST \
  --url "https://app.talkturo.com/api/mcp/plugins/select" \
  --header "Content-Type: application/json" \
  --header "Cookie: sb-access-token=sb_example_access_token; sb-refresh-token=sb_example_refresh_token" \
  --data '{
    "assistantId": "1d9d4e3c-5296-4f9b-a6b7-4f0f2f5851d4",
    "accountSlug": "acme",
    "provider": "google-drive",
    "connectionId": "8f2546ec-2f4f-4e1d-8f39-654f7f2bbf2d",
    "tools": ["drive.search", "drive.get_file"]
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/mcp/plugins/select", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    Cookie: "sb-access-token=sb_example_access_token; sb-refresh-token=sb_example_refresh_token"
  },
  body: JSON.stringify({
    assistantId: "1d9d4e3c-5296-4f9b-a6b7-4f0f2f5851d4",
    accountSlug: "acme",
    provider: "google-drive",
    connectionId: "8f2546ec-2f4f-4e1d-8f39-654f7f2bbf2d",
    tools: ["drive.search", "drive.get_file"]
  })
})

const data = await response.json()
console.log(data)
```
</Request>

<Response tabs="200,400,404" default-tab="1">
```json
{
  "ok": true,
  "attached": true
}
```

```json
{
  "error": "tools must contain at most 100 items"
}
```

```json
{
  "error": "Connection not found"
}
```
</Response>

### Body parameters

<ParamField body="assistantId" param-type="string" required="true">
Assistant UUID that will receive the plugin selection.
</ParamField>

<ParamField body="accountSlug" param-type="string" required="true">
Workspace account slug.
</ParamField>

<ParamField body="provider" param-type="string" required="true">
Provider identifier returned by `GET /api/mcp/providers`.
</ParamField>

<ParamField body="connectionId" param-type="string" required="true">
Connection UUID for the selected provider.
</ParamField>

<ParamField body="tools" param-type="string[]" required="true">
List of tool names to enable for the assistant. Each item can contain up to 200 characters, and the array can contain up to 100 items. Send an empty array to detach the plugin from the assistant.
</ParamField>

### Response fields

<ResponseField name="ok" field-type="boolean" required="true">
Whether the request completed successfully.
</ResponseField>

<ResponseField name="attached" field-type="boolean" required="true">
Whether a plugin configuration is attached after the request completes. `false` indicates the plugin was detached because `tools` was empty.
</ResponseField>

## GET /api/mcp/plugins/tools

Returns the tools exposed by a specific workspace connection. Use this endpoint before saving a plugin selection so you can present the current tool list to the user.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request GET \
  --url "https://app.talkturo.com/api/mcp/plugins/tools?accountSlug=acme&connectionId=8f2546ec-2f4f-4e1d-8f39-654f7f2bbf2d" \
  --header "Cookie: sb-access-token=sb_example_access_token; sb-refresh-token=sb_example_refresh_token"
```

```javascript
const url = new URL("https://app.talkturo.com/api/mcp/plugins/tools")
url.searchParams.set("accountSlug", "acme")
url.searchParams.set("connectionId", "8f2546ec-2f4f-4e1d-8f39-654f7f2bbf2d")

const response = await fetch(url, {
  method: "GET",
  headers: {
    Cookie: "sb-access-token=sb_example_access_token; sb-refresh-token=sb_example_refresh_token"
```

## Error behavior

All endpoints require an authenticated Talkturo session. Beyond `401 Unauthorized`, MCP plugin endpoints can return the following status codes depending on the route and workspace state:

| Status | Meaning |
| --- | --- |
| `400` | Missing or invalid query or body parameters |
| `401` | Missing or invalid session |
| `403` | Authenticated, but not allowed to access the workspace or assistant |
| `404` | Requested assistant or connection was not found |
| `500` | Unexpected server error |
