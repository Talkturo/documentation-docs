## Endpoints at a glance

Use these public endpoints to start demo calls, generate a LiveKit token for browser demos, and fetch the assistants you can expose in public experiences.

<Callout kind="info">

These endpoints do not require authentication headers or API keys.

</Callout>

<Callout kind="alert">

Public call endpoints are protected by Cloudflare Turnstile and rate limits. Expect `403` when Turnstile validation fails and `429` when the request exceeds rate limits.

</Callout>

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `POST` | `/api/public/test-call/outbound` | Initiate a public demo outbound call |
| `GET` | `/api/public/test-call/token` | Generate a LiveKit token for an inbound web demo call |
| `POST` | `/api/public/form-call/outbound` | Initiate an outbound call from a public form or widget embed |
| `GET` | `/api/public/demo-assistants` | List public demo assistants |

## POST /api/public/test-call/outbound

Start a demo outbound call to a visitor-provided phone number.

<Callout kind="alert">

Send a valid `turnstile_token` with every request. The endpoint also requires explicit consent and enforces these limits:

- **10 requests per hour per IP**
- **30 requests per day per IP**
- **3 calls per phone number per 6 hours**

</Callout>

### Request example

<Request tabs="cURL,JavaScript,Python" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/public/test-call/outbound" \
  -H "Content-Type: application/json" \
  -d '{
    "assistant_id": "asst_demo_sales_northamerica",
    "to_number": "+14155550182",
    "turnstile_token": "cf-turnstile-response-example-9xmk7q2r",
    "consent_given": true,
    "visitor_name": "Jane Chen",
    "visitor_email": "jane@acme.com"
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/public/test-call/outbound", {
  method: "POST",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    assistant_id: "asst_demo_sales_northamerica",
    to_number: "+14155550182",
    turnstile_token: "cf-turnstile-response-example-9xmk7q2r",
    consent_given: true,
    visitor_name: "Jane Chen",
    visitor_email: "jane@acme.com"
  })
});

const data = await response.json();
console.log(data);
```

### Body parameters

<ParamField body="assistant_id" param-type="string" required="true">
The public demo assistant to use for the call.
</ParamField>

<ParamField body="to_number" param-type="string" required="true">
Destination phone number in E.164 format, such as `+14155550182`.
</ParamField>

<ParamField body="turnstile_token" param-type="string" required="true">
Cloudflare Turnstile response token from the client-side challenge.
</ParamField>

<ParamField body="consent_given" param-type="boolean" required="true">
Set to `true` only after the visitor explicitly agrees to receive the demo call.
</ParamField>

<ParamField body="visitor_name" param-type="string" required="false">
Visitor name to associate with the demo request.
</ParamField>

<ParamField body="visitor_email" param-type="string" required="false">
Visitor email to associate with the demo request.
</ParamField>

### Response fields

<ResponseField name="success" field-type="boolean" required="true">
Returns `true` when the call request is accepted.
</ResponseField>

<ResponseField name="call_id" field-type="string" required="true">
Unique identifier for the initiated call.
</ResponseField>

<ResponseField name="message" field-type="string" required="true">
Human-readable status message for the accepted request.
</ResponseField>

### Error behavior

| Status | Condition |
| --- | --- |
| `400` | Missing required fields or invalid phone number |
| `403` | Turnstile verification failed or the request was blocked before call creation |
| `429` | IP-based or phone-number-based rate limit exceeded |

## GET /api/public/test-call/token

Generate a LiveKit token and server URL for an inbound browser demo call.

### Request example

<Request tabs="cURL,JavaScript,Python" default-tab="1">
```bash
curl "https://api.talkturo.com/api/public/test-call/token"
```

```javascript
const response = await fetch("https://api.talkturo.com/api/public/test-call/token");
const data = await response.json();
console.log(data);
```

```python
import requests

response = requests.get("https://api.talkturo.com/api/public/test-call/token")
print(response.json())
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.demo_livekit_token_payload",
  "url": "wss://demo-talkturo-7wz9x9.livekit.cloud"
}
```
</Response>

### Query parameters

This endpoint does not accept query parameters.

### Response fields

<ResponseField name="token" field-type="string" required="true">
LiveKit access token for the web demo session.
</ResponseField>

<ResponseField name="url" field-type="string" required="true">
LiveKit server URL to use with the returned token.
</ResponseField>

## Integration notes

Use `GET /api/public/demo-assistants` first when you need to populate a public picker with valid assistant IDs. Then pass the selected `assistant_id` into either outbound call endpoint.

If you offer browser-based demos, request `GET /api/public/test-call/token` immediately before connecting to LiveKit so the client uses a fresh token.

<Callout kind="tip">

A successful outbound request returns a `call_id`. Store that value in your frontend or backend logs so you can correlate demo submissions with call activity later.

</Callout>
