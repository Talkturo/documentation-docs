## Build public calling experiences

Use Talkturo's public endpoints to create AI employee drafts, upload business documents, start browser-based demo calls, and place consented outbound calls from websites and embedded forms.

All endpoints use `https://app.talkturo.com` and do not require a session, JWT, or API key. Talkturo validates the request `Origin` header with CORS rules. Some endpoints also require a Turnstile CAPTCHA token.

<Callout kind="alert">

Every public endpoint requires a valid CORS origin. Requests from unapproved origins fail even when the request body and CAPTCHA token are valid. Endpoints that require CAPTCHA must receive a valid `turnstile_token`.

</Callout>

## Endpoint summary

| Method | Path | Purpose | Authentication |
| --- | --- | --- | --- |
| `POST` | `/api/public/ai-employee/create` | Create an AI employee draft from business details | Turnstile CAPTCHA |
| `POST` | `/api/public/ai-employee/upload` | Add a reference document to an AI employee draft | `draft_token` |
| `POST` | `/api/public/ai-employee/call-token` | Create a browser call token for an AI employee draft | `draft_token` |
| `GET` | `/api/public/ai-employee/use-cases` | List available AI employee use cases | None |
| `GET` | `/api/public/demo-assistants` | List assistants available for public demos | None |
| `POST` | `/api/public/test-call/token` | Create a browser call token for a demo assistant | Turnstile CAPTCHA |
| `POST` | `/api/public/test-call/outbound` | Start a consented outbound demo call | Turnstile CAPTCHA |
| `POST` | `/api/public/form-call/outbound` | Start an outbound call from an embedded form | None |

<Callout kind="info">

The `draft_token` returned by the AI employee creation endpoint authorizes the upload and call-token endpoints for that draft. Treat it as a short-lived public demo credential and do not expose it in server logs.

</Callout>

## AI employee creation

### Create an AI employee draft

Create a draft AI employee from a website URL, business description, or both. The endpoint generates the draft identity and returns a `draft_token` for subsequent upload and browser-call requests.

The endpoint accepts unauthenticated requests, but requires a valid Turnstile token and applies per-IP and global rate limits:

- 10 requests per hour per IP
- 30 requests per day per IP
- 200 requests per day globally

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/public/ai-employee/create" \
  -H "Content-Type: application/json" \
  -H "Origin: https://www.acme-demo-site.com" \
  -d '{
    "website_url": "https://www.acmeexample.com",
    "business_description": "Acme Example provides managed IT support for growing professional services firms.",
    "company_name": "Acme Example",
    "language": "en",
    "use_case": "lead_qualification",
    "first_name": "Jordan",
    "last_name": "Lee",
    "turnstile_token": "turnstile_example_token_7f3a91",
    "fbc": "fb.1.1712345678901.AbCdEfGh",
    "fbp": "fb.1.1712345678901.123456789",
    "fbclid": "IwAR_example_click_id"
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/public/ai-employee/create", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
```

### Upload a reference document

Attach a business document to an existing AI employee draft. Use `multipart/form-data` with the `draft_token` and a supported file.

The endpoint accepts PDF, DOC, DOCX, TXT, and MD files up to 10 MB. It allows 20 requests per hour per IP.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/public/ai-employee/upload" \
  -H "Origin: https://www.acme-demo-site.com" \
  -F "draft_token=draft_example_8f4c2a91b7d6" \
  -F "file=@acme-services.txt"
```

```javascript
const documentFile = new File(
  [
    "Acme Example provides managed IT support, cloud migration, and security monitoring for professional services firms."
  ],
  "acme-services.txt",
  { type: "text/plain" }
);

const formData = new FormData();
formData.append("draft_token", "draft_example_8f4c2a91b7d6");
formData.append("file", documentFile);

const response = await fetch("https://app.talkturo.com/api/public/ai-employee/upload", {
  method: "POST",
  headers: {
    "Origin": "https://www.acme-demo-site.com"
  },
  body: formData
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,400" default-tab="1">
```json
{
  "success": true,
  "used_in_demo": true
}
```

```json
{
  "error": "Unsupported file type"
}
```
</Response>

</ParamField>

<ParamField body="file" param-type="file" required="true">
Reference document in PDF, DOC, DOCX, TXT, or MD format. The maximum file size is 10 MB.

### Create an AI employee call token

The endpoint allows 30 requests per hour and 100 requests per day per IP, with a global limit of 500 requests per day.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash

  -H "Content-Type: application/json" \
  -H "Origin: https://www.acme-demo-site.com" \
  -d '{
    "draft_token": "draft_example_8f4c2a91b7d6"
```

```javascript
const response = await fetch("https://app.talkturo.com/api/public/ai-employee/call-token", {
```
