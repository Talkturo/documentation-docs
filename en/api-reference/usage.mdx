## Track usage across credits, calls, and voice events

Use the Usage and Analytics endpoints to fetch current credit balances, query account usage over time, and log desktop voice transcription activity.

<Callout kind="info">

Usage endpoints use different authentication modes depending on the route. `GET /api/usage/current` accepts API key or session authentication, `GET /api/accounts/accountId/usage` requires a browser session with account access, and `POST /api/usage/voice` accepts a desktop Bearer JWT.

</Callout>

## Endpoints at a glance

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/api/usage/current` | Get the current period usage summary for an account |
| `GET` | `/api/accounts/{accountId}/usage` | Query account usage analytics with time-series and paginated call rows |
| `POST` | `/api/usage/voice` | Log desktop speech-to-text usage events |

### Authentication

This endpoint requires a browser session and account membership. API keys do not authorize `GET /api/accounts/{accountId}/usage`.

### Path parameters

<ParamField path="accountId" param-type="string" required="true">

Account UUID to query.

</ParamField>

### Query parameters

<ParamField query="from" param-type="string" required="true">

Start of the reporting range as an ISO 8601 timestamp.

</ParamField>

<ParamField query="to" param-type="string" required="true">

End of the reporting range as an ISO 8601 timestamp. The value must be equal to or later than `from`.

</ParamField>

<ParamField query="assistantId" param-type="string" required="false">

Optional assistant UUID filter. If provided, the value must be a valid UUID.

</ParamField>

<ParamField query="page" param-type="integer" required="false">

Page number for `rows`. Defaults to `1`.

</ParamField>

<ParamField query="pageSize" param-type="integer" required="false">

Number of rows to return per page. Defaults to `25` and cannot exceed `100`.

</ParamField>

<ParamField query="granularity" param-type="string" required="false" enum="day,week">

Time bucketing applied to `series`. Defaults to `day`.

</ParamField>

<Callout kind="info">

The date range cannot exceed `366` days. Weekly series are bucketed by UTC Monday.

</Callout>

| --- | --- |
| `400` | `{"success":false,"error":"Invalid JSON body"}` |
| `401` | Missing Bearer token, empty Bearer token, or invalid token |
| `500` | `{"success":false,"error":"Usage logging failed"}` |

<Callout kind="info">

Desktop clients can call this endpoint from Electron or other non-browser environments. The route returns permissive CORS headers and calculates `cost_usd` as `durationSeconds / 60 * 0.0077` before writing the event to `talkturo_desktop_usage_events`.

</Callout>
