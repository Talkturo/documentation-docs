## Usage analytics endpoint

Retrieve rolled-up usage metrics and paginated call-level cost records for a single account.

<Callout kind="info">

**Authentication**

This endpoint uses a cookie-based browser session and does not accept API keys. If you are not authenticated, the request returns a `302` redirect to the login flow.

Access is limited to the account primary owner and account members.

</Callout>

## Endpoint summary

| Method | Path | Auth | Purpose |
| --- | --- | --- | --- |
| `GET` | `/api/accounts/{accountId}/usage` | Session cookie only | Retrieve daily or weekly usage analytics for an account |

## Path parameters

<ParamField path="accountId" param-type="string" required="true">

Account UUID to retrieve usage for.

</ParamField>

## Query parameters

<ParamField query="from" param-type="string" required="true">

Start of the reporting range as an ISO 8601 date.

</ParamField>

<ParamField query="to" param-type="string" required="true">

End of the reporting range as an ISO 8601 date. The value must be greater than or equal to `from`.

</ParamField>

<ParamField query="assistantId" param-type="string" required="false">

Filter results to a specific assistant. If provided, the value must be a valid UUID.

</ParamField>

<ParamField query="page" param-type="integer" required="false">

Page number for the paginated `rows` collection. Defaults to `1`.

</ParamField>

<ParamField query="pageSize" param-type="integer" required="false">

Number of call rows to return per page. Defaults to `25` and is capped at `100`.

</ParamField>

<ParamField query="granularity" param-type="string" required="false" enum="day,week">

Time bucket size for the `series` collection. Defaults to `day`.

</ParamField>

<Callout kind="alert">

The date range cannot exceed `366` days. Requests where `to - from` is greater than `366` days return `400`.

</Callout>

## Response fields

### Top-level fields

<ResponseField name="granularity" field-type="string">

Granularity applied to the `series` data. The value is `day` or `week`.

</ResponseField>

<ResponseField name="series" field-type="array">

Rolled-up usage data for the requested time range at the selected granularity.

</ResponseField>

<ResponseField name="totals" field-type="object">

Aggregate usage totals for the entire date range. Totals are always computed from day-level raw data, even when `granularity` is `week`.

</ResponseField>

<ResponseField name="assistants" field-type="array">

Assistants included in the result set. Use this list to populate assistant filters in dashboards.

</ResponseField>

<ResponseField name="rows" field-type="array">

Paginated individual call records ordered by `ended_at` descending. Only calls with a non-null `ended_at` value are included.

</ResponseField>

<ResponseField name="page" field-type="integer">

Current page number for the `rows` collection.

</ResponseField>

<ResponseField name="pageSize" field-type="integer">

Applied page size for the `rows` collection.

</ResponseField>

<ResponseField name="rowCount" field-type="integer">

Total number of matching call rows across all pages.

</ResponseField>

## Behavior notes

`series` and `rows` serve different reporting needs. Use `series` for charts and period-over-period views, and use `rows` when you need per-call drilldown data.

Pagination only applies to `rows`. The `totals`, `series`, and `assistants` collections always describe the full filtered range, not only the current page.

## Error responses

| Status | Condition |
| --- | --- |
| `302` | User is not authenticated and is redirected to login |
| `400` | Missing `from` or `to`, invalid dates, `from` is after `to`, range exceeds `366` days, or `assistantId` is not a valid UUID |
| `403` | Authenticated user is not the account primary owner and is not a member of the account |
| `500` | Internal server error |
