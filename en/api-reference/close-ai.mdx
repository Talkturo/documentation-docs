## Close AI endpoints

Manage Close AI desktop sessions, prompt presets, team-wide analytics dashboards, and branching sales scripts through REST endpoints designed for the Close AI desktop experience.

<Callout kind="info">

All Close AI endpoints require an authenticated session cookie. Row-level security policies enforce user-scoped access across sessions, prompts, dashboards, and scripts.

</Callout>

## Endpoint overview

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/close-ai/sessions` | List Close AI sessions for the current user |
| `GET` | `/api/close-ai/sessions/[sessionId]` | Get one session with transcripts, messages, summary, and analysis |
| `PATCH` | `/api/close-ai/sessions/[sessionId]` | Rename or clear a session title |
| `DELETE` | `/api/close-ai/sessions/[sessionId]` | Delete a session |
| `GET` | `/api/close-ai/prompts` | List saved prompt presets |
| `POST` | `/api/close-ai/prompts` | Create a prompt preset |
| `GET` | `/api/close-ai/dashboard` | Retrieve team analytics for a workspace |
| `GET` | `/api/close-ai/scripts` | List workspace sales scripts |
| `POST` | `/api/close-ai/scripts` | Create a sales script |
| `PUT` | `/api/close-ai/scripts` | Update a sales script |
| `DELETE` | `/api/close-ai/scripts` | Delete a sales script |

## Sessions

Use session endpoints to list recorded Close AI activity, inspect one session in detail, update the session title, or remove a session.

### List sessions

`GET https://api.talkturo.com/api/close-ai/sessions` returns paginated sessions for the authenticated user.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl -X GET "https://api.talkturo.com/api/close-ai/sessions?limit=25&offset=0&q=demo&account=acme-revenue" \
  -H "Cookie: sb-access-token=tt_example_session_cookie"
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/close-ai/sessions?limit=25&offset=0&q=demo&account=acme-revenue",
  {
    method: "GET",
    credentials: "include",
    headers: {
      "Cookie": "sb-access-token=tt_example_session_cookie"
    }
  }
);

const data = await response.json();
console.log(data);
```

</Request>

<Request tabs="cURL,JavaScript" default-tab="1">

```bash

  -H "Content-Type: application/json" \
```

```javascript
const response = await fetch(
```

### Create a prompt preset

`POST https://api.talkturo.com/api/close-ai/prompts` creates a saved preset for the authenticated user.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl -X POST "https://api.talkturo.com/api/close-ai/prompts" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=tt_example_session_cookie" \
  -d '{
    "title": "Procurement risk review",
    "prompt": "Review this call and extract procurement blockers, owner questions, and next actions.",
    "is_default": false,
    "is_template": true
  }'
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/close-ai/prompts",
  {
    method: "POST",
    credentials: "include",
    headers: {
      "Content-Type": "application/json",
      "Cookie": "sb-access-token=tt_example_session_cookie"
    },
    body: JSON.stringify({
      title: "Procurement risk review",
      prompt: "Review this call and extract procurement blockers, owner questions, and next actions.",
      is_default: false,
      is_template: true
    })
  }
);

const data = await response.json();
console.log(data);
```

</Request>

<Response tabs="201" default-tab="1">

```json
{
  "preset": {
    "id": "prm_31aa90bc",
    "user_id": "usr_19c4f2aa",
    "title": "Procurement risk review",

    "is_default": false,
    "is_template": true,
```

#### Body parameters

<ParamField body="title" param-type="string" required="true">
Preset title. Must contain `1` to `200` characters.
</ParamField>

<ParamField body="prompt" param-type="string" required="true">
Prompt text. Must contain `1` to `20000` characters.
</ParamField>

<ParamField body="is_default" param-type="boolean" required="false">
Marks the new preset as the user's default preset. When set to `true`, the API clears the default flag from all other presets.
</ParamField>

<ParamField body="is_template" param-type="boolean" required="false">
Marks the preset as a reusable template. Defaults to `false`.
</ParamField>

#### Response fields

<ResponseField name="preset" field-type="object" required="true">
Created prompt preset.
</ResponseField>

<Callout kind="info">

If you create a preset with `is_default` set to `true`, Close AI removes the default flag from every other preset for that user.

</Callout>

`POST https://api.talkturo.com/api/close-ai/scripts` creates a new script in the target workspace.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl -X POST "https://api.talkturo.com/api/close-ai/scripts?account=acme-revenue" \
  -H "Content-Type: application/json" \

    "name": "Mid-market discovery"
```

```javascript
const response = await fetch(
```
