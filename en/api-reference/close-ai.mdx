## Close AI API

Use the Close AI API to manage desktop coaching sessions, generate session analysis, configure prompt presets and analytics settings, manage sales scripts, and retrieve workspace dashboards.

<Callout kind="info">

All Close AI endpoints use the authenticated browser Supabase session cookie. They do not use desktop JWT authentication. Send requests to `https://app.talkturo.com` with the session cookie included.

</Callout>

## Endpoint summary

| Method | Path | Purpose |
| --- | --- | --- |
| `GET` | `/api/close-ai/sessions` | List Close AI sessions |
| `GET` | `/api/close-ai/sessions/{sessionId}` | Get a session and its related data |
| `PATCH` | `/api/close-ai/sessions/{sessionId}` | Rename or clear a session title |
| `DELETE` | `/api/close-ai/sessions/{sessionId}` | Delete a session and related data |
| `POST` | `/api/close-ai/sessions/{sessionId}/analyze` | Analyze a session transcript |
| `GET` | `/api/close-ai/prompts` | List prompt presets |
| `POST` | `/api/close-ai/prompts` | Create a prompt preset |
| `GET` | `/api/close-ai/settings` | Get analytics settings |
| `PUT` | `/api/close-ai/settings` | Update analytics settings |
| `GET` | `/api/close-ai/dashboard` | Get workspace dashboard metrics |
| `GET` | `/api/close-ai/scripts` | List workspace scripts |
| `POST` | `/api/close-ai/scripts` | Create a workspace script |
| `PUT` | `/api/close-ai/scripts` | Update a workspace script |
| `DELETE` | `/api/close-ai/scripts` | Delete a workspace script |

# Sessions

The sessions endpoints let you find recorded Close AI sessions, retrieve transcripts and analysis, rename sessions, delete sessions, and trigger analysis.

### List sessions

`GET /api/close-ai/sessions`

Use query parameters to paginate results, search session titles, or limit results to a workspace.

#### Query parameters

<ParamField query="limit" param-type="integer" required="false" enum="1,100">
Maximum number of sessions to return. Values are clamped to the range `1` through `100`. Defaults to `50`.
</ParamField>

<ParamField query="offset" param-type="integer" required="false">
Number of sessions to skip before returning results. Defaults to `0`.
</ParamField>

<ParamField query="q" param-type="string" required="false">
Case-insensitive substring search against the session title.
</ParamField>

<ParamField query="account" param-type="string" required="false">
Workspace slug. When provided, the response includes sessions for that workspace and legacy sessions without an account assignment.
</ParamField>

#### Request

<CodeGroup tabs="cURL,JavaScript">

```bash
curl "https://app.talkturo.com/api/close-ai/sessions?limit=25&offset=0&q=discovery&account=acme-sales" \
  -b "sb-session=authenticated-browser-session"
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/close-ai/sessions?limit=25&offset=0&q=discovery&account=acme-sales",
  {
    credentials: "include",
  }
);

const data = await response.json();
console.log(data.sessions);
```

</CodeGroup>

### Rename a session

`PATCH /api/close-ai/sessions/{sessionId}`

An empty title clears the existing title.

<ParamField path="sessionId" param-type="string" required="true">
Session identifier.
</ParamField>

<ParamField body="title" param-type="string" required="true">
New session title. Pass an empty string to clear the title.
</ParamField>

#### Request

<CodeGroup tabs="cURL,JavaScript">

```bash
curl -X PATCH "https://app.talkturo.com/api/close-ai/sessions/sess_7f2c91a4" \
  -H "Content-Type: application/json" \
  -b "sb-session=authenticated-browser-session" \
  -d '{"title":"Northstar discovery call"}'
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/close-ai/sessions/sess_7f2c91a4",
  {
    method: "PATCH",
    credentials: "include",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      title: "Northstar discovery call"
    })
  }
);

const data = await response.json();
console.log(data.title);
```

</CodeGroup>

#### Response

<Response>

```json
{
  "ok": true,
  "title": "Northstar discovery call"
}
```

</Response>

<ResponseField name="ok" field-type="boolean">
Whether the update succeeded.
</ResponseField>

<ResponseField name="title" field-type="string">
The updated session title.
</ResponseField>

### Create a prompt preset

`POST /api/close-ai/prompts`

<ParamField body="title" param-type="string" required="true">
Preset title. Must contain between 1 and 200 characters.
</ParamField>

<ParamField body="prompt" param-type="string" required="true">
Prompt text. Must contain between 1 and 20,000 characters.
</ParamField>

const response = await fetch(

### Update a script

The `id` field is required. Sections can use the type `script` or `info`. When `is_active` is `true`, all other scripts in the workspace are deactivated first.

</ParamField>

<ParamField body="name" param-type="string" required="false">
