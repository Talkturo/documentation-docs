## Voraussetzungen

<Callout kind="info">

Bevor Sie starten, stellen Sie sicher, dass Sie Folgendes haben:

- Ein Talkturo-Konto
- Zugriff auf das Talkturo-Dashboard unter `https://app.talkturo.ai`
- Einen API-Schlüssel, wenn Sie die API nutzen möchten
- Eine Kreditkarte, wenn Sie eine Telefonnummer über Ihre enthaltenen Credits hinaus kaufen möchten

Neue Workspaces starten mit 10 kostenlosen Credits, sodass Sie das initiale Setup abschließen können, bevor Sie sich zu größeren Ausgaben verpflichten.

</Callout>

Talkturo ermöglicht es Ihnen, einen KI-Voice-Assistenten zu erstellen, eine Telefonnummer zu verbinden und einen Live-Anruf in einem einzigen Setup-Flow zu testen. Die folgenden Schritte zeigen den schnellsten Weg zu einem funktionierenden Assistenten.

## Konto erstellen und verifizieren

Erstellen Sie zuerst Ihren Workspace und generieren Sie anschließend einen API-Schlüssel, wenn Sie das Setup automatisieren möchten.

<Steps>
  <Step title="Bei Talkturo registrieren">

    Öffnen Sie `https://app.talkturo.ai/signup` und erstellen Sie Ihr Konto.

    Nach erfolgreicher Registrierung erstellt Talkturo Ihren Workspace und schreibt automatisch 10 kostenlose Credits gut.

  </Step>
  <Step title="E-Mail verifizieren">

    Öffnen Sie die Verifizierungs-E-Mail von Talkturo und bestätigen Sie Ihre Adresse.

    Nach der Verifizierung können Sie sich im Dashboard anmelden und auf Ihre Workspace-Einstellungen zugreifen.

  </Step>
  <Step title="API-Schlüssel erstellen">

    Öffnen Sie im Dashboard Ihre Kontoeinstellungen und generieren Sie einen API-Schlüssel.

    Talkturo-API-Schlüssel verwenden das Format `tk_live_...` für Live-Umgebungen und `tk_test_...` für Testumgebungen. Kopieren Sie den Schlüssel, wenn Talkturo ihn anzeigt. Sie verwenden ihn im `Authorization`-Header als `Bearer tk_test_example_9xmk7q2r`.

  </Step>
</Steps>

## Ihren ersten KI-Assistenten erstellen

Erstellen Sie Ihren ersten Assistenten über den geführten Wizard oder mit einer einzelnen API-Anfrage. Beide Wege erzeugen denselben zugrunde liegenden Assistenten-Datensatz.

<Tabs>
  <Tab title="Dashboard" icon="monitor">

    Das Dashboard führt Sie durch einen 7-stufigen Setup-Flow:

    1. **Configure Assistant** — wählen Sie eine Vorlage und benennen Sie Ihren Assistenten.
    2. **Business Info** — fügen Sie den Geschäftskontext hinzu, den der Assistent in Gesprächen nutzen soll.
    3. **Phone Number** — suchen Sie nach einer Nummer oder verbinden Sie eine.
    4. **Company** — definieren Sie das Unternehmen, das der Assistent vertritt.
    5. **Contacts** — fügen Sie Kontakte hinzu oder importieren Sie sie, wenn Sie ausgehende Anrufe planen.
    6. **Campaign** — konfigurieren Sie bei Bedarf eine ausgehende Kampagne.
    7. **Complete** — prüfen Sie das Setup und schließen Sie es ab.

    Starten Sie unter `https://app.talkturo.ai/assistants` und klicken Sie auf **New Assistant**.

    Wählen Sie eine dieser Vorlagen:

    - **Outbound Setter**
    - **Inbound Support**
    - **Follow-up**
    - **Custom**

    Nach dem Erstellen zeigt Talkturo den Assistenten in Ihrer Assistentenliste und öffnet den Editor, damit Sie das Setup fortsetzen können.

  </Tab>
  <Tab title="API" icon="code">

    Senden Sie eine `POST`-Anfrage an `/api/assistants`, um den Assistenten direkt zu erstellen.

    <CodeGroup tabs="cURL,JavaScript">
      ```bash
      curl -X POST https://app.talkturo.ai/api/assistants \
        -H "Authorization: Bearer tk_test_example_9xmk7q2r" \
        -H "Content-Type: application/json" \
        -d '{
          "accountSlug": "acme-sales",
          "name": "Acme Inbound Assistant",
          "templateId": "custom"
        }'
      ```

      ```javascript
      const response = await fetch("https://app.talkturo.ai/api/assistants", {
        method: "POST",
        headers: {
          "Authorization": "Bearer tk_test_example_9xmk7q2r",
          "Content-Type": "application/json"
        },
        body: JSON.stringify({
          accountSlug: "acme-sales",
          name: "Acme Inbound Assistant",
          templateId: "custom"
        })
      });

      const assistant = await response.json();
      console.log(assistant.id);
      ```

    </CodeGroup>

    Verwenden Sie diese Request-Felder:

    - `accountSlug` — erforderlicher Workspace-Slug
    - `name` — erforderlicher Assistentenname
    - `templateId` — optionale Vorlagenkennung, Standard ist `custom`

    Eine erfolgreiche Anfrage gibt den neuen Assistenten-Datensatz zurück. Bewahren Sie die Assistenten-ID auf, denn Sie benötigen sie beim Zuweisen von Telefonnummern.

  </Tab>
</Tabs>

## Telefonnummer kaufen und zuweisen

Suchen Sie zuerst nach einer Nummer, kaufen Sie sie anschließend und verbinden Sie sie mit Ihrem Assistenten.

<Steps>
  <Step title="Nach einer Telefonnummer suchen" icon="search">

    Nutzen Sie den Telefonnummern-Flow im Dashboard oder rufen Sie die Search-API auf, um verfügbare Nummern zu finden.

    <CodeGroup tabs="cURL,JavaScript">
      ```bash
      curl -X POST https://app.talkturo.ai/api/phone-numbers/search \
        -H "Authorization: Bearer tk_test_example_9xmk7q2r" \
        -H "Content-Type: application/json" \
        -d '{
          "country": "US",
          "searchType": "local",
          "features": ["voice"],
          "limit": 5
        }'
      ```

      ```javascript
      const response = await fetch("https://app.talkturo.ai/api/phone-numbers/search", {
        method: "POST",
        headers: {
          "Authorization": "Bearer tk_test_example_9xmk7q2r",
          "Content-Type": "application/json"
        },
        body: JSON.stringify({
          country: "US",
          searchType: "local",
          features: ["voice"],
          limit: 5
        })
      });

      const results = await response.json();
      console.log(results);
      ```

    </CodeGroup>

    Bei erfolgreicher Suche gibt Talkturo eine Liste verfügbarer Nummern zurück. Wählen Sie einen Wert aus der Antwort für den Kaufschritt.

  </Step>
  <Step title="Nummer kaufen" icon="phone">

    Kaufen Sie die ausgewählte Nummer für Ihren Workspace.

    <CodeGroup tabs="cURL,JavaScript">
      ```bash
      curl -X POST https://app.talkturo.ai/api/phone-numbers/purchase \
        -H "Authorization: Bearer tk_test_example_9xmk7q2r" \
        -H "Content-Type: application/json" \
        -d '{
          "phoneNumber": "+14155550123",
          "accountSlug": "acme-sales"
        }'
      ```

      ```javascript
      const response = await fetch("https://app.talkturo.ai/api/phone-numbers/purchase", {
        method: "POST",
        headers: {
          "Authorization": "Bearer tk_test_example_9xmk7q2r",
          "Content-Type": "application/json"
        },
        body: JSON.stringify({
          phoneNumber: "+14155550123",
          accountSlug: "acme-sales"
        })
      });

      const purchase = await response.json();
      console.log(purchase);
      ```

    </CodeGroup>

    Nach dem Kauf erscheint die Nummer im Telefonnummern-Inventar Ihres Workspace.

  </Step>
  <Step title="Nummer Ihrem Assistenten zuweisen" icon="link">

    Verbinden Sie die gekaufte Nummer mit Ihrem Assistenten und aktivieren Sie die Anrufverarbeitung.

    <CodeGroup tabs="cURL,JavaScript">
      ```bash
      curl -X POST https://app.talkturo.ai/api/assistants/asst_7f3k29d/telephony/settings \
        -H "Authorization: Bearer tk_test_example_9xmk7q2r" \
        -H "Content-Type: application/json" \
        -d '{
          "accountSlug": "acme-sales",
          "phoneNumberIds": ["pn_4m8x2q1"],
          "inboundEnabled": true,
          "outboundEnabled": true
        }'
      ```

      ```javascript
      const response = await fetch("https://app.talkturo.ai/api/assistants/asst_7f3k29d/telephony/settings", {
        method: "POST",
        headers: {
          "Authorization": "Bearer tk_test_example_9xmk7q2r",
          "Content-Type": "application/json"
        },
        body: JSON.stringify({
          accountSlug: "acme-sales",
          phoneNumberIds: ["pn_4m8x2q1"],
          inboundEnabled: true,
          outboundEnabled: true
        })
      });

      const settings = await response.json();
      console.log(settings);
      ```

    </CodeGroup>

    Wenn dieser Schritt erfolgreich ist, kann der Assistent eingehende Anrufe auf der zugewiesenen Nummer entgegennehmen und ausgehende Anrufe tätigen, sofern Sie die ausgehende Telefonie aktiviert haben.

  </Step>
</Steps>

## Ihren ersten Anruf testen

Nutzen Sie die integrierten Testanruf-Tools, nachdem die Nummer zugewiesen wurde.

<Callout kind="tip">

Öffnen Sie Ihren Assistenten im Dashboard und gehen Sie dann zum Tab **Telephony**, um einen Testanruf zu starten.

Für einen Inbound-Test rufen Sie die dem Assistenten zugewiesene Nummer von Ihrem Telefon aus an. Für einen Outbound-Test nutzen Sie die Testanruf-Steuerung im Assistenten-Editor. Ein erfolgreicher Test verbindet den Anruf und leitet Audio über den soeben konfigurierten Assistenten.

</Callout>
