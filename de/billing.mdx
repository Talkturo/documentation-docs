## Verstehe dein Abrechnungsmodell

Talkturo rechnet Nutzung über **Guthaben** ab, nicht über direkte Rechnungen pro Anruf. Dein Workspace-Guthaben sinkt, während Anrufe laufen, und du kannst Guthaben unabhängig von deinem Abonnement hinzufügen.

Abonnements und Guthaben erfüllen unterschiedliche Zwecke. Ein Plan steuert den Produktzugang und die enthaltenen monatlichen Guthaben, während Aufladungen zusätzlich nutzbare Guthaben für Voice-Nutzung hinzufügen, wenn du mehr Kapazität brauchst.

<Callout kind="info" collapsed="false">

Guthaben werden in Echtzeit verbraucht, sobald Anrufe stattfinden. Wenn deine Workflows von Telefonanrufen abhängen, halte genügend Guthaben verfügbar oder aktiviere Auto-Reload, um Unterbrechungen zu vermeiden.

</Callout>

## So funktionieren Guthaben

Jeder Workspace hat ein Guthaben, das auch anteilige Nutzung unterstützt. Talkturo kann kleine Beträge wie `0.025` Guthaben für kurze Anrufe oder teilweise Nutzung abziehen, damit dein Guthaben den tatsächlichen Verbrauch widerspiegelt, statt jedes Ereignis auf ganze Zahlen aufzurunden.

Neue Workspaces starten mit **10 kostenlosen Guthaben**. Talkturo fügt Guthaben über eine kleine Anzahl von Transaktionstypen hinzu oder zieht sie ab. Diese erscheinen in deinem Abrechnungsverlauf.

### Wechselkurs für Guthaben

Talkturo verwendet einen Basis-Wechselkurs von **1 USD = 2 Guthaben**. Dieser Wechselkurs gilt auch für Standard-Aufladungen und Auto-Reload-Berechnungen, sofern keine Aktion mit Bonus-Guthaben gilt.

### Transaktionstypen

| Transaktionstyp | Bedeutung                                                     |
| --------------- | ------------------------------------------------------------- |
| `purchase`      | Guthaben werden nach einer bezahlten Aufladung hinzugefügt    |
| `usage`         | Guthaben werden durch Anrufe und damit verbundene Nutzung verbraucht |
| `bonus`         | Werbe- oder Zusatzguthaben werden dem Workspace hinzugefügt   |
| `refund`        | Guthaben werden nach einer Anpassung zurückerstattet          |
| `signup_bonus`  | Anfängliche kostenlose Guthaben bei der Erstellung eines Workspace |
| `reset`         | Administrative Zurücksetzung oder Korrektur des Guthabens     |

<Callout kind="tip" collapsed="false">

Weil Guthaben anteilige Beträge unterstützen, führen kurze Anrufe und Teilminuten nicht zu Überberechnung in deinem Workspace. Du zahlst für das tatsächliche Nutzungsmuster, nicht für ein aufgerundetes Paket.

</Callout>

## Vergleiche Abonnements

Pläne definieren dein monatliches Basispaket. Die in einem Plan enthaltenen Guthaben werden monatlich erneuert, während gekaufte Aufladungsguthaben getrennt von der Preisgestaltung des Plans verwaltet werden.

| Plan       | Monatlicher Preis     | Enthaltene monatliche Guthaben | Enthält                                  |
| ---------- | --------------------- | ------------------------------ | ---------------------------------------- |
| Free       | 0 $/Monat             | 10                             | Öffentliche Projekte, unbegrenzte Mitwirkende |
| Pro        | Standardmäßig 100 $/Monat | 400                        | Alle Funktionen von Free                 |
| Business   | Standardmäßig 200 $/Monat | 400                        | Alle Funktionen von Pro, SSO, interne Veröffentlichung |
| Enterprise | Individuelle Preise   | Individuell                    | Dedizierter Support, individuelle Verbindungen |

<Callout kind="info" collapsed="false">

Die Preise für Pro und Business werden dynamisch festgelegt und können von den hier gezeigten Standardbeträgen abweichen.

</Callout>

## Füge Guthaben-Aufladungen hinzu

Aufladungen erhöhen dein verfügbares Nutzungsguthaben über die im Abonnement enthaltenen Guthaben hinaus. Diesen Betrag nutzt du während Voice-Aktivitäten.

| Paket                 | Preis       | Hinzugefügte Guthaben                                          |
| --------------------- | ----------- | -------------------------------------------------------------- |
| Starter-Paket         | 99 $        | 198                                                            |
| Pro-Paket             | 349 $       | 698                                                            |
| Business-Paket        | 499 $       | 998                                                            |
| Individuelles Guthaben | Mindestens 99 $ | Jeder Betrag über dem Mindestwert, umgerechnet zum aktuellen Kurs |

Bonus-Guthaben können gelten, wenn du über Zahlungslinks für Agents kaufst. In diesen Fällen kann Talkturo bis zu **20 % zusätzliche Guthaben** zusätzlich zur Standardumrechnung hinzufügen.

## Sieh, wie Anrufe Guthaben verbrauchen

Die Kosten eines Anrufs hängen von den Komponenten ab, die dein Assistant verwendet. Standard-Voice-Pipelines können jeden Dienst separat berechnen, während der Realtime-Modus einen einzigen gebündelten Minutenpreis verwendet.

### Komponenten der Standardnutzung

| Komponente            | Abrechnungseinheit    | Hinweise                                         |
| --------------------- | --------------------- | ------------------------------------------------ |
| Speech-to-Text        | Pro Minute            | Wird für die Transkription von Live-Anrufaudio berechnet |
| LLM prompt tokens     | Pro 1.000 Tokens      | Wird für Modelleingaben berechnet                |
| LLM completion tokens | Pro 1.000 Tokens      | Wird für Modellausgaben berechnet                |
| Text-to-Speech        | Pro 1.000 Zeichen     | Wird für erzeugte Sprachausgabe berechnet        |
| Telephony             | Pro Minute            | Wird für Telefonverbindung und Anrufdauer berechnet |

### Realtime-Modus

Der Realtime-Modus verwendet einen **einzigen Preis pro Minute** statt separater Positionen für Speech-to-Text, LLM und Text-to-Speech. Das vereinfacht die Abrechnung, wenn dein Assistant auf einem Realtime-Stack läuft.

### Beispiel für die Kostenberechnung

Eine typische Schätzung verwendet diese Annahmen pro Gesprächsminute:

- **TTS-Ausgabe:** 750 Zeichen pro Minute
- **LLM-Eingabe:** 600 Prompt-Tokens pro Minute
- **LLM-Ausgabe:** 400 Completion-Tokens pro Minute

Mit einem Standard-Stack wie **Deepgram STT + OpenAI LLM + Cartesia TTS + Telnyx Telephony** liegen die gemischten Kosten bei ungefähr **0.21 Guthaben pro Minute**.

Das bedeutet:

| Anrufdauer | Ungefähre Kosten |
| ---------- | ---------------- |
| 1 Minute   | 0.21 Guthaben    |
| 5 Minuten  | 1.05 Guthaben    |
| 10 Minuten | 2.1 Guthaben     |
| 30 Minuten | 6.3 Guthaben     |

Diese Werte sind Schätzungen, keine feste Garantie. Die tatsächlichen Kosten ändern sich je nach Anrufdauer, Sprechgeschwindigkeit, Token-Nutzung, erzeugtem Sprachvolumen, Telephony-Routing und danach, ob du den Standard- oder Realtime-Modus verwendest.

<Callout kind="info" collapsed="false">

Ein Anruf mit umfangreicherer Modellausgabe oder längeren Assistant-Antworten verbraucht mehr LLM-Tokens und TTS-Zeichen. Daher können zwei Anrufe mit derselben Dauer unterschiedliche Kosten verursachen.

</Callout>

## Konfiguriere Auto-Reload

Auto-Reload hält deinen Workspace finanziert, indem deine gespeicherte Zahlungsmethode belastet wird, wenn das Guthaben unter einen Schwellenwert fällt. Das ist die sicherste Option, wenn du Telefonnummern in Produktion oder geplante ausgehende Aktivitäten betreibst.

### Auto-Reload-Einstellungen

<ParamField body="enabled" param-type="boolean" required="true" deprecated="false" show-location="false">
  Schaltet Auto-Reload für den Workspace ein oder aus.
</ParamField>

<ParamField body="amount" param-type="number" required="true" deprecated="false" show-location="false">
  Dollar-Betrag, der bei jeder Aufladung berechnet wird. Der Standardwert ist `10 $`.
</ParamField>

<ParamField body="threshold" param-type="number" required="true" deprecated="false" show-location="false">
  Guthabenstand, der eine Aufladung auslöst. Der Standardschwellenwert beträgt `10` Guthaben.
</ParamField>

### So werden Reload-Guthaben berechnet

Talkturo rechnet eine Reload-Belastung mit folgender Formel in Guthaben um:

`max(1, round(amount_usd × 2))`

Zum Beispiel fügt ein **10-$-Auto-Reload** **20 Guthaben** hinzu.

### Anforderungen und Verhalten von Auto-Reload

- Auto-Reload erfordert eine gespeicherte **Standard-Zahlungsmethode**
- Belastungen laufen über die **Stripe-Rechnungsstellung**
- Ein erfolgreiches Reload kann **gesperrte Telefonnummern** wieder aktivieren
- Reload erfolgt automatisch, wenn das Guthaben unter den konfigurierten Schwellenwert fällt

<Callout kind="alert" collapsed="false">

Wenn keine Standard-Zahlungsmethode verfügbar ist, kann Talkturo ein Auto-Reload nicht abschließen. Niedrige Guthabenstände können telefonbasierte Workflows unterbrechen, bis du eine Zahlungsmethode hinzufügst oder manuell auflädst.

</Callout>

## Verstehe Desktop-App-Pläne

Der Zugriff auf die Close AI Desktop-App wird getrennt von den Voice-Guthaben deines Workspace abgerechnet. Diese Pläne steuern Desktop-Sitze, nicht das Guthaben für Voice-Agents.

| Desktop-Plan       | Monatlicher Preis         | Sitze  | Hinweise                               |
| ------------------ | ------------------------- | ------ | -------------------------------------- |
| Desktop Starter    | 186 $/Monat               | 1      | Plan für einen einzelnen Sitz          |
| Desktop Pro        | 373 $/Monat               | 3      | Mit zusätzlichen Sitzen erweiterbar    |
| Desktop Enterprise | Individuell               | Individuell | Preise und Bedingungen verhandelbar |
| Zusätzlicher Sitz  | 99 $/Monat oder 1.188 $/Jahr | 1 je Sitz | Preis für Zusatzsitze              |

Wenn dein Team sowohl Desktop-Coaching als auch Voice-Agents nutzt, plane diese als getrennte Budgetposten: Desktop-Sitze für Nutzer, Guthaben für die Ausführung von Anrufen.

## Verwalte Zahlungsmethoden und Rechnungen

Stripe ist der primäre Abrechnungsanbieter für Talkturo. Gespeicherte Karten werden für Käufe und Auto-Reload verwendet, und Rechnungen sind als herunterladbare PDFs verfügbar.

Talkturo unterstützt in einigen Abrechnungsabläufen auch Lemon Squeezy als ältere Alternative. Wenn dein Workspace diesen älteren Weg verwendet, kannst du eine andere Kaufabwicklung sehen als bei Stripe-basierten Abläufen.

### Was du erwarten kannst

- **Gespeicherte Karten** unterstützen automatische Reloads
- **Stripe-Rechnungen** liefern einen Abrechnungsnachweis für Käufe
- **PDF-Rechnungen** stehen zum Download bereit
- **Ältere Lemon-Squeezy-Abläufe** können in älteren Setups weiterhin erscheinen

## Fordere Guthaben-Zuschüsse an

Talkturo kann Guthaben an Käufe anhängen, die über **Agent-Zahlungslinks** erfolgen. Diese Guthaben werden als Zuschüsse ausgegeben und durchlaufen einen einfachen Lebenszyklus, bevor sie sich auf das Guthaben eines Workspace auswirken.

### Lebenszyklus eines Zuschusses

| Status      | Bedeutung                                                     |
| ----------- | ------------------------------------------------------------- |
| `unclaimed` | Der Guthaben-Zuschuss existiert, ist aber keinem Workspace zugewiesen |
| `claimed`   | Der Zuschuss wurde auf einen Workspace angewendet             |

### So werden Zuschüsse verwendet

Workspace-Eigentümer oder Admins können einen Zuschuss im Dashboard einem Workspace zuweisen. Wenn der Zahlungslink ein Kauf-und-Klonen-Verhalten unterstützt, kann Talkturo während des Claim-Ablaufs auch den ursprünglichen Assistant in den Ziel-Workspace klonen.

<Callout kind="tip" collapsed="false">

Wenn du Assistants über Zahlungslinks verkaufst, können Zuschüsse die Nutzung direkt nach dem Kauf finanzieren und den Einrichtungsaufwand verringern, indem der ursprüngliche Assistant in den Workspace des Käufers geklont wird.

</Callout>

## Halte die Abrechnung planbar

Einige Gewohnheiten machen die Nutzung von Guthaben leichter planbar:

- Aktiviere **Auto-Reload**, bevor du Telefonie in Produktion einsetzt
- Prüfe **Kostenaufschlüsselungen pro Anruf**, um zu verstehen, welche Komponenten die Ausgaben treiben
- Trenne **Planbudget** von **Guthabenbudget**
- Achte auf **Bonus-Guthaben**, wenn du Agent-Zahlungslinks verteilst
- Halte eine gültige **Standard-Zahlungsmethode** hinterlegt
