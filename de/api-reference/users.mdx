## Benutzer-Endpunkte

Verwalten Sie das Profil des authentifizierten Desktop-Benutzers, listen Sie zugriffsberechtigte Workspaces auf und lesen Sie den Desktop-Abonnementstatus aus.

<Callout kind="info">

**Authentifizierung**

Alle Endpunkte auf dieser Seite erwarten ein Desktop-Bearer-JWT im Header `Authorization`. Verwenden Sie keinen API-Schlüssel. Die Authentifizierung erfolgt mit `Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt`.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/users/me` | Profil des authentifizierten Benutzers abrufen |
| `PUT` | `/api/users/me` | Anzeigenamen aktualisieren |
| `DELETE` | `/api/users/me` | Benutzerlöschung anfordern |
| `GET` | `/api/users/me/workspaces` | Workspaces mit Desktop-Zugriff auflisten |
| `GET` | `/api/users/me/subscription` | Desktop-Abonnementstatus abrufen |
| `GET` | `/api/users/me/auto-update` | Auto-Update-Status abrufen |
| `PUT` | `/api/users/me/auto-update` | Auto-Update-Einstellung setzen |

## GET /api/users/me

Rufen Sie das Profil des authentifizierten Benutzers ab.

### Header

<ParamField header="Authorization" param-type="string" required="true">

Desktop-Bearer-JWT im Format `Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt`.

</ParamField>

### Anfragebeispiel

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://api.talkturo.com/api/users/me" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt"
```

```javascript
const response = await fetch("https://api.talkturo.com/api/users/me", {
  method: "GET",
  headers: {
    "Authorization": "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt"
  }
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,401" default-tab="1">
```json
{
  "success": true,
  "data": {
    "uid": "usr_2m9x8k41",
    "email": "lea.hoffmann@talkturo.dev",
    "display_name": "Lea Hoffmann",
    "auto_update_enabled": true,
    "has_migrated_to_firebase": 0
  }
}
```

```json
{
  "success": false,
  "error": "Unauthorized"
}
```
</Response>

<ResponseField name="success" field-type="boolean" required="true">

Gibt an, ob die Anfrage erfolgreich war.

</ResponseField>

<ResponseField name="data" field-type="object" required="true">

Enthält die Profildaten des authentifizierten Benutzers.

</ResponseField>

<ResponseField name="data.uid" field-type="string" required="true">

Eindeutige Benutzer-ID.

</ResponseField>

<ResponseField name="data.email" field-type="string" required="true">

E-Mail-Adresse des Benutzers.

</ResponseField>

<ResponseField name="data.display_name" field-type="string" required="true">

Aktueller Anzeigename.

</ResponseField>

<ResponseField name="data.auto_update_enabled" field-type="boolean" required="true">

Auto-Update-Status. Dieser Wert ist derzeit immer `true`.

</ResponseField>

<ResponseField name="data.has_migrated_to_firebase" field-type="integer" required="true">

Migrationskennzeichen. Dieser Wert ist derzeit immer `0`.

</ResponseField>

| Status | Bedeutung |
| --- | --- |
| `401` | Das Bearer-JWT fehlt, ist ungültig oder kann nicht authentifiziert werden. |

## PUT /api/users/me

Aktualisieren Sie den Anzeigenamen des authentifizierten Benutzers.

### Header

<ParamField header="Authorization" param-type="string" required="true">

Desktop-Bearer-JWT im Format `Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt`.

</ParamField>

### Body-Parameter

<ParamField body="display_name" param-type="string" required="true">

Neuer Anzeigename des Benutzers.

</ParamField>

### Anfragebeispiel

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X PUT "https://api.talkturo.com/api/users/me" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt" \
  -H "Content-Type: application/json" \
  -d '{
    "display_name": "Lea M. Hoffmann"
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/users/me", {
  method: "PUT",
  headers: {
    "Authorization": "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    display_name: "Lea M. Hoffmann"
  })
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,400,500" default-tab="1">
```json
{
  "success": true,
  "data": {
    "uid": "usr_2m9x8k41"
  }
}
```

```json
{
  "success": false,
  "error": "Invalid JSON body"
}
```

```json
{
  "success": false,
  "error": "Failed to update user"
}
```
</Response>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">

Gibt an, ob die Aktualisierung erfolgreich war.

</ResponseField>

<ResponseField name="data" field-type="object" required="true">

Enthält das Ergebnis der Aktualisierung.

</ResponseField>

<ResponseField name="data.uid" field-type="string" required="true">

Benutzer-ID des aktualisierten Profils.

</ResponseField>

### Fehler

| Status | Bedeutung |
| --- | --- |
| `400` | Der Request-Body enthält ungültiges JSON. |
| `500` | Die Aktualisierung des Benutzers ist serverseitig fehlgeschlagen. |

## GET /api/users/me/subscription

Rufen Sie den Desktop-Abonnementstatus des authentifizierten Benutzers oder eines Mitglieds-Workspace ab.

Wenn Sie den optionalen Header `X-Talkturo-Account` senden, wertet der Endpunkt das Abonnement für den angegebenen Workspace-Kontext aus.

### Header

<ParamField header="Authorization" param-type="string" required="true">

Desktop-Bearer-JWT im Format `Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt`.

</ParamField>

<ParamField header="X-Talkturo-Account" param-type="string" required="false">

Optionaler Workspace-Bezug für die Abfrage des Abonnementstatus.

</ParamField>

### Anfragebeispiel

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://api.talkturo.com/api/users/me/subscription" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt" \
  -H "X-Talkturo-Account: nordstern-vertrieb"
```

```javascript
const response = await fetch("https://api.talkturo.com/api/users/me/subscription", {
  method: "GET",
  headers: {
    "Authorization": "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt",
    "X-Talkturo-Account": "nordstern-vertrieb"
  }
});

const data = await response.json();
console.log(data);
```
</Request>

<ParamField header="X-Talkturo-Account" param-type="string" required="false">

Workspace-Slug oder konto-bezogener Kontext für eine workspace-spezifische Abfrage. Wenn der Benutzer kein Mitglied ist, gibt der Endpunkt `403` zurück.

</ParamField>

### Antwortfelder

</ResponseField>

<ResponseField name="data.account_id" field-type="string" required="true">

Workspace-ID, für die der Status ausgewertet wurde.

</ResponseField>

<ResponseField name="data.account_slug" field-type="string" required="true">

Workspace-Slug, für den der Status ausgewertet wurde.

</ResponseField>

<ResponseField name="data.access_blocked_reason" field-type="string" required="false">

Grund für gesperrten Zugriff oder `null`, wenn kein Zugriff blockiert ist.

Planlimits für den ausgewerteten Workspace.

<ResponseField name="data.limits.seats" field-type="integer" required="true">

<ResponseField name="data.limits.calls_per_month" field-type="integer" required="true">

<ResponseField name="data.usage.calls_this_month" field-type="integer" required="true">

</ResponseField>

<ResponseField name="data.usage.calls_limit" field-type="integer" required="true">

Monatliches Anruflimit für den aktuellen Plan.

</ResponseField>

## PUT /api/users/me/auto-update

Senden Sie eine Auto-Update-Einstellung an den Endpunkt.

Der Endpunkt akzeptiert einen Request-Body, wertet ihn aber derzeit nicht aus.

<Callout kind="alert">

`PUT /api/users/me/auto-update` ist derzeit ein Stub-Endpunkt. Jeder gültige Request führt zu einer Antwort mit `enabled: true`, unabhängig vom gesendeten Body.

</Callout>

### Header

<ParamField header="Authorization" param-type="string" required="true">

Desktop-Bearer-JWT im Format `Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt`.

</ParamField>

### Body-Parameter

<ParamField body="any" param-type="any" required="false">

Beliebiger JSON-Body. Der Endpunkt ignoriert den Inhalt.

</ParamField>

### Anfragebeispiel

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X PUT "https://api.talkturo.com/api/users/me/auto-update" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt" \
  -H "Content-Type: application/json" \
  -d '{
    "enabled": false
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/users/me/auto-update", {
  method: "PUT",
  headers: {
    "Authorization": "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example_desktop_jwt",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    enabled: false
  })
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "success": true,
  "data": {
    "enabled": true
  }
}
```
</Response>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">

</ResponseField>

<ResponseField name="data" field-type="object" required="true">

Enthält den zurückgegebenen Auto-Update-Status.

</ResponseField>
