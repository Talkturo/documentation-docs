## Nutzungsdaten über die API abrufen

Rufen Sie Kontolimits, aktuelle Guthaben, Nutzungszeitreihen und Desktop-Sprachnutzung über die Talkturo API ab.

<Callout kind="info">

Senden Sie alle API-Anfragen an `https://api.talkturo.com/api`.

</Callout>

### Authentifizierung

Die Nutzungsendpunkte verwenden zwei Authentifizierungsmethoden:

<Tabs>
<Tab title="API-Key oder Web-Session">

Verwenden Sie diese Authentifizierung für `GET /api/usage/current`. Senden Sie entweder einen Talkturo API-Key oder ein Supabase-Session-Token als Bearer-Token. Eine Cookie-basierte Supabase-Session wird ebenfalls akzeptiert.

```http
Authorization: Bearer tk_live_example_9xmk7q2r
```

</Tab>

<Tab title="Desktop-JWT">

Verwenden Sie diese Authentifizierung für die Desktop-Endpunkte. Senden Sie ein gültiges Supabase-Access-Token als Bearer-Token.

```http
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example
```

</Tab>
</Tabs>

## Aktuelle Kontonutzung abrufen

```http
GET /api/usage/current?accountId=acc_7f3a9c2d
```

Dieser Endpunkt gibt die Limits, die Nutzung des aktuellen Monats, verbleibende Ressourcen und prozentuale Auslastungen eines Kontos zurück.

### Anfrage

<Request tabs="cURL,JavaScript">

```bash
curl "https://api.talkturo.com/api/usage/current?accountId=acc_7f3a9c2d" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r"
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/usage/current?accountId=acc_7f3a9c2d",
  {
    headers: {
      Authorization: "Bearer tk_live_example_9xmk7q2r",
    },
  },
);

const usage = await response.json();
console.log(usage);
```

</Request>

<ParamField query="accountId" param-type="string" required="true">

Konto- oder Workspace-Kennung, für die die Limits und Nutzungsdaten abgerufen werden.

</ParamField>

### Antwort

<Response tabs="200,400,404,500">

#### Antwortfelder

<ResponseField name="limits" field-type="object">

Kontolimits aus der Kontokonfiguration. Das Objekt enthält unter anderem `monthly_credits`, `daily_credits`, `max_daily_credits`, `minutes_per_month`, `parallel_calls` und `max_ai_agents`.

</ResponseField>

<ResponseField name="usage" field-type="object">

Nutzung des aktuellen Monats. Das Objekt enthält unter anderem `minutes_used`, `calls_made`, `credits_used`, `peak_parallel_calls`, `ai_agents_created` und `credits_remaining`.

</ResponseField>

<ResponseField name="remaining" field-type="object">

Verbleibende Ressourcen für `credits`, `daily_credits`, `minutes`, `parallel_calls` und `ai_agents`.

</ResponseField>

<ResponseField name="percentages" field-type="object">

Prozentuale Auslastung für `credits`, `daily_credits`, `minutes`, `parallel_calls` und `ai_agents`.

</ResponseField>

<ResponseField name="credit_info" field-type="object">

Zusammengefasste Guthabeninformationen einschließlich verbrauchter, verbleibender und übertragener Guthaben.

</ResponseField>

<Callout kind="alert">

`accountId` ist erforderlich. Der Handler prüft im Pfad ohne zusätzliche Kontoanforderung nicht unabhängig, ob die angegebene Kontokennung zum authentifizierten Benutzer gehört. Verwenden Sie nur Kontokennungen, auf die der authentifizierte Aufrufer zugreifen darf.

</Callout>

## Desktop-Sprachnutzung protokollieren

```http
POST /api/usage/voice
```

Verwenden Sie diesen Endpunkt, um ein Desktop-Sprachnutzungsereignis zu protokollieren. Die Authentifizierung erfolgt über ein Desktop-JWT.

### Anfrage

<Request tabs="cURL,JavaScript">

```bash
curl "https://api.talkturo.com/api/usage/voice" \
  -X POST \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example" \
  -H "Content-Type: application/json" \
  -d '{
    "connectionId": "conn_8d4f1a2c",
    "durationSeconds": 185,
    "provider": "deepgram",
    "model": "nova-3",
    "userEmail": "jane.chen@acme.test"
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/usage/voice", {
  method: "POST",
  headers: {
    Authorization:
      "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    connectionId: "conn_8d4f1a2c",
    durationSeconds: 185,
    provider: "deepgram",
    model: "nova-3",
    userEmail: "jane.chen@acme.test",
  }),
});

const result = await response.json();
console.log(result);
```

</Request>

<ParamField body="connectionId" param-type="unknown" required="false">

Kennung der Desktop-Verbindung. Der Standardwert ist `null`.

</ParamField>

<ParamField body="durationSeconds" param-type="number" required="false">

Dauer der Sprachnutzung in Sekunden. Der Wert wird auf eine nicht negative Ganzzahl gerundet. Der Standardwert ist `0`.

</ParamField>

<ParamField body="provider" param-type="string" required="false">

Name des Sprachdienstanbieters. Der Standardwert ist `deepgram`.

</ParamField>

<ParamField body="model" param-type="string" required="false">

Name des verwendeten Sprachmodells. Der Standardwert ist `nova-3`.

</ParamField>

<ParamField body="userEmail" param-type="unknown" required="false">

E-Mail-Adresse des Desktop-Benutzers. Der Standardwert ist `null`.

</ParamField>

### Antwort

<Response tabs="200,400,500">

```json
{
  "success": true,
  "data": {}
}
```

```json
{
  "success": false,
  "error": "Invalid JSON body"
}
```

```json
{
  "success": false,
  "error": "Usage logging failed"
}
```

</Response>

<ResponseField name="success" field-type="boolean" required="true">

Gibt an, ob die Anfrage verarbeitet wurde.

</ResponseField>

<ResponseField name="data" field-type="object" required="true">

Leeres Objekt bei erfolgreicher Verarbeitung.

</ResponseField>

<Callout kind="info">

Ein Fehler beim Einfügen des Nutzungsereignisses wird protokolliert, führt aber nicht automatisch zu einem Fehler der Anfrage. Der berechnete Kostenwert basiert auf `durationSeconds / 60 * 0.0077`.

</Callout>

## Workspace-Nutzung für einen Zeitraum abrufen

```http
GET /api/accounts/{accountId}/usage
```

Dieser Endpunkt liefert eine tägliche oder wöchentliche Nutzungszeitreihe, aggregierte Summen und paginierte Anrufdaten für einen Workspace. Sie benötigen eine gültige Web-Supabase-Session. Der authentifizierte Benutzer muss Eigentümer des Kontos sein oder über eine Mitgliedschaft verfügen.

### Anfrage

<Request tabs="cURL,JavaScript">

```bash
curl "https://api.talkturo.com/api/accounts/7b3a9c2d-1e4f-4a6b-8c2d-9f0e1a2b3c4d/usage?from=2026-09-01T00%3A00%3A00Z&to=2026-09-12T23%3A59%3A59Z&granularity=day&page=1&pageSize=25" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example"
```

```javascript
const accountId = "7b3a9c2d-1e4f-4a6b-8c2d-9f0e1a2b3c4d";
const params = new URLSearchParams({
  from: "2026-09-01T00:00:00Z",
  to: "2026-09-12T23:59:59Z",
  granularity: "day",
  page: "1",
  pageSize: "25",
});

const response = await fetch(
  `https://api.talkturo.com/api/accounts/${accountId}/usage?${params}`,
  {
    headers: {
      Authorization:
        "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example",
    },
  },
);

const usage = await response.json();
console.log(usage);
```

</Request>

<ParamField path="accountId" param-type="string" required="true">

Kennung des Workspace oder Kontos.

</ParamField>

<ParamField query="from" param-type="string" required="true">

Startzeitpunkt des Nutzungszeitraums im ISO-8601-Format.

</ParamField>

<ParamField query="to" param-type="string" required="true">

Endzeitpunkt des Nutzungszeitraums im ISO-8601-Format.

</ParamField>

<ParamField query="assistantId" param-type="string" required="false">

UUID eines Assistenten. Wenn Sie den Parameter angeben, werden Nutzungs- und Anrufdaten auf diesen Assistenten begrenzt.

</ParamField>

<ParamField query="page" param-type="integer" required="false">

Seitennummer der Anrufdaten. Der Standardwert ist `1`. Werte kleiner als `1` werden auf `1` gesetzt.

</ParamField>

<ParamField query="pageSize" param-type="integer" required="false">

Anzahl der Anrufdaten pro Seite. Der Standardwert ist `25`. Der Wert wird auf den Bereich von `1` bis `100` begrenzt.

</ParamField>

<ParamField query="granularity" param-type="string" required="false" enum="day,week">

Granularität der `series`. Der Standardwert ist `day`. Nur der exakte Wert `week` erzeugt eine wöchentliche Gruppierung. Andere Werte werden als `day` behandelt.

</ParamField>

## Desktop-Nutzung prüfen und erfassen

```http
POST /api/desktop/usage
```

Verwenden Sie diesen Endpunkt, um zu prüfen, ob eine Desktop-Sitzung Zugriff hat und wie viele Aufrufe im aktuellen Monat bereits gezählt wurden.

### Anfrage

<Request tabs="cURL,JavaScript">

```bash
curl "https://api.talkturo.com/api/desktop/usage" \
  -X POST \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example" \
  -H "Content-Type: application/json" \
  -H "x-talkturo-account: 7b3a9c2d-1e4f-4a6b-8c2d-9f0e1a2b3c4d" \
  -d '{
    "session_id": "session_5f8a2c1d",
    "duration_seconds": 120,
    "kind": "listen"
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/desktop/usage", {
  method: "POST",
  headers: {
    Authorization:
      "Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.example",
    "Content-Type": "application/json",
    "x-talkturo-account": "7b3a9c2d-1e4f-4a6b-8c2d-9f0e1a2b3c4d",
  },
  body: JSON.stringify({
    session_id: "session_5f8a2c1d",
    duration_seconds: 120,
    kind: "listen",
  }),
});

const usage = await response.json();
console.log(usage);
```

</Request>

<ParamField header="x-talkturo-account" param-type="string" required="false">

Optionale Workspace- oder Kontokennung. Wenn Sie den Header angeben, muss der authentifizierte Benutzer Eigentümer oder Mitglied des Kontos sein.

</ParamField>

<ParamField body="session_id" param-type="string" required="true">

Kennung der Desktop-Sitzung. Der Endpunkt prüft, ob die Sitzung existiert und zum authentifizierten Benutzer gehört.

</ParamField>

<ParamField body="duration_seconds" param-type="number" required="false">

Optionale Sitzungsdauer in Sekunden. Der aktuelle Handler liest den Wert, verwendet ihn aber nicht für die Nutzungsprüfung.

</ParamField>

<ParamField body="kind" param-type="string" required="false" enum="listen,ask">

Optionale Nutzungsart. Der aktuelle Handler liest den Wert, verwendet ihn aber nicht für die Nutzungsprüfung.

</ParamField>

### Antwort

<Response tabs="200,402,403,404">

```json
{
  "ok": true,
  "calls_this_month": 18,
  "calls_remaining": 82
}
```

```json
{
  "ok": true,
  "calls_this_month": 0,
  "calls_remaining": -1
}
```

```json
{
  "ok": false,
  "reason": "over_cap",
  "upgrade_url": "/home",
  "calls_this_month": 100,
  "calls_limit": 100
}
```

```json
{
  "ok": false,
  "reason": "session_not_found"
}
```

</Response>

<ResponseField name="ok" field-type="boolean" required="true">

Gibt an, ob der Desktop-Aufruf autorisiert und innerhalb des Nutzungslimits liegt.

</ResponseField>

<ResponseField name="calls_this_month" field-type="number" required="true">

Anzahl der Aufrufe im aktuellen Monat.

</ResponseField>

<ResponseField name="calls_remaining" field-type="number" required="true">

Verbleibende Aufrufe. Bei unbegrenzten Tarifen ist der Wert `-1`.

</ResponseField>

<ResponseField name="reason" field-type="string">

Fehlergrund, zum Beispiel `invalid_body`, `missing_session_id`, `session_not_found`, `no_access` oder `over_cap`.

</ResponseField>

<ResponseField name="upgrade_url" field-type="string">

Pfad zur Upgrade-Seite bei fehlendem Desktop-Zugriff oder überschrittenem Nutzungslimit.

</ResponseField>

<Callout kind="info">

Der Endpunkt akzeptiert auch `OPTIONS` ohne Authentifizierung. Diese Anfrage dient der Desktop-CORS-Unterstützung und prüft keine Sitzung.

</Callout>
