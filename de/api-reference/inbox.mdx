## Talkturo Inbox API

Verwalten Sie Kontakte, Anrufe und E-Mail-Threads über einen gemeinsamen Posteingang. Sie können Kontakte suchen, Status ändern, Postfächer verwalten, Nachrichten senden und Nylas-Ereignisse empfangen.

<Callout kind="info">

Alle Inbox-Endpunkte verwenden die Basis-URL `https://app.talkturo.com`. Die Authentifizierung erfolgt ausschließlich über eine authentifizierte Supabase-Browsersitzung oder ein Sitzungs-Bearer-Token. API-Schlüssel werden mit HTTP `403` abgelehnt.

Für Bearer-Sitzungstoken ist `accountSlug` erforderlich. Cookie-basierte Browser-Anfragen können alternativ `teamId` verwenden.

</Callout>

| `GET` | `/api/inbox/members` | Workspace-Mitglieder auflisten | Sitzung |
| `GET` | `/api/inbox/availability` | E-Mail-Adresse prüfen | Sitzung |
| `GET` | `/api/inbox/assistants/{assistantId}/calls` | Anrufe eines Assistenten auflisten | Sitzung |
| `GET` | `/api/inbox/assistants/{assistantId}/calls/{callId}` | Anrufdetails abrufen | Sitzung |

| `GET`, `POST`, `PATCH`, `DELETE` | `/api/inbox/assistants/{assistantId}/mailbox` | Postfach verwalten | Sitzung |
| `POST` | `/api/inbox/assistants/{assistantId}/send` | E-Mail senden | Sitzung |
| `GET` | `/api/inbox/assistants/{assistantId}/threads` | E-Mail-Threads auflisten | Sitzung |
| `POST`, `DELETE` | `/api/inbox/assistants/{assistantId}/threads/{threadId}/block` | Absender blockieren oder entsperren | Sitzung |
| `POST` | `/api/inbox/assistants/{assistantId}/threads/{threadId}/folder` | Thread verschieben | Sitzung |
| `GET`, `POST` | `/api/inbox/threads/{threadId}` | Thread-Nachrichten abrufen oder als gelesen markieren | Sitzung |
| `GET` | `/api/inbox/attachments/{attachmentId}` | Anhang herunterladen | Sitzung |
| `GET`, `POST` | `/api/inbox/nylas/webhook` | Nylas-Challenge und Ereignisse verarbeiten | HMAC-SHA256 |

### Gemeinsame Authentifizierungsfehler

| Status | Antwort | Bedeutung |
| --- | --- | --- |
| `401` | `Unauthorized` | Keine gültige Authentifizierung vorhanden |
| `401` | `Invalid session token` | Das Sitzungstoken ist ungültig |
| `400` | `Account slug required` | `accountSlug` fehlt |
| `400` | `teamId or accountSlug query parameter or body field required` | Workspace-Auswahl fehlt |
| `404` | `Account not found` | Workspace wurde nicht gefunden |
| `403` | `Access denied` | Kein Zugriff auf den Workspace |
| `403` | `Not available with an API key` | Der Endpunkt akzeptiert keine API-Schlüssel |

#### Query-Parameter

<ParamField query="accountSlug" param-type="string" required="true">Slug des ausgewählten Workspace.</ParamField>
<ParamField query="assistants" param-type="string">Kommagetrennte Assistenten-UUIDs.</ParamField>
<ParamField query="channel" param-type="string" enum="phone,web,email">Filtert nach Telefon-, Web- oder E-Mail-Aktivität.</ParamField>
<ParamField query="q" param-type="string">Suchtext, auf 100 Zeichen gekürzt.</ParamField>

<ParamField query="assigned" param-type="string">`me`, `unassigned` oder die UUID eines Workspace-Mitglieds.</ParamField>

<ResponseField name="contacts" field-type="array" required="true">Kontakte mit letzter Aktivität, Kanälen, Zuständigkeit und Lesestatus.</ResponseField>

<Callout kind="alert">

Bei einem Fehler beim Laden des Posteingangs antwortet der Endpunkt mit HTTP `500` und `{ "error": "Could not load the Inbox" }`.

</Callout>

## Kontaktsuche

Suchen Sie nach Kontakten mit Namen, E-Mail-Adresse oder Unternehmen. Ergebnisse ohne gültige E-Mail-Adresse werden nicht zurückgegeben.

### Endpunkt

`GET /api/inbox/contacts`

<Request tabs="cURL">

```bash
curl "https://app.talkturo.com/api/inbox/contacts?q=Mara&accountSlug=acme-sales" \
  -H "Authorization: Bearer tk_test_example_9xmk7q2r"
```

</Request>

<Response tabs="200">

```json
{
  "contacts": [
    {
      "id": "cnt_a1b2c3d4",
      "name": "Mara Weber",
      "email": "mara.weber@beispiel.de",
      "company": "Nordstern GmbH"
    }
  ]
}
```

</Response>

#### Query-Parameter

<ParamField query="q" param-type="string" required="true">Suchtext. Sonderzeichen werden entfernt, der Text wird getrimmt und auf 60 Zeichen gekürzt.</ParamField>
<ParamField query="accountSlug" param-type="string" required="true">Slug des ausgewählten Workspace.</ParamField>

#### Antwortfelder

<ResponseField name="contacts" field-type="array" required="true">Bis zu acht Kontakte mit nicht leerer E-Mail-Adresse.</ResponseField>

<Callout kind="tip">

Suchtexte mit weniger als zwei Zeichen liefern eine leere Ergebnisliste, ohne die Datenbank abzufragen.

</Callout>

## Kontakt-Status

Ändern Sie den Status mehrerer Kontakte oder weisen Sie Kontakte einem Workspace-Mitglied zu.

### Endpunkt

`POST /api/inbox/contact-state`

<Request tabs="cURL">

```bash
curl "https://app.talkturo.com/api/inbox/contact-state?accountSlug=acme-sales" \
  -X POST \
  -H "Authorization: Bearer tk_test_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "contactIds": ["cnt_a1b2c3d4"],
    "action": "assign",
    "assigneeId": "usr_m3n4o5p6"
  }'
```

</Request>

<Response tabs="200">

```json
{
  "updated": 1
}
```

</Response>

#### Anfragefelder

<ParamField body="contactIds" param-type="string[]" required="true">Eine bis 200 Kontakt-UUIDs.</ParamField>
<ParamField body="action" param-type="string" required="true" enum="assign,unassign,done,reopen">Auszuführende Statusaktion.</ParamField>
<ParamField body="assigneeId" param-type="string">UUID des Workspace-Mitglieds. Für `assign` erforderlich.</ParamField>

#### Antwortfelder

<ResponseField name="updated" field-type="integer" required="true">Anzahl der Kontakte, deren Status geändert wurde.</ResponseField>

## E-Mail senden

Senden Sie neue E-Mails, Antworten oder Weiterleitungen mit optionalen Anhängen.

### Endpunkt

`POST /api/inbox/assistants/{assistantId}/send`

<Request tabs="cURL">

```bash
curl "https://app.talkturo.com/api/inbox/assistants/ast_12345678/send?accountSlug=acme-sales" \

  -H "Authorization: Bearer tk_test_example_9xmk7q2r" \
  -F 'payload={"mode":"new","to":[{"email":"mara.weber@beispiel.de","name":"Mara Weber"}],"cc":[],"bcc":[],"subject":"Ihre Produktdemo","text":"Gerne vereinbaren wir einen Termin.","locale":"de"}'
```

</Request>

<Response tabs="201">

```json
{
  "ok": true,
  "id": "msg_e5f6g7h8"
}
```

</Response>

#### Parameter

<ParamField path="assistantId" param-type="string" required="true">UUID des Assistenten.</ParamField>
<ParamField query="accountSlug" param-type="string" required="true">Slug des ausgewählten Workspace.</ParamField>
<ParamField body="payload" param-type="JSON string" required="true">JSON-Objekt mit Versandmodus, Empfängern, Betreff, Nachrichtentext und Sprache.</ParamField>
<ParamField body="files" param-type="File[]">Hochzuladende Anhänge. Die kombinierte Größe darf das konfigurierte Nachrichtenlimit nicht überschreiten.</ParamField>

#### Felder von `payload`

<ParamField body="mode" param-type="string" required="true" enum="new,reply,replyAll,forward">Versandmodus.</ParamField>
<ParamField body="messageId" param-type="string">UUID der Nachricht für Antworten oder Weiterleitungen.</ParamField>

<ParamField body="subject" param-type="string" required="true">Betreff mit maximal 998 Zeichen.</ParamField>
<ParamField body="text" param-type="string" required="true">Nachrichtentext mit maximal 100.000 Zeichen.</ParamField>
<ParamField body="locale" param-type="string">Sprache mit maximal 10 Zeichen. Standardwert ist `en`.</ParamField>

## Nylas-Webhook

Verarbeiten Sie die Nylas-Challenge und empfangen Sie signierte E-Mail-Ereignisse. Dieser Webhook verwendet keine Sitzungsauthentifizierung und akzeptiert keine API-Schlüssel.

### Challenge bestätigen

`GET /api/inbox/nylas/webhook`

<Request tabs="cURL">

```bash
curl "https://app.talkturo.com/api/inbox/nylas/webhook?challenge=nylas_challenge_7f3a"
```

</Request>

<Response tabs="200">

```text
nylas_challenge_7f3a
```

</Response>

#### Query-Parameter

<ParamField query="challenge" param-type="string" required="true">Von Nylas übermittelte Challenge. Der Wert wird unverändert als Text zurückgegeben.</ParamField>

### Ereignisse empfangen

`POST /api/inbox/nylas/webhook`

<Request tabs="cURL">

```bash
curl "https://app.talkturo.com/api/inbox/nylas/webhook" \
  -X POST \
  -H "Content-Type: application/json" \
  -H "X-Nylas-Signature: 4d2f8a6e1c9b7a5f3e2d1c0b9a8f7e6d5c4b3a291817161514131211100f0e0d" \
  -d '{
    "object": "event",
    "id": "evt_c1d2e3f4",
    "type": "message.created"
  }'
```

</Request>

<Response tabs="200">

```json
{
  "ok": true
}
```

</Response>

#### Header und Anfrage

<ParamField header="X-Nylas-Signature" param-type="string" required="true">Hexadezimale HMAC-SHA256-Signatur des unveränderten Anfrage-Bodys.</ParamField>
<ParamField body="event" param-type="JSON" required="true">Roher JSON-Body eines Nylas-Ereignisses.</ParamField>

#### Antwortfelder

<ResponseField name="ok" field-type="boolean" required="true">Gibt an, dass das Ereignis akzeptiert und verarbeitet wurde.</ResponseField>

<Callout kind="info">

Berechnen Sie die Signatur mit dem Secret `NYLAS_INBOX_WEBHOOK_SECRET`. Fehlende, ungültige oder nicht übereinstimmende Signaturen führen zu `401`. Ungültiges JSON führt zu `400`; Verarbeitungsfehler führen zu `500`, damit Nylas das Ereignis erneut sendet.

</Callout>
