## Telefonnummern mit der Talkturo-Telefonie verwalten

Mit den Endpunkten für Telefonnummern suchen Sie verfügbare Rufnummern, kaufen neue Nummern, listen bereits gekaufte Nummern auf, rufen vorhandene Nummern ab, geben nicht mehr benötigte Nummern frei und verarbeiten Carrier-Webhooks für KYC- und Compliance-Statusänderungen. Diese Endpunkte decken den vollständigen Lebenszyklus einer Telefonnummer innerhalb der Talkturo-Telefonie ab.

Für alle regulären Telefonnummern-Endpunkte ist entweder eine authentifizierte Sitzung per Session-Cookie oder ein API-Key per Bearer-Token erforderlich. Die beiden Webhook-Endpunkte bilden die Ausnahme, da sie von externen Carriern aufgerufen werden.

<Callout kind="info">

Verwenden Sie diese Endpunkte für die Verwaltung von Telefonnummern in Ihrem Account. Wenn Sie allgemeine Telephony-Einstellungen verwalten möchten, siehe [Telephony](/de/api-reference/telephony).

</Callout>

## Authentifizierung

Die folgenden Endpunkte akzeptieren Session-Cookie- oder Bearer-Token-Authentifizierung:

- `POST /api/phone-numbers/search`
- `POST /api/phone-numbers/purchase`
- `GET /api/phone-numbers/purchase`
- `GET /api/phone-numbers/{id}`
- `DELETE /api/phone-numbers/{id}`

Die folgenden Webhook-Endpunkte akzeptieren Anfragen von Carriern und verwenden kein Session-Cookie und kein API-Key-Bearer-Token:

- `POST /api/phone-numbers/telnyx-webhook`
- `POST /api/phone-numbers/twilio-webhook`

## Endpunktübersicht

| Methode | Pfad | Authentifizierung | Zweck |
| --- | --- | --- | --- |
| `POST` | `/api/phone-numbers/search` | Session-Cookie oder Bearer-Token | Verfügbare Telefonnummern beim Carrier suchen |
| `POST` | `/api/phone-numbers/purchase` | Session-Cookie oder Bearer-Token | Eine Telefonnummer kaufen und bereitstellen |
| `GET` | `/api/phone-numbers/purchase` | Session-Cookie oder Bearer-Token | Gekaufte Telefonnummern für ein Team auflisten |
| `GET` | `/api/phone-numbers/{id}` | Session-Cookie oder Bearer-Token | Eine bestimmte Telefonnummer abrufen |
| `DELETE` | `/api/phone-numbers/{id}` | Session-Cookie oder Bearer-Token | Eine Telefonnummer freigeben |
| `POST` | `/api/phone-numbers/telnyx-webhook` | ED25519-Signatur | KYC- und Compliance-Status von Telnyx verarbeiten |
| `POST` | `/api/phone-numbers/twilio-webhook` | Keine direkte Signaturprüfung | Bundle-Status von Twilio verarbeiten |

## Verfügbare Telefonnummern suchen

Rufen Sie `POST /api/phone-numbers/search` auf, um freie Telefonnummern anhand von Land, Nummerntyp, Vorwahl und Carrier-Konfiguration zu finden.

<Request tabs="cURL" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/phone-numbers/search" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tt_api_example_9xmk7q2r" \
  -d '{
    "filters": {
      "countryCode": "US",
      "numberType": "local",
      "areaCode": "415"
    },
    "teamId": "8f4b7d7f-2a91-4fd2-9d5f-2ab0e6c73d11",
    "carrier": "talkturo"
  }'
```
</Request>

```json
      "phoneNumber": "+14155550199",

```

### Request-Body

<ParamField body="filters" param-type="object" required="true">
Enthält die Suchkriterien für verfügbare Telefonnummern.
</ParamField>

<ParamField body="countryCode" param-type="string" required="true" show-location="false">
ISO-3166-Alpha-2-Ländercode, nach dem gesucht werden soll.
</ParamField>

<ParamField body="numberType" param-type="string" required="false" show-location="false" enum="local,mobile,toll-free">
Typ der gesuchten Telefonnummer. Standard ist `local`.
</ParamField>

<ParamField body="areaCode" param-type="string" required="false" show-location="false">
Filtert lokale Nummern nach Vorwahl.
</ParamField>

<ParamField body="teamId" param-type="string" required="false">
Team-Kennung für die Suche. Bei API-Key-basierten Anfragen kann das Team abhängig von der Key-Konfiguration bereits feststehen.
</ParamField>

<ParamField body="carrier" param-type="string" required="false" enum="talkturo,talkturo_2">
Carrier, gegen den die Suche ausgeführt werden soll.
</ParamField>

<ParamField body="provider" param-type="string" required="false">
Veralteter Alias für `carrier`. Verwenden Sie für neue Integrationen `carrier`.
</ParamField>

<ResponseField name="success" field-type="boolean" required="true">

</ResponseField>

<ResponseField name="numbers" field-type="array" required="true">
Liste der verfügbaren Telefonnummern, die den angegebenen Filtern entsprechen.
</ResponseField>

<ResponseField name="carrier" field-type="string" required="true">
Carrier, der für die Suche verwendet wurde.
</ResponseField>

<ResponseField name="provider" field-type="string" required="true">
Rückgabewert für bestehende Clients. Entspricht dem verwendeten Carrier.
</ResponseField>

<ResponseField name="pricing" field-type="object" required="true">
Preisangaben für die gefundenen Nummern in Credits.
</ResponseField>

<ResponseField name="billing" field-type="string" required="true">
Abrechnungsmodus für die gefundenen Nummern. Mögliche Werte sind `byoa`, `exempt` und `credits`.
</ResponseField>

<ResponseField name="verifiedLocalities" field-type="array" required="true">
Orte, für die bereits die erforderlichen Verifizierungen vorliegen.
</ResponseField>

<ResponseField name="addressRequirements" field-type="array" required="true">
Zusätzliche Adressanforderungen, die vor dem Kauf erfüllt sein müssen.
</ResponseField>

<ResponseField name="count" field-type="number" required="true">
Anzahl der zurückgegebenen Nummern.
</ResponseField>

<Callout kind="alert">

Wenn `countryCode` fehlt, antwortet der Endpunkt mit `400`. Wenn für den ausgewählten Carrier eine KYC-Prüfung erforderlich ist, antwortet der Endpunkt mit `403` und `requiresVerification: true`. Wenn der Carrier für das Team nicht eingerichtet ist, antwortet der Endpunkt mit `409`.

</Callout>

## Telefonnummer kaufen

Rufen Sie `POST /api/phone-numbers/purchase` auf, um eine verfügbare Telefonnummer einem Account zuzuordnen und zu provisionieren.

<Request tabs="cURL" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/phone-numbers/purchase" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tt_api_example_9xmk7q2r" \
  -d '{
    "phoneNumber": "+14155550188",
    "teamId": "8f4b7d7f-2a91-4fd2-9d5f-2ab0e6c73d11",
    "carrier": "talkturo",
    "numberType": "local",
    "region": {
      "state": "CA",
      "locality": "San Francisco",
      "rateCenter": "SNFCISCO"
    }
  }'
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "success": true,
  "phoneNumber": {
    "id": "pn_2f6c9a41",
    "phoneNumber": "+14155550188",
    "accountSlug": "acme-support",
    "status": "active"
  }
}
```
</Response>

### Request-Body

<ParamField body="phoneNumber" param-type="string" required="true">
Die zu kaufende Telefonnummer im E.164-Format.
</ParamField>

<ParamField body="teamId" param-type="string" required="true">
Die Team-Kennung, der die Telefonnummer zugeordnet werden soll. Bei API-Key-basierten Anfragen kann der Wert aus dem API-Key-Kontext abgeleitet werden.
</ParamField>

<ParamField body="connectionId" param-type="string" required="false">
Optionale Verbindungskennung, über die die Nummer provisioniert werden soll.
</ParamField>

<ParamField body="carrier" param-type="string" required="false">
Carrier für den Kaufvorgang.
</ParamField>

<ParamField body="provider" param-type="string" required="false">
Veralteter Alias für `carrier`. Verwenden Sie für neue Integrationen `carrier`.
</ParamField>

<ParamField body="numberType" param-type="string" required="false">
Typ der zu kaufenden Nummer.
</ParamField>

<ParamField body="region" param-type="object" required="false">
Optionale Regionaldaten, die für bestimmte lokale Nummern erforderlich sein können.
</ParamField>

<ParamField body="state" param-type="string" required="false" show-location="false">
Bundesstaat oder Region innerhalb von `region`.
</ParamField>

<ParamField body="locality" param-type="string" required="false" show-location="false">
Ort innerhalb von `region`.
</ParamField>

<ParamField body="rateCenter" param-type="string" required="false" show-location="false">
Rate Center innerhalb von `region`.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob der Kauf erfolgreich war.
</ResponseField>

<ResponseField name="phoneNumber" field-type="object" required="true">
Die bereitgestellte Telefonnummer mit den zugehörigen Metadaten.
</ResponseField>

## Telnyx-Webhook für KYC-Status

`POST /api/phone-numbers/telnyx-webhook` verarbeitet Statusaktualisierungen von Telnyx für KYC- und Compliance-Prüfungen.

<Callout kind="alert">

Dieser Endpunkt prüft eine ED25519-Signatur gegen den konfigurierten öffentlichen Schlüssel aus `TELNYX_PUBLIC_KEY`. Wenn der Schlüssel nicht konfiguriert ist, antwortet der Endpunkt mit `503`. Bei ungültiger Signatur antwortet der Endpunkt mit `400`. Nach erfolgreicher Prüfung verarbeitet der Endpunkt das rohe Event-JSON, synchronisiert den Status der `requirement_group_id` und gibt anschließend immer `200` zurück, damit Telnyx keine Wiederholungsversuche startet.

</Callout>

<Request tabs="HTTP" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/phone-numbers/telnyx-webhook" \
  -H "Content-Type: application/json" \
  -H "Telnyx-Signature-Ed25519: 4f8f7f4f2fb1d5e8a03ef9b4df2ac7f1a0d75c2d6d1f2e8c9a3e7b5f4d2c1a9e" \
  -H "Telnyx-Timestamp: 1731002201" \
  -d '{
    "data": {
      "payload": {
        "requirement_group_id": "rg_7c9a2b11"
      }
    }
  }'
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "received": true,
  "status": "approved",
  "updated": true,
  "matchedRequest": true
}
```
</Response>

## Twilio-Webhook für Bundle-Status

`POST /api/phone-numbers/twilio-webhook` verarbeitet Statusaktualisierungen von Twilio für Compliance-Bundles.

<Callout kind="info">

Dieser Endpunkt vertraut dem eingehenden Statusfeld nicht direkt. Stattdessen liest er `BundleSID`, `BundleSid` oder `bundle_sid` aus dem Formular und ruft den tatsächlichen Status erneut über die Twilio-API ab. Der Endpunkt gibt danach immer `200` zurück, damit Twilio keine unnötigen Wiederholungsversuche sendet.

</Callout>

<Request tabs="HTTP" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/phone-numbers/twilio-webhook" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "BundleSID=BU7f3b0d9c5a1e44e6a8c2f11d9a7b3c4"
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "received": true,
  "status": "in_review",
  "matchedRequest": true
}
```
</Response>
