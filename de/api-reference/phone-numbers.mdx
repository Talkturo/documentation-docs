## Telefonnummern mit der Talkturo-Telefonie verwalten

Mit den Endpunkten für Telefonnummern suchen Sie verfügbare Rufnummern, kaufen neue Nummern, listen gekaufte Nummern auf, aktualisieren vorhandene Nummern, geben nicht mehr benötigte Nummern frei und verarbeiten Carrier-Webhooks für KYC- und Compliance-Statusänderungen. Diese Endpunkte decken den vollständigen Lebenszyklus einer Telefonnummer innerhalb der Talkturo-Telefonie ab.

Für alle regulären Telefonnummern-Endpunkte akzeptiert die `withApiAuth`-Middleware entweder einen API-Key im `Authorization`-Header oder ein angemeldetes Session-Cookie. Die beiden Webhook-Endpunkte bilden die Ausnahme, da sie von externen Carriern aufgerufen werden.

<Callout kind="info">

Verwenden Sie diese Endpunkte für die Verwaltung von Telefonnummern in Ihrem Account. Wenn Sie Telefonnummern einem Assistant zuweisen oder allgemeine Telephony-Einstellungen verwalten möchten, siehe [Telephony](/de/api-reference/telephony).

</Callout>

## Authentifizierung

Die regulären Telefonnummern-Endpunkte verwenden duale Authentifizierung über `withApiAuth`. Senden Sie entweder einen API-Key im Header `Authorization: Bearer tk_live_example_9xmk7q2r` oder verwenden Sie ein angemeldetes Session-Cookie.

Die folgenden Endpunkte unterstützen API-Key oder Session-Cookie:

- `POST /api/phone-numbers/search`
- `GET /api/phone-numbers/cities`
- `GET /api/phone-numbers/purchase`
- `POST /api/phone-numbers/purchase`
- `GET /api/phone-numbers/{id}`
- `PATCH /api/phone-numbers/{id}`
- `DELETE /api/phone-numbers/{id}`

Die folgenden Webhook-Endpunkte akzeptieren Anfragen von Carriern und verwenden kein Session-Cookie:

- `POST /api/phone-numbers/telnyx-webhook`
- `POST /api/phone-numbers/twilio-webhook`

<Callout kind="info">

Verwenden Sie für serverseitige Integrationen bevorzugt einen API-Key. Session-Cookies eignen sich für Aufrufe aus einer angemeldeten Anwendung oder dem Dashboard.

</Callout>

<Callout kind="info">

Carrier-Auswahl steuert, über welchen Anbieter Nummern gesucht und gekauft werden:

- `talkturo_1` — Telnyx als verwalteter Carrier für Nummern in den USA und Kanada
- `talkturo_2` — Twilio als verwalteter Sub-Account mit breiterer internationaler Abdeckung
- `own_twilio` — Bring Your Own Twilio Account mit eigenen Twilio-Anmeldedaten

</Callout>

| Methode | Pfad | Authentifizierung | Zweck |

| `POST` | `/api/phone-numbers/search` | API-Key oder Session-Cookie | Verfügbare Telefonnummern beim Carrier suchen |
| `GET` | `/api/phone-numbers/cities` | API-Key oder Session-Cookie | Verfügbare Städte für die Nummernsuche abrufen |
| `GET` | `/api/phone-numbers/purchase` | API-Key oder Session-Cookie | Gekaufte Telefonnummern auflisten |
| `POST` | `/api/phone-numbers/purchase` | API-Key oder Session-Cookie | Eine Telefonnummer kaufen und bereitstellen |
| `GET` | `/api/phone-numbers/{id}` | API-Key oder Session-Cookie | Eine bestimmte Telefonnummer abrufen |
| `PATCH` | `/api/phone-numbers/{id}` | API-Key oder Session-Cookie | Label oder Assistentenzuweisung einer Telefonnummer aktualisieren |

| `POST` | `/api/phone-numbers/twilio-webhook` | Keine direkte Signaturprüfung | Bundle-Status von Twilio verarbeiten |

## Verfügbare Telefonnummern suchen

Rufen Sie `POST /api/phone-numbers/search` auf, um freie Telefonnummern anhand von Team, Carrier, Region und gewünschten Funktionen zu finden.

<Request tabs="cURL" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/phone-numbers/search" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -d '{
    "teamId": "9f3c2c1a-6f1d-4cb1-b9e3-2d4a5c7e8f10",
    "carrier": "talkturo_1",
    "provider": "telnyx",
    "filters": {
      "countryCode": "US",
      "areaCode": "415",
      "numberType": "local",
      "features": ["sms", "voice"],
      "limit": 2
    }
  }'
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "success": true,
  "numbers": [
    {
      "phoneNumber": "+14155550188",
      "countryCode": "US",
      "areaCode": "415",
      "numberType": "local",
      "features": [
        "sms",
        "voice"
      ],
      "upfrontCredits": 4,
      "monthlyCredits": 2,
      "upfrontUsd": 2,
      "monthlyUsd": 1,
      "requirement": {
        "required": false,
        "countryCode": "US"
      }
    },
    {
      "phoneNumber": "+14155550199",
      "countryCode": "US",
      "areaCode": "415",
      "numberType": "local",
      "features": [
        "voice"
      ],
      "upfrontCredits": 4,
      "monthlyCredits": 2,
      "upfrontUsd": 2,
      "monthlyUsd": 1,
      "requirement": {
        "required": true,
        "countryCode": "US",
        "regulatoryBundleType": "business"
      }
    }
  ]
}
```
</Response>

## Telefonnummer kaufen

Rufen Sie `POST /api/phone-numbers/purchase` auf, um eine verfügbare Telefonnummer für ein Team zu kaufen und zu provisionieren. Vor dem Kauf prüft der Endpunkt, ob ausreichend Credits vorhanden sind.

<Request tabs="cURL" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/phone-numbers/purchase" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -d '{
    "phoneNumber": "+14155550188",
    "teamId": "9f3c2c1a-6f1d-4cb1-b9e3-2d4a5c7e8f10",
    "carrier": "talkturo_1",
    "provider": "telnyx",
    "connectionId": "209174398463829101",
    "numberType": "local",
    "region": {
      "country": "US",
      "state": "CA",
      "locality": "San Francisco"
    }
  }'
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "success": true,
  "phoneNumber": {
    "id": "pn_2f6c9a41",
    "phoneNumber": "+14155550188",
    "teamId": "9f3c2c1a-6f1d-4cb1-b9e3-2d4a5c7e8f10",
    "carrier": "talkturo_1",
    "status": "active",
    "monthlyCredits": 2,
    "monthlyUsd": 1
  }
}
```
</Response>

### Request-Body

<ParamField body="phoneNumber" param-type="string" required="true">
Die zu kaufende Telefonnummer im E.164-Format.
</ParamField>

<ParamField body="teamId" param-type="string" required="true">
Die UUID des Teams, dem die Telefonnummer zugeordnet werden soll.
</ParamField>

<ParamField body="carrier" param-type="string" required="false" enum="talkturo_1,talkturo_2,own_twilio">
Wählt den Carrier für den Kauf aus.
</ParamField>

<ParamField body="provider" param-type="string" required="false">
Optionaler Provider-Wert für carrier-spezifische Kauflogik.
</ParamField>

<ParamField body="connectionId" param-type="string" required="false">
Telnyx-FQDN-Verbindungs-ID für die Nummernzuordnung.
</ParamField>

<ParamField body="numberType" param-type="string" required="false">
Der Nummerntyp der zu kaufenden Telefonnummer.
</ParamField>

<ParamField body="region" param-type="object" required="false">
Optionale Regionsdaten mit `country`, `state` und `locality`.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob der Kauf erfolgreich war.
</ResponseField>

<ResponseField name="phoneNumber" field-type="object" required="true">
Die bereitgestellte Telefonnummer mit den zugehörigen Metadaten.
</ResponseField>

<Callout kind="info">

Aktive Telefonnummern verursachen derzeit monatliche Kosten von `2` Credits, was ungefähr `1` US-Dollar entspricht.

</Callout>

## Telnyx-Webhook für KYC-Status

`POST /api/phone-numbers/telnyx-webhook` verarbeitet Statusaktualisierungen von Telnyx für KYC- und Compliance-Prüfungen.

<Callout kind="alert">

Dieser Endpunkt prüft eine ED25519-Signatur gegen den konfigurierten öffentlichen Schlüssel aus `TELNYX_PUBLIC_KEY`. Wenn der Schlüssel nicht konfiguriert ist, antwortet der Endpunkt mit `503`. Bei ungültiger Signatur antwortet der Endpunkt mit `400`. Nach erfolgreicher Prüfung verarbeitet der Endpunkt das rohe Event-JSON, synchronisiert den Status der `requirement_group_id` und gibt anschließend immer `200` zurück, damit Telnyx keine Wiederholungsversuche startet.

</Callout>

<Request tabs="HTTP" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/phone-numbers/telnyx-webhook" \
  -H "Content-Type: application/json" \
  -H "Telnyx-Signature-Ed25519: 4f8f7f4f2fb1d5e8a03ef9b4df2ac7f1a0d75c2d6d1f2e8c9a3e7b5f4d2c1a9e" \
  -H "Telnyx-Timestamp: 1731002201" \
  -d '{
    "data": {
      "payload": {
        "requirement_group_id": "rg_7c9a2b11"
      }
    }
  }'
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "received": true,
  "status": "approved",
  "updated": true,
  "matchedRequest": true
}
```
</Response>

## Twilio-Webhook für Bundle-Status

`POST /api/phone-numbers/twilio-webhook` verarbeitet Statusaktualisierungen von Twilio für Compliance-Bundles.

<Callout kind="info">

Dieser Endpunkt vertraut dem eingehenden Statusfeld nicht direkt. Stattdessen liest er `BundleSID`, `BundleSid` oder `bundle_sid` aus dem Formular und ruft den tatsächlichen Status erneut über die Twilio-API ab. Der Endpunkt gibt danach immer `200` zurück, damit Twilio keine unnötigen Wiederholungsversuche sendet.

</Callout>

<Request tabs="HTTP" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/phone-numbers/twilio-webhook" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "BundleSID=BU7f3b0d9c5a1e44e6a8c2f11d9a7b3c4"
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "received": true,
  "status": "in_review",
  "matchedRequest": true
}
```
</Response>
