## Telefonnummern mit der Talkturo-Telefonie verwalten

Mit den Endpunkten für Telefonnummern suchen Sie verfügbare Rufnummern, kaufen neue Nummern, listen bereits gekaufte Nummern auf, rufen vorhandene Nummern ab, geben nicht mehr benötigte Nummern frei und verarbeiten Carrier-Webhooks für KYC- und Compliance-Statusänderungen. Diese Endpunkte decken den vollständigen Lebenszyklus einer Telefonnummer innerhalb der Talkturo-Telefonie ab.

Für alle regulären Telefonnummern-Endpunkte können Sie entweder einen API-Schlüssel oder eine authentifizierte Sitzung verwenden. Die beiden Webhook-Endpunkte bilden die Ausnahme, da sie von externen Carriern aufgerufen werden.

<Callout kind="info">

Verwenden Sie diese Endpunkte für die Verwaltung von Telefonnummern in Ihrem Account. Wenn Sie Telefonnummern einem Assistant zuweisen oder allgemeine Telephony-Einstellungen verwalten möchten, siehe [Telephony](/de/api-reference/telephony).

</Callout>

## Authentifizierung

Die folgenden Endpunkte unterstützen API-Schlüssel oder Sitzung:

- `POST /api/phone-numbers/search`
- `POST /api/phone-numbers/purchase`
- `GET /api/phone-numbers/purchase`
- `GET /api/phone-numbers/{id}`
- `DELETE /api/phone-numbers/{id}`

Die folgenden Webhook-Endpunkte akzeptieren Anfragen von Carriern und verwenden keine reguläre Account-Authentifizierung:

- `POST /api/phone-numbers/telnyx-webhook`
- `POST /api/phone-numbers/twilio-webhook`

## Endpunktübersicht

| Methode | Pfad | Authentifizierung | Zweck |
| --- | --- | --- | --- |
| `POST` | `/api/phone-numbers/search` | API-Schlüssel oder Sitzung | Verfügbare Telefonnummern beim Carrier suchen |
| `POST` | `/api/phone-numbers/purchase` | API-Schlüssel oder Sitzung | Eine Telefonnummer kaufen und bereitstellen |
| `GET` | `/api/phone-numbers/purchase` | API-Schlüssel oder Sitzung | Bereits gekaufte Telefonnummern auflisten |
| `GET` | `/api/phone-numbers/{id}` | API-Schlüssel oder Sitzung | Eine bestimmte Telefonnummer abrufen |
| `DELETE` | `/api/phone-numbers/{id}` | API-Schlüssel oder Sitzung | Eine Telefonnummer freigeben |
| `POST` | `/api/phone-numbers/telnyx-webhook` | ED25519-Signatur | KYC- und Compliance-Status von Telnyx verarbeiten |
| `POST` | `/api/phone-numbers/twilio-webhook` | Keine direkte Signaturprüfung | Bundle-Status von Twilio verarbeiten |

## Verfügbare Telefonnummern suchen

Rufen Sie `POST /api/phone-numbers/search` auf, um freie Telefonnummern anhand von Filter, Berechtigung und gewünschter Preisgestaltung zu finden.

<Request tabs="cURL" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/phone-numbers/search" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -d '{
    "countryCode": "US",
    "region": "CA",
    "numberType": "local",
    "features": ["sms", "voice"],
    "filters": {
      "contains": "555",
      "areaCode": "415"
    },
    "pricing": {
      "upfrontCreditsMax": 20,
      "monthlyCreditsMax": 5
    },
    "eligibility": {
      "verifiedLocalities": ["San Francisco"]
    }
  }'
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "success": true,
  "numbers": [
    {
      "phoneNumber": "+14155550188",
      "countryCode": "US",
      "region": "CA",
      "locality": "San Francisco",
      "numberType": "local",
      "features": [
        "sms",
        "voice"
      ],
      "provider": "telnyx",
      "carrier": "Onvoy",
      "pricing": {
        "upfrontCredits": 10,
        "monthlyCredits": 2
      }
    },
    {
      "phoneNumber": "+14155550199",
      "countryCode": "US",
      "region": "CA",
      "locality": "San Francisco",
      "numberType": "local",
      "features": [
        "voice"
      ],
      "provider": "twilio",
      "carrier": "Bandwidth",
      "pricing": {
        "upfrontCredits": 12,
        "monthlyCredits": 3
      }
    }
  ]
}
```
</Response>

### Request-Body

<ParamField body="countryCode" param-type="string" required="false">
Filtert verfügbare Nummern nach Ländercode.
</ParamField>

<ParamField body="region" param-type="string" required="false">
Filtert verfügbare Nummern nach Region.
</ParamField>

<ParamField body="numberType" param-type="string" required="false">
Filtert verfügbare Nummern nach Nummerntyp, zum Beispiel `local`, `mobile` oder `toll_free`.
</ParamField>

<ParamField body="features" param-type="array" required="false">
Filtert nach gewünschten Funktionen wie `sms` oder `voice`.
</ParamField>

<ParamField body="filters" param-type="object" required="false">
Zusätzliche Filter für die Nummernsuche, zum Beispiel enthaltene Ziffernfolgen oder Vorwahl.
</ParamField>

<ParamField body="pricing" param-type="object" required="false">
Grenzt Ergebnisse anhand der Preisgestaltung ein, einschließlich maximaler einmaliger und monatlicher Credits.
</ParamField>

<ParamField body="eligibility" param-type="object" required="false">
Begrenzt Ergebnisse auf Nummern, die zu Ihren Berechtigungsdaten passen, einschließlich verifizierter Standorte.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob die Suche erfolgreich war.
</ResponseField>

<ResponseField name="numbers" field-type="array" required="true">
Liste der verfügbaren Telefonnummern, die den angegebenen Filtern entsprechen.
</ResponseField>

## Telefonnummer kaufen

Rufen Sie `POST /api/phone-numbers/purchase` auf, um eine verfügbare Telefonnummer einem Team zuzuordnen und zu provisionieren.

<Request tabs="cURL" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/phone-numbers/purchase" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -d '{
    "phoneNumber": "+14155550188",
    "teamId": "team_7c9a2b11"
  }'
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "success": true,
  "phoneNumber": {
    "id": "pn_2f6c9a41",
    "phoneNumber": "+14155550188",
    "teamId": "team_7c9a2b11",
    "provider": "telnyx",
    "status": "active",
    "is_trial": false,
    "trial_expires_at": null
  }
}
```
</Response>

### Request-Body

<ParamField body="phoneNumber" param-type="string" required="true">
Die zu kaufende Telefonnummer im internationalen Format.
</ParamField>

<ParamField body="teamId" param-type="string" required="true">
Die Kennung des Teams, dem die Telefonnummer zugeordnet werden soll.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob der Kauf erfolgreich war.
</ResponseField>

<ResponseField name="phoneNumber" field-type="object" required="true">
Die bereitgestellte Telefonnummer mit den zugehörigen Metadaten.
</ResponseField>

## Allgemeine Antwortmuster

Die regulären Telefonnummern-Endpunkte geben ein einheitliches Erfolgsformat mit einem `success`-Feld zurück. Endpunkte, die eine einzelne Ressource liefern, verwenden zusätzlich `phoneNumber`, während Listenendpunkte `phoneNumbers` oder `numbers` zurückgeben.

<Callout kind="info">

Carrier-Webhooks folgen einem anderen Antwortmuster. Nach erfolgreicher Verarbeitung antworten sie immer mit `200`, damit der Carrier keine unnötigen Wiederholungsversuche startet.

</Callout>

## Telnyx-Webhook für KYC-Status

`POST /api/phone-numbers/telnyx-webhook` verarbeitet Statusaktualisierungen von Telnyx für KYC- und Compliance-Prüfungen.

<Callout kind="alert">

Dieser Endpunkt prüft eine ED25519-Signatur gegen den konfigurierten öffentlichen Schlüssel aus `TELNYX_PUBLIC_KEY`. Wenn der Schlüssel nicht konfiguriert ist, antwortet der Endpunkt mit `503`. Bei ungültiger Signatur antwortet der Endpunkt mit `400`. Nach erfolgreicher Prüfung verarbeitet der Endpunkt das rohe Event-JSON, synchronisiert den Status der `requirement_group_id` und gibt anschließend immer `200` zurück, damit Telnyx keine Wiederholungsversuche startet.

</Callout>

<Request tabs="HTTP" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/phone-numbers/telnyx-webhook" \
  -H "Content-Type: application/json" \
  -H "Telnyx-Signature-Ed25519: 4f8f7f4f2fb1d5e8a03ef9b4df2ac7f1a0d75c2d6d1f2e8c9a3e7b5f4d2c1a9e" \
  -H "Telnyx-Timestamp: 1731002201" \
  -d '{
    "data": {
      "payload": {
        "requirement_group_id": "rg_7c9a2b11"
      }
    }
  }'
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "received": true,
  "status": "approved",
  "updated": true,
  "matchedRequest": true
}
```
</Response>

## Twilio-Webhook für Bundle-Status

`POST /api/phone-numbers/twilio-webhook` verarbeitet Statusaktualisierungen von Twilio für Compliance-Bundles.

<Callout kind="info">

Dieser Endpunkt vertraut dem eingehenden Statusfeld nicht direkt. Stattdessen liest er `BundleSID`, `BundleSid` oder `bundle_sid` aus dem Formular und ruft den tatsächlichen Status erneut über die Twilio-API ab. Der Endpunkt gibt danach immer `200` zurück, damit Twilio keine unnötigen Wiederholungsversuche sendet.

</Callout>

<Request tabs="HTTP" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/phone-numbers/twilio-webhook" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "BundleSID=BU7f3b0d9c5a1e44e6a8c2f11d9a7b3c4"
```
</Request>

<Response tabs="200" default-tab="1">
```json
{
  "received": true,
  "status": "in_review",
  "matchedRequest": true
}
```
</Response>
