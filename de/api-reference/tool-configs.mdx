## Werkzeugkonfigurationen verwalten

Weisen Sie Assistenten externe Werkzeuge zu, damit der KI-Agent diese während Gesprächen aufrufen kann. Konfigurieren Sie Zapier-Webhook-Integrationen, benutzerdefinierte HTTP-Webhook-Endpunkte mit KI-generierten Parametern und TurboFlow-Workflow-Trigger über dedizierte Endpunkte.

<Callout kind="info">

Alle Werkzeugkonfigurations-Endpunkte erfordern ein authentifiziertes Sitzungs-Cookie. Der angemeldete Benutzer muss Mitglied des Workspace sein, dem der Assistent gehört.

</Callout>

## Endpunktübersicht

| Methode | Endpunkt |
|---|---|
| GET | `/api/assistants/:assistantId/tool-configs/:toolType` |
| POST | `/api/assistants/:assistantId/tool-configs/:toolType` |
| DELETE | `/api/assistants/:assistantId/tool-configs/:toolType` |
| GET | `/api/assistants/:assistantId/tool-configs/custom_webhook` |
| POST | `/api/assistants/:assistantId/tool-configs/custom_webhook` |
| DELETE | `/api/assistants/:assistantId/tool-configs/custom_webhook` |
| POST | `/api/assistants/:assistantId/tools/workflow` |

## Integrations-Werkzeugkonfigurationen

Verwalten Sie integrationsbasierte Werkzeugkonfigurationen über den dynamischen `toolType`-Endpunkt. Diese Route deckt die Zapier-Werkzeugkonfiguration ab.

### Zapier-Werkzeugkonfiguration abrufen

Rufen Sie die aktive Zapier-Werkzeugkonfiguration eines Assistenten ab oder zielen Sie mit einer Abfrage auf eine bestimmte Konfiguration.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl --request GET \
  --url "https://api.talkturo.com/api/assistants/asst_7f3d2a91/tool-configs/zapier" \
  --cookie "talkturo_session=sess_example_a9k3lm2p"
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/assistants/asst_7f3d2a91/tool-configs/zapier",
  {
    method: "GET",
    credentials: "include",
    headers: {
      Cookie: "talkturo_session=sess_example_a9k3lm2p",
    },
  }
);

const data = await response.json();
console.log(data);
```

</Request>

### Zapier-Werkzeugkonfiguration erstellen oder aktualisieren

Erstellen Sie eine neue Zapier-Zuordnung oder aktualisieren Sie eine vorhandene Konfiguration für denselben Assistenten.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl --request POST \
  --url "https://api.talkturo.com/api/assistants/asst_7f3d2a91/tool-configs/zapier" \
  --cookie "talkturo_session=sess_example_a9k3lm2p" \
  --header "Content-Type: application/json" \
  --data '{
    "config": {
      "integration_id": "int_4n9v1q3z"
    },
    "is_enabled": true
  }'
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/assistants/asst_7f3d2a91/tool-configs/zapier",
  {
    method: "POST",
    credentials: "include",
    headers: {
      "Content-Type": "application/json",
      Cookie: "talkturo_session=sess_example_a9k3lm2p",
    },
    body: JSON.stringify({
      config: {
        integration_id: "int_4n9v1q3z",
      },
      is_enabled: true,
    }),
  }
);

const data = await response.json();
```

### Zapier-Werkzeugkonfiguration löschen

Löschen Sie eine Zapier-Werkzeugkonfiguration für den Assistenten. Wenn Sie `configId` übergeben, löscht die API genau diese Konfiguration.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl --request DELETE \
  --url "https://api.talkturo.com/api/assistants/asst_7f3d2a91/tool-configs/zapier?configId=cfg_9m2x8k1p" \
  --cookie "talkturo_session=sess_example_a9k3lm2p"
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/assistants/asst_7f3d2a91/tool-configs/zapier?configId=cfg_9m2x8k1p",
  {
    method: "DELETE",
    credentials: "include",
    headers: {
      Cookie: "talkturo_session=sess_example_a9k3lm2p",
    },
  }
);

const data = await response.json();
console.log(data);
```

</Request>

<Response tabs="200,500" default-tab="1">

```json
{
  "success": true
}
```

```json
{
  "error": "Failed to delete tool configuration"
}
```

</Response>

#### Pfadparameter

<ParamField path="assistantId" param-type="string" required="true">
Die eindeutige Kennung des Assistenten.
</ParamField>

<ParamField path="toolType" param-type="string" required="true">
Der Werkzeugtyp. Verwenden Sie für diese Route `zapier`.
</ParamField>

#### Query-Parameter

<ParamField query="configId" param-type="string" required="false">
Die Kennung der zu löschenden Konfiguration. Ohne diesen Parameter löscht die API die Konfigurationen für den angegebenen Werkzeugtyp des Assistenten.
</ParamField>

#### Response-Felder

<ResponseField name="success" field-type="boolean" required="true">
Gibt `true` zurück, wenn die Konfiguration erfolgreich gelöscht wurde.
</ResponseField>

<ExpandableGroup>
<Expandable title="Form des Zapier-Konfigurationsobjekts" default-open="false">

Das Zapier-Konfigurationsobjekt verweist in der Regel auf eine vorhandene Kontointegration.

```json
{
  "integration_id": "int_4n9v1q3z"
}
```

</Expandable>
<Expandable title="GET-Verhalten nach Query-Parameter" default-open="false">

Die Route verhält sich je nach Abfrage unterschiedlich:

- Mit `configId` gibt die API genau eine Konfiguration nach Kennung zurück.
- Mit `all=true` gibt die API ein Objekt mit dem Feld `configs` zurück.
- Ohne Query-Parameter gibt die API die erste aktivierte Konfiguration dieses Werkzeugtyps zurück.

</Expandable>
</ExpandableGroup>


</Expandable>
<Expandable title="Feldbedeutung für Webhook-Parameter" default-open="false">

Jeder Eintrag in `headers`, `query_params` und `body_params` verwendet dieselbe Struktur:

- `key` definiert den Namen des Parameters oder Headers.
- `value_type` ist entweder `static` oder `ai_generated`.
- `value` enthält den festen Wert für `static`.
- `ai_prompt` beschreibt, wie das Modell den Wert für `ai_generated` erzeugen soll.
- `required` markiert Parameter, die bei der Ausführung vorhanden sein müssen.

## Workflow-Werkzeugkonfigurationen

Verknüpfen Sie einen Assistenten mit einem TurboFlow-Workflow, damit der Agent den Flow als Werkzeug auslösen kann.

### Workflow-Werkzeugkonfiguration erstellen

Erstellen Sie eine Workflow-Werkzeugkonfiguration über den dedizierten Workflow-Endpunkt.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl --request POST \
  --url "https://api.talkturo.com/api/assistants/asst_7f3d2a91/tools/workflow" \
  --cookie "talkturo_session=sess_example_a9k3lm2p" \
  --header "Content-Type: application/json" \
  --data '{
    "flow_id": "flow_3c8k1m9q"
  }'
```

```javascript
const response = await fetch(
```
