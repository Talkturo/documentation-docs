## CRM-Datensätze mit benutzerdefinierten Feldern erweitern

Benutzerdefinierte Felder ergänzen Kontakte und Unternehmen um zusätzliche Datenpunkte, die in Ihrem CRM-Workflow benötigt werden. Über diese Endpunkte listen Sie vorhandene Felder auf, legen neue Felder an, rufen einzelne Felder ab, aktualisieren konfigurierbare Eigenschaften und löschen nicht mehr benötigte Felder.

Alle Endpunkte in diesem Bereich verwenden Session-Authentifizierung. Die Antworten folgen durchgängig dem Muster `success: true` und liefern je nach Operation entweder `fields`, `field` oder nur eine Erfolgsbestätigung zurück.

<Callout kind="info">

Unterstützte Entitätstypen sind `company` und `contact`. Unterstützte Feldtypen sind `text`, `number`, `boolean`, `date`, `select` und `textarea`.

</Callout>

## Endpunkte im Überblick

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/custom-fields` | Alle benutzerdefinierten Felder auflisten |
| `POST` | `/api/crm/custom-fields` | Ein neues benutzerdefiniertes Feld erstellen |
| `GET` | `/api/crm/custom-fields/[id]` | Ein benutzerdefiniertes Feld anhand seiner ID abrufen |
| `PUT` | `/api/crm/custom-fields/[id]` | Konfigurierbare Eigenschaften eines Felds aktualisieren |
| `DELETE` | `/api/crm/custom-fields/[id]` | Ein benutzerdefiniertes Feld löschen |

## GET /api/crm/custom-fields

Rufen Sie alle benutzerdefinierten Felder für ein Team ab. Sie können die Ergebnisliste optional auf einen Entitätstyp einschränken oder auch inaktive Felder einschließen.

<Request>
```bash
curl -X GET "https://api.talkturo.com/api/crm/custom-fields?teamId=team_4f8k2m1q&entityType=company&includeInactive=true" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r"
```
</Request>

<Response>
```json
{
  "success": true,
  "fields": [
    {
      "id": "cf_8d3a2f91",
      "entity_type": "company",
      "key": "industry_segment",
      "label": "Branchensegment",
      "field_type": "select",
      "options": {
        "options": ["SaaS", "Automotive", "Healthcare"]
      },
      "is_required": false,
      "sort_order": 10,
      "is_active": true
    },
    {
      "id": "cf_3b7c4e20",
      "entity_type": "contact",
      "key": "preferred_language",
      "label": "Bevorzugte Sprache",
      "field_type": "text",
      "options": null,
      "is_required": false,
      "sort_order": 20,
      "is_active": false
    }
  ]
}
```
</Response>

### Query-Parameter

<ParamField query="teamId" param-type="string" required="true">

</ParamField>

<ParamField query="entityType" param-type="string" required="false" enum="company,contact">

</ParamField>

<ParamField query="includeInactive" param-type="string" required="false" enum="true">

</ParamField>

## POST /api/crm/custom-fields

Erstellen Sie ein neues benutzerdefiniertes Feld für Kontakte oder Unternehmen. Für Felder vom Typ `select` müssen Sie das Options-Objekt mitsenden.

<Request>
```bash
curl -X POST "https://api.talkturo.com/api/crm/custom-fields" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r" \
  -d '{
    "teamId": "team_4f8k2m1q",
    "entityType": "contact",
    "key": "lead_source",
    "label": "Lead-Quelle",
    "fieldType": "select",
    "options": {
      "options": ["Empfehlung", "Website", "Partner"]
    },
    "isRequired": false,
    "sortOrder": 5,
    "isActive": true
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "field": {
    "id": "cf_b5f29410",
    "entity_type": "contact",
    "key": "lead_source",
    "label": "Lead-Quelle",
    "field_type": "select",
    "options": {
      "options": ["Empfehlung", "Website", "Partner"]
    },
    "is_required": false,
    "sort_order": 5,
    "is_active": true
  }
}
```
</Response>

### Body-Parameter

<ParamField body="teamId" param-type="string" required="true">
Kennung des Teams, für das das Feld erstellt wird.
</ParamField>

<ParamField body="entityType" param-type="string" required="true" enum="company,contact">
Legt fest, ob das Feld für `company` oder `contact` erstellt wird.
</ParamField>

<ParamField body="key" param-type="string" required="true">
Technischer Schlüssel des Felds. Der Wert wird automatisch nach `snake_case` normalisiert und muss dem Muster `^[a-z][a-z0-9_]{1,63}$` entsprechen.
</ParamField>

<ParamField body="label" param-type="string" required="true">
Anzeigename des Felds. Der Wert darf nicht leer sein.
</ParamField>

<ParamField body="fieldType" param-type="string" required="true" enum="text,number,boolean,date,select,textarea">
Definiert den Feldtyp des neuen benutzerdefinierten Felds.
</ParamField>

<ParamField body="options" param-type="object" required="false">
Konfigurationsobjekt für zusätzliche Feldoptionen. Für `select` muss das Objekt ein nicht leeres Array unter `options.options` enthalten.
</ParamField>

<ParamField body="isRequired" param-type="boolean" required="false">
Legt fest, ob das Feld erforderlich ist. Standardwert ist `false`.
</ParamField>

<ParamField body="sortOrder" param-type="number" required="false">
Legt die Sortierreihenfolge fest. Standardwert ist `0`.
</ParamField>

<ParamField body="isActive" param-type="boolean" required="false">
Legt fest, ob das Feld direkt aktiv ist. Standardwert ist `true`.
</ParamField>

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob das Feld erfolgreich erstellt wurde.

</ResponseField>

<ResponseField name="is_required" field-type="boolean" required="true">
Gibt an, ob das Feld erforderlich ist.
</ResponseField>

Sortierreihenfolge des Felds.

## PUT /api/crm/custom-fields/[id]

Aktualisieren Sie die konfigurierbaren Eigenschaften eines vorhandenen Felds. `key`, `entityType` und `teamId` werden nur bei der Erstellung gesetzt und können nicht geändert werden.

<Request>
```bash
curl -X PUT "https://api.talkturo.com/api/crm/custom-fields/cf_b5f29410" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r" \
  -d '{
    "label": "Primäre Lead-Quelle",
    "fieldType": "select",
    "options": {
      "options": ["Empfehlung", "Website", "Partner", "Event"]
    },
    "isRequired": true,
    "sortOrder": 15,
    "isActive": true
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "field": {
    "id": "cf_b5f29410",
    "entity_type": "contact",
    "key": "lead_source",
    "label": "Primäre Lead-Quelle",
    "field_type": "select",
    "options": {
      "options": ["Empfehlung", "Website", "Partner", "Event"]
    },
    "is_required": true,
    "sort_order": 15,
    "is_active": true
  }
}
```
</Response>

}
