## CRM-Datensätze mit benutzerdefinierten Feldern erweitern

Benutzerdefinierte Felder ergänzen Kontakte und Unternehmen um eigene Datenpunkte, die in Ihrem CRM-Workflow fehlen. Über diese Endpunkte listen Sie vorhandene Felder auf, legen neue Felder an, aktualisieren vorhandene Felder und löschen nicht mehr benötigte Felder.

Alle Endpunkte in diesem Bereich verwenden Session-Authentifizierung per Cookie. Die Antworten folgen durchgängig dem Muster `success: true` und liefern je nach Operation entweder `fields`, `field` oder nur eine Erfolgsbestätigung zurück.

<Callout kind="info">

Benutzerdefinierte Felder unterstützen die Feldtypen `text`, `number`, `boolean`, `date`, `select` und `textarea`. Für Auswahlfelder verwenden Sie `options` im Format `{"options": ["Choice A", "Choice B"]}`.

</Callout>

## Endpunkte im Überblick

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/custom-fields` | Benutzerdefinierte Felder auflisten |
| `POST` | `/api/crm/custom-fields` | Ein neues benutzerdefiniertes Feld erstellen |
| `PUT` | `/api/crm/custom-fields/[id]` | Ein vorhandenes benutzerdefiniertes Feld aktualisieren |
| `DELETE` | `/api/crm/custom-fields/[id]` | Ein benutzerdefiniertes Feld löschen |

### Query-Parameter

<ParamField query="teamId" param-type="string" required="true">
Kennung des Teams, dessen benutzerdefinierte Felder Sie abrufen möchten.
</ParamField>

<ParamField query="entityType" param-type="string" required="false" enum="company,contact">
Filtert die Liste auf einen Entitätstyp. Ohne diesen Parameter enthält die Antwort Felder für Kontakte und Unternehmen.
</ParamField>

<ParamField query="includeInactive" param-type="string" required="false" enum="true">
Setzen Sie den Wert auf `true`, um auch inaktive Felder zurückzugeben. Standardmäßig enthält die Antwort nur aktive Felder.
</ParamField>

## POST /api/crm/custom-fields

Erstellen Sie ein neues benutzerdefiniertes Feld für Kontakte oder Unternehmen. Der technische Schlüssel wird serverseitig normalisiert und muss innerhalb derselben Kombination aus Team, Entitätstyp und Schlüssel eindeutig sein.

<Request>
```bash
curl -X POST "https://api.talkturo.com/api/crm/custom-fields" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r" \
  -d '{
    "teamId": "team_7f4c2a91",
    "entityType": "contact",
    "key": "Lead Source",
    "label": "Lead Source",
    "fieldType": "select",
    "options": {
      "options": ["Referral", "Website", "Partner"]
    },
    "isRequired": false,
    "sortOrder": 10,
    "isActive": true
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "field": {
    "id": "cf_b5f29410",
    "team_id": "team_7f4c2a91",
    "entity_type": "contact",
    "key": "lead_source",
    "label": "Lead Source",
    "field_type": "select",
    "options": {
      "options": ["Referral", "Website", "Partner"]
    },
    "is_required": false,
    "sort_order": 10,
    "is_active": true,
    "created_at": "2025-02-03T11:22:45.000Z",
    "updated_at": "2025-02-03T11:22:45.000Z",
    "created_by": "usr_2f9c1a77",
    "updated_by": "usr_2f9c1a77"
  }
}
```
</Response>

### Body-Parameter

<ParamField body="teamId" param-type="string" required="true">
Kennung des Teams, für das das Feld erstellt wird.
</ParamField>

<ParamField body="entityType" param-type="string" required="true" enum="company,contact">
Legt fest, für welche CRM-Entität das Feld verfügbar ist.
</ParamField>

<ParamField body="key" param-type="string" required="true">
Technischer Schlüssel des Felds. Der Server normalisiert den Wert nach dem Muster `trim().toLowerCase().replace(/\s+/g, "_")`. Der normalisierte Schlüssel muss dem Muster `^[a-z][a-z0-9_]{1,63}$` entsprechen und pro Kombination aus Team, `entity_type` und Schlüssel eindeutig sein.
</ParamField>

<ParamField body="label" param-type="string" required="true">
Anzeigename des benutzerdefinierten Felds im CRM.
</ParamField>

<ParamField body="fieldType" param-type="string" required="true" enum="text,number,boolean,date,select,textarea">
Definiert den Feldtyp des neuen Felds.
</ParamField>

<ParamField body="options" param-type="object" required="false">
Optionen für Felder vom Typ `select`. Wenn `fieldType` den Wert `select` hat, ist dieses Objekt erforderlich und muss unter `options` eine nicht leere Liste von Auswahlwerten enthalten.
</ParamField>

<ParamField body="isRequired" param-type="boolean" required="false">
Legt fest, ob das Feld verpflichtend ist. Standardwert ist `false`.
</ParamField>

<ParamField body="sortOrder" param-type="number" required="false">
Bestimmt die Sortierreihenfolge des Felds. Standardwert ist `0`.
</ParamField>

<ParamField body="isActive" param-type="boolean" required="false">
Legt fest, ob das Feld sofort aktiv ist. Standardwert ist `true`.
</ParamField>

## PUT /api/crm/custom-fields/[id]

Aktualisieren Sie die bearbeitbaren Eigenschaften eines vorhandenen Felds. `key` und `entity_type` lassen sich über diesen Endpunkt nicht ändern.

<Request>
```bash

  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r" \
  -d '{
    "label": "Primary Lead Source",
    "fieldType": "select",
    "options": {
      "options": ["Referral", "Website", "Partner", "Event"]

    "isRequired": true,
    "sortOrder": 20,
```

## DELETE /api/crm/custom-fields/[id]

Löschen Sie ein benutzerdefiniertes Feld dauerhaft über seine ID. Die Antwort enthält nur die Erfolgsbestätigung.

<Callout kind="alert">

Dieser Endpunkt löscht das Feld endgültig. Es gibt keinen Schutzmechanismus für aktive oder verwendete Felder.

</Callout>

<Request>
```bash
curl -X DELETE "https://api.talkturo.com/api/crm/custom-fields/cf_b5f29410" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r"
```
</Request>

<Response>
```json
{
  "success": true
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige Kennung des zu löschenden Felds.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob das Feld erfolgreich gelöscht wurde.
</ResponseField>
