## CRM-Kontakte mit benutzerdefinierten Feldern erweitern

Benutzerdefinierte Felder ergänzen CRM-Kontakte um zusätzliche Datenpunkte. Über diese Endpunkte listen Sie Felder für ein Team auf, erstellen neue Felder, aktualisieren bestehende Felder und löschen nicht mehr benötigte Felder.

Alle Endpunkte in diesem Bereich verwenden Session-Authentifizierung. Eine API-Key-Authentifizierung wird für diese Endpunkte nicht unterstützt. Benutzerdefinierte Felder gelten derzeit ausschließlich für die Entität `contact`.

<Callout kind="info">

Unterstützte Feldtypen sind `text`, `number`, `boolean`, `date`, `select` und `textarea`. Das Feld `options` verwenden Sie für Felder vom Typ `select`.

</Callout>

## Endpunkte im Überblick

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/custom-fields` | Benutzerdefinierte Kontaktfelder eines Teams auflisten |
| `POST` | `/api/crm/custom-fields` | Ein neues benutzerdefiniertes Kontaktfeld erstellen |
| `PUT` | `/api/crm/custom-fields/[id]` | Ein benutzerdefiniertes Kontaktfeld aktualisieren |
| `DELETE` | `/api/crm/custom-fields/[id]` | Ein benutzerdefiniertes Kontaktfeld löschen |

## GET /api/crm/custom-fields

Rufen Sie die benutzerdefinierten Kontaktfelder eines Teams ab. Verwenden Sie `entityType=contact`, um die Entität explizit anzugeben. Mit `includeInactive=true` beziehen Sie auch deaktivierte Felder in die Antwort ein.

<Request>
```bash
curl -X GET "https://api.talkturo.com/api/crm/custom-fields?teamId=team_7f3a91c2&entityType=contact&includeInactive=true" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r"
```
</Request>

<Response>
```json
{
  "success": true,
  "fields": [
    {
      "id": "cf_8d3a2f91",
      "teamId": "team_7f3a91c2",
      "entityType": "contact",
      "key": "industry_segment",
      "label": "Industry Segment",
      "fieldType": "select",
      "options": ["Enterprise", "Mid-market", "SMB"],
      "isRequired": false,
      "sortOrder": 10,
      "isActive": true
    },
    {
      "id": "cf_3b7c4e20",
      "teamId": "team_7f3a91c2",
      "entityType": "contact",
      "key": "renewal_date",
      "label": "Renewal Date",
      "fieldType": "date",
      "isRequired": true,
      "sortOrder": 20,
      "isActive": true
    }
  ]
}
```
</Response>

### Query-Parameter

<ParamField query="teamId" param-type="string" required="true">
ID des Teams, dessen benutzerdefinierte Kontaktfelder abgerufen werden sollen.
</ParamField>

<ParamField query="entityType" param-type="string" required="false" enum="contact">
Filtert die Ergebnisse nach Entität. Der einzige unterstützte Wert ist `contact`.
</ParamField>

<ParamField query="includeInactive" param-type="boolean" required="false">
Wenn `true`, enthält die Antwort auch deaktivierte Felder. Ohne diesen Parameter werden nur aktive Felder zurückgegeben.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob die Anfrage erfolgreich verarbeitet wurde.
</ResponseField>

<ResponseField name="fields" field-type="array" required="true">
Enthält die benutzerdefinierten Kontaktfelder, die den Query-Filtern entsprechen.
</ResponseField>

<ResponseField name="id" field-type="string" required="true">
Eindeutige Kennung des benutzerdefinierten Felds.
</ResponseField>

<ResponseField name="teamId" field-type="string" required="true">
ID des Teams, dem das Feld zugeordnet ist.
</ResponseField>

<ResponseField name="entityType" field-type="string" required="true">
Entität, für die das Feld gilt. Der Wert ist immer `contact`.
</ResponseField>

<ResponseField name="key" field-type="string" required="true">
Stabiler Schlüssel, unter dem der Feldwert gespeichert und abgerufen wird.
</ResponseField>

<ResponseField name="label" field-type="string" required="true">
Anzeigename des Felds.
</ResponseField>

<ResponseField name="fieldType" field-type="string" required="true">
Datentyp des Felds. Mögliche Werte sind `text`, `number`, `boolean`, `date`, `select` und `textarea`.
</ResponseField>

<ResponseField name="options" field-type="array" required="false">
Auswahlwerte für Felder vom Typ `select`.
</ResponseField>

<ResponseField name="isRequired" field-type="boolean" required="true">
Gibt an, ob das Feld beim Erfassen eines Kontakts ausgefüllt werden muss.
</ResponseField>

<ResponseField name="sortOrder" field-type="number" required="true">
Position des Felds in der Anzeige.
</ResponseField>

<ResponseField name="isActive" field-type="boolean" required="true">
Gibt an, ob das Feld aktiv ist und standardmäßig in den Ergebnissen erscheint.
</ResponseField>

## POST /api/crm/custom-fields

Erstellen Sie ein benutzerdefiniertes Kontaktfeld für ein Team. Der Wert `key` sollte stabil bleiben, während Sie den sichtbaren Namen später über `label` ändern können.

<Request>
```bash
curl -X POST "https://api.talkturo.com/api/crm/custom-fields" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r" \
  -d '{
    "teamId": "team_7f3a91c2",
    "entityType": "contact",
    "key": "lead_source",
    "label": "Lead Source",
    "fieldType": "select",
    "options": ["Referral", "Website", "Partner"],
    "isRequired": false,
    "sortOrder": 30,
    "isActive": true
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "field": {
    "id": "cf_b5f29410",
    "teamId": "team_7f3a91c2",
    "entityType": "contact",
    "key": "lead_source",
    "label": "Lead Source",
    "fieldType": "select",
    "options": ["Referral", "Website", "Partner"],
    "isRequired": false,
    "sortOrder": 30,
    "isActive": true
  }
}
```
</Response>

### Body-Parameter

<ParamField body="teamId" param-type="string" required="true">
ID des Teams, für das das benutzerdefinierte Kontaktfeld erstellt wird.
</ParamField>

<ParamField body="entityType" param-type="string" required="true" enum="contact">
Entität, für die das Feld verfügbar ist. Der einzige unterstützte Wert ist `contact`.
</ParamField>

<ParamField body="key" param-type="string" required="true">
Stabiler Schlüssel des Felds. Verwenden Sie den Schlüssel, um den Feldwert in Integrationen zu identifizieren.
</ParamField>

<ParamField body="label" param-type="string" required="true">
Anzeigename des Felds im CRM.
</ParamField>

<ParamField body="fieldType" param-type="string" required="true" enum="text,number,boolean,date,select,textarea">
Datentyp des Felds. Verwenden Sie `options`, wenn der Wert `select` ist.
</ParamField>

<ParamField body="options" param-type="array" required="false">
Liste der auswählbaren Werte für Felder vom Typ `select`.
</ParamField>

<ParamField body="isRequired" param-type="boolean" required="false">
Legt fest, ob das Feld beim Erfassen eines Kontakts erforderlich ist.
</ParamField>

<ParamField body="sortOrder" param-type="number" required="false">
Position des Felds in der Anzeige. Kleinere Werte werden zuerst angezeigt.
</ParamField>

<ParamField body="isActive" param-type="boolean" required="false">
Legt fest, ob das Feld aktiv ist.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob das Feld erfolgreich erstellt wurde.
</ResponseField>

<ResponseField name="field" field-type="object" required="true">
Enthält das neu erstellte benutzerdefinierte Kontaktfeld.
</ResponseField>

## PUT /api/crm/custom-fields/[id]

Aktualisieren Sie ein vorhandenes benutzerdefiniertes Kontaktfeld. Sie können jedes der unterstützten Änderungsfelder einzeln oder mehrere Felder gemeinsam übergeben. `teamId`, `entityType` und `key` werden bei diesem Vorgang nicht aktualisiert.

<Request>
```bash
curl -X PUT "https://api.talkturo.com/api/crm/custom-fields/cf_b5f29410" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r" \
  -d '{
    "label": "Primary Lead Source",
    "fieldType": "select",
    "options": ["Referral", "Website", "Partner", "Event"],
    "isRequired": true,
    "sortOrder": 25,
    "isActive": true
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "field": {
    "id": "cf_b5f29410",
    "teamId": "team_7f3a91c2",
    "entityType": "contact",
    "key": "lead_source",
    "label": "Primary Lead Source",
    "fieldType": "select",
    "options": ["Referral", "Website", "Partner", "Event"],
    "isRequired": true,
    "sortOrder": 25,
    "isActive": true
  }
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige Kennung des zu aktualisierenden benutzerdefinierten Kontaktfelds.
</ParamField>

### Body-Parameter

<ParamField body="label" param-type="string" required="false">
Neuer Anzeigename des Felds.
</ParamField>

<ParamField body="fieldType" param-type="string" required="false" enum="text,number,boolean,date,select,textarea">
Neuer Datentyp des Felds.
</ParamField>

<ParamField body="options" param-type="array" required="false">
Aktualisierte Auswahlwerte für ein Feld vom Typ `select`.
</ParamField>

<ParamField body="isRequired" param-type="boolean" required="false">
Legt fest, ob das Feld beim Erfassen eines Kontakts erforderlich ist.
</ParamField>

<ParamField body="sortOrder" param-type="number" required="false">
Neue Position des Felds in der Anzeige.
</ParamField>

<ParamField body="isActive" param-type="boolean" required="false">
Legt fest, ob das Feld aktiv ist.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob das Feld erfolgreich aktualisiert wurde.
</ResponseField>

<ResponseField name="field" field-type="object" required="true">
Enthält das aktualisierte benutzerdefinierte Kontaktfeld.
</ResponseField>

<Callout kind="info">

Die Endpunkte zum Aktualisieren und Löschen verwenden ausschließlich Session-Authentifizierung. Senden Sie keinen API-Key an diese Endpunkte.

</Callout>

## DELETE /api/crm/custom-fields/[id]

Löschen Sie ein benutzerdefiniertes Kontaktfeld dauerhaft über seine ID. Das Löschen entfernt die Felddefinition aus dem Team.

<Request>
```bash
curl -X DELETE "https://api.talkturo.com/api/crm/custom-fields/cf_b5f29410" \
  -H "Cookie: sb-access-token=example_session_token_9xmk7q2r"
```
</Request>

<Response>
```json
{
  "success": true
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige Kennung des zu löschenden benutzerdefinierten Kontaktfelds.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob das Feld erfolgreich gelöscht wurde.
</ResponseField>
