## CRM-Kontakte im Talkturo-CRM verwalten

Mit den CRM-Kontakt-Endpunkten verwalten Sie Kontakte im Talkturo-CRM zentral. Sie können Kontakte auflisten, neue Datensätze erstellen, einzelne Kontakte abrufen, bestehende Kontakte aktualisieren, löschen und Kontakte gesammelt per Datei importieren.

Die Authentifizierung hängt vom jeweiligen Endpunkt ab. Endpunkte zum Auflisten, Erstellen und Importieren akzeptieren **API-Schlüssel oder Sitzung**, während Endpunkte zum Abrufen, Aktualisieren und Löschen einen **Sitzungs-Cookie** erfordern.

<Callout kind="info">

Verwenden Sie für API-Schlüssel-basierte Anfragen den Header `x-api-key`. Für sitzungsgebundene Anfragen muss die Anfrage eine gültige Session-Cookie-Authentifizierung enthalten.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Authentifizierung | Zweck |
| --- | --- | --- | --- |
| `GET` | `/api/crm/contacts` | API-Schlüssel oder Sitzung | Kontakte auflisten |
| `POST` | `/api/crm/contacts` | API-Schlüssel oder Sitzung | Kontakt erstellen |
| `GET` | `/api/crm/contacts/{id}` | Sitzungs-Cookie | Einzelnen Kontakt abrufen |
| `PUT` | `/api/crm/contacts/{id}` | Sitzungs-Cookie | Kontakt aktualisieren |
| `DELETE` | `/api/crm/contacts/{id}` | Sitzungs-Cookie | Kontakt löschen |
| `POST` | `/api/crm/contacts/import` | API-Schlüssel oder Sitzung | Kontakte gesammelt importieren |

## Kontakte auflisten

Rufen Sie `GET /api/crm/contacts` auf, um Kontakte mit `limit`- und `offset`-Paginierung abzurufen und die Ergebnismenge nach Suchbegriff, Unternehmen oder Kampagne zu filtern.

<Request>
```bash
curl -X GET "https://app.talkturo.com/api/crm/contacts?limit=25&offset=0&search=Jane&companyId=cmp_42&campaignId=camp_17" \
  -H "x-api-key: dkai_example_9xmk7q2r"
```
</Request>

<Response>
```json
{
  "success": true,
  "contacts": [
    {
      "id": "ctc_8f3a21",
      "firstName": "Jane",
      "lastName": "Chen",
      "email": "jane.chen@northstar.io",
      "phone": "+14155550189",
      "companyId": "cmp_42",
      "campaignId": "camp_17",
      "campaignPriority": "high",
      "customFields": {
        "job_title": "Head of Operations"
      }
    }
  ],
  "count": 1,
  "limit": 25,
  "offset": 0
}
```
</Response>

### Query-Parameter

<ParamField query="limit" param-type="integer" required="false">
Maximale Anzahl von Kontakten pro Antwort.
</ParamField>

<ParamField query="offset" param-type="integer" required="false">
Anzahl der Einträge, die vor dem Beginn der Ergebnismenge übersprungen werden.
</ParamField>

<ParamField query="search" param-type="string" required="false">
Freitextsuche für Kontakte.
</ParamField>

<ParamField query="companyId" param-type="string" required="false">
Filtert Kontakte nach einer bestimmten Unternehmens-ID.
</ParamField>

<ParamField query="campaignId" param-type="string" required="false">
Filtert Kontakte nach einer bestimmten Kampagnen-ID.
</ParamField>

Kennzeichnet eine erfolgreiche Anfrage.
</ResponseField>

<ResponseField name="contacts" field-type="array" required="true">
Liste der gefundenen Kontakte innerhalb des angeforderten Ausschnitts.
</ResponseField>

<ResponseField name="count" field-type="integer" required="true">
Anzahl der in dieser Antwort zurückgegebenen Kontakte.
</ResponseField>

<ResponseField name="limit" field-type="integer" required="true">
Angewendeter `limit`-Wert.
</ResponseField>

<ResponseField name="offset" field-type="integer" required="true">
Angewendeter `offset`-Wert.
</ResponseField>

## Kontakt erstellen

Rufen Sie `POST /api/crm/contacts` auf, um einen neuen Kontakt im CRM anzulegen.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts" \
  -H "Content-Type: application/json" \
  -H "x-api-key: dkai_example_9xmk7q2r" \
  -d '{
    "firstName": "Jane",
    "lastName": "Chen",
    "email": "jane.chen@northstar.io",
    "phone": "+14155550189",
    "companyId": "cmp_42",
    "campaignId": "camp_17",
    "campaignPriority": "high"
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "contact": {
    "id": "ctc_8f3a21",
    "firstName": "Jane",
    "lastName": "Chen",
    "email": "jane.chen@northstar.io",
    "phone": "+14155550189",
    "companyId": "cmp_42",
    "campaignId": "camp_17",
    "campaignPriority": "high",
    "customFields": {
      "job_title": "Head of Operations"
    }
  }
}
```
</Response>

## Kontakt löschen

Rufen Sie `DELETE /api/crm/contacts/{id}` auf, um einen Kontakt dauerhaft zu entfernen.

<Request>
```bash
curl -X DELETE "https://app.talkturo.com/api/crm/contacts/ctc_8f3a21" \
  -H "Cookie: sb-session=example_session_cookie"
```
</Request>

<Response tabs="200,400">
```json
{
  "success": true
}
```

```json
{
  "success": false,
  "error": "Contact is part of an active campaign"
}
```
</Response>

<Callout kind="alert">

Wenn der Kontakt Teil einer aktiven Kampagne ist, gibt der Endpunkt `400 Bad Request` zurück und verhindert die Löschung.

</Callout>

## Kontakte gesammelt importieren

Rufen Sie `POST /api/crm/contacts/import` auf, um Kontakte per `multipart/form-data` zu importieren. Laden Sie eine Datei hoch und übergeben Sie zusätzlich das Spalten-Mapping und den Modus für Dubletten.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "x-api-key: dkai_example_9xmk7q2r" \
  -F "file=@contacts.csv" \
  -F 'columnMapping={"First Name":"firstName","Last Name":"lastName","Email":"email","Phone":"phone","Company ID":"companyId","Campaign ID":"campaignId","Campaign Priority":"campaignPriority"}' \
  -F "duplicateMode=skip"
```
</Request>

<Response>
```json
{
  "success": true,
  "imported": 2,
  "failed": 0,
  "errors": []
}
```
</Response>

<Callout kind="info">

Der Import-Endpunkt akzeptiert Datei-Uploads per `multipart/form-data`. Verwenden Sie `columnMapping`, um Spalten aus der Importdatei den unterstützten CRM-Feldern zuzuordnen, und `duplicateMode`, um das Verhalten bei Dubletten zu steuern.

</Callout>

### Formularfelder

<ParamField body="file" param-type="file" required="true">
CSV-Datei oder andere unterstützte Importdatei mit den zu importierenden Kontakten.
</ParamField>

<ParamField body="columnMapping" param-type="string" required="true">
JSON-kodiertes Mapping zwischen Spaltennamen in der Datei und den unterstützten Feldnamen im CRM.
</ParamField>

<ParamField body="duplicateMode" param-type="string" required="false">
Strategie für den Umgang mit doppelten Kontakten während des Imports.
</ParamField>

### Unterstützte Feldnamen für Mapping

- `firstName`
- `lastName`
- `email`
- `phone`
- `companyId`
- `campaignId`
- `campaignPriority`

### Antwortfelder

</ResponseField>

<ResponseField name="imported" field-type="integer" required="true">
Anzahl der erfolgreich importierten Kontakte.
</ResponseField>

<ResponseField name="failed" field-type="integer" required="true">

</ResponseField>

<ResponseField name="errors" field-type="array" required="true">

</ResponseField>

## Hinweise zu benutzerdefinierten Feldern

Benutzerdefinierte Felder werden in den Kontaktantworten als Objekt `customFields` zurückgegeben. Die verfügbaren Schlüssel hängen von Ihrer CRM-Konfiguration und den in Ihrem Workspace definierten Feldern ab.

Wenn Sie Importdateien vorbereiten oder Kontakte programmgesteuert erstellen, verwenden Sie die standardisierten Kernfelder für Namens-, Kampagnen- und Unternehmenszuordnung. Benutzerdefinierte Felder sollten nur dann berücksichtigt werden, wenn Ihr Workflow diese Felder bereits in Talkturo definiert.
