## CRM-Kontakte im Talkturo-CRM verwalten

Mit den CRM-Kontakt-Endpunkten verwalten Sie Ihre Kontaktdaten zentral im Talkturo-CRM. Sie können Kontakte auflisten, einzelne Datensätze anlegen, bestehende Kontakte aktualisieren, löschen und größere Datenmengen gesammelt importieren.

Die Authentifizierung hängt vom jeweiligen Endpunkt ab. Die Listen- und Erstellungsendpunkte unterstützen API-Key-Authentifizierung oder eine gültige Session-Cookie-Authentifizierung. Endpunkte für einzelne Kontakte erfordern dagegen eine gültige Session-Cookie-Authentifizierung.

<Callout kind="info">

`GET /api/crm/contacts` und `POST /api/crm/contacts` akzeptieren API-Keys oder Session-Cookies. `GET /api/crm/contacts/{id}`, `PUT /api/crm/contacts/{id}` und `DELETE /api/crm/contacts/{id}` akzeptieren nur Session-Cookies.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | Kontakte auflisten |
| `POST` | `/api/crm/contacts` | Kontakt erstellen |
| `GET` | `/api/crm/contacts/{id}` | Einzelnen Kontakt abrufen |
| `PUT` | `/api/crm/contacts/{id}` | Kontakt aktualisieren |
| `DELETE` | `/api/crm/contacts/{id}` | Kontakt löschen |
| `POST` | `/api/crm/contacts/import` | Kontakte gesammelt importieren |

## Kontakte auflisten

Rufen Sie `GET /api/crm/contacts` auf, um Kontakte mit Offset-Paginierung abzurufen und die Ergebnismenge nach Team, Unternehmen, Lead-Status, Telefonnummern und Freitext zu filtern.

<Request tabs="cURL,JavaScript">
```bash
curl -X GET "https://app.talkturo.com/api/crm/contacts?teamId=team_7k2m9&companyId=cmp_42&search=chen&leadStatus=qualified&doNotCall=false&hasPhone=true&limit=25&offset=0" \
  -H "x-api-key: ttr_example_9xmk7q2r"
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/contacts?teamId=team_7k2m9&companyId=cmp_42&search=chen&leadStatus=qualified&doNotCall=false&hasPhone=true&limit=25&offset=0", {
  method: "GET",
  headers: {
    "x-api-key": "ttr_example_9xmk7q2r"
  }
});

const data = await response.json();
console.log(data);

</Request>

### Query-Parameter

<ParamField query="teamId" param-type="string" required="false">
Filtert Kontakte nach einer bestimmten Team-ID. Wenn Sie keine Team-ID übergeben, verwendet der Endpunkt den Team-Kontext der authentifizierten Anfrage.
</ParamField>

<ParamField query="companyId" param-type="string" required="false">
Filtert Kontakte nach einer bestimmten Unternehmens-ID.
</ParamField>

<ParamField query="search" param-type="string" required="false">
Durchsucht `first_name`, `last_name`, `email` und `phone` mit einer ILIKE-Suche.
</ParamField>

<ParamField query="leadStatus" param-type="string" required="false">
Filtert Kontakte nach Lead-Status.
</ParamField>

<ParamField query="doNotCall" param-type="boolean" required="false" enum="true,false">
Filtert Kontakte danach, ob sie als nicht anrufbar markiert sind.
</ParamField>

<ParamField query="hasPhone" param-type="boolean" required="false" enum="true,false">
Filtert Kontakte danach, ob eine primäre Telefonnummer vorhanden ist.
</ParamField>

<ParamField query="limit" param-type="integer" required="false">
Maximale Anzahl von Kontakten pro Antwort. Der Standardwert ist `50`.
</ParamField>

<ParamField query="offset" param-type="integer" required="false">
Anzahl der Datensätze, die vor dem Beginn der Ergebnismenge übersprungen werden. Der Standardwert ist `0`.
</ParamField>

## Kontakt erstellen

  -H "Content-Type: application/json" \
  -H "x-api-key: ttr_example_9xmk7q2r" \
  -d '{
    "teamId": "team_7k2m9",
    "companyId": "cmp_42",
    "firstName": "Jane",
    "lastName": "Chen",
    "phone": "+14155550189",
    "phoneSecondary": "+14155550190",
    "email": "jane.chen@northstar.io",
    "jobTitle": "Revenue Operations Manager",
    "leadStatus": "qualified",

    },
    "tags": ["priority", "enterprise"],
    "campaignId": "camp_17",
    "campaignPriority": 2
  }'
```

## Kontakt löschen

Rufen Sie `DELETE /api/crm/contacts/{id}` auf, um einen Kontakt dauerhaft zu entfernen. Dieser Endpunkt akzeptiert nur Session-Cookie-Authentifizierung.

<Request>
```bash
curl -X DELETE "https://app.talkturo.com/api/crm/contacts/ctc_8f3a21" \
  -H "Cookie: sb-session=example_session_cookie"
```
</Request>

<Response tabs="200,400">
```json
{
  "success": true
}
```

```json
{
  "success": false,
  "error": "Contact is currently enrolled in an active campaign"
}
```
</Response>

<Callout kind="alert">

Der Endpunkt gibt `400` zurück, wenn der Kontakt Teil einer aktiven Kampagne mit dem Status `pending`, `queued` oder `calling` ist. Entfernen Sie den Kontakt zuerst aus der aktiven Kampagne oder warten Sie, bis der Kampagnenlauf beendet ist.

</Callout>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige ID des Kontakts, den Sie löschen möchten.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Kennzeichnet eine erfolgreiche Löschung.
</ResponseField>

<ResponseField name="error" field-type="string" required="false">
Fehlermeldung, wenn das Löschen blockiert wird.
</ResponseField>

## Kontakte gesammelt importieren

Rufen Sie `POST /api/crm/contacts/import` auf, um viele Kontakte in einer Anfrage zu importieren. Der Endpunkt akzeptiert einen Body im Format `contacts: [...]` oder einen CSV-basierten Import, abhängig von Ihrem Import-Workflow.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-session=example_session_cookie" \
  -d '{
    "contacts": [
      {
        "firstName": "Jane",
        "lastName": "Chen",
        "email": "jane.chen@northstar.io",
        "phone": "+14155550189",
        "companyId": "cmp_42"
      },
      {
        "firstName": "Marcus",
        "lastName": "Rivera",
        "email": "marcus.rivera@northstar.io",
        "phone": "+14155550192",
        "companyId": "cmp_42"
      }
    ]
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "imported": 2,
  "failed": 0,
  "errors": []
}
```
</Response>

<Callout kind="info">

Der Import-Endpunkt unterstützt laut Implementierung sowohl strukturierte JSON-Daten als auch CSV-Importe. Die Antwort enthält die Anzahl erfolgreich importierter Kontakte, fehlgeschlagener Einträge und gegebenenfalls eine Fehlerliste.

</Callout>

### Request-Body

<ParamField body="contacts" param-type="array" required="false">
Liste von Kontakten für den JSON-Import.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Kennzeichnet einen erfolgreich verarbeiteten Importaufruf.
</ResponseField>

<ResponseField name="imported" field-type="integer" required="true">
Anzahl der erfolgreich importierten Kontakte.
</ResponseField>

<ResponseField name="failed" field-type="integer" required="true">
Anzahl der Kontakte, die nicht importiert werden konnten.
</ResponseField>

<ResponseField name="errors" field-type="array" required="true">
Liste der Importfehler, sofern einzelne Einträge fehlschlagen.
</ResponseField>
