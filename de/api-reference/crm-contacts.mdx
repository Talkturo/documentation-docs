## CRM-Kontakte im Talkturo-CRM verwalten

Mit den CRM-Kontakt-Endpunkten verwalten Sie Kontakte, Unternehmenszuordnungen und Import-Workflows im Talkturo-CRM. Die Referenz unten zeigt die unterstützten Authentifizierungsmethoden, die korrekten Feldnamen und das tatsächliche Anfrageformat pro Route.

<Callout kind="info">

`GET /api/crm/contacts`, `POST /api/crm/contacts` und `POST /api/crm/contacts/import` akzeptieren Session-Cookie oder API-Key im Header `Authorization: Bearer tk_live_example_9xmk7q2r`. `GET /api/crm/contacts/{id}`, `PUT /api/crm/contacts/{id}` und `DELETE /api/crm/contacts/{id}` akzeptieren nur Session-Authentifizierung.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck | Auth |
| --- | --- | --- | --- |
| `GET` | `/api/crm/contacts` | Kontakte auflisten | Session oder API-Key |
| `POST` | `/api/crm/contacts` | Kontakt erstellen | Session oder API-Key |
| `GET` | `/api/crm/contacts/{id}` | Einzelnen Kontakt abrufen | Nur Session |
| `PUT` | `/api/crm/contacts/{id}` | Kontakt aktualisieren | Nur Session |
| `DELETE` | `/api/crm/contacts/{id}` | Kontakt löschen | Nur Session |
| `POST` | `/api/crm/contacts/import` | Kontakte per CSV importieren | Session oder API-Key |


## Kontakt löschen

Rufen Sie `DELETE /api/crm/contacts/{id}` auf, um einen Kontakt dauerhaft zu entfernen. Der Endpunkt blockiert das Löschen, wenn der Kontakt aktuell in aktiven Kampagnen eingeschrieben ist.

<Request>
```bash
curl -X DELETE "https://app.talkturo.com/api/crm/contacts/ctc_8f3a21" \
  -H "Cookie: sb-session=example_session_cookie"
```
</Request>

<Response tabs="200,400">
```json
{
  "success": true
}
```

```json
{
  "success": false,
  "error": "Cannot delete contact: currently enrolled in active campaigns"
}
```
</Response>

<Callout kind="alert">

Wenn der Kontakt einen Kampagnenstatus `pending`, `queued` oder `calling` hat, antwortet der Endpunkt mit `400` und löscht den Datensatz nicht. Wenn das Löschen erlaubt ist, entfernt der Endpunkt den Kontakt dauerhaft und kaskadiert auf `contact_activities` und `campaign_contacts`.

</Callout>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige ID des Kontakts, den Sie löschen möchten.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Kennzeichnet eine erfolgreiche Löschung.
</ResponseField>

<ResponseField name="error" field-type="string" required="false">
Fehlermeldung, wenn das Löschen blockiert ist.
</ResponseField>

## Kontakte per CSV importieren

Rufen Sie `POST /api/crm/contacts/import` mit `multipart/form-data` auf, um Kontakte gesammelt aus einer CSV-Datei zu importieren. Der Endpunkt akzeptiert keinen JSON-Import.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -F "file=@contacts.csv;type=text/csv" \
  -F "teamId=8c1f2e88-4de3-4a29-b7d1-41870a7e32b1" \
  -F 'columnMapping={"First Name":"first_name","Last Name":"last_name","Company":"company_name","Email":"email","Phone":"phone","Lead Status":"lead_status","Source":"source","Tags":"tags"}' \
  -F "autoCreateCompanies=true" \
  -F "importCompanyFields=false" \
  -F "defaultCompanyId=2a31fc5b-c7f8-43e2-8a2a-cf3be4c8a4b4" \
  -F "duplicateMode=skip"
```
</Request>

<Response>
```json
{
  "success": true,
  "imported": 2,
  "failed": 0,
  "errors": []
}
```
</Response>

<Callout kind="info">

`columnMapping` ist ein JSON-kodierter String, der CSV-Spaltenüberschriften internen Feldnamen zuordnet. Der Wert `first_name` ist erforderlich. Für `lead_status` und `source` akzeptiert der Import nur die unten dokumentierten Werte.

</Callout>

### Request-Body

<ParamField body="file" param-type="File" required="true">
CSV-Datei mit den zu importierenden Kontakten.
</ParamField>

<ParamField body="teamId" param-type="string" required="true">
Workspace- oder Team-ID als UUID.
</ParamField>

<ParamField body="columnMapping" param-type="string" required="true">
JSON-kodiertes Mapping von CSV-Headern zu internen Feldnamen.
</ParamField>

<ParamField body="autoCreateCompanies" param-type="string" required="false" enum="true">
