## CRM-Kontakte im Talkturo-CRM verwalten

Mit den CRM-Kontakt-Endpunkten verwalten Sie Ihre Kontaktdaten zentral im Talkturo-CRM. Sie können Kontakte auflisten, einzelne Datensätze anlegen, bestehende Kontakte aktualisieren, löschen und größere Datenmengen gesammelt importieren.

Alle Endpunkte in diesem Bereich verwenden die Middleware `withApiAuth`. Sie authentifizieren Anfragen entweder mit einem API-Key im `Authorization`-Header oder über eine gültige browserbasierte Session.

<Callout kind="info">

Diese Endpunkte unterstützen duale Authentifizierung. Verwenden Sie entweder einen API-Key im Format `Authorization: Bearer tk_live_...` oder ein angemeldetes Session-Cookie. Für API-Keys gelten Scope-Prüfungen: `contacts:read` für `GET`-Endpunkte und `contacts:write` für `POST`-, `PUT`- und `DELETE`-Endpunkte.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | Kontakte auflisten |
| `POST` | `/api/crm/contacts` | Kontakt erstellen |
| `GET` | `/api/crm/contacts/{id}` | Einzelnen Kontakt abrufen |
| `PUT` | `/api/crm/contacts/{id}` | Kontakt aktualisieren |
| `DELETE` | `/api/crm/contacts/{id}` | Kontakt löschen |
| `POST` | `/api/crm/contacts/import` | Kontakte gesammelt importieren |

## Kontakte auflisten

Rufen Sie `GET /api/crm/contacts` auf, um Kontakte mit `limit`- und `offset`-Paginierung abzurufen und die Ergebnismenge nach Team, Gruppe, Lead-Status oder Erreichbarkeit zu filtern.

<Request>
```bash
curl -X GET "https://app.talkturo.com/api/crm/contacts?limit=50&offset=0&search=chen&teamId=team_6f2b9d10&groupId=grp_42&leadStatus=new&doNotCall=false&hasPhone=true" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z"
```
</Request>

<Response>
```json
{
  "success": true,
  "contacts": [
    {
      "id": "ctc_8f3a21",
      "teamId": "team_6f2b9d10",
      "groupId": "grp_42",
      "firstName": "Jane",
      "lastName": "Chen",
      "phone": "+14155550189",
      "email": "jane.chen@northstar.io",
      "phoneSecondary": "+14155550190",
      "jobTitle": "Revenue Operations Manager",
      "companyName": "Northstar Labs",
      "leadStatus": "new",
      "preferredContactMethod": "phone",
      "doNotCall": false,
      "customFields": {
        "region": "west",
        "accountTier": "enterprise"
      }
    }
  ],
  "limit": 50,
  "offset": 0
}
```
</Response>

## Kontakt erstellen

Rufen Sie `POST /api/crm/contacts` auf, um einen neuen Kontakt im CRM anzulegen.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -d '{
    "teamId": "team_6f2b9d10",
    "groupId": "grp_42",
    "firstName": "Jane",
    "lastName": "Chen",
    "phone": "+14155550189",
    "email": "jane.chen@northstar.io",
    "phoneSecondary": "+14155550190",
    "jobTitle": "Revenue Operations Manager",
    "companyName": "Northstar Labs",
    "leadStatus": "new",
    "source": "api",
    "timezone": "America/Los_Angeles",
    "preferredContactMethod": "phone",
    "doNotCall": false,
    "notes": "Best time to call is after 14:00 PT.",
    "customFields": {
      "region": "west",
      "accountTier": "enterprise"
    },
    "tags": ["demo-request", "priority-a"],
    "campaignId": "camp_17",
    "campaignPriority": 3
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "contact": {
    "id": "ctc_8f3a21",
    "teamId": "team_6f2b9d10",
    "groupId": "grp_42",
    "firstName": "Jane",
    "lastName": "Chen",
    "phone": "+14155550189",
    "email": "jane.chen@northstar.io",
    "phoneSecondary": "+14155550190",
    "jobTitle": "Revenue Operations Manager",
    "companyName": "Northstar Labs",
    "leadStatus": "new",
    "source": "api",
    "timezone": "America/Los_Angeles",
    "preferredContactMethod": "phone",
    "doNotCall": false,
    "notes": "Best time to call is after 14:00 PT.",
    "customFields": {
      "region": "west",
      "accountTier": "enterprise"
```

<Callout kind="info">

</Callout>

## Kontakte gesammelt importieren

Rufen Sie `POST /api/crm/contacts/import` auf, um viele Kontakte in einer Anfrage zu importieren.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -d '{
    "teamId": "team_6f2b9d10",
    "contacts": [
      {
        "firstName": "Jane",
        "lastName": "Chen",
        "phone": "+14155550189",
        "email": "jane.chen@northstar.io",
        "groupId": "grp_42",
        "companyName": "Northstar Labs"
      },
      {
        "firstName": "Marcus",
        "lastName": "Rivera",
        "phone": "+14155550192",
        "email": "marcus.rivera@northstar.io",
        "groupId": "grp_42",
        "companyName": "Northstar Labs"
      }
    ]
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "imported": 2,
  "failed": 0,
  "errors": []
}
```
</Response>

<Callout kind="info">

Der Import erwartet `teamId` auf oberster Ebene. Kontaktfelder im Import verwenden camelCase, insbesondere `firstName`, `lastName`, `phone`, `email`, `groupId` und `companyName`. Telefonnummern müssen auch beim Import im E.164-Format vorliegen.

</Callout>
