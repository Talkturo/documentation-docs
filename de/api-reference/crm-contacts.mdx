## CRM-Kontakte im Talkturo-CRM verwalten

Mit den CRM-Kontakt-Endpunkten erstellen, suchen, aktualisieren, löschen und importieren Sie Kontakte. Die API unterstützt Gruppen, benutzerdefinierte Felder, Tags, Kampagnenzuordnungen und Filter für Telefonstatus und Lead-Status.

Alle Endpunkte unterstützen API-Key-Authentifizierung und Session-Cookie-Authentifizierung über `withApiAuth`.

<Callout kind="info">

API-Key-Anfragen verwenden automatisch das dem Schlüssel zugeordnete Konto. `teamId` ist bei diesen Anfragen optional. Session-Anfragen müssen `teamId` im Query-String oder im Request-Body enthalten.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | Kontakte auflisten und filtern |
| `POST` | `/api/crm/contacts` | Kontakt erstellen oder anhand der Telefonnummer zusammenführen |
| `GET` | `/api/crm/contacts/{id}` | Einzelnen Kontakt mit Aktivitäten und Zuordnungen abrufen |
| `PUT` | `/api/crm/contacts/{id}` | Kontakt aktualisieren |
| `DELETE` | `/api/crm/contacts/{id}` | Kontakt löschen |
| `POST` | `/api/crm/contacts/import` | Kontakte aus einer CSV-Datei importieren |
| `GET` | `/api/crm/import-batches` | Import-Stapel auflisten |

## Kontakte auflisten

Rufen Sie `GET /api/crm/contacts` auf, um Kontakte zu suchen, nach Gruppen und Lead-Status zu filtern und die Ergebnisse mit `limit` und `offset` zu paginieren.

<Request>
```bash
curl -X GET "https://api.talkturo.com/api/crm/contacts?teamId=team_42&groupId=grp_sales&search=jane&leadStatus=qualified&doNotCall=false&hasPhone=true&limit=50&offset=0" \
  -H "x-api-key: dkai_example_9xmk7q2r"
```
</Request>

<Response>
```json
{
  "success": true,
  "contacts": [
    {
      "id": "ctc_8f3a21",
      "firstName": "Jane",
      "lastName": "Chen",
      "email": "jane.chen@northstar.io",
      "phone": "+14155550189",
      "leadStatus": "qualified",
      "doNotCall": false,
      "groups": [
        {
          "id": "grp_sales",
          "name": "Vertrieb"
        }
      ]
    }
  ],
  "count": 1,
  "limit": 50,
  "offset": 0
}
```
</Response>

## Kontakt erstellen

Rufen Sie `POST /api/crm/contacts` auf, um einen Kontakt mit camelCase-Feldern zu erstellen. `firstName`, `lastName` und eine Telefonnummer im E.164-Format sind erforderlich.

<CodeGroup tabs="API-Key,Session-Cookie">
```bash
curl -X POST "https://api.talkturo.com/api/crm/contacts" \
  -H "Content-Type: application/json" \
  -H "x-api-key: dkai_example_9xmk7q2r" \
  -d '{
    "firstName": "Jane",
    "lastName": "Chen",
    "phone": "+14155550189",
    "email": "jane.chen@northstar.io",
    "companyName": "Northstar Analytics",
    "leadStatus": "qualified",
    "source": "api",
    "preferredContactMethod": "phone",
    "customFields": {
      "customerTier": "enterprise",
      "renewalMonth": "October"
    },
    "tags": ["priority", "conference-lead"],
    "campaignId": "camp_17",
    "campaignPriority": 10
  }'
```

```bash
curl -X POST "https://api.talkturo.com/api/crm/contacts" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-session=example_session_cookie" \
  -d '{
    "teamId": "team_42",
    "firstName": "Jane",
    "lastName": "Chen",
    "phone": "+14155550189",
    "email": "jane.chen@northstar.io",
    "companyName": "Northstar Analytics",
    "leadStatus": "qualified"
  }'
```
</CodeGroup>

<Response>
```json
{
  "success": true,
  "contact": {
    "id": "ctc_8f3a21",
    "firstName": "Jane",
    "lastName": "Chen",
    "phone": "+14155550189",
    "email": "jane.chen@northstar.io",
    "companyName": "Northstar Analytics",
    "leadStatus": "qualified"
  },
  "existing": false,
  "campaign_enrollment": {
    "campaign_contact_id": "cc_5d7e91",
    "status": "enrolled",
    "excludedReason": null
  }
}
```
</Response>

Die API dedupliziert Kontakte anhand der Telefonnummer. Findet sie einen bestehenden Kontakt mit derselben Telefonnummer, führt sie die übergebenen Felder mit dem vorhandenen Datensatz zusammen und gibt `existing: true` zurück.

Wenn Sie `campaignId` übergeben, enthält die Antwort zusätzlich `campaign_enrollment`. Der Status ist `enrolled`, `already_enrolled` oder `excluded`. Bei `excluded` beschreibt `excludedReason` den Grund mit `no_phone` oder `do_not_call`.

## Kontakte aus einer CSV-Datei importieren

Rufen Sie `POST /api/crm/contacts/import` mit `multipart/form-data` auf, um Kontakte aus einer CSV-Datei zu importieren. Der Endpunkt akzeptiert keinen JSON-Body.

<Request>
```bash
curl -X POST "https://api.talkturo.com/api/crm/contacts/import" \
  -H "x-api-key: dkai_example_9xmk7q2r" \
  -F "file=@contacts-february.csv;type=text/csv" \
  -F "teamId=team_42" \
  -F "groupId=grp_sales" \
  -F "duplicateMode=skip" \
  -F 'columnMapping={"first_name":"first_name","last_name":"last_name","phone":"phone","email":"email","companyName":"company_name"}'
```
</Request>

<Response>
```json
{
  "success": true,
  "imported": 184,
  "updated": 0,
  "skipped": 12,
  "failed": 3,
  "total": 199,
  "errors": [
    {
      "row": 47,
      "message": "Invalid phone number"
    }
  ],
  "groupId": "grp_sales",
  "batchId": "batch_7c91e2"
}
```
</Response>

Für CSV-Importe ist nur die Spalte `first_name` erforderlich. `last_name` ist optional. Verwenden Sie `newGroupName` anstelle von `groupId`, wenn der Import eine neue Gruppe anlegen soll.
