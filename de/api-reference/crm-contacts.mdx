## CRM-Kontakte im Talkturo-CRM verwalten

Mit den CRM-Kontakt-Endpunkten verwalten Sie Ihre Kontaktdaten zentral im Talkturo-CRM. Sie können Kontakte auflisten, einzelne Datensätze anlegen, bestehende Kontakte aktualisieren, löschen und größere Datenmengen gesammelt importieren.

Alle Endpunkte in diesem Bereich sind für browserbasierte Sitzungen ausgelegt. Wenn Sie mit diesen Routen arbeiten, muss die Anfrage eine gültige Authentifizierung enthalten.

<Callout kind="info">

Alle CRM-Kontakt-Endpunkte unterstützen duale Authentifizierung. Verwenden Sie entweder einen API-Schlüssel in `Authorization: Bearer tk_live_...` oder ein authentifiziertes Session-Cookie. Die Code-Beispiele auf dieser Seite verwenden API-Schlüssel-Authentifizierung.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | Kontakte auflisten |
| `POST` | `/api/crm/contacts` | Kontakt erstellen |
| `GET` | `/api/crm/contacts/{id}` | Einzelnen Kontakt abrufen |
| `PATCH` | `/api/crm/contacts/{id}` | Kontakt aktualisieren |
| `DELETE` | `/api/crm/contacts/{id}` | Kontakt löschen |
| `POST` | `/api/crm/contacts/import` | Kontakte gesammelt importieren |

## Kontakte auflisten

Rufen Sie `GET /api/crm/contacts` auf, um Kontakte seitenweise abzurufen und die Ergebnismenge nach Suchbegriff, Unternehmen, Lead-Status und weiteren Kriterien zu filtern.

<Request>
```bash
curl -X GET "https://app.talkturo.com/api/crm/contacts?search=chen&companyId=cmp_9f3e21&leadStatus=new&limit=25&offset=0" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z"
```
</Request>

<Response>
```json
{
  "success": true,
  "contacts": [
    {
      "id": "ctc_8f3a21",
      "first_name": "Jane",
      "last_name": "Chen",
      "email": "jane.chen@northstar.io",
      "phone": "+14155550189",
      "company_id": "cmp_9f3e21",
      "company": {
        "id": "cmp_9f3e21",
        "name": "Northstar Health"
      }
    }
  ],
  "count": 1,
  "limit": 25,
  "offset": 0
}
```
</Response>

## Kontakt erstellen

Rufen Sie `POST /api/crm/contacts` auf, um einen neuen Kontakt im CRM anzulegen.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -d '{
    "firstName": "Jane",
    "lastName": "Chen",
    "email": "jane.chen@northstar.io",
    "phone": "+14155550189",
    "companyId": "cmp_9f3e21",
    "teamId": "team_2a7d10",
    "phoneSecondary": "+14155550190",
    "jobTitle": "Operations Manager",
    "leadStatus": "new",
    "source": "webinar",
    "timezone": "America/Los_Angeles",
    "preferredContactMethod": "phone",
    "doNotCall": false,
    "notes": "Hat Interesse an einem Piloten im Q3.",
    "customFields": {
      "industrySegment": "Healthcare",
      "region": "West"
    },
    "tags": ["priority", "demo-request"],
    "campaignId": "camp_17",
    "campaignPriority": "high"
  }'
```

## Kontakt aktualisieren

  -H "Content-Type: application/json" \

  -d '{
    "phone": "+14155550190",
    "company_id": "cmp_84"
  }'

## Kontakte gesammelt importieren

Rufen Sie `POST /api/crm/contacts/import` auf, um viele Kontakte in einer Anfrage zu importieren. Der Endpunkt akzeptiert einen Body im Format `contacts: [...]` oder einen CSV-basierten Import, abhängig von Ihrem Import-Workflow.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -d '{
    "contacts": [
      {
        "firstName": "Jane",
        "lastName": "Chen",
        "email": "jane.chen@northstar.io",
        "phone": "+14155550189",
        "companyId": "cmp_42"
      },
      {
        "firstName": "Marcus",
        "lastName": "Rivera",
        "email": "marcus.rivera@northstar.io",
        "phone": "+14155550192",
        "companyId": "cmp_42"
      }
    ]
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "imported": 2,
  "failed": 0,
  "errors": []
}
```
</Response>

<Callout kind="info">

Der Import-Endpunkt unterstützt laut Implementierung sowohl strukturierte JSON-Daten als auch CSV-Importe. Die Antwort enthält die Anzahl erfolgreich importierter Kontakte, fehlgeschlagener Einträge und gegebenenfalls eine Fehlerliste.

</Callout>

### Request-Body

<ParamField body="contacts" param-type="array" required="false">
Liste von Kontakten für den JSON-Import.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Kennzeichnet einen erfolgreich verarbeiteten Importaufruf.
</ResponseField>

<ResponseField name="imported" field-type="integer" required="true">
Anzahl der erfolgreich importierten Kontakte.
</ResponseField>

<ResponseField name="failed" field-type="integer" required="true">
Anzahl der Kontakte, die nicht importiert werden konnten.
</ResponseField>

<ResponseField name="errors" field-type="array" required="true">
Liste der Importfehler, sofern einzelne Einträge fehlschlagen.
</ResponseField>
