## CRM-Kontakte im Talkturo-CRM verwalten

Mit den CRM-Kontakt-Endpunkten verwalten Sie Ihre Kontaktdaten zentral im Talkturo-CRM. Sie können Kontakte auflisten, einzelne Datensätze anlegen, bestehende Kontakte aktualisieren, löschen und größere Datenmengen gesammelt importieren.

Alle Endpunkte in diesem Bereich akzeptieren entweder eine authentifizierte Browser-Sitzung per Session-Cookie oder einen API-Key per Bearer-Token.

<Callout kind="info">

Diese Endpunkte akzeptieren entweder **Session-Cookie-Authentifizierung** oder **API-Key-Bearer-Token-Authentifizierung**.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/contacts` | Kontakte auflisten |
| `POST` | `/api/crm/contacts` | Kontakt erstellen |
| `GET` | `/api/crm/contacts/{id}` | Einzelnen Kontakt abrufen |
| `PATCH` | `/api/crm/contacts/{id}` | Kontakt aktualisieren |
| `DELETE` | `/api/crm/contacts/{id}` | Kontakt löschen |
| `POST` | `/api/crm/contacts/import` | Kontakte gesammelt importieren |

## Kontakte auflisten

Rufen Sie `GET /api/crm/contacts` auf, um Kontakte seitenweise abzurufen und die Ergebnismenge nach Suchbegriff, Unternehmen oder Kampagne zu filtern.

<Request>
```bash
curl -X GET "https://app.talkturo.com/api/crm/contacts?teamId=8f4b7d7f-2a91-4fd2-9d5f-2ab0e6c73d11&limit=25&offset=0&search=Jane&companyId=cmp_42&leadStatus=new&hasPhone=true" \
  -H "Authorization: Bearer tt_api_example_9xmk7q2r"
```
</Request>

<Response>
```json
{
  "success": true,
  "contacts": [
    {
      "id": "ctc_8f3a21",
      "firstName": "Jane",
      "lastName": "Chen",
      "email": "jane.chen@northstar.io",
      "phone": "+14155550189",
      "companyId": "cmp_42"
    }
  ],
  "total": 1
}
```
</Response>

### Query-Parameter

<ParamField query="teamId" param-type="string" required="false">
Workspace-UUID. Standard ist die Kennung des authentifizierten Accounts.
</ParamField>

<ParamField query="companyId" param-type="string" required="false">
Filtert Kontakte nach einer bestimmten Unternehmens-ID.
</ParamField>

<ParamField query="search" param-type="string" required="false">
Freitextsuche für Kontakte (ilike auf first_name, last_name, email, phone).
</ParamField>

<ParamField query="leadStatus" param-type="string" required="false">
Filtert nach Lead-Status (exakte Übereinstimmung).
</ParamField>

<ParamField query="doNotCall" param-type="string" required="false" enum="true,false">
Filtert nach DNC-Status (Do Not Call).
</ParamField>

<ParamField query="hasPhone" param-type="string" required="false" enum="true,false">
Filtert Kontakte mit oder ohne Telefonnummer.
</ParamField>

<ParamField query="limit" param-type="integer" required="false">
Maximale Anzahl von Kontakten pro Seite. Standard ist 50.
</ParamField>

<ParamField query="offset" param-type="integer" required="false">
Offset für die Paginierung. Standard ist 0.
</ParamField>

</ResponseField>

</ResponseField>

<ResponseField name="contacts[].id" field-type="string" required="true">
Eindeutige ID des Kontakts.
</ResponseField>

<ResponseField name="contacts[].firstName" field-type="string" required="true">
Vorname des Kontakts.
</ResponseField>

<ResponseField name="contacts[].lastName" field-type="string" required="true">
Nachname des Kontakts.
</ResponseField>

<ResponseField name="contacts[].email" field-type="string" required="false">
E-Mail-Adresse des Kontakts, sofern vorhanden.
</ResponseField>

<ResponseField name="contacts[].phone" field-type="string" required="false">
Telefonnummer des Kontakts, sofern vorhanden.
</ResponseField>

<ResponseField name="contacts[].companyId" field-type="string" required="false">
ID des zugeordneten Unternehmens, sofern gesetzt.
</ResponseField>

<ResponseField name="total" field-type="integer" required="true">
Gesamtzahl aller Treffer über alle Seiten hinweg.
</ResponseField>

## Kontakt erstellen

Rufen Sie `POST /api/crm/contacts` auf, um einen neuen Kontakt im CRM anzulegen.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tt_api_example_9xmk7q2r" \
  -d '{
    "companyId": "cmp_42",
    "firstName": "Jane",
    "lastName": "Chen",
    "phone": "+14155550189",
    "email": "jane.chen@northstar.io"
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "contact": {
    "id": "ctc_8f3a21",
    "firstName": "Jane",
    "lastName": "Chen",
    "email": "jane.chen@northstar.io",
    "phone": "+14155550189",
    "companyId": "cmp_42"
  }
}
```
</Response>

## Kontakt aktualisieren

Rufen Sie `PATCH /api/crm/contacts/{id}` auf, um einen bestehenden Kontakt teilweise zu aktualisieren. Sie können nur die Felder senden, die sich ändern sollen.

<Request>
```bash
curl -X PATCH "https://app.talkturo.com/api/crm/contacts/ctc_8f3a21" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tt_api_example_9xmk7q2r" \
  -d '{
    "phone": "+14155550190",
    "companyId": "cmp_84"
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "contact": {
    "id": "ctc_8f3a21",
    "firstName": "Jane",
    "lastName": "Chen",
    "email": "jane.chen@northstar.io",
    "phone": "+14155550190",
    "companyId": "cmp_84"
  }
}
```
</Response>

## Kontakte gesammelt importieren

Rufen Sie `POST /api/crm/contacts/import` auf, um viele Kontakte in einer Anfrage zu importieren. Der Endpunkt akzeptiert einen Body im Format `contacts: [...]` oder einen CSV-basierten Import, abhängig von Ihrem Import-Workflow.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/crm/contacts/import" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tt_api_example_9xmk7q2r" \
  -d '{
    "contacts": [
      {
        "firstName": "Jane",
        "lastName": "Chen",
        "email": "jane.chen@northstar.io",
        "phone": "+14155550189",
        "companyId": "cmp_42"
      },
      {
        "firstName": "Marcus",
        "lastName": "Rivera",
        "email": "marcus.rivera@northstar.io",
        "phone": "+14155550192",
        "companyId": "cmp_42"
      }
    ]
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "imported": 2,
  "failed": 0,
  "errors": []
}
```
</Response>

<Callout kind="info">

Der Import-Endpunkt unterstützt laut Implementierung sowohl strukturierte JSON-Daten als auch CSV-Importe. Die Antwort enthält die Anzahl erfolgreich importierter Kontakte, fehlgeschlagener Einträge und gegebenenfalls eine Fehlerliste.

</Callout>

### Request-Body

<ParamField body="contacts" param-type="array" required="false">
Liste von Kontakten für den JSON-Import.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Kennzeichnet einen erfolgreich verarbeiteten Importaufruf.
</ResponseField>

<ResponseField name="imported" field-type="integer" required="true">
Anzahl der erfolgreich importierten Kontakte.
</ResponseField>

<ResponseField name="failed" field-type="integer" required="true">
Anzahl der Kontakte, die nicht importiert werden konnten.
</ResponseField>

<ResponseField name="errors" field-type="array" required="true">
Liste der Importfehler, sofern einzelne Einträge fehlschlagen.
</ResponseField>
