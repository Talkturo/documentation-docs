## Unternehmen im CRM verwalten

Die Unternehmensendpunkte im Talkturo-CRM sind veraltet. Verwenden Sie bestehende Endpunkte nur noch für kompatible Lese-, Änderungs- und Löschvorgänge und migrieren Sie neue Organisationsstrukturen zu [CRM-Gruppen](/de/api-reference/crm-groups).

Alle Endpunkte in diesem Abschnitt verwenden Session-Authentifizierung. Senden Sie die Anfragen aus einer angemeldeten Anwendungssitzung.

<Callout kind="alert" collapsed="false">

Unternehmen sind deprecated. Das Erstellen neuer Unternehmen mit `POST /api/crm/companies` ist nicht mehr möglich und gibt `410 Gone` zurück. Verwenden Sie CRM-Gruppen als Ersatz für neue Organisationsstrukturen.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/companies` | Unternehmen auflisten |
| `POST` | `/api/crm/companies` | Nicht verfügbar, gibt `410 Gone` zurück |
| `GET` | `/api/crm/companies/{id}` | Einzelnes Unternehmen abrufen |
| `PATCH` | `/api/crm/companies/{id}` | Unternehmen aktualisieren |
| `DELETE` | `/api/crm/companies/{id}` | Unternehmen löschen |
| `GET` | `/api/crm/companies/{id}/contacts` | Kontakte eines Unternehmens auflisten |

## Unternehmen auflisten

Rufen Sie `GET /api/crm/companies` auf, um bestehende Unternehmensdatensätze mit Begrenzung und Offset abzurufen oder nach einem Suchbegriff zu filtern.

<Request show-lines="true">
  ```bash
  curl -X GET "https://api.talkturo.local/api/crm/companies?limit=20&offset=0&search=Acme" \
    -H "Cookie: sb-session=example_session_token"
  ```
</Request>

<Response show-lines="true">

        "industry": "Manufacturing",
        "company_size": "201-500",
        "address_line1": "Industriestraße 18",
        "address_line2": "Building A",
        "city": "Hamburg",
        "state": "Hamburg",
        "postal_code": "20457",
        "country": "Germany",
        "phone": "+49 40 55550123",
        "notes": "Primary manufacturing partner",
        "custom_fields": {
          "account_tier": "enterprise"
        },

        "updated_at": "2024-06-18T14:45:00Z",

## Unternehmen erstellen

`POST /api/crm/companies` ist veraltet und erstellt keine neuen Unternehmensdatensätze mehr. Jede Anfrage an diesen Endpunkt gibt `410 Gone` zurück.

<Request show-lines="true">
  ```bash
  curl -X POST "https://api.talkturo.local/api/crm/companies" \
    -H "Content-Type: application/json" \
    -H "Cookie: sb-session=example_session_token" \
    -d '{
      "name": "Northwind Health Partners",
      "website": "https://northwind-health.com",
      "industry": "Healthcare"
    }'
  ```
</Request>

<Response show-lines="true">
  ```json
  {
    "error": "Companies are gone. Create a group via POST /api/crm/groups instead."
  }
  ```
</Response>

<Callout kind="info" collapsed="false">

Verwenden Sie [CRM-Gruppen](/de/api-reference/crm-groups), wenn Sie neue Organisationsstrukturen anlegen oder Kontakte gruppieren müssen.

</Callout>

## Unternehmen aktualisieren

Senden Sie `PATCH /api/crm/companies/{id}`, um vorhandene Felder eines Unternehmens zu ändern. Der Endpunkt gibt den aktualisierten Datensatz zurück.

<Request show-lines="true">
  ```bash
  curl -X PATCH "https://api.talkturo.local/api/crm/companies/cmp_9f2c7a1d" \
    -H "Content-Type: application/json" \
    -H "Cookie: sb-session=example_session_token" \
    -d '{
      "industry": "Industrial Technology",
      "company_size": "501-1000",
      "notes": "Expanded manufacturing partner"
    }'
  ```
</Request>

<Response show-lines="true">
  ```json
  {
    "success": true,
    "company": {
      "id": "cmp_9f2c7a1d",
      "team_id": "team_7c4e91b2",
      "name": "Acme Industrial Group",
      "industry": "Industrial Technology",
      "company_size": "501-1000",
      "notes": "Expanded manufacturing partner",
      "contact_count": 12,
      "updated_at": "2024-06-19T10:15:00Z",
      "updated_by": "usr_4e8a2c19"
    }
  }
  ```
</Response>

## Unternehmen löschen

Senden Sie `DELETE /api/crm/companies/{id}`, um einen bestehenden Unternehmensdatensatz aus dem CRM zu entfernen.

<Request show-lines="true">
  ```bash
  curl -X DELETE "https://api.talkturo.local/api/crm/companies/cmp_9f2c7a1d" \
    -H "Cookie: sb-session=example_session_token"
  ```
</Request>

<Response show-lines="true">
  ```json
  {
    "success": true
  }
  ```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true" deprecated="false" show-location="true">
  Eindeutige ID des zu löschenden Unternehmens.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true" deprecated="false">
  Gibt an, ob der Datensatz erfolgreich gelöscht wurde.
</ResponseField>

<Callout kind="alert" collapsed="false">

Das Löschen eines Unternehmens ist destruktiv. Prüfen Sie vor dem Entfernen, ob nachgelagerte Prozesse oder verknüpfte Datensätze die Unternehmens-ID noch verwenden.

</Callout>

## Kontakte eines Unternehmens auflisten

Rufen Sie `GET /api/crm/companies/{id}/contacts` auf, um alle Kontakte abzurufen, die einem Unternehmen zugeordnet sind.

<Request show-lines="true">
  ```bash
  curl -X GET "https://api.talkturo.local/api/crm/companies/cmp_9f2c7a1d/contacts" \
    -H "Cookie: sb-session=example_session_token"
  ```
</Request>

<Response show-lines="true">
  ```json
  {
    "success": true,
    "contacts": [
      {
        "id": "cnt_71d4a8c2",
        "first_name": "Maria",
        "last_name": "Schmidt",
        "email": "maria.schmidt@acme-industrial.com",
        "company_id": "cmp_9f2c7a1d"
      }
    ]
  }
  ```
</Response>

</ParamField>
