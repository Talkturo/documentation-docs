## Veraltete Unternehmen im CRM verwalten

Unternehmensendpunkte verwalten Organisationsdatensätze im Talkturo-CRM. Sie können Unternehmen auflisten, neue Datensätze anlegen, einzelne Unternehmen abrufen, bestehende Einträge aktualisieren, löschen und die zugeordneten Kontakte eines Unternehmens abfragen.

Alle Endpunkte in diesem Abschnitt sind veraltet und verwenden Session-Authentifizierung. Senden Sie die Anfragen aus einer angemeldeten Anwendungssitzung.

<Callout kind="info" collapsed="false">
  Die Listenansicht unterstützt Seitennummerierung und Suche. Die Detailendpunkte arbeiten mit der Unternehmens-ID aus dem CRM.
</Callout>

## Endpunktübersicht

| Methode  | Pfad                               | Zweck                                 | Status                         |
| -------- | ---------------------------------- | ------------------------------------- | ------------------------------ |
| `GET`    | `/api/crm/companies`               | Unternehmen auflisten                 | Veraltet                      |
| `POST`   | `/api/crm/companies`               | Unternehmen erstellen                 | Veraltet; gibt 410 Gone zurück |
| `GET`    | `/api/crm/companies/{id}`          | Einzelnes Unternehmen abrufen         | Veraltet                      |
| `PATCH`  | `/api/crm/companies/{id}`          | Unternehmen aktualisieren             | Veraltet                      |
| `DELETE` | `/api/crm/companies/{id}`          | Unternehmen löschen                   | Veraltet                      |
| `GET`    | `/api/crm/companies/{id}/contacts` | Kontakte eines Unternehmens auflisten | Veraltet                      |

## Unternehmen auflisten

Rufen Sie `GET /api/crm/companies` auf, um Unternehmensdatensätze seitenweise abzurufen oder mit einer Suchanfrage zu filtern.

<Callout kind="info" collapsed="false">
  `GET /api/crm/companies` ist veraltet, bleibt aber weiterhin funktionsfähig. Verwenden Sie für neue Integrationen die Gruppenendpunkte.
</Callout>

<Request show-lines="true">
  ```bash
  curl -X GET "https://api.talkturo.local/api/crm/companies?page=1&limit=20&search=Acme" \
    -H "Cookie: sb-session=example_session_token"
  ```
</Request>

<Response show-lines="true">
  ```json
  {
    "success": true,
    "companies": [
      {
        "id": "cmp_9f2c7a1d",
        "name": "Acme Industrial Group",
        "website": "https://acme-industrial.com",
        "industry": "Manufacturing"
      },
      {
        "id": "cmp_2b7d1e4a",
        "name": "Acme Logistics GmbH",
        "website": "https://acme-logistics.de",
        "industry": "Logistics"
      }
    ],
    "total": 42,
    "page": 1
  }
  ```
</Response>

<ParamField query="teamId" param-type="string" required="true" deprecated="false" show-location="true">

</ParamField>

<ParamField query="page" param-type="integer" required="false" deprecated="false" show-location="true">

</ParamField>

<ParamField query="limit" param-type="integer" required="false" deprecated="false" show-location="true">

</ParamField>

<ParamField query="search" param-type="string" required="false" deprecated="false" show-location="true">

</ResponseField>

## Unternehmen erstellen

`POST /api/crm/companies` ist veraltet und gibt HTTP 410 Gone zurück. Der Endpunkt erstellt keine neuen Unternehmensdatensätze mehr.

<Callout kind="alert" collapsed="false">
  Verweisen Sie Clients auf `POST /api/crm/groups`, um neue CRM-Gruppen anzulegen. Verwenden Sie die [CRM-Gruppen-Referenz](/de/api-reference/crm-groups) für Request- und Antwortfelder.
</Callout>

## Unternehmen löschen

Senden Sie `DELETE /api/crm/companies/{id}`, um einen Unternehmensdatensatz aus dem CRM zu entfernen.

### Pfadparameter

<ParamField path="id" param-type="string" required="true" deprecated="false" show-location="true">
  Eindeutige ID des zu löschenden Unternehmens.
</ParamField>

### Antwortstruktur

<ResponseField name="success" field-type="boolean" required="true" deprecated="false">
  Gibt an, ob der Datensatz erfolgreich gelöscht wurde.
</ResponseField>

<Callout kind="alert" collapsed="false">
  Das Löschen eines Unternehmens ist als Operation destruktiv. Prüfen Sie vor dem Entfernen, ob nachgelagerte Prozesse oder verknüpfte Datensätze die Unternehmens-ID noch verwenden.
</Callout>
