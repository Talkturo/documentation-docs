## Unternehmen im CRM verwalten

Unternehmensendpunkte verwalten Organisationsdatensätze im Talkturo-CRM. Sie können Unternehmen auflisten, neue Datensätze anlegen, einzelne Unternehmen abrufen, bestehende Einträge aktualisieren, löschen und die zugeordneten Kontakte eines Unternehmens abfragen.

Alle Endpunkte in diesem Abschnitt akzeptieren entweder Session-Cookie-Authentifizierung oder API-Key-Bearer-Token-Authentifizierung. Senden Sie die Anfragen aus einer angemeldeten Anwendungssitzung oder mit einem gültigen API-Schlüssel.

<Callout kind="info" collapsed="false">
  Die Listenansicht unterstützt Filterung über `limit` und `offset` sowie Suche. Die Detailendpunkte arbeiten mit der Unternehmens-ID aus dem CRM.
</Callout>

## Endpunktübersicht

| Methode  | Pfad                               | Zweck                                 |
| -------- | ---------------------------------- | ------------------------------------- |
| `GET`    | `/api/crm/companies`               | Unternehmen auflisten                 |
| `POST`   | `/api/crm/companies`               | Unternehmen erstellen                 |
| `GET`    | `/api/crm/companies/{id}`          | Einzelnes Unternehmen abrufen         |
| `PATCH`  | `/api/crm/companies/{id}`          | Unternehmen aktualisieren             |
| `DELETE` | `/api/crm/companies/{id}`          | Unternehmen löschen                   |
| `GET`    | `/api/crm/companies/{id}/contacts` | Kontakte eines Unternehmens auflisten |

## Unternehmen auflisten

Rufen Sie `GET /api/crm/companies` auf, um Unternehmensdatensätze seitenweise abzurufen oder mit einer Suchanfrage zu filtern.

<Request show-lines="true">
  ```bash
  curl -X GET "https://api.talkturo.local/api/crm/companies?teamId=3f6a2d91-5c4b-4a7f-9c11-2d8e4b7a6f20&search=Acme&industry=Manufacturing&limit=20&offset=0" \
    -H "Authorization: Bearer ttrk_example_9xmk7q2r"
  ```
</Request>

### Query-Parameter

<ParamField query="teamId" param-type="string" required="false" deprecated="false" show-location="true">
  Workspace-UUID. Standardmäßig wird `auth.accountId` verwendet.
</ParamField>

<ParamField query="search" param-type="string" required="false" deprecated="false" show-location="true">
  Filtert mit einer `ilike`-Suche auf `name` und `website`.
</ParamField>

<ParamField query="industry" param-type="string" required="false" deprecated="false" show-location="true">
  Filtert die Liste nach Branche.
</ParamField>

<ParamField query="limit" param-type="integer" required="false" deprecated="false" show-location="true">
  Die maximale Anzahl der zurückgegebenen Unternehmen. Standardwert ist `50`.
</ParamField>

<ParamField query="offset" param-type="integer" required="false" deprecated="false" show-location="true">
  Der Versatz für die Paginierung. Standardwert ist `0`.
</ParamField>

## Unternehmen erstellen

Senden Sie `POST /api/crm/companies`, um einen neuen Unternehmensdatensatz im CRM anzulegen.

<Request show-lines="true">
  ```bash
  curl -X POST "https://api.talkturo.local/api/crm/companies" \
    -H "Authorization: Bearer ttrk_example_9xmk7q2r" \
    -H "Content-Type: application/json" \
    -d '{
      "teamId": "3f6a2d91-5c4b-4a7f-9c11-2d8e4b7a6f20",
      "name": "Northwind Health Partners",
      "website": "https://northwind-health.com",
      "industry": "Healthcare",
      "companySize": "51-200",
      "addressLine1": "Friedrichstraße 120",
      "addressLine2": "5. Etage",
      "city": "Berlin",
      "state": "BE",
      "postalCode": "10117",
      "country": "DE",
      "phone": "+49 30 55550123",
      "notes": "Bestandskunde mit Fokus auf Partnervertrieb",
      "customFields": {
        "crmTier": "gold",
        "renewalMonth": "September"
      }
    }'
  ```
</Request>

<Response show-lines="true">
  ```json
  {
    "success": true,
    "company": {
  ```

## Unternehmen löschen

Senden Sie `DELETE /api/crm/companies/{id}`, um einen Unternehmensdatensatz aus dem CRM zu entfernen.

### Pfadparameter

<ParamField path="id" param-type="string" required="true" deprecated="false" show-location="true">
  Eindeutige ID des zu löschenden Unternehmens.
</ParamField>

### Antwortstruktur

<ResponseField name="success" field-type="boolean" required="true" deprecated="false">
  Gibt an, ob der Datensatz erfolgreich gelöscht wurde.
</ResponseField>

<Callout kind="alert" collapsed="false">
  Das Löschen eines Unternehmens ist als Operation destruktiv. Prüfen Sie vor dem Entfernen, ob nachgelagerte Prozesse oder verknüpfte Datensätze die Unternehmens-ID noch verwenden.
</Callout>
