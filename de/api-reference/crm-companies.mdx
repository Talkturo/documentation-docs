## Unternehmen im CRM verwalten

Unternehmensendpunkte verwalten Organisationsdatensätze im Talkturo-CRM. Sie können Unternehmen auflisten, neue Datensätze anlegen, einzelne Unternehmen abrufen, bestehende Einträge aktualisieren, löschen und Kontakte direkt einem Unternehmen zuordnen.

<Callout kind="info" collapsed="false">

`GET /api/crm/companies` und `POST /api/crm/companies` akzeptieren API-Keys oder Session-Cookies. `GET /api/crm/companies/{id}`, `PUT /api/crm/companies/{id}` und `DELETE /api/crm/companies/{id}` funktionieren nur mit einem Session-Cookie aus einer angemeldeten Anwendungssitzung.

</Callout>

## Endpunktübersicht

| Methode | Pfad                               | Zweck                                      |
| ------- | ---------------------------------- | ------------------------------------------ |
| `GET`   | `/api/crm/companies`               | Unternehmen auflisten                      |
| `POST`  | `/api/crm/companies`               | Unternehmen erstellen                      |
| `GET`   | `/api/crm/companies/{id}`          | Einzelnes Unternehmen abrufen              |
| `PUT`   | `/api/crm/companies/{id}`          | Unternehmen aktualisieren                  |
| `DELETE`| `/api/crm/companies/{id}`          | Unternehmen löschen                        |
| `GET`   | `/api/crm/companies/{id}/contacts` | Kontakte eines Unternehmens auflisten      |
| `POST`  | `/api/crm/companies/{id}/contacts` | Kontakt direkt für ein Unternehmen anlegen |

## Unternehmen auflisten


```bash
curl -X PUT "https://api.talkturo.local/api/crm/companies/cmp_c4a91e7b" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-session=example_session_token" \
```

## Unternehmen löschen

Senden Sie `DELETE /api/crm/companies/{id}`, um einen Unternehmensdatensatz aus dem CRM zu entfernen. Der Endpunkt akzeptiert nur Session-Cookies.

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
  Eindeutige ID des zu löschenden Unternehmens.
</ParamField>

### Antwortstruktur

<ResponseField name="success" field-type="boolean" required="true">
  Gibt an, ob der Datensatz erfolgreich gelöscht wurde.
</ResponseField>

<Callout kind="alert" collapsed="false">

Wenn dem Unternehmen noch Kontakte zugeordnet sind, gibt der Endpunkt `400` zurück und löscht den Datensatz nicht. Entfernen oder verschieben Sie die verknüpften Kontakte zuerst.

</Callout>

## Kontakt direkt für ein Unternehmen anlegen

Senden Sie `POST /api/crm/companies/{id}/contacts`, um einen neuen Kontakt direkt mit einem Unternehmen zu verknüpfen. Die Unternehmens-ID stammt aus dem Pfad, nicht aus dem Request-Body.

<Request show-lines="true">
```bash
curl -X POST "https://api.talkturo.local/api/crm/companies/cmp_c4a91e7b/contacts" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-session=example_session_token" \
  -d '{
    "firstName": "Mara",
    "lastName": "Klein",
    "phone": "+493055550124",
    "email": "mara.klein@northwind-health.com",
    "jobTitle": "Head of Operations",
    "leadStatus": "qualified",
    "notes": "Operative Ansprechpartnerin für den Berlin-Rollout."
  }'
```
</Request>
