## Unternehmen im CRM verwalten

Unternehmensendpunkte verwalten Organisationsdatensätze im Talkturo-CRM. Sie können Unternehmen auflisten, neue Datensätze anlegen, einzelne Unternehmen abrufen, bestehende Einträge aktualisieren, löschen und die zugeordneten Kontakte eines Unternehmens abfragen.

Alle Endpunkte in diesem Abschnitt verwenden Session-Authentifizierung. Senden Sie die Anfragen aus einer angemeldeten Anwendungssitzung.

<Callout kind="info">

Die Listenansicht unterstützt Seitennummerierung und Suche. Die Detailendpunkte arbeiten mit der Unternehmens-ID aus dem CRM.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/companies` | Unternehmen auflisten |
| `POST` | `/api/crm/companies` | Unternehmen erstellen |
| `GET` | `/api/crm/companies/{id}` | Einzelnes Unternehmen abrufen |
| `PATCH` | `/api/crm/companies/{id}` | Unternehmen aktualisieren |
| `DELETE` | `/api/crm/companies/{id}` | Unternehmen löschen |
| `GET` | `/api/crm/companies/{id}/contacts` | Kontakte eines Unternehmens auflisten |

## Unternehmen auflisten

Rufen Sie `GET /api/crm/companies` auf, um Unternehmensdatensätze seitenweise abzurufen oder mit einer Suchanfrage zu filtern.

<Request>
```bash
curl -X GET "https://api.talkturo.local/api/crm/companies?page=1&limit=20&search=Acme" \
  -H "Cookie: sb-session=example_session_token"
```
</Request>

<Response>
```json
{
  "success": true,
  "companies": [
    {
      "id": "cmp_9f2c7a1d",
      "name": "Acme Industrial Group",
      "website": "https://acme-industrial.com",
      "industry": "Manufacturing"
    },
    {
      "id": "cmp_2b7d1e4a",
      "name": "Acme Logistics GmbH",
      "website": "https://acme-logistics.de",
      "industry": "Logistics"
    }
  ],
  "total": 42,
  "page": 1
}
```
</Response>

### Query-Parameter

<ParamField query="page" param-type="integer" required="false">
Die Seitennummer der Ergebnisliste.
</ParamField>

<ParamField query="limit" param-type="integer" required="false">
Die maximale Anzahl der zurückgegebenen Unternehmen pro Seite.
</ParamField>

<ParamField query="search" param-type="string" required="false">
Filtert die Liste nach einem Suchbegriff.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob die Anfrage erfolgreich war.
</ResponseField>

<ResponseField name="companies" field-type="array" required="true">
Liste der gefundenen Unternehmensdatensätze.
</ResponseField>

<ResponseField name="companies[].id" field-type="string" required="true">
Eindeutige ID des Unternehmens.
</ResponseField>

<ResponseField name="companies[].name" field-type="string" required="true">
Name des Unternehmens.
</ResponseField>

<ResponseField name="companies[].website" field-type="string" required="false">
Webadresse des Unternehmens, falls hinterlegt.
</ResponseField>

<ResponseField name="companies[].industry" field-type="string" required="false">
Branche des Unternehmens, falls hinterlegt.
</ResponseField>

<ResponseField name="total" field-type="integer" required="true">
Gesamtzahl der Treffer über alle Seiten hinweg.
</ResponseField>

<ResponseField name="page" field-type="integer" required="true">
Die aktuelle Ergebnisseite.
</ResponseField>

## Unternehmen erstellen

Senden Sie `POST /api/crm/companies`, um einen neuen Unternehmensdatensatz im CRM anzulegen.

<Request>
```bash
curl -X POST "https://api.talkturo.local/api/crm/companies" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-session=example_session_token" \
  -d '{
    "name": "Northwind Health Partners",
    "website": "https://northwind-health.com",
    "industry": "Healthcare",
    "phone": "+49 30 55550123",
    "address": "Friedrichstraße 120, 10117 Berlin"
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "company": {
    "id": "cmp_c4a91e7b",
    "name": "Northwind Health Partners",
    "website": "https://northwind-health.com",
    "industry": "Healthcare",
    "phone": "+49 30 55550123",
    "address": "Friedrichstraße 120, 10117 Berlin"
  }
}
```
</Response>

### Request-Body

<ParamField body="name" param-type="string" required="true">
Name des Unternehmens.
</ParamField>

<ParamField body="website" param-type="string" required="false">
Webadresse des Unternehmens.
</ParamField>

<ParamField body="industry" param-type="string" required="false">
Branche oder Marktsegment des Unternehmens.
</ParamField>

<ParamField body="phone" param-type="string" required="false">
Telefonnummer des Unternehmens.
</ParamField>

<ParamField body="address" param-type="string" required="false">
Postanschrift oder Geschäftsadresse des Unternehmens.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob das Unternehmen erfolgreich erstellt wurde.
</ResponseField>

<ResponseField name="company" field-type="object" required="true">
Der neu angelegte Unternehmensdatensatz.
</ResponseField>

<ResponseField name="company.id" field-type="string" required="true">
Eindeutige ID des neuen Unternehmens.
</ResponseField>

<Callout kind="tip">

Wenn Sie Unternehmensdatensätze später mit Kontakten oder Opportunities verknüpfen möchten, speichern Sie die zurückgegebene `company.id` direkt nach dem Erstellen.

</Callout>

## Unternehmen löschen

Senden Sie `DELETE /api/crm/companies/{id}`, um einen Unternehmensdatensatz aus dem CRM zu entfernen.

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige ID des zu löschenden Unternehmens.
</ParamField>

### Antwortstruktur

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob der Datensatz erfolgreich gelöscht wurde.
</ResponseField>

<Callout kind="alert">

Das Löschen eines Unternehmens ist als Operation destruktiv. Prüfen Sie vor dem Entfernen, ob nachgelagerte Prozesse oder verknüpfte Datensätze die Unternehmens-ID noch verwenden.

</Callout>
