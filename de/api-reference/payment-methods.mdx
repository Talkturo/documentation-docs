## Endpunkte für Zahlungsmethoden verwenden

Verwalten Sie Stripe-Zahlungsmethoden für ein Talkturo-Abrechnungskonto, indem Sie vorhandene Methoden auflisten, neue hinzufügen, eine Standardmethode festlegen oder eine Methode entfernen.

<Callout kind="info">

Alle Endpunkte unter `/api/payment-methods` akzeptieren Authentifizierung per API-Schlüssel, Bearer-Sitzungstoken oder Cookie-basierter Sitzung. Wenn der Account nicht aus dem Auth-Kontext abgeleitet werden kann, übergeben Sie `accountId` explizit.

</Callout>

## Endpunkte auf einen Blick

| Methode | Endpunkt | Zweck |
| --- | --- | --- |
| `GET` | `/api/payment-methods` | Zahlungsmethoden auflisten |
| `POST` | `/api/payment-methods` | Zahlungsmethode hinzufügen |
| `PATCH` | `/api/payment-methods/{id}` | Zahlungsmethode aktualisieren |
| `DELETE` | `/api/payment-methods/{id}` | Zahlungsmethode entfernen |

## GET /api/payment-methods

Rufen Sie alle aktiven Zahlungsmethoden für ein Abrechnungskonto ab.

<Request tabs="cURL,JavaScript,Python" default-tab="1">
```bash
curl -X GET "https://api.talkturo.com/api/payment-methods?accountId=acc_9f3b2e11" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r"
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/payment-methods?accountId=acc_9f3b2e11",
  {
    headers: {
      Authorization: "Bearer tk_live_example_9xmk7q2r",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python
import requests

response = requests.get(

    headers={"Authorization": "Bearer tk_live_example_9xmk7q2r"},
```

## POST /api/payment-methods

Fügen Sie einem Konto eine neue Stripe-Zahlungsmethode hinzu.

<Request tabs="cURL,JavaScript,Python" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/payment-methods" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "accountId": "acc_9f3b2e11",
    "paymentMethodId": "pm_1Qz7KfExample8w2L",
    "setAsDefault": true
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/payment-methods", {
  method: "POST",
  headers: {
    Authorization: "Bearer tk_live_example_9xmk7q2r",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    accountId: "acc_9f3b2e11",
    paymentMethodId: "pm_1Qz7KfExample8w2L",
    setAsDefault: true,
  }),
});

const data = await response.json();
console.log(data);
```

```python
import requests

response = requests.post(
    "https://api.talkturo.com/api/payment-methods",
    headers={
        "Authorization": "Bearer tk_live_example_9xmk7q2r",
        "Content-Type": "application/json",
    },
    json={
        "accountId": "acc_9f3b2e11",
        "paymentMethodId": "pm_1Qz7KfExample8w2L",
        "setAsDefault": True,
    },
)

print(response.json())
```
</Request>

### Request-Body

<ParamField body="accountId" param-type="string" required="true">

Konto, mit dem die Zahlungsmethode verknüpft werden soll.

</ParamField>

<ParamField body="paymentMethodId" param-type="string" required="true">

Stripe PaymentMethod-ID, die zuvor mit Stripe.js oder Stripe Elements erstellt wurde.

</ParamField>

<ParamField body="setAsDefault" param-type="boolean" required="false">

Setzt die neue Zahlungsmethode als Standardmethode, wenn der Wert `true` ist.

</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">

`true`, wenn die Zahlungsmethode erfolgreich gespeichert wurde.

</ResponseField>

<ResponseField name="paymentMethod" field-type="object" required="true">

Zusammenfassung der neu gespeicherten Zahlungsmethode.

</ResponseField>

<ResponseField name="paymentMethod.id" field-type="string" required="true">

Interne ID des Datensatzes der Zahlungsmethode in Talkturo.

</ResponseField>

<ResponseField name="paymentMethod.stripe_payment_method_id" field-type="string" required="true">

Stripe PaymentMethod-ID der gespeicherten Zahlungsmethode.

</ResponseField>

<ResponseField name="paymentMethod.card_brand" field-type="string" required="false">

Kartenmarke der gespeicherten Karte.

</ResponseField>

<ResponseField name="paymentMethod.card_last4" field-type="string" required="false">

Die letzten vier Ziffern der gespeicherten Karte.

</ResponseField>

<ResponseField name="paymentMethod.card_exp_month" field-type="integer" required="false">

Ablaufmonat der gespeicherten Karte.

</ResponseField>

<ResponseField name="paymentMethod.card_exp_year" field-type="integer" required="false">

Ablaufjahr der gespeicherten Karte.

</ResponseField>

<ResponseField name="paymentMethod.is_default" field-type="boolean" required="true">

Gibt an, ob die Zahlungsmethode nach dem Anlegen als Standardmethode gesetzt wurde.

</ResponseField>

### Verhalten

- Talkturo verknüpft die Stripe-Zahlungsmethode zuerst mit dem Stripe-Kunden des Kontos.
- Wenn das Speichern in der Datenbank nach dem Stripe-Attach fehlschlägt, wird die Zahlungsmethode in Stripe wieder entfernt, damit kein verwaister Eintrag zurückbleibt.
- Wenn `setAsDefault` auf `true` gesetzt ist, wird die Standardmethode atomar aktualisiert, sodass andere Methoden nicht mehr als Standard markiert sind.

### Fehler

| Status | Bedeutung |
| --- | --- |
| `400` | `accountId` oder `paymentMethodId` fehlt im Request-Body. |
| `401` | Authentifizierung fehlgeschlagen. |
| `404` | Für das Konto wurde kein Stripe-Abrechnungskunde gefunden. |
| `409` | Die Stripe PaymentMethod-ID ist bereits für dieses Konto gespeichert. |
| `500` | Beim Anhängen an Stripe oder beim Speichern in der Datenbank ist ein Fehler aufgetreten. |

## PATCH /api/payment-methods/{id}

Aktualisieren Sie eine vorhandene Zahlungsmethode. Dieser Endpunkt wird verwendet, um eine Methode als Standard festzulegen.

<Request tabs="cURL,JavaScript,Python" default-tab="1">
```bash
curl -X PATCH "https://api.talkturo.com/api/payment-methods/pmdb_2d84f6c0-7f5c-4e0d-8b35-9c7db4af52f1" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "accountId": "acc_9f3b2e11",
    "setAsDefault": true
  }'
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/payment-methods/pmdb_2d84f6c0-7f5c-4e0d-8b35-9c7db4af52f1",
  {
    method: "PATCH",
    headers: {
      Authorization: "Bearer tk_live_example_9xmk7q2r",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      accountId: "acc_9f3b2e11",
      setAsDefault: true,
    }),
  }
);

const data = await response.json();
console.log(data);
```

```python

        "Content-Type": "application/json",
    },
    json={

        "setAsDefault": True,

print(response.json())
```

## DELETE /api/payment-methods/{id}

Entfernen Sie eine Zahlungsmethode aus einem Konto. Der Datensatz wird soft-gelöscht, indem `deleted_at` gesetzt wird.

<Request tabs="cURL,JavaScript,Python" default-tab="1">
```bash
curl -X DELETE "https://api.talkturo.com/api/payment-methods/pmdb_2d84f6c0-7f5c-4e0d-8b35-9c7db4af52f1?accountId=acc_9f3b2e11" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r"
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/payment-methods/pmdb_2d84f6c0-7f5c-4e0d-8b35-9c7db4af52f1?accountId=acc_9f3b2e11",
  {
    method: "DELETE",
    headers: {
      Authorization: "Bearer tk_live_example_9xmk7q2r",
    },
  }
);

const data = await response.json();
console.log(data);
```

```python
import requests

response = requests.delete(
    "https://api.talkturo.com/api/payment-methods/pmdb_2d84f6c0-7f5c-4e0d-8b35-9c7db4af52f1",
    params={"accountId": "acc_9f3b2e11"},
    headers={"Authorization": "Bearer tk_live_example_9xmk7q2r"},
)

print(response.json())
```
</Request>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">

Interne ID der zu entfernenden Zahlungsmethode.

</ParamField>

### Query-Parameter

<ParamField query="accountId" param-type="string" required="true">

Konto, zu dem die Zahlungsmethode gehört.

</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">

`true`, wenn die Zahlungsmethode erfolgreich entfernt wurde.

</ResponseField>

### Verhalten

- Der Endpunkt entfernt den Datensatz per Soft-Delete. Statt den Datensatz dauerhaft zu löschen, wird `deleted_at` gesetzt.
- Gelöschte Zahlungsmethoden erscheinen nicht mehr in der Antwort von `GET /api/payment-methods`.
- Der Eintrag bleibt für Abrechnungs- und Prüfzwecke in der Datenbank erhalten.

### Fehler

| Status | Bedeutung |
| --- | --- |
| `400` | `accountId` fehlt in der Query. |
| `401` | Authentifizierung fehlgeschlagen. |
| `404` | Die Zahlungsmethode wurde für das angegebene Konto nicht gefunden. |
| `500` | Beim Entfernen der Zahlungsmethode ist ein Server- oder Datenbankfehler aufgetreten. |

## Hinweise zur Integration

Diese Endpunkte erwarten, dass das Konto bereits mit einem Stripe-Kunden verknüpft ist. Wenn `404` mit einer Meldung zum fehlenden Billing Customer zurückgegeben wird, erstellen oder synchronisieren Sie zuerst den Abrechnungskunden für das Konto.

<Callout kind="tip">

Rufen Sie nach `POST`, `PATCH` oder `DELETE` erneut `GET /api/payment-methods` auf, wenn Ihre Integration den aktuellen Zustand der Standardmethode oder die vollständige Liste rendern muss.

</Callout>
