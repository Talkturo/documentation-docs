## Zahlungsmethoden-Endpunkte

Verwalten Sie gespeicherte Stripe-Zahlungsmethoden für einen Talkturo-Account über die Endpunkte unter ` /api/payment-methods ` und ` /api/payment-methods/[id] `. Die API unterstützt das Auflisten, Hinzufügen, Abrufen, Entfernen und Setzen der Standard-Zahlungsmethode.

<Callout kind="info">

**Authentifizierung**

Alle Zahlungsmethoden-Endpunkte verwenden `withApiAuth` und akzeptieren entweder einen API-Schlüssel im `Authorization`-Header oder einen gültigen Session-Cookie.

</Callout>

<Callout kind="alert">

**Stripe Elements erforderlich**

Für `POST /api/payment-methods` müssen Sie zuerst clientseitig mit Stripe Elements eine gültige `pm_`-ID erzeugen. Der Endpunkt erstellt keine neue Karteingabe selbst, sondern speichert eine bereits bei Stripe angelegte Zahlungsmethode im Talkturo-Account.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | ` /api/payment-methods ` | Gespeicherte Zahlungsmethoden eines Accounts auflisten |
| `POST` | ` /api/payment-methods ` | Eine neue Zahlungsmethode hinzufügen |
| `GET` | ` /api/payment-methods/[id] ` | Eine einzelne Zahlungsmethode abrufen |
| `PATCH` | ` /api/payment-methods/[id] ` | Eine Zahlungsmethode als Standard setzen |
| `DELETE` | ` /api/payment-methods/[id] ` | Eine Zahlungsmethode per Soft-Delete entfernen |

## GET /api/payment-methods

Rufen Sie alle aktiven gespeicherten Zahlungsmethoden für einen Account ab. Wenn Sie `accountId` nicht senden, versucht der Endpunkt `auth.accountId` aus dem Auth-Kontext zu verwenden.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X GET "https://api.talkturo.com/api/payment-methods?accountId=acc_9f2k3m8q1" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -H "Accept: application/json"
```

```javascript
const response = await fetch(
```

## POST /api/payment-methods

Fügen Sie eine neue Stripe-Zahlungsmethode zu einem Talkturo-Account hinzu. Optional können Sie die neue Methode direkt als Standard markieren.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/payment-methods" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -d '{
    "accountId": "acc_9f2k3m8q1",
    "paymentMethodId": "pm_1QxR7L2eZvKYlo2C7fA9mP4d",
    "setAsDefault": true
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/payment-methods", {
  method: "POST",
  headers: {
    Authorization: "Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z",
    "Content-Type": "application/json",
    Accept: "application/json"
  },
  body: JSON.stringify({
    accountId: "acc_9f2k3m8q1",
    paymentMethodId: "pm_1QxR7L2eZvKYlo2C7fA9mP4d",
    setAsDefault: true
```

### Fehlerfälle

| Status | Ursache |
| --- | --- |
| `400` | Pflichtfelder fehlen oder sind ungültig |
| `404` | Für den Account existiert kein Billing-Customer |
| `409` | Die Stripe-Zahlungsmethode ist bereits im Account gespeichert |

## DELETE /api/payment-methods/[id]

Entfernen Sie eine gespeicherte Zahlungsmethode aus dem Account. Der Endpunkt trennt die Zahlungsmethode bei Stripe, markiert den Datensatz intern als gelöscht und setzt bei Bedarf automatisch eine andere aktive Methode als neuen Standard.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X DELETE "https://api.talkturo.com/api/payment-methods/d1a2b3c4-8a72-4f6b-9f2d-7a1c5e3b9d10?accountId=acc_9f2k3m8q1" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -H "Accept: application/json"
```

```javascript
const response = await fetch(
  "https://api.talkturo.com/api/payment-methods/d1a2b3c4-8a72-4f6b-9f2d-7a1c5e3b9d10?accountId=acc_9f2k3m8q1",
  {
    method: "DELETE",
    headers: {
      Authorization: "Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z",

    }
  }

const data = await response.json();
```

## Verhalten beim Entfernen und Setzen des Standards

Die `DELETE`-Route führt keinen Hard-Delete aus. Stattdessen wird die Zahlungsmethode bei Stripe getrennt und in Talkturo intern als gelöscht oder inaktiv markiert.

Wenn Sie die aktuelle Standard-Zahlungsmethode entfernen, fördert Talkturo automatisch eine andere aktive Zahlungsmethode zum neuen Standard, sofern eine weitere Methode verfügbar ist. Die `PATCH`-Route setzt die Standardmarkierung gezielt für eine vorhandene Methode.
