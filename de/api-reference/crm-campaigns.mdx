## CRM-Kampagnen für ausgehende Anrufe verwalten

Mit den CRM-Kampagnen-Endpunkten erstellen, konfigurieren und steuern Sie ausgehende Anrufkampagnen in Talkturo. Sie können Kampagnen auflisten, anlegen, aktualisieren, Kontakte hinzufügen, eine Kampagne starten und den Fortschritt im Dashboard überwachen.

Die Authentifizierung hängt vom Endpunkt ab. Listen-, Start- und Kontakt-Endpunkte akzeptieren entweder einen Session-Cookie oder einen API-Key. Einzelabruf, Aktualisierung, Löschung und Dashboard erfordern eine angemeldete Session.

<Callout kind="info">

Gültige Kampagnen-Status sind `draft`, `scheduled`, `running`, `paused`, `completed` und `cancelled`.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Authentifizierung | Zweck |
| --- | --- | --- | --- |
| `GET` | `/api/crm/campaigns` | Session oder API-Key | Kampagnen auflisten |
| `POST` | `/api/crm/campaigns` | Session oder API-Key | Kampagne erstellen |
| `GET` | `/api/crm/campaigns/[id]` | Nur Session | Kampagne abrufen |
| `PUT` | `/api/crm/campaigns/[id]` | Nur Session | Kampagne aktualisieren |
| `DELETE` | `/api/crm/campaigns/[id]` | Nur Session | Kampagne weich löschen |
| `GET` | `/api/crm/campaigns/[id]/contacts` | Session oder API-Key | Kontakte einer Kampagne auflisten |
| `POST` | `/api/crm/campaigns/[id]/contacts` | Session oder API-Key | Kontakte zu einer Kampagne hinzufügen |
| `GET` | `/api/crm/campaigns/[id]/dashboard` | Nur Session | Echtzeit-Dashboard einer Kampagne abrufen |
| `POST` | `/api/crm/campaigns/[id]/run` | Session oder API-Key | Kampagne starten oder fortsetzen |

## Kampagnen auflisten

Rufen Sie Kampagnen gefiltert nach Team, Status, Assistent oder Kontaktstatus ab. Standardmäßig blendet der Endpunkt weich gelöschte Kampagnen aus.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl "https://app.talkturo.com/api/crm/campaigns?teamId=9c8e7b36-1e91-4d95-9a1f-9baf7d3f4c20&status=running&includeContactStats=true&limit=25&offset=0" \
  -H "x-api-key: talkturo_example_9xmk7q2r"
```

```javascript
const params = new URLSearchParams({
  teamId: "9c8e7b36-1e91-4d95-9a1f-9baf7d3f4c20",
  status: "running",
  includeContactStats: "true",
  limit: "25",
  offset: "0"
});

const response = await fetch(`https://app.talkturo.com/api/crm/campaigns?${params}`, {
  headers: {
    "x-api-key": "talkturo_example_9xmk7q2r"
  }
});

const campaigns = await response.json();
console.log(campaigns);
```
</Request>

### Query-Parameter

<ParamField query="teamId" param-type="string" required="false">
UUID des Teams. Wenn Sie keinen Wert übergeben, verwendet der Endpunkt `auth.accountId` als Fallback.

</ParamField>

## Kampagne aktualisieren

Aktualisieren Sie vorhandene Kampagnen mit `PUT`. Während eine Kampagne den Status `running` hat, sind Konfigurationsänderungen gesperrt. In diesem Zustand können Sie nur den Status ändern.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X PUT "https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-session=example_session_token" \
  -d '{
    "name": "Q3 Renewal Outreach - DACH",
    "maxConcurrentCalls": 8,
    "status": "paused",
    "noAutoComplete": true
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71", {
  method: "PUT",
  headers: {
    "Content-Type": "application/json"
  },
  credentials: "include",
  body: JSON.stringify({
    name: "Q3 Renewal Outreach - DACH",
    maxConcurrentCalls: 8,
    status: "paused",
    noAutoComplete: true
  })
});

const campaign = await response.json();
console.log(campaign);
```
</Request>

<Response tabs="200,400">

## Kampagne löschen

Löschen Sie Kampagnen per Soft-Delete. Die API erlaubt das nur für Kampagnen mit dem Status `draft` oder `cancelled`.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X DELETE "https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71" \
  -H "Cookie: sb-session=example_session_token"
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71", {
  method: "DELETE",
  credentials: "include"
});

const result = await response.json();
console.log(result);
```
</Request>

<Response tabs="200,400">
```json
{
  "success": true,
  "deleted": true
}
```

```json

  "error": "Only campaigns with status draft or cancelled can be deleted"

```

## Kampagne starten oder fortsetzen

Der Run-Endpunkt startet eine Kampagne sofort oder setzt eine pausierte Kampagne fort. Der Request verwendet kein `action`-Feld. Sobald der Endpunkt erfolgreich ausgeführt wird, versucht Talkturo die Kampagne direkt in den Status `running` zu überführen.

Zum Start einer Kampagne muss mindestens ein Credit verfügbar sein. Für API-Keys ist zusätzlich der Scope `campaigns:run` erforderlich.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/run" \
  -H "Content-Type: application/json" \
  -H "x-api-key: talkturo_example_9xmk7q2r" \
  -d '{
    "accountSlug": "northstar-industries",
    "maxCalls": 25,
    "dryRun": false,
    "noAutoComplete": false
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/run", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "x-api-key": "talkturo_example_9xmk7q2r"
  },
  body: JSON.stringify({
    accountSlug: "northstar-industries",
    maxCalls: 25,
    dryRun: false,
    noAutoComplete: false
  })
});

const result = await response.json();
console.log(result);
```
</Request>

## Kampagnenkontakte hinzufügen

Fügen Sie Kontakte in einer von drei gegenseitig ausschließenden Varianten hinzu: per Kontakt-ID, per Inline-Erstellung oder per Audience-Einschreibung. Kontakte lassen sich nur zu Kampagnen mit `draft`, `scheduled` oder `paused` hinzufügen.

Für laufende Kampagnen ist das Hinzufügen nur im Evergreen-Modus erlaubt, also wenn `settings.no_auto_complete = true` aktiv ist. Für API-Keys ist der Scope `campaigns:write` erforderlich.
