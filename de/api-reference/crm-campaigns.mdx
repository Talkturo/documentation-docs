## CRM-Kampagnen für ausgehende Anrufe verwalten

Mit den CRM-Kampagnen-Endpunkten erstellen und steuern Sie ausgehende Anrufkampagnen in Talkturo. Sie können Kampagnen anlegen, Kontakte zuordnen, eine Kampagne starten oder stoppen und den aktuellen Fortschritt über Dashboard-Statistiken verfolgen.

Alle CRM-Kampagnen-Endpunkte unterstützen duale Authentifizierung — verwenden Sie entweder einen API-Schlüssel oder ein authentifiziertes Session-Cookie.

<Callout kind="info">

Authentifizieren Sie diese Endpunkte entweder mit einem API-Schlüssel (`Authorization: Bearer tk_live_...`) oder einem gültigen Talkturo-Session-Cookie.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck |
| --- | --- | --- |
| `GET` | `/api/crm/campaigns` | Kampagnen auflisten |
| `POST` | `/api/crm/campaigns` | Kampagne erstellen |
| `GET` | `/api/crm/campaigns/[id]` | Kampagne abrufen |
| `PATCH` | `/api/crm/campaigns/[id]` | Kampagne aktualisieren |
| `DELETE` | `/api/crm/campaigns/[id]` | Kampagne löschen |
| `GET` | `/api/crm/campaigns/[id]/contacts` | Kontakte einer Kampagne auflisten |
| `POST` | `/api/crm/campaigns/[id]/contacts` | Kontakte zu einer Kampagne hinzufügen |
| `GET` | `/api/crm/campaigns/[id]/dashboard` | Echtzeit-Statistiken einer Kampagne abrufen |
| `POST` | `/api/crm/campaigns/[id]/run` | Kampagne starten oder stoppen |
| `GET` | `/api/crm/outbound-assistants` | Für Outbound verfügbare Assistenten auflisten |
| `GET` | `/api/crm/calls` | Anrufprotokolle auflisten |
| `GET` | `/api/crm/intelligence` | KI-Einblicke abrufen |

## Kampagnen auflisten

Rufen Sie Kampagnen gefiltert nach Status, Assistent oder Kontaktstatus ab und steuern Sie die Seitengröße über `limit` und `offset`.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl "https://app.talkturo.com/api/crm/campaigns?status=running&includeContactStats=true&limit=25&offset=0" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z"
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/crm/campaigns?status=running&includeContactStats=true&limit=25&offset=0",
  {
    headers: {
      Authorization: "Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z"
    }
  }
);

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "campaigns": [
    {
      "id": "cmp_2d9a4c71",
      "name": "Q3 Renewal Outreach",
      "status": "running",
      "assistant": {
        "id": "asst_7f3d2c91",
        "name": "Sales Bot"
      },
      "contact_stats": {
        "voicemail": 5,
        "awaiting_retry": 3
      }
    }
  ],
  "count": 1,
  "limit": 25,
  "offset": 0
}
```
</Response>

### Query-Parameter

<ParamField query="teamId" param-type="string" required="false">
Optionaler Team-Kontext für die Abfrage.
</ParamField>

<ParamField query="status" param-type="string" required="false" enum="draft,scheduled,running,paused,completed,cancelled">
Filtert Kampagnen nach ihrem aktuellen Status.
</ParamField>

<ParamField query="assistantId" param-type="string" required="false">
Filtert Kampagnen nach der ID des zugewiesenen Assistenten.
</ParamField>

<ParamField query="deleted" param-type="string" required="false" enum="exclude,include,only">
Steuert, ob gelöschte Kampagnen ausgeschlossen, zusätzlich einbezogen oder ausschließlich zurückgegeben werden. Standardwert: `exclude`.
</ParamField>

<ParamField query="contactFilter" param-type="string" required="false" enum="voicemail,awaiting_retry,answered,no_answer,busy,error">
Filtert Kampagnen nach einem Kontaktstatus oder Anrufergebnis.
</ParamField>

<ParamField query="includeContactStats" param-type="string" required="false" enum="1,true">
Liefert zusätzliche Kontaktstatistiken pro Kampagne, wenn der Wert auf `1` oder `true` gesetzt ist.
</ParamField>

<ParamField query="limit" param-type="number" required="false">
Maximale Anzahl der zurückgegebenen Kampagnen. Standardwert: `50`.
</ParamField>

<ParamField query="offset" param-type="number" required="false">
Anzahl der zu überspringenden Einträge für die Paginierung. Standardwert: `0`.
</ParamField>

### Antwort

<ResponseField name="success" field-type="boolean">
Gibt an, ob die Abfrage erfolgreich verarbeitet wurde.
</ResponseField>

<ResponseField name="campaigns" field-type="array">
Liste der gefundenen Kampagnen.
</ResponseField>

<ResponseField name="count" field-type="number">
Anzahl der in dieser Antwort enthaltenen Kampagnen.
</ResponseField>

<ResponseField name="limit" field-type="number">
Verwendete Seitengröße der Abfrage.
</ResponseField>

<ResponseField name="offset" field-type="number">
Verwendeter Startoffset der Abfrage.
</ResponseField>

## Kampagne erstellen

Erstellen Sie eine Kampagne mit einem Namen, einem zugewiesenen Outbound-Assistenten und dem zugehörigen Unternehmen. Optional ergänzen Sie Startzeit, Anruffenster, Parallelisierung und Webhook-Einstellungen.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/campaigns" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -d '{
    "assistantId": "asst_7f3d2c91",
    "companyId": "cmpny_4c8a1e52",
    "name": "Q3 Renewal Outreach",
    "fromNumberIds": ["num_1d93ab44"],
    "description": "Bestandskunden zu Vertragsverlängerungen kontaktieren",
    "scheduledStartAt": "2025-09-15T09:00:00.000Z",
    "callWindowStart": "09:00",
    "callWindowEnd": "17:00",
    "callWindowTimezone": "Europe/Berlin",
    "maxConcurrentCalls": 5,
    "maxAttemptsPerContact": 3,
    "retryDelayMinutes": 60,
    "settings": {
      "leave_voicemail": false
    },
    "noAutoComplete": false,
    "webhookEnabled": true,
    "webhookUrl": "https://hooks.northstar-industries.de/talkturo/campaigns",
    "webhookSecret": "whsec_example_5v8m2q1x7c4n9r6",
    "webhookEvents": ["campaign.started", "call.completed"]
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/campaigns", {
```

### Request-Body

<ParamField body="assistantId" param-type="string" required="true">
ID des Assistenten. Der Assistent muss existieren, zum Team gehören und für Outbound mit `outbound_enabled=true` konfiguriert sein.
</ParamField>

<ParamField body="companyId" param-type="string" required="true">
ID des Unternehmens. Das Unternehmen muss existieren und zum Team gehören.
</ParamField>

<ParamField body="name" param-type="string" required="true">
Name der Kampagne. Der Wert darf nicht leer sein.
</ParamField>

<ParamField body="fromNumberIds" param-type="string[]" required="false">
Liste der Absendernummern für ausgehende Anrufe. Dieses Feld ist erforderlich, außer wenn ein Standard-Workspace verwendet wird.
</ParamField>

<ParamField body="teamId" param-type="string" required="false">
Team-ID im Kontext, in dem die Kampagne angelegt wird. Dieses Feld ist nur in bedingten Szenarien erforderlich.
</ParamField>

<ParamField body="description" param-type="string" required="false">
Freitextbeschreibung der Kampagne.
</ParamField>

<ParamField body="scheduledStartAt" param-type="string" required="false">
Geplanter Startzeitpunkt im ISO-8601-Format. Wenn Sie diesen Wert setzen, erhält die Kampagne den Status `scheduled`.
</ParamField>

<ParamField body="callWindowStart" param-type="string" required="false">
Frühester Zeitpunkt im Tagesfenster, zu dem Anrufe gestartet werden dürfen.
</ParamField>

<ParamField body="callWindowEnd" param-type="string" required="false">
Spätester Zeitpunkt im Tagesfenster, zu dem Anrufe gestartet werden dürfen.
</ParamField>

<ParamField body="callWindowTimezone" param-type="string" required="false">
Zeitzone für `callWindowStart` und `callWindowEnd`, zum Beispiel `Europe/Berlin`.
</ParamField>

<ParamField body="maxConcurrentCalls" param-type="number" required="false">
Maximale Anzahl gleichzeitig laufender Anrufe.
</ParamField>

<ParamField body="maxAttemptsPerContact" param-type="number" required="false">
Maximale Anzahl von Anrufversuchen pro Kontakt.
</ParamField>

<ParamField body="retryDelayMinutes" param-type="number" required="false">
Wartezeit in Minuten, bevor ein Kontakt erneut angerufen wird.
</ParamField>

<ParamField body="settings" param-type="object" required="false">
Zusätzliche Kampagneneinstellungen als JSON-Objekt.
</ParamField>

<ParamField body="noAutoComplete" param-type="boolean" required="false">
Verhindert das automatische Abschließen der Kampagne, wenn alle Kontakte verarbeitet wurden.
</ParamField>

<ParamField body="webhookEnabled" param-type="boolean" required="false">
Aktiviert, deaktiviert oder überschreibt die Webhook-Nutzung für diese Kampagne.
</ParamField>

<ParamField body="webhookUrl" param-type="string" required="false">
Ziel-URL für Kampagnen-Webhooks.
</ParamField>

<ParamField body="webhookSecret" param-type="string" required="false">
Secret zur Signaturprüfung eingehender Webhook-Anfragen.
</ParamField>

<ParamField body="webhookEvents" param-type="string[]" required="false">
Liste der Events, für die Webhooks gesendet werden sollen.
</ParamField>

## Kampagne starten oder stoppen

Mit dem Run-Endpunkt steuern Sie den Laufstatus einer vorhandenen Kampagne. Senden Sie `start`, um die Kampagne zu starten, oder `stop`, um sie anzuhalten.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/run" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z" \
  -d '{
    "action": "start"
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/run", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    Authorization: "Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z"
  },
  body: JSON.stringify({
    action: "start"
  })
});

const result = await response.json();
console.log(result);
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "status": "running"
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
ID der Kampagne, die Sie starten oder stoppen möchten.
</ParamField>

### Request-Body

<ParamField body="action" param-type="string" required="true" enum="start,stop">
Legt fest, ob die Kampagne gestartet oder gestoppt wird.
</ParamField>

### Antwort

<ResponseField name="success" field-type="boolean">
Gibt an, ob die Aktion erfolgreich ausgeführt wurde.
</ResponseField>

<ResponseField name="status" field-type="string">
Aktueller Status der Kampagne nach der Aktion.
</ResponseField>

## Echtzeit-Dashboard-Statistiken abrufen

Das Kampagnen-Dashboard liefert einen kompakten Überblick über den aktuellen Fortschritt. Sie erhalten Zähler für alle Anrufe sowie für beantwortete, fehlgeschlagene und laufende Anrufe.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl "https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/dashboard" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z"
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/dashboard", {
  headers: {
    Authorization: "Bearer tk_live_example_9xmk7q2r5s8d4m1n6p3v7y2z"
  }
});

const dashboard = await response.json();
console.log(dashboard);
```
</Request>

<Response tabs="200">
```json
{
  "total_calls": 148,
  "answered": 96,
  "failed": 27,
  "in_progress": 5
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
ID der Kampagne, deren Dashboard-Daten Sie abrufen möchten.
</ParamField>

### Antwort

<ResponseField name="total_calls" field-type="number">
Gesamtzahl der zur Kampagne erfassten oder ausgeführten Anrufe.
</ResponseField>

<ResponseField name="answered" field-type="number">
Anzahl beantworteter Anrufe.
</ResponseField>

<ResponseField name="failed" field-type="number">
Anzahl fehlgeschlagener Anrufe.
</ResponseField>

<ResponseField name="in_progress" field-type="number">
Anzahl aktuell laufender Anrufe.
</ResponseField>

## Kampagnenkontakte auflisten

Rufen Sie die einer Kampagne zugeordneten Kontakte über den Kontakt-Endpunkt der Kampagne ab. Dieser Endpunkt unterstützt außerdem `POST`, um zusätzliche Kontakte zu einer vorhandenen Kampagne hinzuzufügen.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl "https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/contacts" \
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/contacts", {
  headers: {
```
