## CRM-Kampagnen verwalten

Mit der CRM Campaigns API erstellen und verwalten Sie Kampagnen, ordnen Kontakte zu, prüfen Einschreibungen und starten Anrufläufe.

<Callout kind="info">

Die API verwendet `PUT` zum Aktualisieren einer Kampagne. `PATCH` wird für diesen Endpunkt nicht unterstützt.

</Callout>

## Endpunkte

| Methode | Endpunkt | Beschreibung |
| --- | --- | --- |
| `GET` | `/api/crm/campaigns` | Kampagnen auflisten |
| `POST` | `/api/crm/campaigns` | Kampagne erstellen |
| `GET` | `/api/crm/campaigns/[id]` | Kampagne abrufen |
| `PUT` | `/api/crm/campaigns/[id]` | Kampagne aktualisieren |
| `DELETE` | `/api/crm/campaigns/[id]` | Kampagne löschen |
| `GET` | `/api/crm/campaigns/[id]/contacts` | Kampagnenkontakte auflisten |
| `POST` | `/api/crm/campaigns/[id]/contacts` | Kontakte zur Kampagne hinzufügen |
| `GET` | `/api/crm/campaigns/[id]/dashboard` | Kampagnen-Dashboard abrufen |
| `POST` | `/api/crm/campaigns/[id]/run` | Kampagnenlauf starten |
| `POST` | `/api/crm/campaigns/preview-enrollment` | Einschreibung vorab prüfen |
| `GET` | `/api/crm/outbound-assistants` | Outbound-Assistenten auflisten |
| `GET` | `/api/crm/calls` | CRM-Anrufe abrufen |
| `GET` | `/api/crm/intelligence` | CRM-Intelligence-Daten abrufen |

## Authentifizierung

Senden Sie Ihren API-Schlüssel im `Authorization`-Header jeder Anfrage.

```bash
curl https://api.talkturo.com/api/crm/campaigns?accountSlug=acme \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r"
```

Der API-Schlüssel muss Zugriff auf den angegebenen Workspace besitzen.

## Kampagnen auflisten

Mit `GET /api/crm/campaigns` rufen Sie die Kampagnen eines Workspaces ab. Die Ergebnisse verwenden eine Limit- und Offset-Paginierung.

### Abfrageparameter

<ParamField query="accountSlug" param-type="string" required="true">Workspace, dessen Kampagnen abgerufen werden sollen.</ParamField>

<ParamField query="limit" param-type="integer" required="false">Maximale Anzahl der Kampagnen in der Antwort.</ParamField>

<ParamField query="offset" param-type="integer" required="false">Anzahl der Kampagnen, die vor dem ersten zurückgegebenen Ergebnis übersprungen werden.</ParamField>

### Anfrage

<Request tabs="cURL">

```bash
curl "https://api.talkturo.com/api/crm/campaigns?accountSlug=acme&limit=25&offset=0" \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r"
```

</Request>

### Antwort

<Response tabs="200">

```json
{
  "campaigns": [
    {
      "id": "cmp_7f3a91c2",
      "teamId": "team_sales",
      "assistantId": "asst_42b7d9e1",
      "name": "Q4 renewal outreach",
      "status": "draft"
    }
  ],
  "limit": 25,
  "offset": 0
}
```

</Response>

## Kampagne erstellen

Mit `POST /api/crm/campaigns` erstellen Sie eine Kampagne für ein Team und weisen ihr einen Assistant zu.

### Body-Parameter

<ParamField body="teamId" param-type="string" required="true">ID des Teams, dem die Kampagne zugeordnet wird.</ParamField>

<ParamField body="assistantId" param-type="string" required="true">ID des Assistants, der die Kontakte der Kampagne anruft.</ParamField>

<ParamField body="fromNumberIds" param-type="string[]" required="true">IDs der Telefonnummern, die für ausgehende Anrufe verwendet werden.</ParamField>

<ParamField body="name" param-type="string" required="true">Name der Kampagne.</ParamField>

<ParamField body="callWindow" param-type="object" required="false">Zeitfenster, in dem die Kampagne ausgehende Anrufe ausführen darf.</ParamField>

<ParamField body="enrollment" param-type="object" required="false">Einstellungen für die Einschreibung von Kontakten in die Kampagne.</ParamField>

### Anfrage

<Request tabs="cURL">

```bash
curl https://api.talkturo.com/api/crm/campaigns \
  -X POST \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "accountSlug": "acme",
    "teamId": "team_sales",
    "assistantId": "asst_42b7d9e1",
    "fromNumberIds": ["num_4155550128"],
    "name": "Q4 renewal outreach",
    "callWindow": {
      "timezone": "America/Los_Angeles",
      "start": "09:00",
      "end": "17:00"
    },
    "enrollment": {
      "status": "active"
    }
  }'
```

</Request>

### Antwort

<Response tabs="201">

```json
{
  "id": "cmp_7f3a91c2",
  "teamId": "team_sales",
  "assistantId": "asst_42b7d9e1",
  "name": "Q4 renewal outreach",
  "status": "draft",
  "fromNumberIds": ["num_4155550128"]
}
```

</Response>

### Kampagnenfelder

<ResponseField name="id" field-type="string" required="true">Eindeutige ID der Kampagne.</ResponseField>

<ResponseField name="teamId" field-type="string" required="true">ID des zugeordneten Teams.</ResponseField>

<ResponseField name="assistantId" field-type="string" required="true">ID des Assistants, der für die Kampagne verwendet wird.</ResponseField>

<ResponseField name="fromNumberIds" field-type="string[]" required="true">Telefonnummern, die für ausgehende Anrufe verwendet werden.</ResponseField>

<ResponseField name="name" field-type="string" required="true">Anzeigename der Kampagne.</ResponseField>

<ResponseField name="status" field-type="string" required="true">Aktueller Status der Kampagne.</ResponseField>

<ResponseField name="callWindow" field-type="object" required="false">Konfiguration des zulässigen Anruffensters.</ResponseField>

<ResponseField name="enrollment" field-type="object" required="false">Konfiguration für die Einschreibung von Kontakten.</ResponseField>

## Einzelne Kampagne abrufen

Mit `GET /api/crm/campaigns/[id]` rufen Sie eine Kampagne anhand ihrer ID ab.

### Pfad-Parameter

<ParamField path="id" param-type="string" required="true">Eindeutige ID der Kampagne.</ParamField>

### Abfrageparameter

<ParamField query="accountSlug" param-type="string" required="true">Workspace, zu dem die Kampagne gehört.</ParamField>

```bash
curl "https://api.talkturo.com/api/crm/campaigns/cmp_7f3a91c2?accountSlug=acme" \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r"
```

## Kampagne aktualisieren

Mit `PUT /api/crm/campaigns/[id]` aktualisieren Sie die Einstellungen einer bestehenden Kampagne.

<Callout kind="alert">

Kampagnen können nur aktualisiert werden, wenn ihr aktueller Status Änderungen zulässt. Verwenden Sie `PUT` mit den Feldern, die Sie ändern möchten.

</Callout>

### Body-Parameter

<ParamField body="teamId" param-type="string" required="false">Neue Team-ID der Kampagne.</ParamField>

<ParamField body="assistantId" param-type="string" required="false">Neue Assistant-ID der Kampagne.</ParamField>

<ParamField body="fromNumberIds" param-type="string[]" required="false">Neue Liste der Telefonnummern für ausgehende Anrufe.</ParamField>

<ParamField body="name" param-type="string" required="false">Neuer Name der Kampagne.</ParamField>

<ParamField body="callWindow" param-type="object" required="false">Neues Zeitfenster für ausgehende Anrufe.</ParamField>

<ParamField body="enrollment" param-type="object" required="false">Neue Einschreibungseinstellungen.</ParamField>

```bash
curl https://api.talkturo.com/api/crm/campaigns/cmp_7f3a91c2 \
  -X PUT \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "accountSlug": "acme",
    "name": "Q4 renewal outreach - priority",
    "callWindow": {
      "timezone": "America/Los_Angeles",
      "start": "10:00",
      "end": "16:00"
    }
  }'
```

## Kampagne löschen

Mit `DELETE /api/crm/campaigns/[id]` löschen Sie eine Kampagne.

Kampagnen können nur gelöscht werden, wenn sie den Status `draft` oder `cancelled` haben. Entfernen Sie Kontakte nicht einzeln, um eine aktive Kampagne zu stoppen. Verwenden Sie stattdessen den vorgesehenen Kampagnenstatus oder beenden Sie den laufenden Prozess.

```bash
curl "https://api.talkturo.com/api/crm/campaigns/cmp_7f3a91c2?accountSlug=acme" \
  -X DELETE \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r"
```

## Kontakte verwalten

Mit den Unterendpunkten `/api/crm/campaigns/[id]/contacts` können Sie die Kontakte einer Kampagne auflisten und neue Kontakte hinzufügen.

### Kontakte auflisten

`GET /api/crm/campaigns/[id]/contacts` gibt die Kontakte der Kampagne zurück.

<ParamField path="id" param-type="string" required="true">Eindeutige ID der Kampagne.</ParamField>

<ParamField query="accountSlug" param-type="string" required="true">Workspace, zu dem die Kampagne gehört.</ParamField>

<ParamField query="limit" param-type="integer" required="false">Maximale Anzahl der Kontakte in der Antwort.</ParamField>

<ParamField query="offset" param-type="integer" required="false">Anzahl der Kontakte, die vor dem ersten Ergebnis übersprungen werden.</ParamField>

```bash
curl "https://api.talkturo.com/api/crm/campaigns/cmp_7f3a91c2/contacts?accountSlug=acme&limit=50&offset=0" \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r"
```

### Kontakte hinzufügen

Mit `POST /api/crm/campaigns/[id]/contacts` fügen Sie Kontakte anhand ihrer IDs, einzelner Kontaktdaten oder einer Audience hinzu.

<ParamField body="contactIds" param-type="string[]" required="false">IDs der Kontakte, die eingeschrieben werden sollen.</ParamField>

<ParamField body="contact" param-type="object" required="false">Ein einzelner Kontakt, der der Kampagne hinzugefügt werden soll.</ParamField>

<ParamField body="audience" param-type="object" required="false">Audience, deren Kontakte der Kampagne hinzugefügt werden sollen.</ParamField>

```bash
curl https://api.talkturo.com/api/crm/campaigns/cmp_7f3a91c2/contacts \
  -X POST \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "accountSlug": "acme",
    "contactIds": ["contact_8c2f6a10", "contact_19d4b7e2"]
  }'
```

## Kampagnen-Dashboard abrufen

Mit `GET /api/crm/campaigns/[id]/dashboard` rufen Sie die zusammengefassten Kampagnenkennzahlen ab.

Die Antwort enthält Zählwerte, die aktuelle Anrufwarteschlange und die letzten Anrufe.

<ParamField path="id" param-type="string" required="true">Eindeutige ID der Kampagne.</ParamField>

<ParamField query="accountSlug" param-type="string" required="true">Workspace, zu dem die Kampagne gehört.</ParamField>

### Antwortfelder

<ResponseField name="counts" field-type="object" required="true">Zusammengefasste Zählwerte der Kampagne.</ResponseField>

<ResponseField name="queue" field-type="array" required="true">Kontakte, die für einen Anruf in der Warteschlange stehen.</ResponseField>

<ResponseField name="recentCalls" field-type="array" required="true">Die letzten Anrufe der Kampagne.</ResponseField>

```bash
curl "https://api.talkturo.com/api/crm/campaigns/cmp_7f3a91c2/dashboard?accountSlug=acme" \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r"
```

## Kampagnenlauf starten

Mit `POST /api/crm/campaigns/[id]/run` starten Sie einen Anruflauf für eine Kampagne.

### Body-Parameter

<ParamField body="maxCalls" param-type="integer" required="false">Maximale Anzahl der Anrufe, die in diesem Lauf ausgeführt werden.</ParamField>

<ParamField body="dryRun" param-type="boolean" required="false">Wenn `true`, wird der Lauf simuliert, ohne tatsächliche Anrufe zu starten.</ParamField>

<ParamField body="accountSlug" param-type="string" required="true">Workspace, zu dem die Kampagne gehört.</ParamField>

```bash
curl https://api.talkturo.com/api/crm/campaigns/cmp_7f3a91c2/run \
  -X POST \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "accountSlug": "acme",
    "maxCalls": 25,
    "dryRun": true
  }'
```

<Callout kind="tip">

Verwenden Sie zuerst `dryRun: true`, um die Auswahl und Anzahl der vorgesehenen Anrufe zu prüfen. Setzen Sie `dryRun` erst danach auf `false`, um den Lauf auszuführen.

</Callout>

## Einschreibung vorab prüfen

Mit `POST /api/crm/campaigns/preview-enrollment` prüfen Sie, welche Kontakte für eine Einschreibung ausgewählt würden, bevor Sie sie einer Kampagne hinzufügen.

### Body-Parameter

<ParamField body="accountSlug" param-type="string" required="true">Workspace, in dem die Einschreibung geprüft werden soll.</ParamField>

<ParamField body="campaignId" param-type="string" required="false">ID der Kampagne, für die die Einschreibung geprüft wird.</ParamField>

<ParamField body="contactIds" param-type="string[]" required="false">Kontakte, deren Einschreibungsfähigkeit geprüft werden soll.</ParamField>

<ParamField body="audience" param-type="object" required="false">Audience-Kriterien für die Vorschau der Einschreibung.</ParamField>

```bash
curl https://api.talkturo.com/api/crm/campaigns/preview-enrollment \
  -X POST \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "accountSlug": "acme",
    "campaignId": "cmp_7f3a91c2",
    "contactIds": ["contact_8c2f6a10", "contact_19d4b7e2"]
  }'
```

## CRM-Anrufe abrufen

Mit `GET /api/crm/calls` rufen Sie die Anrufe ab, die mit CRM-Kampagnen verbunden sind.

<ParamField query="accountSlug" param-type="string" required="true">Workspace, dessen CRM-Anrufe abgerufen werden sollen.</ParamField>

<ParamField query="campaignId" param-type="string" required="false">Filtert die Ergebnisse nach einer Kampagne.</ParamField>

<ParamField query="limit" param-type="integer" required="false">Maximale Anzahl der zurückgegebenen Anrufe.</ParamField>

<ParamField query="offset" param-type="integer" required="false">Anzahl der Anrufe, die vor dem ersten Ergebnis übersprungen werden.</ParamField>

```bash
curl "https://api.talkturo.com/api/crm/calls?accountSlug=acme&campaignId=cmp_7f3a91c2&limit=25&offset=0" \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r"
```

<ParamField query="accountSlug" param-type="string" required="true">Workspace, für den die Intelligence-Daten abgerufen werden sollen.</ParamField>

<ParamField query="campaignId" param-type="string" required="false">Filtert die Intelligence-Daten nach einer Kampagne.</ParamField>

```bash
curl "https://api.talkturo.com/api/crm/intelligence?accountSlug=acme&campaignId=cmp_7f3a91c2" \
  -H "Authorization: Bearer sk_live_example_9xmk7q2r"
```

## Typischer Workflow

Der folgende Ablauf eignet sich für eine neue Kampagne:

<Steps>

<Step title="Kampagne erstellen" icon="plus">

Erstellen Sie eine Kampagne mit einem `teamId`, einem `assistantId`, mindestens einer Telefonnummer und einem Namen.

</Step>

<Step title="Einschreibung prüfen" icon="search">

Rufen Sie `preview-enrollment` auf, um die vorgesehenen Kontakte und mögliche Ausschlüsse vor dem Hinzufügen zu prüfen.

</Step>

<Step title="Kontakte hinzufügen" icon="users">

Fügen Sie einzelne Kontakte, eine Liste von `contactIds` oder eine Audience hinzu.

</Step>

<Step title="Dashboard prüfen" icon="bar-chart">

Rufen Sie das Dashboard ab, um Zählwerte, Warteschlange und letzte Anrufe zu kontrollieren.

</Step>

<Step title="Lauf simulieren" icon="play-circle">

Starten Sie einen Lauf mit `dryRun: true`, um die Auswahl ohne tatsächliche Anrufe zu validieren.

</Step>

<Step title="Lauf starten" icon="rocket">

Starten Sie den produktiven Lauf mit `dryRun: false` und begrenzen Sie die Anzahl bei Bedarf mit `maxCalls`.

</Step>

</Steps>
