## CRM-Kampagnen für ausgehende Anrufe verwalten

Mit den CRM-Kampagnen-Endpunkten erstellen und steuern Sie ausgehende Anrufkampagnen in Talkturo. Sie können Kampagnen anlegen, Kontakte oder Einschreibungsregeln zuordnen, eine Kampagne starten oder stoppen und den aktuellen Fortschritt über Dashboard-Statistiken verfolgen.

Alle Endpunkte in diesem Bereich verwenden duale Authentifizierung über die `withApiAuth`-Middleware. Sie können jeden Endpunkt entweder mit einem API-Key im Header `Authorization: Bearer tk_live_example_9xmk7q2r` oder aus einer angemeldeten Talkturo-Sitzung mit Session-Cookie aufrufen.

<Callout kind="info">

Die Kampagnen-API deckt den Kampagnenablauf selbst ab. Für verfügbare Outbound-Assistenten, Anrufprotokolle und KI-Einblicke stehen separate CRM-Endpunkte bereit, die in der Übersicht unten mit aufgeführt sind.

</Callout>

| `GET` | `/api/crm/intelligence` | KI-Einblicke abrufen |

## Kampagnen auflisten

Listen Sie Kampagnen teambezogen auf und filtern Sie die Ergebnisse nach Status, Assistent, Löschstatus oder Kontaktzustand. Der Endpunkt verwendet `limit`- und `offset`-Paginierung.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl "https://app.talkturo.com/api/crm/campaigns?teamId=4c8f7f4b-6c41-4db0-9d9a-d3b8bb3d3b0a&status=running&includeContactStats=true&limit=20&offset=0" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r"
```

```javascript
const params = new URLSearchParams({
  teamId: "4c8f7f4b-6c41-4db0-9d9a-d3b8bb3d3b0a",
  status: "running",
  includeContactStats: "true",
  limit: "20",
  offset: "0"
});

const response = await fetch(`https://app.talkturo.com/api/crm/campaigns?${params.toString()}`, {
  headers: {
    Authorization: "Bearer tk_live_example_9xmk7q2r"
  }
});

const campaigns = await response.json();
console.log(campaigns);
```
</Request>

### Query-Parameter

<ParamField query="teamId" param-type="string" required="false">
Team-UUID. Verwenden Sie diesen Parameter, um Kampagnen auf ein bestimmtes Team zu begrenzen.
</ParamField>

<ParamField query="status" param-type="string" required="false">
Filtert nach Kampagnenstatus.
</ParamField>

<ParamField query="assistantId" param-type="string" required="false">
Filtert nach der UUID des zugewiesenen Outbound-Assistenten.
</ParamField>

<ParamField query="deleted" param-type="string" required="false" enum="exclude,include,only">
Steuert, ob soft-gelöschte Kampagnen ausgeschlossen, zusätzlich einbezogen oder ausschließlich zurückgegeben werden.
</ParamField>

<ParamField query="contactFilter" param-type="string" required="false" enum="voicemail,awaiting_retry,answered,no_answer,busy,error">
Filtert Kampagnen anhand von Kontakt- oder Anrufzuständen.
</ParamField>

<ParamField query="includeContactStats" param-type="boolean" required="false">
Gibt zusätzliche Kontaktstatistiken pro Kampagne zurück.
</ParamField>

<ParamField query="limit" param-type="integer" required="false">
Maximale Anzahl der zurückgegebenen Kampagnen.
</ParamField>

<ParamField query="offset" param-type="integer" required="false">
Anzahl der zu überspringenden Einträge für die Paginierung.
</ParamField>

</ResponseField>

<ResponseField name="offset" field-type="number">
Verwendeter Startversatz innerhalb der Gesamtergebnisliste.
</ResponseField>

Die Einschreibungsmodi steuern, welche Kontakte beim Erstellen der Kampagne hinzugefügt werden. `all_eligible` schreibt alle passenden Kontakte ein, `delta` nur neue Kontakte seit dem letzten Lauf und `none` erstellt die Kampagne ohne automatische Einschreibung.

</Callout>

<Callout kind="tip">

Wenn Sie `liveSync` auf `true` setzen, aktiviert das System automatisch auch `noAutoComplete` mit `true`.

</Callout>

<Callout kind="alert">

Mindestens 1 Credit ist erforderlich, um eine ausgehende Kampagne zu starten. Pro Assistent ist nur eine aktive Kampagne gleichzeitig erlaubt.

</Callout>

const params = new URLSearchParams({

## Kampagne löschen

Löschen Sie eine Kampagne per Soft-Delete. Der Datensatz bleibt dabei erhalten und kann über den Filter `deleted` in Listenabfragen einbezogen werden.

<Callout kind="alert">

Soft-Delete ist nur für Kampagnen im Status `draft` oder `cancelled` erlaubt.

</Callout>

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X DELETE "https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r"
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71", {
  method: "DELETE",
  headers: {
    Authorization: "Bearer tk_live_example_9xmk7q2r"
  }
});

const result = await response.json();
console.log(result);
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "deleted": true
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
ID der Kampagne, die Sie soft-löschen möchten.
</ParamField>

### Antwort

<ResponseField name="success" field-type="boolean">
Gibt an, ob die Löschanfrage erfolgreich verarbeitet wurde.
</ResponseField>

<ResponseField name="deleted" field-type="boolean">
Gibt an, ob die Kampagne als gelöscht markiert wurde.
</ResponseField>

## Kampagne starten oder stoppen

Mit dem Run-Endpunkt steuern Sie den Laufstatus einer vorhandenen Kampagne. Senden Sie `start`, um die Kampagne zu starten, oder `stop`, um sie anzuhalten.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/run" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer tk_live_example_9xmk7q2r" \
  -d '{
    "action": "start"
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/crm/campaigns/cmp_2d9a4c71/run", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    Authorization: "Bearer tk_live_example_9xmk7q2r"
  },
  body: JSON.stringify({
    action: "start"
  })
});

const result = await response.json();
console.log(result);
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "status": "running"
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
ID der Kampagne, die Sie starten oder stoppen möchten.
</ParamField>

### Request-Body

<ParamField body="action" param-type="string" required="true" enum="start,stop">
Legt fest, ob die Kampagne gestartet oder gestoppt wird.
</ParamField>

### Antwort

<ResponseField name="success" field-type="boolean">
Gibt an, ob die Aktion erfolgreich ausgeführt wurde.
</ResponseField>

<ResponseField name="status" field-type="string">
Aktueller Status der Kampagne nach der Aktion.
</ResponseField>

<Callout kind="alert">

Das Starten einer Kampagne erfordert mindestens 1 verfügbaren Credit.

</Callout>
