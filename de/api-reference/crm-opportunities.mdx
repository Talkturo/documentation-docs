## CRM-Opportunities verwalten

Verwalten Sie Verkaufschancen im Talkturo-CRM über Endpunkte zum Auflisten, Erstellen, Abrufen, Aktualisieren und Löschen. Eine Opportunity enthält unter anderem ihren Namen, ihre Pipeline-Phase, den Betrag, die Abschlusswahrscheinlichkeit, den verantwortlichen Benutzer und optionale benutzerdefinierte Felder.

<Callout kind="info">

Alle CRM-Opportunity-Endpunkte verwenden Session-Cookie-Authentifizierung. Senden Sie die Anfragen aus einer angemeldeten Sitzung heraus.

</Callout>

## Endpunkte im Überblick

| Methode | Pfad | Beschreibung |
| --- | --- | --- |
| `GET` | `/api/crm/opportunities` | Opportunities eines Teams auflisten und nach Phase oder verantwortlichem Benutzer filtern |
| `POST` | `/api/crm/opportunities` | Eine neue Opportunity erstellen |
| `GET` | `/api/crm/opportunities/{id}` | Eine einzelne Opportunity mit Aktivitätshistorie abrufen |
| `PUT` | `/api/crm/opportunities/{id}` | Eine bestehende Opportunity aktualisieren |
| `DELETE` | `/api/crm/opportunities/{id}` | Eine Opportunity löschen |

## GET `/api/crm/opportunities`

Rufen Sie die Opportunities eines Teams mit optionalen Filtern und Offset-basierter Pagination ab. Die Antwort enthält außerdem aggregierte Summen pro Pipeline-Phase in `stageTotals`.

<Request>
```bash
curl -X GET "https://api.talkturo.com/api/crm/opportunities?teamId=team_7c42m9ab&stage=proposal&ownerUserId=usr_5d18c2ef&limit=20&offset=0" \
  -H "Cookie: sb-access-token=session_example_7fd82k"
```
</Request>

<Response>
```json
{
  "opportunities": [
    {
      "id": "opp_4b29d7e1",
      "teamId": "team_7c42m9ab",
      "name": "Annual renewal - Acme GmbH",
      "primaryContactId": "cnt_8c13fa20",
      "stage": "proposal",
      "amount": 24000,
      "currency": "EUR",
      "probability": 70,
      "expectedCloseDate": "2025-10-15",
      "ownerUserId": "usr_5d18c2ef"
    }
  ],
  "count": 1,
  "limit": 20,
  "offset": 0,
  "stageTotals": {
    "lead": 0,
    "qualified": 0,
    "proposal": 24000,
    "negotiation": 0,
    "won": 0,
    "lost": 0
  }
}
```
</Response>

### Query-Parameter

<ParamField query="teamId" param-type="string" required="true">
ID des Teams, dessen Opportunities abgerufen werden sollen.
</ParamField>

<ParamField query="stage" param-type="string" required="false" enum="lead,qualified,proposal,negotiation,won,lost">
Filtert die Ergebnisse nach einer Pipeline-Phase.
</ParamField>

<ParamField query="ownerUserId" param-type="string" required="false">
Filtert die Ergebnisse nach dem Benutzer, der für die Opportunity verantwortlich ist.
</ParamField>

<ParamField query="limit" param-type="integer" required="false">
Maximale Anzahl der Opportunities in der Antwort.
</ParamField>

<ParamField query="offset" param-type="integer" required="false">
Anzahl der Opportunities, die vor dem ersten zurückgegebenen Ergebnis übersprungen werden.
</ParamField>

Name der Opportunity.

ID des primären Kontakts, falls ein Kontakt zugeordnet ist.

## POST `/api/crm/opportunities`

Erstellen Sie eine Opportunity für ein Team. Der Name und die Team-ID sind erforderlich; alle weiteren Felder ergänzen die Pipeline- und Vertriebsdaten.

<Request>
```bash
curl -X POST "https://api.talkturo.com/api/crm/opportunities" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=session_example_7fd82k" \
  -d '{
    "teamId": "team_7c42m9ab",
    "name": "Expansion deal - Nordstern AG",
    "primaryContactId": "cnt_28d91fa4",
    "stage": "qualified",
    "amount": 18500,
    "currency": "EUR",
    "probability": 45,
    "expectedCloseDate": "2025-10-15",
    "ownerUserId": "usr_5d18c2ef",
    "notes": "Budget ist für das vierte Quartal vorgesehen.",
    "customFields": {
      "region": "DACH",
      "contractType": "expansion"
    }
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "opportunity": {
    "id": "opp_91cd34ab",
    "teamId": "team_7c42m9ab",
    "name": "Expansion deal - Nordstern AG",
    "primaryContactId": "cnt_28d91fa4",
    "stage": "qualified",
    "amount": 18500,
    "currency": "EUR",
    "probability": 45,
    "expectedCloseDate": "2025-10-15",
    "ownerUserId": "usr_5d18c2ef",
    "notes": "Budget ist für das vierte Quartal vorgesehen.",
    "customFields": {
      "region": "DACH",
      "contractType": "expansion"
    }
  }
}
```
</Response>

</ParamField>

<ParamField body="currency" param-type="string" required="false">

</ParamField>

<ParamField body="probability" param-type="number" required="false">
Wahrscheinlichkeit, mit der die Opportunity abgeschlossen wird.
</ParamField>

ID des Benutzers, der für die Opportunity verantwortlich ist.

## GET `/api/crm/opportunities/{id}`

Rufen Sie eine einzelne Opportunity anhand ihrer ID ab. Die Antwort enthält zusätzlich die mit der Opportunity verbundenen Aktivitäten.

<Request>
```bash

  -H "Cookie: sb-access-token=session_example_7fd82k"
```
</Request>

<Response>
```json
{
  "success": true,
  "opportunity": {
    "id": "opp_4b29d7e1",
    "teamId": "team_7c42m9ab",
    "name": "Annual renewal - Acme GmbH",
    "primaryContactId": "cnt_8c13fa20",
    "stage": "proposal",
    "amount": 24000,
    "currency": "EUR",
    "probability": 70,
    "expectedCloseDate": "2025-10-15",
    "ownerUserId": "usr_5d18c2ef",
    "notes": "Vertragsverlängerung mit erweitertem Leistungsumfang.",
    "customFields": {
      "region": "DACH"
    }
  },
  "activities": [
    {
      "id": "act_72f19c0b",
      "type": "call",
      "subject": "Budget und Zeitplan besprechen",
      "createdAt": "2025-08-20T09:30:00Z"
    }
  ]
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige ID der Opportunity, die Sie abrufen möchten.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Kennzeichnet, ob die Opportunity erfolgreich geladen wurde.
</ResponseField>

<ResponseField name="opportunity" field-type="object" required="true">
Enthält die angeforderte Opportunity.
</ResponseField>

<ResponseField name="activities" field-type="array" required="true">

</ResponseField>

<Callout kind="info">

Die Einzelroute leitet `team_id` aus der Opportunity ab und prüft, ob Ihre Sitzung Zugriff auf das zugehörige Team hat.

</Callout>

## PUT `/api/crm/opportunities/{id}`

Aktualisieren Sie eine bestehende Opportunity anhand ihrer ID. Senden Sie nur die Felder, die Sie ändern möchten.

<Request>
```bash
curl -X PUT "https://api.talkturo.com/api/crm/opportunities/opp_4b29d7e1" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=session_example_7fd82k" \
  -d '{
    "name": "Annual renewal - Acme GmbH",
    "stage": "negotiation",
    "amount": 26000,
    "currency": "EUR",
    "probability": 80,
    "expectedCloseDate": "2025-11-01",
    "ownerUserId": "usr_5d18c2ef",
    "notes": "Konditionen befinden sich in der finalen Abstimmung.",
    "customFields": {
      "region": "DACH",
      "renewalTerm": "24 months"
    },
    "actualCloseDate": null,
    "lostReason": null,
    "wonDetails": null
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "opportunity": {
    "id": "opp_4b29d7e1",
    "teamId": "team_7c42m9ab",
    "name": "Annual renewal - Acme GmbH",
    "primaryContactId": "cnt_8c13fa20",
    "stage": "negotiation",
    "amount": 26000,
    "currency": "EUR",
    "probability": 80,
    "expectedCloseDate": "2025-11-01",
    "ownerUserId": "usr_5d18c2ef",
    "notes": "Konditionen befinden sich in der finalen Abstimmung.",
    "customFields": {
      "region": "DACH",
      "renewalTerm": "24 months"
    },
    "actualCloseDate": null,
    "lostReason": null,
    "wonDetails": null
  }
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige ID der Opportunity, die Sie aktualisieren möchten.
</ParamField>

### Aktualisierbare Felder

<ParamField body="name" param-type="string" required="false">
Aktualisiert den Namen der Opportunity.
</ParamField>

<ParamField body="stage" param-type="string" required="false">
Aktualisiert die Pipeline-Phase. Zulässige Werte sind `lead`, `qualified`, `proposal`, `negotiation`, `won` und `lost`.
</ParamField>

<ParamField body="amount" param-type="number" required="false">
Aktualisiert den monetären Betrag.
</ParamField>

<ParamField body="currency" param-type="string" required="false">
Aktualisiert die Währung des Betrags.
</ParamField>

<ParamField body="probability" param-type="number" required="false">
Aktualisiert die Abschlusswahrscheinlichkeit.
</ParamField>

<ParamField body="expectedCloseDate" param-type="string" required="false">
Aktualisiert das voraussichtliche Abschlussdatum.
</ParamField>

<ParamField body="ownerUserId" param-type="string" required="false">
Aktualisiert den verantwortlichen Benutzer.
</ParamField>

<ParamField body="notes" param-type="string" required="false">
Aktualisiert die Notizen zur Opportunity.
</ParamField>

<ParamField body="customFields" param-type="object" required="false">
Aktualisiert die benutzerdefinierten Felder.
</ParamField>

<ParamField body="actualCloseDate" param-type="string" required="false">
Setzt das tatsächliche Abschlussdatum, sobald die Opportunity abgeschlossen wurde.
</ParamField>

<ParamField body="lostReason" param-type="string" required="false">
Dokumentiert den Grund, aus dem die Opportunity verloren wurde.
</ParamField>

<ParamField body="wonDetails" param-type="object" required="false">
Enthält zusätzliche Informationen zu einer gewonnenen Opportunity.
</ParamField>

## DELETE `/api/crm/opportunities/{id}`

Löschen Sie eine Opportunity dauerhaft anhand ihrer ID.

<Request>
```bash
curl -X DELETE "https://api.talkturo.com/api/crm/opportunities/opp_4b29d7e1" \
  -H "Cookie: sb-access-token=session_example_7fd82k"
```
</Request>

<Response>
```json
{
  "success": true
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige ID der Opportunity, die Sie löschen möchten.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Ist `true`, wenn die Opportunity erfolgreich gelöscht wurde.
</ResponseField>

<Callout kind="alert">

Das Löschen ist dauerhaft. Stellen Sie sicher, dass die Opportunity nicht mehr für Berichte, Aktivitäten oder Vertriebsprozesse benötigt wird.

</Callout>
