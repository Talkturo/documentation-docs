## CRM-Opportunities verwalten

Verwalten Sie Verkaufschancen im Talkturo-CRM über Endpunkte zum Auflisten, Erstellen, Abrufen, Aktualisieren und Löschen. Jede Opportunity speichert Pipeline-Phase, Betrag, Verantwortliche, erwartete Abschlussdaten sowie Verknüpfungen zu Unternehmen und primären Kontakten.

<Callout kind="info">

`GET /api/crm/opportunities` und `POST /api/crm/opportunities` akzeptieren API-Keys oder Session-Cookies. `GET`, `PUT` und `DELETE` für `/api/crm/opportunities/{id}` benötigen eine angemeldete Sitzung und damit ein gültiges Session-Cookie.

</Callout>

## Endpunkte im Überblick

| Methode | Pfad | Beschreibung |
| --- | --- | --- |
| `GET` | `/api/crm/opportunities` | Opportunities auflisten und nach Team, Unternehmen, Phase oder Verantwortlichem filtern |
| `POST` | `/api/crm/opportunities` | Eine neue Opportunity erstellen |
| `GET` | `/api/crm/opportunities/{id}` | Eine einzelne Opportunity mit verknüpften Daten abrufen |
| `PUT` | `/api/crm/opportunities/{id}` | Eine bestehende Opportunity vollständig oder teilweise aktualisieren |
| `DELETE` | `/api/crm/opportunities/{id}` | Eine Opportunity dauerhaft löschen |

### Query-Parameter

<ParamField query="teamId" param-type="string" required="false">

## DELETE /api/crm/opportunities/{id}

Löschen Sie eine Opportunity dauerhaft anhand ihrer ID. Der Endpunkt führt einen Hard Delete ohne zusätzliche Schutzmechanismen aus.

<Request>
```bash
curl -X DELETE "https://api.talkturo.com/api/crm/opportunities/opp_4b29d7e1" \
  -H "Cookie: sb-access-token=session_example_7fd82k"
```
</Request>

<Response>
```json
{
  "success": true
}
```
</Response>

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige ID der Opportunity, die Sie löschen möchten.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Ist `true`, wenn die Opportunity erfolgreich gelöscht wurde.
</ResponseField>

<Callout kind="alert">

Der Endpunkt löscht Opportunities dauerhaft und ohne Prüfungen. Stellen Sie vor dem Aufruf sicher, dass die Opportunity nicht mehr für Berichte, Automatisierungen oder Vertriebsprozesse benötigt wird.

</Callout>
