## CRM-Opportunities verwalten

Verwalten Sie Verkaufschancen im Talkturo-CRM über Endpunkte zum Auflisten, Erstellen, Abrufen, Aktualisieren und Löschen. Jede Opportunity enthält einen Namen, eine Phase, optionale Beträge, Zuständigkeiten sowie Verknüpfungen zu Unternehmen und primären Kontakten.

<Callout kind="info">

Die Listen- und Erstellungsendpunkte akzeptieren entweder einen Session-Cookie oder einen API-Key. Detailabruf, Aktualisierung und Löschen erfordern eine angemeldete Session.

</Callout>

## Endpunkte im Überblick

| Methode | Pfad | Beschreibung |
| --- | --- | --- |
| `GET` | `/api/crm/opportunities` | Opportunities auflisten und nach Team, Unternehmen, Phase oder Owner filtern |
| `POST` | `/api/crm/opportunities` | Eine neue Opportunity erstellen |
| `GET` | `/api/crm/opportunities/{id}` | Eine einzelne Opportunity abrufen |
| `PUT` | `/api/crm/opportunities/{id}` | Eine bestehende Opportunity vollständig aktualisieren |
| `DELETE` | `/api/crm/opportunities/{id}` | Eine Opportunity löschen |

## Gültige Opportunity-Phasen

Verwenden Sie für `stage` nur die vom System unterstützten Phasen. Ungültige Werte führen dazu, dass die Anfrage abgelehnt wird.

- `lead` — neuer Deal mit noch offener Erstqualifizierung
- `qualified` — Deal wurde geprüft und ist vertriebsrelevant
- `proposal` — Angebot oder konkreter Lösungsvorschlag liegt vor
- `negotiation` — Preis, Umfang oder Bedingungen werden verhandelt
- `won` — Deal wurde erfolgreich abgeschlossen
- `lost` — Deal wurde verloren oder abgebrochen

<Callout kind="tip">

Wenn Sie eigene Pipeline-Bezeichnungen in der Oberfläche verwenden, ordnen Sie diese Werte vor dem API-Aufruf auf eine der gültigen Phasen zu.

</Callout>

## POST /api/crm/opportunities

  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=session_example_7fd82k" \

## PUT /api/crm/opportunities/{id}

Aktualisieren Sie eine bestehende Opportunity anhand ihrer ID. Alle Body-Felder sind optional und müssen in Camel Case gesendet werden.

<Request>
```bash
curl -X PUT "https://api.talkturo.com/api/crm/opportunities/opp_4b29d7e1" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=session_example_7fd82k" \
  -d '{
    "stage": "won",
    "amount": 26000,
    "probability": 100,
    "expectedCloseDate": "2025-11-01",
    "wonDetails": "Vertrag unterschrieben nach finaler Preisrunde."
  }'
```
</Request>

<Response>
```json
{
  "success": true,
  "opportunity": {
    "id": "opp_4b29d7e1",
    "name": "Jahresverlängerung Acme GmbH",
    "stage": "won",
    "amount": 26000,
    "currency": "EUR",
    "probability": 100,
    "expected_close_date": "2025-11-01",
    "actual_close_date": "2025-11-01",
    "won_details": "Vertrag unterschrieben nach finaler Preisrunde."
  }
}
```
</Response>

### Authentifizierung

Senden Sie diesen Endpunkt aus einer angemeldeten Session. API-Keys werden für Aktualisierungen nicht akzeptiert.

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige ID der Opportunity, die Sie aktualisieren möchten.
</ParamField>

<ParamField body="name" param-type="string" required="false">

<ParamField body="stage" param-type="string" required="false" enum="lead,qualified,proposal,negotiation,won,lost">

<ParamField body="amount" param-type="number" required="false">
Aktualisiert den Deal-Wert. Senden Sie `null`, um den Wert zu entfernen.

</ParamField>

## DELETE /api/crm/opportunities/{id}

Löschen Sie eine Opportunity dauerhaft anhand ihrer ID.

<Request>
```bash

  -H "Cookie: sb-access-token=session_example_7fd82k"
```
</Request>

<Response>
```json
{
  "success": true
}
```
</Response>

### Authentifizierung

Senden Sie diesen Endpunkt aus einer angemeldeten Session. API-Keys werden für Löschvorgänge nicht akzeptiert.

### Pfadparameter

<ParamField path="id" param-type="string" required="true">
Eindeutige ID der Opportunity, die Sie löschen möchten.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Ist `true`, wenn die Opportunity erfolgreich gelöscht wurde.
</ResponseField>

<Callout kind="alert">

Das Löschen ist dauerhaft. Stellen Sie sicher, dass die Opportunity nicht mehr für Berichte, Automatisierungen oder Vertriebsprozesse benötigt wird.

</Callout>
