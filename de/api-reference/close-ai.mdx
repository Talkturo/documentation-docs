## Close AI API

Die Close AI API stellt Sitzungen, Transkripte, Analysen, Prompt-Vorlagen, Coaching-Dashboards, Skripte und Analytics-Einstellungen bereit.

**Base URL:**

```text
https://app.talkturo.com
```

Alle Endpunkte verwenden die browserbasierte Supabase-Session-Cookie-Authentifizierung. Browser senden das Session-Cookie automatisch mit. Für cURL-Beispiele verwenden Sie einen Cookie-Jar mit einer bereits authentifizierten Supabase-Session.

<Callout kind="info">

Die Datenzugriffsrechte werden abhängig vom Endpunkt über Supabase RLS oder eine explizite Session- und Workspace-Prüfung erzwungen.

</Callout>

## Sitzungen

### Sitzungen auflisten

```http
GET /api/close-ai/sessions
```

Ruft die Sitzungen der authentifizierten Person ab. Die Ergebnisse werden paginiert und können nach Titel und Workspace gefiltert werden.

#### Abfrageparameter

<ParamField query="limit" param-type="number" required="false">

Anzahl der zurückgegebenen Sitzungen. Der Wert wird auf den Bereich `1` bis `100` begrenzt. Standardwert ist `50`.

</ParamField>

<ParamField query="offset" param-type="number" required="false">

Anzahl der zu überspringenden Sitzungen. Ungültige oder nicht numerische Werte werden effektiv als `0` behandelt.

</ParamField>

<ParamField query="q" param-type="string" required="false">

Case-insensitive Teilstringsuche im Feld `title`.

</ParamField>

<ParamField query="account" param-type="string" required="false">

Workspace-Slug. Wenn der Workspace gefunden wird, enthält die Antwort Sitzungen dieses Workspaces sowie Legacy-Sitzungen mit `account_id` gleich `null`.

</ParamField>

#### Anfrage

<CodeGroup tabs="cURL,JavaScript">

```bash
curl "https://app.talkturo.com/api/close-ai/sessions?limit=25&offset=0&q=discovery&account=acme-sales" \
  --cookie-jar /tmp/talkturo-session-cookies.txt \
  --cookie /tmp/talkturo-session-cookies.txt
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/close-ai/sessions?limit=25&offset=0&q=discovery&account=acme-sales",
  {
    credentials: "include"
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

#### Antwortfelder

<ResponseField name="sessions" field-type="array">

Liste der Sitzungen.

</ResponseField>

<ResponseField name="count" field-type="number">

Anzahl der Sitzungen in der aktuellen Antwort.

</ResponseField>

#### Sitzungsfelder

<ResponseField name="sessions[].id" field-type="string">

UUID der Sitzung.

</ResponseField>

<ResponseField name="sessions[].user_id" field-type="string">

UUID der Person, der die Sitzung gehört.

</ResponseField>

<ResponseField name="sessions[].account_id" field-type="string|null">

UUID des zugehörigen Workspaces oder `null` für Legacy-Sitzungen.

</ResponseField>

<ResponseField name="sessions[].title" field-type="string|null">

Titel der Sitzung.

</ResponseField>

<ResponseField name="sessions[].session_type" field-type="string">

Typ der Sitzung.

</ResponseField>

<ResponseField name="sessions[].started_at" field-type="string">

Startzeitpunkt der Sitzung als Timestamp.

</ResponseField>

<ResponseField name="sessions[].ended_at" field-type="string|null">

Endzeitpunkt der Sitzung oder `null`, wenn die Sitzung noch nicht beendet wurde.

</ResponseField>

<ResponseField name="sessions[].status" field-type="string">

Aktueller Status der Sitzung.

</ResponseField>

<ResponseField name="sessions[].duration_seconds" field-type="number|null">

Sitzungsdauer in Sekunden.

</ResponseField>

<ResponseField name="sessions[].updated_at" field-type="string">

Zeitpunkt der letzten Änderung.

</ResponseField>

### Sitzung abrufen

```http
GET /api/close-ai/sessions/{sessionId}
```

Ruft eine einzelne Sitzung mit Transkripten, AI-Nachrichten, Zusammenfassung und Analyse ab.

#### Pfadparameter

<ParamField path="sessionId" param-type="string" required="true">

UUID der Sitzung.

</ParamField>

#### Anfrage

<CodeGroup tabs="cURL,JavaScript">

```bash
curl "https://app.talkturo.com/api/close-ai/sessions/4f8c2e19-7c5d-4e1a-9b2d-7a8f3c6d1e20" \
  --cookie /tmp/talkturo-session-cookies.txt
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/close-ai/sessions/4f8c2e19-7c5d-4e1a-9b2d-7a8f3c6d1e20",
  {
    credentials: "include"
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

<ResponseField name="session" field-type="object">

Sitzungsmetadaten einschließlich `id`, `title`, `status`, Zeitstempeln und Dauer.

</ResponseField>

Transkriptsegmente. Das Array ist leer, wenn keine Transkripte vorhanden sind.

</ResponseField>

</ResponseField>

### Sitzung umbenennen

```http
PATCH /api/close-ai/sessions/{sessionId}
```

Ändert den Titel einer Sitzung. Ein leerer String löscht den Titel.

#### Pfadparameter

<ParamField path="sessionId" param-type="string" required="true">

UUID der Sitzung.

</ParamField>

#### Body-Parameter

<ParamField body="title" param-type="string" required="true">

Neuer Sitzungstitel. Verwenden Sie einen leeren String, um den Titel zu löschen.

</ParamField>

#### Anfrage

<CodeGroup tabs="cURL,JavaScript">

```bash
curl -X PATCH "https://app.talkturo.com/api/close-ai/sessions/4f8c2e19-7c5d-4e1a-9b2d-7a8f3c6d1e20" \
  -H "Content-Type: application/json" \
  --data '{"title":"Northwind discovery review"}' \
  --cookie /tmp/talkturo-session-cookies.txt
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/close-ai/sessions/4f8c2e19-7c5d-4e1a-9b2d-7a8f3c6d1e20",
  {
    method: "PATCH",
    credentials: "include",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      title: "Northwind discovery review"
    })
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

<Response>

```json
{
  "ok": true,
  "title": "Northwind discovery review"
}
```

</Response>

### Sitzung löschen

```http
DELETE /api/close-ai/sessions/{sessionId}
```

Löscht eine Sitzung. Die zugehörigen Transkripte, AI-Nachrichten, Zusammenfassungen und Analysen werden über den Foreign-Key-Cascade ebenfalls gelöscht.

#### Pfadparameter

<ParamField path="sessionId" param-type="string" required="true">

UUID der Sitzung.

</ParamField>

#### Anfrage

<CodeGroup tabs="cURL,JavaScript">

```bash
curl -X DELETE "https://app.talkturo.com/api/close-ai/sessions/4f8c2e19-7c5d-4e1a-9b2d-7a8f3c6d1e20" \
  --cookie /tmp/talkturo-session-cookies.txt
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/close-ai/sessions/4f8c2e19-7c5d-4e1a-9b2d-7a8f3c6d1e20",
  {
    method: "DELETE",
    credentials: "include"
  }
);

const data = await response.json();
console.log(data);
```

</CodeGroup>

<Response>

```json
{
  "ok": true,
  "deleted": true
}
```

</Response>

<Callout kind="alert">

Ein Löschvorgang für eine nicht vorhandene oder nicht zugängliche ID wird als erfolgreich gemeldet, wenn Supabase keinen Fehler zurückgibt.

</Callout>

### Prompt-Vorlage erstellen

```http
POST /api/close-ai/prompts
```

Erstellt eine Prompt-Vorlage für die authentifizierte Person.

#### Body-Parameter

<ParamField body="title" param-type="string" required="true">

Titel der Vorlage mit einer Länge von `1` bis `200` Zeichen.

</ParamField>

<ParamField body="prompt" param-type="string" required="true">

Prompt-Inhalt mit einer Länge von `1` bis `20000` Zeichen.

</ParamField>

<ParamField body="is_default" param-type="boolean" required="false">

Markiert die Vorlage als Standardvorlage. Standardwert ist `false`. Wenn der Wert `true` ist, werden bestehende Standardvorlagen der Person zuerst zurückgesetzt.

</ParamField>

<ParamField body="is_template" param-type="boolean" required="false">

Markiert die Vorlage als Template. Standardwert ist `false`.

</ParamField>

#### Anfrage

<CodeGroup tabs="cURL,JavaScript">

```bash
curl -X POST "https://app.talkturo.com/api/close-ai/prompts" \
  -H "Content-Type: application/json" \
  --data '{"title":"Discovery coaching","prompt":"Evaluate discovery depth, question quality, and next-step clarity.","is_default":true,"is_template":true}' \
  --cookie /tmp/talkturo-session-cookies.txt
```

```javascript
const response = await fetch("https://app.talkturo.com/api/close-ai/prompts", {
  method: "POST",
  credentials: "include",
  headers: {
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    title: "Discovery coaching",
    prompt: "Evaluate discovery depth, question quality, and next-step clarity.",
    is_default: true,
    is_template: true
  })
});

const data = await response.json();
console.log(data);
```

</CodeGroup>

## Dashboard

### Dashboard-Daten abrufen

```http

```

#### Abfrageparameter

<ParamField query="account" param-type="string" required="true">

## Fehlerbehandlung

Die Endpunkte verwenden je nach Authentifizierung, Validierung und Datenzugriff unterschiedliche HTTP-Statuscodes.

| Status | Bedeutung |
| --- | --- |
| `400` | Ungültige Anfrage, fehlende Parameter, ungültiges JSON oder Datenbankfehler |
| `401` | Keine gültige Session vorhanden |
| `403` | Kein Zugriff auf den Workspace oder die Ressource |
| `404` | Ressource oder Workspace nicht gefunden |
| `422` | Sitzung enthält keine Transkript-Daten für die Analyse |
| `502` | Close AI Analyse konnte nicht ausgeführt werden |
| `500` | Unerwarteter Fehler oder Fehler beim Speichern |

<Callout kind="info">

Prüfen Sie bei `401` zuerst das Supabase-Session-Cookie. Bei `403` und `404` prüfen Sie zusätzlich die Workspace-Mitgliedschaft und den verwendeten `account`-Slug.

</Callout>
