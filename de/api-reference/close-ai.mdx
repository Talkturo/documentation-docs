## Close-AI-Endpunkte

Close AI stellt Endpunkte für Team-Analysen, Sitzungslisten, Prompt-Vorlagen, Verkaufsskripte und persönliche Analytics-Einstellungen bereit. Alle Endpunkte auf dieser Seite verwenden Sitzungscookie-Authentifizierung.

<Callout kind="info">

Wenn du diese Endpunkte außerhalb der Desktop-App aufrufst, authentifiziere dich zuerst über die Desktop-Authentifizierung. Details findest du unter [Desktop-Auth](/de/api-reference/desktop).

</Callout>

## GET /api/close-ai/sessions

Listet Desktop-Sitzungen auf, die für dich sichtbar sind. Mit `account` kannst du die Ergebnisse auf einen Workspace eingrenzen, ohne ältere Sitzungen mit leerer Workspace-Zuordnung auszuschließen.

<Request>
```bash
curl -X GET "https://app.talkturo.com/api/close-ai/sessions?limit=25&offset=0&q=Acme&account=acme" \
  -H "Cookie: sb-access-token=sb_example_9xmk7q2r; sb-refresh-token=sb_refresh_example_8kd2p1"
```
</Request>

<Response>
```json
{
  "sessions": [
    {
      "id": "3f1da8f0-04c9-4c72-bc74-66fdb88352f0",
      "user_id": "c2b1f6df-2d25-4d7c-a24b-81218f4153b3",
      "account_id": "7f10f114-2fb7-4c39-91d8-0e3e4e31d011",
      "title": "Call with Acme Corp",
      "session_type": "sales_call",
      "started_at": "2026-08-24T10:00:00Z",
      "ended_at": "2026-08-24T10:30:00Z",
      "status": "completed",
      "duration_seconds": 1800,
      "updated_at": "2026-08-24T10:30:00Z"
    }
  ],
  "count": 123
}
```
</Response>

### Query-Parameter

<ParamField query="limit" param-type="integer" required="false">
Maximale Anzahl zurückgegebener Sitzungen. Gültige Werte liegen zwischen `1` und `100`. Standardwert ist `50`.
</ParamField>

<ParamField query="offset" param-type="integer" required="false">
Startposition für die Paginierung. Der Wert muss `0` oder größer sein. Standardwert ist `0`.
</ParamField>

<ParamField query="q" param-type="string" required="false">
Suchbegriff für eine `ILIKE`-Suche auf dem Sitzungs-Titel.
</ParamField>

<ParamField query="account" param-type="string" required="false">
Optionaler Workspace-Slug. Wenn gesetzt, werden Workspace-Sitzungen sowie ältere Sitzungen mit `account_id = null` berücksichtigt.
</ParamField>

### Antwortfelder

<ResponseField name="sessions" field-type="array" required="true">
Die Liste der gefundenen Desktop-Sitzungen, sortiert nach `started_at` absteigend.
</ResponseField>

<ResponseField name="count" field-type="integer" required="true">
Gesamtzahl aller Treffer für die aktuelle Filterkombination.
</ResponseField>

## POST /api/close-ai/prompts

Erstellt eine neue Prompt-Vorlage für den angemeldeten Benutzer. Wenn `is_default` auf `true` gesetzt ist, entfernt der Endpunkt den Standardstatus von allen anderen Vorlagen dieses Benutzers.

<Request>
```bash
curl -X POST "https://app.talkturo.com/api/close-ai/prompts" \
  -H "Content-Type: application/json" \
  -H "Cookie: sb-access-token=sb_example_9xmk7q2r; sb-refresh-token=sb_refresh_example_8kd2p1" \
  -d '{
    "title": "Objection review",
    "prompt": "Focus on pricing objections, buying signals, and next-step clarity.",
    "is_default": true,
    "is_template": false
  }'
```
</Request>

<Response tabs="201,400">
```json
{
  "preset": {
    "id": "0d5f67b0-7637-4c74-82f3-c54eec5df66e",
    "user_id": "c2b1f6df-2d25-4d7c-a24b-81218f4153b3",
    "title": "Objection review",
    "prompt": "Focus on pricing objections, buying signals, and next-step clarity.",
    "is_default": true,
    "is_template": false,
    "created_at": "2026-08-24T09:00:00Z",
    "updated_at": "2026-08-24T09:00:00Z"
  }
}
```

```json
{
  "error": "invalid_body",
  "detail": {
    "fieldErrors": {
      "title": [
        "String must contain at least 1 character"
      ]
    }
  }
}
```
</Response>

### Body-Parameter

<ParamField body="title" param-type="string" required="true">
Titel der Vorlage. Muss zwischen `1` und `200` Zeichen lang sein.
</ParamField>

<ParamField body="prompt" param-type="string" required="true">
Prompt-Inhalt. Muss zwischen `1` und `20000` Zeichen lang sein.
</ParamField>

<ParamField body="is_default" param-type="boolean" required="false">
Markiert die Vorlage als Standardvorlage für den Benutzer. Standardwert ist `false`.
</ParamField>

<ParamField body="is_template" param-type="boolean" required="false">
Markiert die Vorlage als Template. Standardwert ist `false`.
</ParamField>

### Antwortfelder

<ResponseField name="preset" field-type="object" required="true">
Die neu erstellte Prompt-Vorlage.
</ResponseField>

## Authentifizierung und Verhalten

Alle Endpunkte auf dieser Seite erwarten eine gültige Sitzung. Die Autorisierung wird je nach Ressource unterschiedlich durchgesetzt.

- `/api/close-ai/dashboard` prüft zusätzlich die Workspace-Mitgliedschaft explizit.
- `/api/close-ai/sessions` verwendet Row Level Security für benutzerspezifische Sichtbarkeit.
- `/api/close-ai/prompts` und `/api/close-ai/settings` sind auf den angemeldeten Benutzer beschränkt.
- `/api/close-ai/scripts` verwendet Row Level Security für Workspace-Zugriff.

<Callout kind="info">

Fehlerantworten können je nach Endpunkt Validierungsfehler, Autorisierungsfehler oder Datenbankfehler enthalten. Die Beispiele auf dieser Seite zeigen die typischen Erfolgs- und Fehlerformen.

</Callout>
