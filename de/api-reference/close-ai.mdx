## Close AI-Endpunkte

Verwalten Sie Close AI Desktop-Sitzungen, Prompt-Vorlagen, teamweite Analytics-Dashboards und verzweigte Vertriebsskripte über REST-Endpunkte, die für die Close AI Desktop-Erfahrung entwickelt wurden.

<Callout kind="info">

Alle Close AI-Endpunkte erfordern ein authentifiziertes Sitzungs-Cookie. Row-Level-Security-Richtlinien erzwingen benutzerspezifischen Zugriff auf Sitzungen, Prompts, Dashboards und Skripte.

</Callout>

### Endpunktübersicht

| Methode | Pfad |
| --- | --- |
| GET | `https://api.talkturo.com/close-ai/sessions` |
| GET | `https://api.talkturo.com/close-ai/sessions/:id` |
| PATCH | `https://api.talkturo.com/close-ai/sessions/:id` |
| DELETE | `https://api.talkturo.com/close-ai/sessions/:id` |
| GET | `https://api.talkturo.com/close-ai/prompts` |
| POST | `https://api.talkturo.com/close-ai/prompts` |
| GET | `https://api.talkturo.com/close-ai/dashboard` |
| GET | `https://api.talkturo.com/close-ai/scripts` |
| POST | `https://api.talkturo.com/close-ai/scripts` |
| PUT | `https://api.talkturo.com/close-ai/scripts/:id` |
| DELETE | `https://api.talkturo.com/close-ai/scripts/:id` |

## Sitzungen

Rufen Sie gespeicherte Close AI Desktop-Sitzungen ab, lesen Sie eine einzelne Sitzung, aktualisieren Sie den sichtbaren Titel oder löschen Sie nicht mehr benötigte Aufzeichnungen.

### Sitzungen auflisten

Gibt die Sitzungen zurück, auf die der authentifizierte Benutzer Zugriff hat.

<Request tabs="cURL,JavaScript" default-tab="1">

```bash
curl -X GET "https://api.talkturo.com/close-ai/sessions" \
  -H "Cookie: tt_session=tt_session_example_9xmk7q2r"
```

```javascript
const response = await fetch("https://api.talkturo.com/close-ai/sessions", {
  method: "GET",
  headers: {
    Cookie: "tt_session=tt_session_example_9xmk7q2r",

const data = await response.json();
```

### Sitzungstitel aktualisieren

```bash
  -H "Content-Type: application/json" \
  -H "Cookie: tt_session=tt_session_example_9xmk7q2r" \
```
