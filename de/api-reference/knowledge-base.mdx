## Wissensdatenbank-Endpunkte

Verwalten Sie Dateien in der Wissensdatenbank Ihres Arbeitsbereichs und ordnen Sie vorhandene Bibliotheksdateien Ihren Assistenten zu. Die Endpunkte unterstützen Uploads, Suche, Downloads, Neuverarbeitung und das Entfernen von Zuordnungen für retrievalbasierte Antworten während Sprachanrufen.

<Callout kind="info">

Die Wissensdatenbank-API unterstützt Session-JWT- und API-Schlüssel-Authentifizierung. API-Schlüssel benötigen `kb:read` für Lese- und Suchvorgänge sowie `kb:write` für Uploads, Löschung, Neuverarbeitung und Änderungen an Assistenten-Zuordnungen.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck | Berechtigung |
| --- | --- | --- | --- |
| `POST` | `/api/kb/files` | Datei in die Arbeitsbereich-Bibliothek hochladen | `kb:write` |
| `GET` | `/api/kb/files` | Dateien der Arbeitsbereich-Bibliothek auflisten | `kb:read` |
| `GET` | `/api/kb/files/{fileId}` | Dateimetadaten abrufen | `kb:read` |
| `DELETE` | `/api/kb/files/{fileId}` | Datei dauerhaft aus der Bibliothek löschen | `kb:write` |
| `GET` | `/api/kb/files/{fileId}/download` | Signierte Download-URL abrufen | `kb:read` |
| `POST` | `/api/kb/files/{fileId}/reprocess` | Datei erneut verarbeiten | `kb:write` |
| `POST` | `/api/kb/search` | Wissensdatenbank durchsuchen | `kb:read` |
| `GET` | `/api/assistants/{assistantId}/knowledge-base` | Dem Assistenten zugeordnete Dateien auflisten | `kb:read` |
| `POST` | `/api/assistants/{assistantId}/knowledge-base` | Vorhandene Bibliotheksdatei einem Assistenten zuordnen | `kb:write` |
| `DELETE` | `/api/assistants/{assistantId}/knowledge-base/{fileId}` | Datei vom Assistenten entfernen | `kb:write` |

## Dateiobjekt

Die Datei-Endpunkte verwenden ein gemeinsames Dateiobjekt. Die Datei gehört zur Arbeitsbereich-Bibliothek und kann unabhängig davon einem oder mehreren Assistenten zugeordnet werden.

<ResponseField name="id" field-type="uuid" required="true">
Eindeutige Kennung der Datei.
</ResponseField>

<ResponseField name="filename" field-type="string" required="true">
Ursprünglicher Dateiname.
</ResponseField>

<ResponseField name="mime_type" field-type="string" required="true">
MIME-Typ der Datei, zum Beispiel `application/pdf`.
</ResponseField>

<ResponseField name="size_bytes" field-type="number" required="true">
Dateigröße in Bytes.
</ResponseField>

<ResponseField name="status" field-type="string" required="true">
Verarbeitungsstatus der Datei. Mögliche Werte sind `pending`, `parsing`, `embedding`, `indexing`, `ready` und `failed`.
</ResponseField>

<ResponseField name="status_error" field-type="string" required="true">
Fehlerbeschreibung, wenn die Verarbeitung fehlgeschlagen ist. Der Wert ist `null`, wenn kein Fehler vorliegt.
</ResponseField>

<ResponseField name="char_count" field-type="number" required="true">
Anzahl der aus der Datei extrahierten Zeichen. Der Wert ist `null`, solange die Extraktion noch nicht abgeschlossen ist.
</ResponseField>

<ResponseField name="chunk_count" field-type="number" required="true">
Anzahl der für die Suche erzeugten Textabschnitte. Der Wert ist `null`, solange die Verarbeitung noch nicht abgeschlossen ist.
</ResponseField>

<ResponseField name="created_at" field-type="string" required="true">
Zeitstempel der Dateierstellung im ISO-8601-Format.
</ResponseField>

<ResponseField name="updated_at" field-type="string" required="true">
Zeitstempel der letzten Änderung am Dateiobjekt im ISO-8601-Format.
</ResponseField>

<Callout kind="info">

Die Verarbeitung durchläuft normalerweise `pending`, `parsing`, `embedding` und `indexing`, bevor sie `ready` erreicht. Bei einem Fehler wechselt der Status zu `failed`, und `status_error` enthält weitere Informationen.

</Callout>

## Datei hochladen

Laden Sie eine PDF-, DOCX-, TXT- oder MD-Datei mit `multipart/form-data` in die Arbeitsbereich-Bibliothek hoch. Die maximale Dateigröße beträgt 1 GiB.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request POST \
  --url "https://app.talkturo.com/api/kb/files" \
  --header "Authorization: Bearer sk_test_example_7Kp3mN8qL2" \
  --form "file=@./docs/acme-support-playbook.pdf"
```

```javascript
const formData = new FormData();
formData.append("file", fileInput.files[0]);

const response = await fetch("https://app.talkturo.com/api/kb/files", {
  method: "POST",
  headers: {
    Authorization: "Bearer sk_test_example_7Kp3mN8qL2",
  },
  body: formData,
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="201">
```json
{
  "success": true,
  "file": {
    "id": "6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714",
    "filename": "acme-support-playbook.pdf",
    "mime_type": "application/pdf",
    "size_bytes": 248193,
    "status": "pending",
    "status_error": null,
    "char_count": null,
    "chunk_count": null,
    "created_at": "2026-02-11T14:22:09.000Z",
    "updated_at": "2026-02-11T14:22:09.000Z"
  }

```
</Response>

### Body-Parameter

<ParamField body="file" param-type="binary" required="true">
Die hochzuladende PDF-, DOCX-, TXT- oder MD-Datei. Senden Sie das Feld als `multipart/form-data`. Die Datei darf höchstens 1 GiB groß sein.
</ParamField>

Der Upload dedupliziert Dateien anhand ihres Inhalts. Ein erneuter Upload derselben Datei erzeugt keine zusätzliche Bibliotheksdatei. Für den Speicherverbrauch sind die ersten 50 MiB kostenlos; jedes weitere 50-MiB-Intervall belastet ein Credit.

## Datei löschen

Löschen Sie eine Datei dauerhaft aus der Arbeitsbereich-Bibliothek. Das Löschen entfernt die Datei auch aus allen Assistenten-Zuordnungen. Bereits belastete Speichercredits werden nicht zurückgegeben.

<Callout kind="alert">

Das Löschen ist endgültig. Laden Sie die Datei erneut hoch, wenn Sie sie später wieder benötigen.

</Callout>

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request DELETE \
  --url "https://app.talkturo.com/api/kb/files/6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714" \
  --header "Authorization: Bearer sk_test_example_7Kp3mN8qL2"
```

## Wissensdatenbank durchsuchen

Durchsuchen Sie die Wissensdatenbank mit einer Assistentenkennung und einer natürlichsprachlichen Anfrage. Die Suche liefert die relevantesten Textabschnitte aus den Dateien, die diesem Assistenten zugeordnet sind.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request POST \
  --url "https://app.talkturo.com/api/kb/search" \
  --header "Authorization: Bearer sk_test_example_7Kp3mN8qL2" \
  --header "Content-Type: application/json" \
  --data '{
    "assistant_id": "9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2",
    "query": "What is the return window for annual subscriptions?",
    "top_k": 5
  }'
```

```javascript
const response = await fetch("https://app.talkturo.com/api/kb/search", {
  method: "POST",
  headers: {
    Authorization: "Bearer sk_test_example_7Kp3mN8qL2",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    assistant_id: "9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2",
    query: "What is the return window for annual subscriptions?",
    top_k: 5,
  }),
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200">

## Typischer Workflow

Verwenden Sie die beiden API-Oberflächen in dieser Reihenfolge, wenn Sie Dokumente für einen Assistenten bereitstellen:

<Steps>
<Step title="Datei in die Bibliothek hochladen" icon="upload">

Senden Sie die Datei mit `POST /api/kb/files`. Warten Sie, bis die Datei den Status `ready` erreicht, bevor Sie sie durchsuchen oder einem Assistenten zuordnen.

</Step>

<Step title="Verarbeitungsstatus prüfen" icon="check-circle">

Rufen Sie `GET /api/kb/files/{fileId}` oder `GET /api/kb/files` auf. Bei `failed` finden Sie die Ursache in `status_error`; mit `POST /api/kb/files/{fileId}/reprocess` starten Sie die Verarbeitung erneut.

</Step>

<Step title="Datei dem Assistenten zuordnen" icon="users">

Senden Sie `POST /api/assistants/{assistantId}/knowledge-base` mit der vorhandenen Datei-ID im Feld `file_id`.

Die Antwort enthält `success: true`. Bei einer bereits bestehenden Zuordnung kann die Antwort zusätzlich `idempotent: true` enthalten.

</Step>

<Step title="Wissensdatenbank durchsuchen" icon="database">

Senden Sie `POST /api/kb/search` mit `assistant_id`, `query` und `top_k`. Die Antwort enthält die relevantesten Treffer aus den dem Assistenten zugeordneten Dateien.

</Step>

<Step title="Zuordnung oder Datei entfernen" icon="trash">

Entfernen Sie eine Datei mit dem Assistenten-DELETE-Endpunkt, wenn sie nur für diesen Assistenten nicht mehr verfügbar sein soll. Verwenden Sie den Bibliotheks-DELETE-Endpunkt nur, wenn Sie die Datei dauerhaft aus dem Arbeitsbereich löschen möchten.

</Step>
</Steps>
