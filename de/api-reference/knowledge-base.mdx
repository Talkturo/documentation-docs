## Wissensdatenbank-Endpunkte

Verwalten Sie assistentenspezifische Wissensdatenbank-Dateien mit sitzungsauthentifizierten Endpunkten unter `/api/assistants/{assistantId}/knowledge-base`. Hochgeladene Dateien werden pro Assistent gespeichert und für Retrieval während Anrufen verarbeitet.

<Callout kind="info">

Diese Endpunkte unterstützen duale Authentifizierung. Verwenden Sie entweder eine authentifizierte Browser-Sitzung oder einen API-Schlüssel. Bei Verwendung eines API-Schlüssels benötigt `GET` den Scope `kb:read` und `POST` den Scope `kb:write`.

</Callout>

<Callout kind="alert">

Upload-Anfragen verwenden `multipart/form-data` und müssen ein Dateifeld enthalten. Die Dateiverarbeitung erfolgt nach dem Upload; eine neu hochgeladene Datei kann daher mit einem noch nicht bereiten `status` erscheinen, bevor sie für Retrieval verfügbar wird.

</Callout>

## Endpunktübersicht

| Methode | Pfad | Zweck | Auth |
| --- | --- | --- | --- |
| `GET` | `/api/assistants/{assistantId}/knowledge-base` | Wissensdatenbank-Dateien eines Assistenten auflisten | API-Schlüssel oder Sitzung |
| `POST` | `/api/assistants/{assistantId}/knowledge-base` | Wissensdatenbank-Datei hochladen | API-Schlüssel oder Sitzung |
| `POST` (vorhandene Datei anhängen) | `/api/assistants/{assistantId}/knowledge-base` | Vorhandene Wissensdatenbank-Datei per JSON-Body mit `file_id` anhängen | API-Schlüssel oder Sitzung |
| `DELETE` | `/api/assistants/{assistantId}/knowledge-base/{fileId}` | Wissensdatenbank-Datei löschen | Sitzungs-Cookie |
| `GET` | `/api/assistants/{assistantId}/billing/estimate` | Kostenschätzung für die Wissensdatenbank-Verarbeitung abrufen | Sitzungs-Cookie |

## Wissensdatenbank-Dateien auflisten

```bash

  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base" \
```

## Wissensdatenbank-Datei hochladen

Laden Sie eine Datei mit `multipart/form-data` in die Wissensdatenbank eines Assistenten hoch.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request POST \
  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base" \
  --cookie "sb-access-token=sb_example_session_token" \
  --form "file=@./docs/acme-support-playbook.pdf"
```

```javascript
const formData = new FormData();
formData.append("file", fileInput.files[0]);

  "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base",
  {
    method: "POST",
    body: formData,
    credentials: "include",
  }
);

const data = await response.json();
console.log(data);
```

## Vorhandene Datei anhängen

Hängen Sie eine bereits vorhandene Wissensdatenbank-Datei an einen Assistenten an, indem Sie einen JSON-Body mit `file_id` senden.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl --request POST \
  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base" \
  --header "Content-Type: application/json" \
  --header "Authorization: Bearer tk_example_9xmk7q2r" \
  --data '{
    "file_id": "6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714"
  }'
```

```javascript
const response = await fetch(
  "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      Authorization: "Bearer tk_example_9xmk7q2r",
    },
    body: JSON.stringify({
      file_id: "6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714",
    }),
  }
);

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200,200 idempotent" default-tab="1">
```json
{
  "success": true,
  "file": {
    "id": "6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714",
    "filename": "acme-support-playbook.pdf",
    "size_bytes": 248193,
    "mime_type": "application/pdf",
    "status": "ready",
    "status_error": null,
    "char_count": 18420,
    "chunk_count": 37,
    "created_at": "2026-02-11T14:22:09.000Z",
    "updated_at": "2026-02-11T14:22:46.000Z"
  }
}
```

```json
{
  "success": true,
  "idempotent": true
}
```
</Response>

Diese Anfrage ist idempotent. Wenn die Datei bereits an den Assistenten angehängt ist, gibt der Endpunkt `success: true` und `idempotent: true` zurück.

Die Datei muss bereits existieren und zum selben Konto gehören wie der Assistent. Bei Verwendung eines API-Schlüssels benötigt diese Anfrage den Scope `kb:write`.

## Wissensdatenbank-Datei löschen

Entfernen Sie eine Datei aus der Wissensdatenbank eines Assistenten.

<Request tabs="cURL" default-tab="1">
```bash
curl --request DELETE \
  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/knowledge-base/6b9d58b9-4b43-4f94-8cb8-2d3d9f18d714" \
  --cookie "sb-access-token=sb_example_session_token"
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "message": "File deleted"
}
```
</Response>

### Pfadparameter

<ParamField path="assistantId" param-type="uuid" required="true">
Assistentenkennung, der die Datei gehört.
</ParamField>

<ParamField path="fileId" param-type="uuid" required="true">
Kennung der zu löschenden Wissensdatenbank-Datei.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt `true` zurück, wenn die Datei entfernt wurde.
</ResponseField>

<ResponseField name="message" field-type="string" required="true">
Menschenlesbares Löschergebnis.
</ResponseField>

## Abrechnungsschätzung abrufen

Rufen Sie die Abrechnungsschätzung für die Wissensdatenbank-Verarbeitung eines Assistenten ab.

```bash
curl --request GET \
  --url "https://app.talkturo.com/api/assistants/9d3f6cf5-3c12-4e60-bd8a-1b1d57a8c4d2/billing/estimate" \
  --cookie "sb-access-token=sb_example_session_token"
```

Die Antwort enthält ein Erfolgsflag und ein `estimate`-Objekt.

### Pfadparameter

<ParamField path="assistantId" param-type="uuid" required="true">
Assistentenkennung, anhand derer die Schätzung berechnet wird.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt `true` zurück, wenn die Schätzung verfügbar ist.
</ResponseField>

<ResponseField name="estimate" field-type="object" required="true">
Details der Abrechnungsschätzung für die Wissensdatenbank-Verarbeitung. Die Objektstruktur hängt von der aktuellen Abrechnungsimplementierung ab.
</ResponseField>

## Typischer Workflow

Verwenden Sie die Wissensdatenbank-Endpunkte in dieser Reihenfolge, wenn Sie die Dokumentenverwaltung automatisieren:

<Steps>
<Step title="Datei hochladen" icon="upload">

Senden Sie eine `POST`-Anfrage mit `multipart/form-data` an den Wissensdatenbank-Endpunkt des Assistenten.

Erfolg sieht aus wie eine Antwort mit `success: true` und einem `file`-Objekt.

</Step>
<Step title="Verarbeitungsstatus abfragen" icon="check-circle">

Rufen Sie `GET /api/assistants/{assistantId}/knowledge-base` auf und prüfen Sie den `status` jeder Datei.

Ihr Workflow kann fortfahren, sobald die hochgeladene Datei in der Liste erscheint und der Status anzeigt, dass die Verarbeitung abgeschlossen ist.

</Step>
<Step title="Verarbeitungskosten bei Bedarf schätzen" icon="bar-chart">

Rufen Sie `GET /api/assistants/{assistantId}/billing/estimate` vor oder nach dem Upload auf, wenn Sie Abrechnungstransparenz für die Wissensdatenbank-Nutzung des Assistenten benötigen.

Erfolg sieht aus wie eine Antwort mit `success: true` und einem `estimate`-Objekt.

</Step>
<Step title="Veraltete Dateien entfernen" icon="trash">

Löschen Sie Dateien, die der Assistent nicht mehr verwenden soll, mit `DELETE /api/assistants/{assistantId}/knowledge-base/{fileId}`.

Eine erfolgreiche Löschung gibt `success: true` und eine Bestätigungsnachricht zurück.

</Step>
</Steps>
