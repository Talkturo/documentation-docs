## Assistenten verwalten

Erstellen Sie Assistenten, aktualisieren Sie ihre Konfiguration, klonen Sie bestehende Setups, löschen Sie nicht mehr benötigte Assistenten und rufen Sie Nutzungsdaten für Reporting oder operative Prüfungen ab.

Alle Assistant-Endpunkte unterstützen Dual-Authentifizierung über `withApiAuth`. Authentifizieren Sie sich entweder mit einem Talkturo-API-Schlüssel oder mit einem authentifizierten Session-Cookie.

Basispfad: `/api/assistants`

## Endpunktübersicht

| Methode | Pfad | Beschreibung |
| --- | --- | --- |
| `POST` | `/api/assistants` | Erstellt einen neuen Assistenten |
| `PATCH` | `/api/assistants/{assistantId}` | Aktualisiert die Konfiguration eines vorhandenen Assistenten |
| `DELETE` | `/api/assistants/{assistantId}` | Löscht einen Assistenten |
| `POST` | `/api/assistants/{assistantId}/clone` | Klont einen vorhandenen Assistenten |
| `GET` | `/api/assistants/{assistantId}/usage-stats` | Ruft Nutzungsstatistiken für einen Assistenten ab |
| `GET` | `/api/assistants/{assistantId}/tool-configs` | Werkzeugkonfigurationen auflisten |
| `GET` | `/api/assistants/{assistantId}/tool-configs/{toolType}` | Spezifische Werkzeugkonfiguration abrufen |
| `POST` | `/api/assistants/{assistantId}/tool-configs/{toolType}` | Werkzeugkonfiguration erstellen oder aktualisieren |
| `DELETE` | `/api/assistants/{assistantId}/tool-configs/{toolType}` | Werkzeugkonfiguration(en) löschen |
| `GET` | `/api/assistants/{assistantId}/billing/estimate` | Kostenschätzung pro Minute |

## Einen Assistenten erstellen

Erstellen Sie einen Assistenten mit einem Kontoslug und einem Namen. Optional können Sie auch eine Vorlage angeben, um den Assistententyp beim Anlegen zu setzen.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X POST "https://api.talkturo.com/api/assistants" \
  -H "Authorization: Bearer tk_test_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "accountSlug": "acme-sales",
    "name": "Inbound Qualification Assistant",
    "templateId": "tmpl_voice_inbound"
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/assistants", {
  method: "POST",
  headers: {
    "Authorization": "Bearer tk_test_example_9xmk7q2r",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    accountSlug: "acme-sales",
    name: "Inbound Qualification Assistant",
    templateId: "tmpl_voice_inbound"
  })
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "assistant": {
    "id": "7d2d1b8f-1f2e-4c24-8d31-6bf0c3d54b4e",
```

## Einen Assistenten aktualisieren

Aktualisieren Sie einen vorhandenen Assistenten, indem Sie seine Kennung im Pfad und die zu ändernden Felder im Request-Body übergeben. Der Endpunkt akzeptiert `accountSlug` optional und validiert `transcriptor_options` gegen den gewählten Provider und das Modell, bevor Änderungen gespeichert werden.

<Request tabs="cURL,JavaScript" default-tab="1">
```bash
curl -X PATCH "https://api.talkturo.com/api/assistants/7d2d1b8f-1f2e-4c24-8d31-6bf0c3d54b4e" \
  -H "Authorization: Bearer tk_test_example_9xmk7q2r" \
  -H "Content-Type: application/json" \
  -d '{
    "accountSlug": "acme-sales",
    "name": "Inbound Qualification Assistant v2",
    "voice": "alloy",
    "model": "gpt-4o-realtime",
    "transcriptor_options": {
      "provider": "deepgram",
      "model": "nova-2"
    }
  }'
```

```javascript
const response = await fetch("https://api.talkturo.com/api/assistants/7d2d1b8f-1f2e-4c24-8d31-6bf0c3d54b4e", {
  method: "PATCH",
  headers: {
    "Authorization": "Bearer tk_test_example_9xmk7q2r",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    accountSlug: "acme-sales",
    name: "Inbound Qualification Assistant v2",
    voice: "alloy",
    model: "gpt-4o-realtime",
    transcriptor_options: {
      provider: "deepgram",
      model: "nova-2"
    }
  })
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "assistant": {
    "id": "7d2d1b8f-1f2e-4c24-8d31-6bf0c3d54b4e",
    "account_slug": "acme-sales",
    "name": "Inbound Qualification Assistant v2",
    "type": "tmpl_voice_inbound",
    "created_at": "2025-01-14T10:22:31.000Z",
    "updated_at": "2025-01-14T11:04:09.000Z"
  }
}
```
</Response>

### Pfadparameter

<ParamField path="assistantId" param-type="string" required="true">
Die UUID des zu aktualisierenden Assistenten.
</ParamField>

### Request-Body

<ParamField body="accountSlug" param-type="string" required="false">
Optionaler Kontoslug. Geben Sie ihn an, wenn Ihre Integration das Zielkonto explizit festlegen soll.
</ParamField>

<ParamField body="...assistant fields" param-type="object" required="false">
Beliebige Assistant-Felder, die aktualisiert werden sollen. Der Endpunkt akzeptiert partielle Updates.
</ParamField>

<ParamField body="transcriptor_options" param-type="object" required="false">
Optionale Transkriptionskonfiguration. Talkturo validiert diese Konfiguration gegen den ausgewählten Provider und das Modell, bevor die Aktualisierung gespeichert wird.
</ParamField>

### Antwortfelder

<ResponseField name="success" field-type="boolean" required="true">
Gibt an, ob die Anfrage erfolgreich war.
</ResponseField>

<ResponseField name="assistant" field-type="object" required="true">
Das aktualisierte Assistant-Objekt.
</ResponseField>

## Einen Assistenten löschen

Löschen Sie einen Assistenten dauerhaft über seine Kennung. Der Endpunkt prüft, ob der Assistent dem authentifizierten Konto gehört, bevor der Löschvorgang ausgeführt wird.

```bash
curl -X DELETE "https://api.talkturo.com/api/assistants/7d2d1b8f-1f2e-4c24-8d31-6bf0c3d54b4e" \
  -H "Authorization: Bearer tk_test_example_9xmk7q2r"
```

```javascript
const response = await fetch("https://api.talkturo.com/api/assistants/7d2d1b8f-1f2e-4c24-8d31-6bf0c3d54b4e", {
  method: "DELETE",
  headers: {
    "Authorization": "Bearer tk_test_example_9xmk7q2r"
  }
});

const data = await response.json();
console.log(data);
```
</Request>

<Response tabs="200">
```json
{
  "success": true,
  "message": "Assistant deleted successfully"
}
```
</Response>

## Werkzeugkonfigurationen

Werkzeugkonfigurationen ermöglichen es Ihnen, Drittanbieter-Tools wie Cal.com-Scheduling, Zapier oder benutzerdefinierte Webhooks an einen Assistenten anzuhängen. Alle Endpunkte erfordern Session-Authentifizierung.

| Methode | Pfad | Beschreibung |
| --- | --- | --- |
| `GET` | `/api/assistants/{assistantId}/tool-configs` | Alle aktivierten Werkzeugkonfigurationen auflisten |
| `GET` | `/api/assistants/{assistantId}/tool-configs/{toolType}` | Konfigurationen für einen bestimmten Werkzeugtyp abrufen |
| `POST` | `/api/assistants/{assistantId}/tool-configs/{toolType}` | Werkzeugkonfiguration erstellen oder aktualisieren |
| `DELETE` | `/api/assistants/{assistantId}/tool-configs/{toolType}` | Werkzeugkonfiguration(en) löschen |

### Konfigurationen für einen Werkzeugtyp abrufen

Rufen Sie Konfigurationen für einen einzelnen Werkzeugtyp ab. Verwenden Sie `configId`, wenn Sie eine bestimmte Konfiguration adressieren möchten, oder `all=true`, um alle Konfigurationen dieses Typs zurückzugeben.

### Pfadparameter

<ParamField path="assistantId" param-type="string" required="true">
Die UUID des Assistenten, dessen Werkzeugkonfigurationen Sie abrufen möchten.
</ParamField>

<ParamField path="toolType" param-type="string" required="true" enum="cal_com,zapier,cal_com_schedule,cal_com_get_bookings,cal_com_cancel">
Der Werkzeugtyp. Gültige Werte sind `cal_com`, `zapier`, `cal_com_schedule`, `cal_com_get_bookings` und `cal_com_cancel`.
</ParamField>

### Abfrageparameter

<ParamField query="configId" param-type="string" required="false">
Optionale UUID einer bestimmten Konfiguration.
</ParamField>

<ParamField query="all" param-type="string" required="false">
Setzen Sie den Wert auf `true`, um alle Konfigurationen dieses Typs zurückzugeben.
</ParamField>

### Werkzeugkonfiguration erstellen oder aktualisieren

Erstellen Sie eine neue Werkzeugkonfiguration oder aktualisieren Sie eine vorhandene Konfiguration für den angegebenen Werkzeugtyp.

### Abfrageparameter

<ParamField query="configId" param-type="string" required="false">
Optionale UUID einer vorhandenen Konfiguration, die aktualisiert werden soll.
</ParamField>

### Request-Body

<ParamField body="config" param-type="object" required="true">
Freiform-Konfiguration für das Werkzeug.
</ParamField>

<ParamField body="is_enabled" param-type="boolean" required="false">
Aktiviert oder deaktiviert die Konfiguration. Standardwert ist `true`.
</ParamField>

### Werkzeugkonfigurationen löschen

Löschen Sie entweder eine bestimmte Konfiguration oder alle Konfigurationen eines Werkzeugtyps.

### Abfrageparameter

<ParamField query="configId" param-type="string" required="false">
Optionale UUID einer bestimmten Konfiguration. Wenn weggelassen, löscht der Endpunkt alle Konfigurationen dieses Typs.
</ParamField>

<Callout kind="info">
Die Werkzeugkonfigurations-Endpunkte verwenden Session-Authentifizierung und stehen nicht über API-Schlüssel zur Verfügung.
</Callout>

## Kostenschätzung

Gibt eine geschätzte Kosten pro Minute in Credits zurück, basierend auf den Provider-Einstellungen des Assistenten und dem aktiven Kostenkatalog.

### Endpunkt

`GET /api/assistants/{assistantId}/billing/estimate`

### Pfadparameter

<ParamField path="assistantId" param-type="string" required="true">
Die UUID des Assistenten, für den Sie die Kostenschätzung abrufen möchten.
</ParamField>

### Abfrageparameter

<ParamField query="accountId" param-type="string" required="true">
Konto-UUID.
</ParamField>

<ParamField query="llm_provider" param-type="string" required="false">
LLM-Provider überschreiben für Live-Vorschau.
</ParamField>

<ParamField query="llm_model" param-type="string" required="false">
LLM-Modell überschreiben.
</ParamField>

<ParamField query="stt_provider" param-type="string" required="false">
STT-Provider überschreiben.
</ParamField>

<ParamField query="stt_model" param-type="string" required="false">
STT-Modell überschreiben.
</ParamField>

<ParamField query="tts_provider" param-type="string" required="false">
TTS-Provider überschreiben.
</ParamField>

<ParamField query="tts_model" param-type="string" required="false">
TTS-Modell überschreiben.
</ParamField>

<ParamField query="is_realtime" param-type="string" required="false">
Setzen Sie den Wert auf `true` oder `1` für eine Realtime-Modus-Schätzung.
</ParamField>

### Antwortfelder

<ResponseField name="catalog" field-type="object" required="true">
Aktiver Kostenkatalog mit Kennung und Namen.
</ResponseField>

<ResponseField name="catalog.id" field-type="string" required="true">
Die eindeutige Kennung des aktiven Kostenkatalogs.
</ResponseField>

<ResponseField name="catalog.name" field-type="string" required="true">
Der Name des aktiven Kostenkatalogs.
</ResponseField>

<ResponseField name="assumptions" field-type="object" required="true">
Annahmen, die zur Berechnung der Schätzung verwendet werden.
</ResponseField>

<ResponseField name="assumptions.chars_per_minute" field-type="number" required="true">
Angenommene Zeichen pro Minute für die TTS-Berechnung.
</ResponseField>

<ResponseField name="assumptions.prompt_tokens_per_minute" field-type="number" required="true">
Angenommene Prompt-Tokens pro Minute für die LLM-Berechnung.
</ResponseField>

<ResponseField name="assumptions.completion_tokens_per_minute" field-type="number" required="true">
Angenommene Completion-Tokens pro Minute für die LLM-Berechnung.
</ResponseField>

<ResponseField name="assistant" field-type="object" required="true">
Effektive Provider- und Modellinformationen des Assistenten für die Schätzung.
</ResponseField>

<ResponseField name="rates" field-type="object" required="true">
Angewendete Raten pro Minute und pro 1.000 Einheiten.
</ResponseField>

<ResponseField name="breakdown_credits_per_minute" field-type="object" required="true">
Aufschlüsselung der geschätzten Kosten pro Minute nach STT-, TTS-, LLM- und Telefonie-Komponenten.
</ResponseField>

<ResponseField name="estimated_credits_per_minute" field-type="number" required="true">
Geschätzte Gesamtkosten pro Minute in Credits.
</ResponseField>

## Gemeinsame Antwortstruktur

Die Assistant-Endpunkte verwenden eine konsistente Antwortform mit einem `success`-Flag und einem ressourcenspezifischen Payload.

<Response tabs="Success,Delete success">
```json
{
  "success": true,
  "assistant": {
    "id": "7d2d1b8f-1f2e-4c24-8d31-6bf0c3d54b4e",
    "account_slug": "acme-sales",
    "name": "Inbound Qualification Assistant",
    "type": "tmpl_voice_inbound",
    "created_at": "2025-01-14T10:22:31.000Z",
    "updated_at": "2025-01-14T10:22:31.000Z"
  }
}
```

```json
{
  "success": true,
  "message": "Assistant deleted successfully"
}
```
</Response>

<Callout kind="info">
Einzelne Endpunkte geben unterschiedliche Payload-Schlüssel zurück, zum Beispiel `assistant` oder `message`. Prüfen Sie die Antwortform des jeweiligen Endpunkts, wenn Sie Ihren Client implementieren.
</Callout>
