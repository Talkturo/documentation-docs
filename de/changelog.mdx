## Aktuelle Updates

Bleibe über die neuesten Verbesserungen der Enterprise-Voice-AI-Plattform von Talkturo informiert. Die Release Notes unten sind von neu nach alt sortiert.

<Update label="2026-09-04" description="v3.3.0" tags={["feature","improvement"]}>
  ## Neue Features

  - **Registerkarte „Zahlungsmethoden\"** — Verwalte gespeicherte Karten direkt über die Abrechnungsseite. Füge Karten über Stripe hinzu, sieh alle gespeicherten Karten, lege eine Standardkarte fest und entferne Karten, die nicht mehr benötigt werden. Die letzte Karte kann nicht entfernt werden, solange Auto-Reload oder ein aktives Desktop-App-Abonnement darauf angewiesen ist. Siehe [Abrechnung](/de/billing).

  ## Verbesserungen

  - **Automatische Kartenhinterlegung bei Desktop-App-Abonnements** — Wenn ein Abonnement über die Desktop-App erstellt wird, wird die verwendete Karte automatisch in deinem Workspace gespeichert. Siehe [Abrechnung](/de/billing).
  - **Stripe-Kartensynchronisation** — Wenn eine Karte direkt in Stripe entfernt wird, wird sie automatisch auch aus deiner Liste der gespeicherten Karten in Talkturo entfernt, sodass beide Seiten konsistent bleiben. Siehe [Abrechnung](/de/billing).
</Update>

<Update label="2026-09-03" description="v3.2.0" tags={["feature","improvement","bugfix"]}>
  ## Neue Features

  - **AI Employee — Self-Service für Voice-Agent-Erstellung** — Besucher können einen Entwurf eines Voice-Agents aus einer Website-URL oder einer Geschäftsbeschreibung generieren, ihn mit einem kostenlosen Browser-Demo-Anruf testen, Dokumente hochladen, einen Anwendungsfall wählen und über einen geteilten Zahlungslink kaufen. Nach dem Kauf werden der Entwurfs-Agent und seine Dokumente in den Workspace des Käufers übernommen, wobei die Dokumente in die Knowledge Base importiert werden. Siehe [KI-Sprachagenten](/de/assistants/overview).

  ## Verbesserungen

  - **Admin-verwaltete Anwendungsfälle** — Admins können AI-Employee-Anwendungsfälle mit lokalisierten Bezeichnungen, bearbeitbaren Kern-Prompts, Aktivierungsschaltern und benutzerdefinierter Reihenfolge erstellen und verwalten.
  - **Dedizierte AI-Employee-Zahlungslinks** — Admins können jetzt Zahlungslinks speziell für AI-Employee-Käufe erstellen, getrennt von Standard-Agent-Zahlungslinks. Siehe [Abrechnung](/de/billing).
  - **Umfangreichere Entwurfs-Prompts** — AI-Employee-Entwurfs-Agents generieren jetzt umfangreichere, websitebasierte Prompts mit anwendungsfallspezifischer Steuerung.
  - **Eingebetteter Dokumentinhalt in Demo-Anrufen** — Hochgeladene TXT- und Markdown-Dateien werden direkt in den Prompt des Entwurfs-Agents eingefügt, sodass Demo-Anrufe diese Geschäftsinformationen sofort nutzen können. PDFs und Word-Dokumente werden nach dem Kauf in die Knowledge Base verarbeitet. Siehe [Knowledge Base](/de/knowledge-base).
  - **Nicht zwischengespeicherte Zahlungslink-Seiten** — Zahlungslink-Seiten laden jetzt immer Live-Daten, sodass aktuelle Preise und Entwurfszustände ohne veraltete Cache-Inhalte angezeigt werden.

  ## Bugfixes

  - **Irrelevanter Setup-Gebühr-Hinweis bei gebührenfreien Links** — Die Zahlungs-Erfolgsseite zeigt keinen Setup-Gebühr-Hinweis mehr, wenn der Link keine Setup-Gebühr erhebt.
</Update>

<Update label="2026-09-02" description="v3.1.0" tags={["feature","improvement","bugfix"]}>
  ## Neue Features

  - **Anruferfolgs-Scoring** — Definiere für jeden Assistenten, was einen erfolgreichen Anruf ausmacht, mit KI-generierten Kriterien. Jeder Anruf wird nach deiner Definition mit 1–10 bewertet, und die Erfolgsraten werden im Dashboard angezeigt. EU-Scoring-Regeln sind optional und standardmäßig deaktiviert. Siehe [Intelligence](/de/intelligence).
  - **Close.com-CRM-Integration** — Verbinde dein Close.com-Konto mit einem API-Key, mit Tools für Assistenten und Workflows. Verbindungen werden mit deinem Kontonamen beschriftet, zur einfachen Identifikation. Siehe [Integrationen](/de/integrations).
  - **Telefonnummern für Finnland, Niederlande, Estland und das Vereinigte Königreich** — Kaufe lokale Mobilnummern in vier neuen Ländern mit vollständiger Compliance-Unterstützung, einschließlich Finnlands vereinfachter adressbasierter Verifizierung. Siehe [Telefonie](/de/telephony).
  - **Tagesbasierte Kampagnenplanung** — Wähle, an welchen Wochentagen deine Kampagne läuft, lege Tageszeitfenster fest, füge ein Enddatum hinzu und verfolge Anrufbeantworter-Statistiken — alles im Kampagnen-Editor. Siehe [Kampagnen-Konfiguration](/de/campaigns/configuration).
  - **Telefonie-Nutzung in Abrechnungsdiagrammen** — Das Abrechnungs-Nutzungsdiagramm enthält jetzt Telefonie- und Realtime-Credits neben den bestehenden Metriken. Siehe [Abrechnung](/de/billing).
  - **Kopierbare Gruppen-IDs** — Jede Kontaktgruppe zeigt jetzt eine kopierbare ID in der Gruppenliste, was es einfacher macht, Gruppen in API-Aufrufen zu referenzieren. Siehe [Kampagnen](/de/campaigns/overview).

  ## Verbesserungen

  - **Mehr anrufbare Länder** — Finnland, Niederlande, Estland, Polen und das Vereinigte Königreich sind jetzt in Testanruf-, Transfer- und Rückruf-Dropdowns verfügbar. Siehe [Telefonie](/de/telephony).
  - **Länderspezifische Compliance-Anforderungen** — Verifizierungsanforderungen entsprechen jetzt dem, was der Carrier des jeweiligen Landes tatsächlich verlangt: nur Name für die Niederlande, Adressnachweis-Dokument für das Vereinigte Königreich. Siehe [Telefonie](/de/telephony).

  ## Bugfixes

  - **Trenddiagramme vermissen heutige Anrufe** — Tages-Buckets wurden in der falschen Zeitzone erzeugt, wodurch heutige Anrufe erst am nächsten Tag in den Trenddiagrammen erschienen. Siehe [Intelligence](/de/intelligence).
  - **OAuth-Verbindungen durch Browser-Isolation blockiert** — Integrationsverbindungen werden jetzt zuverlässig abgeschlossen, auch wenn Browser-Cross-Origin-Isolation den Popup-Handshake blockiert. Siehe [Integrationen](/de/integrations).
  - **Verifizierung blockiert bei nicht erforderlichen Dokumenten** — Einreichungen wurden fälschlich abgelehnt, wenn die Verordnung eines Landes keine hochgeladenen Dokumente verlangt. Siehe [Telefonie](/de/telephony).
  - **Adressfehler beim deutschen Telefonnummernkauf** — Die Adresse des Bundles wird jetzt beibehalten und vor Ort neu validiert, statt beim Kauf ausgetauscht zu werden, was fehlgeschlagene Käufe verhindert. Siehe [Telefonie](/de/telephony).
</Update>

<Update label="2026-08-30" description="v3.0.0" tags={["feature","improvement","bugfix"]}>
  ## Neue Features

  - **Gespeicherte Karten von Agent-Zahlungslinks** — Beim Kauf über einen Agent-Zahlungslink kann die Karte jetzt als Standardzahlungsmethode für den Workspace gespeichert werden. Auto-Reload und zukünftige Abbuchungen verwenden diese Karte automatisch. Siehe [Abrechnung](/de/billing).
  - **Bis zu 20 gleichzeitige Kampagnen-Anrufe** — Kampagnen unterstützen jetzt bis zu 20 gleichzeitige Anrufe (zuvor 10). Passe das Nebenläufigkeitslimit im Kampagnen-Detailmodal an, während die Kampagne pausiert ist. Siehe [Kampagnen](/de/campaigns/overview).
  - **Cal.com-Integration auf Talkturo-Infrastruktur** — Die Cal.com-Scheduling-Integration läuft jetzt auf Talkturo-eigenen Servern. Bestehende Verbindungen benötigen ggf. eine einmalige Neuanmeldung. Siehe [Integrationen](/de/integrations).

  ## Verbesserungen

  - **Ursprungsabhängige Anrufpreise** — Anrufkosten berücksichtigen jetzt sowohl Ursprungs- als auch Zielland, mit Routentyp-Klassifizierung (Mobil, Festnetz, Sonderrufnummern, Sonstige). Abrechnungsschätzungen und Anrufprotokolle zeigen diese genauere Aufschlüsselung. Siehe [Abrechnung](/de/billing).
  - **Serverseitige Kontakt-Paginierung** — Kontaktlisten paginieren jetzt über die ersten 100 Datensätze hinaus, mit Seitensteuerung und Gesamtanzahl. Siehe [Kontakte](/de/crm/contacts).
  - **Kampagnen-Ergebnisse synchronisieren ins CRM** — Abgeschlossene Kampagnen-Anrufe aktualisieren automatisch den CRM-Kontaktstatus — Kontakte wechseln von „neu" zu „kontaktiert" und der letzte Kontaktzeitstempel wird aktualisiert. Siehe [Kontakte](/de/crm/contacts).
  - **Genauere Kostenschätzungen** — Abrechnungsschätzungen für Assistenten verwenden jetzt die eigene Telefonnummer des Assistenten als Preisursprung für präzisere Kostenschätzungen. Siehe [Abrechnung](/de/billing).
  - **Automatische SIP-Trunk-Aktualisierung** — Wenn Telefonnummern zwischen Assistenten verschoben werden, werden SIP-Trunks automatisch bereinigt und neu erstellt. Siehe [Telefonie](/de/telephony).

  ## Bugfixes

  - **Tabelle für Zahlungsmethoden in Produktion wiederhergestellt** — Behoben: Ein Produktionsproblem, bei dem das System für gespeicherte Karten fehlte, was dazu führte, dass Auto-Reload „Keine gespeicherte Karte hinterlegt" meldete. Siehe [Abrechnung](/de/billing).
  - **Phantom-Guthaben verhindert** — Unbekannte Stripe-Produkte erzeugen keine Guthaben mehr über eine Fallback-Konvertierung, was Phantom-Guthaben verhindert. Siehe [Abrechnung](/de/billing).
  - **Telefonie-Einstellungen speichern über Carrier hinweg** — Workspaces können jetzt Telefonie-Einstellungen speichern, ohne wegen fehlender Carrier-Verbindung abgelehnt zu werden. Siehe [Telefonie](/de/telephony).
  - **Anrufbeantworter-Änderungen aktivieren Speichern** — Änderungen an Anrufbeantworter-Erkennung, Aktion und Nachricht werden jetzt als ungespeicherte Änderungen erkannt, sodass die Schaltfläche „Speichern" korrekt aktiviert wird. Siehe [Telefonie](/de/telephony).
</Update>

Enthält eine Standardstimme und deutsche Fallback-Prompts. Siehe [Schnellstart](/de/quickstart).
  - **Do-Not-Call-Schutz während Live-Anrufen** — Verhindert das Hinzufügen einer Nummer zur Do-Not-Call-Liste während eines aktiven Anrufs, mit Anrufergebnis-Tracking pro Kontakt und Kampagnen-DNC-Zählern mit Badges. Siehe [Kampagnen](/de/campaigns/overview).

  - **Aktualisierter LLM-Modellkatalog** — Google Gemini 3.x-Modelle ersetzen die eingestellten 2.x-Versionen. DeepSeek V4 Pro und Kimi K2.6 hinzugefügt; Qwen entfernt. Gemini Live verwendet jetzt standardmäßig den stabilen `-latest`-Bezeichner. Siehe [Features](/de/features).
  - **Pause-Grund bei unzureichendem Guthaben** — Kampagnen zeigen jetzt einen klaren Grund an, wenn sie wegen unzureichendem Guthaben pausieren, und der Grund wird beim Fortsetzen automatisch gelöscht. Siehe [Kampagnen](/de/campaigns/overview).

  - **Schnell-Setup überspringt Unternehmens-Schritte** — Das Onboarding im Schnell-Setup-Modus erfordert keine Unternehmenskonfiguration mehr, sodass du schneller zu deinem ersten Assistenten kommst. Siehe [Schnellstart](/de/quickstart).

  ## Bugfixes

  - **Onboarding-Modus überlappt zwischen Durchläufen** — Behoben: Die Wahl zwischen Schnell-Setup und vollem Setup aus einem vorherigen Onboarding-Durchlauf wurde in den nächsten übernommen. Siehe [Schnellstart](/de/quickstart).

  - **Inline-Validierung im Kampagnenformular** — Fehlende Felder im Kampagnen-Erstellungsdialog werden jetzt direkt im Formular hervorgehoben, nicht nur als Toast-Benachrichtigung. Siehe [Kampagnen-Konfiguration](/de/campaigns/configuration).

  - **Behandlung leerer Filter** — Die Auswahl von keinen Kontakten oder Import-Chargen führt jetzt korrekt zu keinen Treffern statt zur Einschreibung der gesamten Gruppe.
  - **Webhook-Secret-Exposition** — Webhook-Secrets werden nicht mehr in Kampagnen-API-Antworten zurückgegeben.
  - **Kampagnen-Aktivierungsreihenfolge** — Kampagnen werden jetzt erst aktiviert, nachdem Kontakte erfolgreich eingeschrieben wurden, was leere Kampagnen-Starts verhindert.

## Migrationsleitfaden

Bei Upgrades mit Breaking Changes folge diesen Schritten, um deine Talkturo-Integration nahtlos zu aktualisieren.

<Steps>
  <Step title="SDK-Version aktualisieren" icon="package" title-type="p">
    Installiere das neueste SDK auf allen Plattformen.

    <CodeGroup show-lines="true">
      ```bash
      npm install @talkturo/sdk@2.1.0
      ```

      ```bash
      yarn add @talkturo/sdk@2.1.0
      ```

      ```bash
      pip install talkturo-sdk==2.1.0
      ```
    </CodeGroup>
  </Step>

  <Step title="API-Keys durch JWT ersetzen" icon="key" title-type="p">
    Generiere JWT-Tokens über den neuen Auth-Endpunkt.

    ```bash
    curl -X POST https://api.example.com/v2/auth/token \
      -H "Content-Type: application/json" \
      -d '{"client_id": "YOUR_CLIENT_ID", "client_secret": "YOUR_CLIENT_SECRET"}'
    ```

    Aktualisiere deine Anfragen:

    <ParamField header="Authorization" param-type="string" required="true" deprecated="false" show-location="true">
      Bearer `{YOUR_JWT_TOKEN}`
    </ParamField>
  </Step>

  <Step title="Aktualisierte Endpunkte testen" icon="play" title-type="p">
    Verifiziere Voice-Konfigurationen mit den neuen Pfaden.

    <Callout kind="tip" collapsed="false">
      Führe End-to-End-Tests auf Staging durch, bevor du in Produktion gehst.
    </Callout>
  </Step>
</Steps>
