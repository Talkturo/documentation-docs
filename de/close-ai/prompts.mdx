## Speichere Prompts, die du oft nutzt

Die Prompt-Bibliothek speichert persönliche Prompt-Presets für den Ask-Modus von Close AI. Nutze sie, um Anweisungen zu speichern, auf die du dich während Live-Anrufen verlässt, damit du sie schnell anwenden kannst, statt dieselbe Guidance jedes Mal neu zu schreiben.

Systemvorlagen erscheinen in der Bibliothek ebenfalls als Startpunkte. Du kannst eine Vorlage unverändert weiterverwenden oder sie zu einem Prompt bearbeiten, der zu deiner Verkaufsweise passt.

<Callout kind="info">

Nur ein Prompt kann gleichzeitig der Default sein. Wenn du einen neuen Default-Prompt setzt, entfernt Close AI die Default-Einstellung automatisch vom vorherigen.

</Callout>

## Was jede Prompt-Karte zeigt

Jeder Prompt erscheint als Karte in der Bibliothek, damit du deine Presets vor einem Anruf schnell scannen kannst.

| Feld | Was es zeigt |
| --- | --- |
| Title | Der Prompt-Name, gekürzt, wenn er zu lang ist |
| Default badge | Ein Stern-Badge, das den aktuellen Default-Prompt markiert |
| Template badge | Kennzeichnet einen systemseitig bereitgestellten Starter-Prompt |
| Preview | Die ersten beiden Zeilen des Prompt-Texts |
| Updated timestamp | Wann der Prompt zuletzt geändert wurde |

## Verwalte Prompts aus der Bibliothek

Nutze die Aktionen auf jeder Karte, um zu steuern, welchen Prompt du verwendest, und deine Bibliothek aktuell zu halten.

| Aktion | Was sie macht |
| --- | --- |
| Set default / Unset default | Schaltet den Stern um und markiert diesen Prompt als deinen Default |
| Edit | Öffnet den Prompt-Editor-Dialog |
| Delete | Entfernt den Prompt, nachdem du die Aktion bestätigt hast |

### Default-Prompts

Ein Default-Prompt gibt dir im Ask-Modus einen sofort nutzbaren Startpunkt. Das funktioniert gut, wenn du einen Satz Anweisungen hast, den du bei den meisten Anrufen verwendest.

Wenn du zu einem anderen Default wechselst, aktualisiert Close AI ihn sofort und entfernt den älteren für dich.

### Systemvorlagen

Systemseitig bereitgestellte Prompts enthalten ein Template-Badge. Diese Presets geben dir einen Startpunkt, wenn du einen gängigen Workflow speichern möchtest, ohne den gesamten Prompt von Grund auf zu schreiben.

Prompts, die du selbst erstellst, zeigen das Template-Badge nicht.

## Bearbeite oder erstelle einen Prompt

Nutze den Prompt-Editor, um ein neues Preset zu erstellen oder ein bestehendes zu aktualisieren.

| Feld | Typ | Erforderlich | Hinweise |
| --- | --- | --- | --- |
| Title | Text input | Ja | Benennt den Prompt |
| Prompt text | Monospace textarea | Ja | Mindesthöhe von 220 Pixeln und Rechtschreibprüfung ist aus |
| Use by default | Switch | Nein | Markiert den Prompt als deinen Default |

<Callout kind="tip">

Erstelle kurze, spezifische Prompts, die dem Ask-Modus genau sagen, was du möchtest. Klare Anweisungen lassen sich während eines Live-Anrufs schneller prüfen.

</Callout>

## Wann du die Prompt-Bibliothek nutzen solltest

Die Prompt-Bibliothek ist am nützlichsten, wenn du dieselbe Art von Anfrage über Anrufe hinweg wiederholst.

- Speichere Objection-Handling-Anweisungen, die du jeden Tag nutzt.
- Halte Discovery- oder Qualification-Prompts für die schnelle Wiederverwendung bereit.
- Starte mit einer Systemvorlage, wenn du einen schnelleren ersten Entwurf möchtest.
- Setze einen Prompt als Default, wenn der Ask-Modus mit deiner üblichen Guidance öffnen soll.
